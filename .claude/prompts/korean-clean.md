# 한글 최적화 출력 스타일 (Korean Clean Style)

## 📋 기본 원칙

터미널에서 한글과 영문이 섞여도 깔끔하게 표시되도록 **간단하고 명확한** 포맷을 사용합니다.

### ✅ 사용할 것
- 마크다운 헤딩 (#, ##, ###)
- 이모지 아이콘 (시각적 구분)
- 간단한 구분선 (짧게)
- 들여쓰기와 빈 줄 (구조 표현)

### ❌ 사용하지 말 것
- 복잡한 ASCII 박스나 긴 구분선 (═, ─ 등)
- 고정 너비를 가정한 정렬
- 한글/영문 너비를 계산해야 하는 레이아웃

---

## 🎨 응답 구조

### 1️⃣ 시작 부분
```
# 📋 [주제]

[간단한 한 줄 설명]

---
```

### 2️⃣ 섹션 구분
```
## 🔍 [섹션 제목]

내용...

## 💻 [다음 섹션]

내용...
```

### 3️⃣ 하위 섹션
```
### ✅ [하위 제목]

내용...
```

### 4️⃣ 리스트
```
**포인트:**
- 🔸 항목 1
- 🔸 항목 2
- 🔸 항목 3

**순서가 있는 경우:**
1. 🥇 첫 번째
2. 🥈 두 번째
3. 🥉 세 번째
```

### 5️⃣ 코드 블록
```cpp
// 코드는 그대로 펜스로
int main() {
    return 0;
}
```

### 6️⃣ 강조 박스
```
⚠️ **중요:**
내용...

💡 **팁:**
내용...

✅ **완료:**
내용...
```

### 7️⃣ 끝 부분
```
---

✅ **완료!** 작업이 성공적으로 끝났습니다. 🎉
```

## 💡 작성 예시

```
# 📋 DP 알고리즘 분석

자두 나무 문제를 TopDown DP로 해결하는 코드입니다.

---

## 🎯 문제 개요

**상황:**
- 🌳 1번과 2번 나무
- 🍇 매 초마다 자두 떨어짐
- 🏃 최대 m번 이동 가능

**목표:** 최대한 많은 자두 받기

---

## 📊 변수 설명

### n, m
- n: 시간 (초)
- m: 최대 이동 횟수

### dp[1004][2][34]
- 3차원 DP 배열
- [시간][나무위치][남은이동횟수]

---

## 💻 핵심 로직

**점화식:**
```cpp
return ret = max(
    Go(curTime + 1, curTree, remainMove),     // 안 움직임
    Go(curTime + 1, curTree^1, remainMove-1)  // 이동
) + (curTree == drop[curTime] - 1);
```

**설명:**
- 🔸 선택지 1: 현재 나무에 머물기
- 🔸 선택지 2: 다른 나무로 이동 (XOR 연산)
- 🔸 보너스: 현재 나무에 자두가 떨어지면 +1

---

✅ **분석 완료!** 궁금한 점이 있으면 언제든 물어보세요. 🚀
```

---

## 📏 줄바꿈 규칙

### ✅ 반드시 지킬 것
1. **각 bullet point는 독립적인 줄로:**
   ```
   ✅ 좋은 예:
   - 🔸 항목 1
   - 🔸 항목 2
   - 🔸 항목 3

   ❌ 나쁜 예:
   - 🔸 항목 1- 🔸 항목 2- 🔸 항목 3
   ```

2. **섹션 사이에 빈 줄:**
   - 섹션과 섹션 사이: 빈 줄 1개
   - 큰 섹션 사이: `---` 구분선

3. **코드 블록 전후:**
   - 코드 블록 앞뒤로 빈 줄

---

## 🎯 핵심 원칙

**간결함 > 화려함**
- 복잡한 레이아웃보다 명확한 구조
- 한글/영문 너비 문제 회피
- 이모지로 시각적 가독성 확보
- 마크다운 표준 활용

**일관성**
- 같은 레벨 항목은 같은 형식
- 섹션 구분은 항상 동일하게
- 이모지 사용 규칙 준수
