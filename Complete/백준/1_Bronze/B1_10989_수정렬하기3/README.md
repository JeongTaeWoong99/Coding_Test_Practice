## 🔗 문제 링크

[백준 10989번 - 수 정렬하기 3](https://www.acmicpc.net/problem/10989)

**난이도**: Bronze 1

---

## 🤔 접근법

**핵심 제약사항**:
- N: 최대 10,000,000 (1천만)
- 메모리 제한: **8MB**
- 수의 범위: 1 ~ 10,000

일반적인 정렬(O(N log N))로도 가능하지만, **메모리 제한 8MB** 때문에 N개의 수를 배열에 모두 저장할 수 없다.

하지만 **수의 범위가 10,000으로 제한**되어 있다는 점을 활용하면 **카운팅 정렬(Counting Sort)** 로 효율적으로 해결할 수 있다.

**카운팅 정렬 아이디어**:
- `int numArr[10001]` 배열로 각 숫자의 등장 횟수를 카운팅 (≈ 40KB)
- 1부터 10000까지 순회하며 카운트된 횟수만큼 출력

---

## 💡 정답 풀이 방법

### 📌 알고리즘: 카운팅 정렬 (Counting Sort)

**동작 방식**:

1. **카운팅 배열 선언**: `int numArr[10004]` (0으로 초기화)

2. **입력 받으며 카운팅**:
   ```cpp
   for (int i = 0; i < n; ++i)
   {
       cin >> temp;
       numArr[temp]++;  // 해당 숫자 카운트 증가
   }
   ```

3. **정렬된 결과 출력**:
   ```cpp
   for (int i = 0; i < 10004; ++i)  // 0부터 10003까지 순회
   {
       for (int k = 0; k < numArr[i]; ++k)  // 카운트만큼 출력
       {
           cout << i << '\n';
       }
   }
   ```

## ⏱️ 시간복잡도 분석

### 🔍 O(N²)가 아닌 이유

**2중 루프 = 무조건 O(N²)?** ❌

시간복잡도는 **두 루프의 관계**에 따라 결정된다:

| 관계 | 예시 | 복잡도 |
|------|------|--------|
| **곱하기** | 각 원소마다 N번씩 반복 | O(N²) |
| **더하기** | 외부 K번 + 내부 총합 N번 | O(K + N) |

### 📊 현재 코드 분석

```cpp
// 외부 루프: O(10004) - 상수 K
for (int i = 0; i < 10004; ++i)
{
    // 내부 루프: O(numArr[i]) - 매번 다름!
    // 내부 루프의 총 합은 N
    for (int k = 0; k < numArr[i]; ++k)
    {
        cout << i << '\n';
    }
}
```

**핵심**: 내부 루프는 매번 `numArr[i]`번씩 실행되는데, **모든 i에 대한 총합이 N**!

```
numArr[1] + numArr[2] + ... + numArr[10000] = N
```

**따라서**:
- 외부 루프 순회: O(10004) = O(K)
- 내부 루프 총합: O(N)
- **곱하기가 아닌 더하기 관계**: O(K + N)
- K는 상수이므로 **O(N)**

### 💡 비교: O(N²) vs O(N)

**O(N²) 예시** (진짜 곱하기):
```cpp
for (int i = 0; i < N; ++i)
{
    for (int j = 0; j < N; ++j)  // 항상 N번
    {
        // 총 N × N = N²번
    }
}
```

**O(N) 예시** (더하기 관계, 현재 코드):
```cpp
for (int i = 0; i < K; ++i)  // K번 (상수)
{
    for (int k = 0; k < count[i]; ++k)  // 총합이 N
    {
        // 총 K + N = O(N)번
    }
}
```

## 📈 최종 시간복잡도

```
입력 처리:     O(N)
정렬 출력:     O(10004 + N) = O(N)
────────────────────────────────
전체:         O(N)
```

**공간복잡도**: O(10004) ≈ O(1) (상수 크기 배열)

## 🎯 핵심 포인트

✅ **메모리 제한** → 카운팅 정렬 선택

✅ **수 범위 제한** → 작은 배열로 카운팅 가능

✅ **2중 루프 ≠ O(N²)** → 관계가 더하기면 O(N)

✅ **내부 루프 총합 = N** → 곱하기가 아닌 더하기
