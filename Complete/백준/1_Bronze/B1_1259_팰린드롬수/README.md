## 🔗 문제 링크

[백준 1259번 - 팰린드롬수](https://www.acmicpc.net/problem/1259)

**난이도**: Bronze 1

---

## 🤔 접근법

수를 문자열로 입력받아 뒤집은 문자열과 비교하는 문제.

팰린드롬수는 앞에서 읽으나 뒤에서 읽으나 같은 수를 의미한다.

여러 테스트 케이스를 처리하며, 입력이 0이면 종료한다.

---

## 💡 정답 풀이 방법

**알고리즘**: 문자열 처리

**핵심 아이디어**:
```
1. 숫자를 문자열로 입력받기
2. reverse()로 문자열 뒤집기
3. 원본과 뒤집은 문자열 비교
4. 같으면 "yes", 다르면 "no" 출력
5. 입력이 "0"이면 종료
```

**시간 복잡도**: O(N × L)
- N: 테스트 케이스 개수
- L: 각 숫자의 자릿수 (최대 5)

**공간 복잡도**: O(L) - 문자열 저장

---

## 📊 풀이 과정

1. **문자열 입력**: 숫자를 문자열로 입력받는다

2. **종료 조건 확인**: "0"이면 프로그램 종료

3. **문자열 뒤집기**: `reverse()` 함수로 복사본을 뒤집는다

4. **비교 및 출력**: 원본과 뒤집은 문자열을 비교하여 결과 출력
