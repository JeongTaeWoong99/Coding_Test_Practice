## 🔗 문제 링크
[백준 1546번 - 평균](https://www.acmicpc.net/problem/1546)

---

## 🤔 접근법
세준이가 점수를 조작하여 새로운 평균을 구하는 문제.

모든 점수를 `점수/M*100`으로 변환한 후, 변환된 점수들의 평균을 계산한다.

---

## 💡 정답 풀이 방법

1. **과목 개수 N 입력**: 시험 본 과목의 개수

2. **점수 입력 및 최댓값 찾기**: 각 점수를 입력받으면서 최댓값 M을 찾는다

3. **점수 변환 및 합산**: 각 점수를 `점수/M*100` 공식으로 변환하여 합산

4. **새로운 평균 출력**: 변환된 점수들의 합을 과목 개수로 나눈 값 출력

---

## 🔑 핵심 개념: double 타입 사용

**⚠️ 중요: float vs double**

이 문제는 소수점 계산이 포함되어 있어 **정밀도**가 중요합니다!

### 📌 1. float의 문제점
```cpp
float sum = 0;
// 예제: 10 20 30
// 결과: 66.666666... (유효숫자 6~7자리)
// → 오차 발생 가능!
```

**float 특징:**
- 유효숫자 약 6~7자리
- 메모리: 4바이트
- 정밀도가 부족하여 오차 누적 가능

---

### 📌 2. double 사용 (권장!)
```cpp
double sum = 0;
// 예제: 10 20 30
// 결과: 66.66666666666667 (유효숫자 15~16자리)
// → 정확한 계산!
```

**double 특징:**
- 유효숫자 약 15~16자리
- 메모리: 8바이트
- 충분한 정밀도로 정확한 계산 가능

---

### 📌 3. 수학적 최적화 가능성

**현재 방식:**
```cpp
for (int i = 0; i < n; ++i)
    sum += arr[i] / mx * 100;
result = sum / n;
```

**수학적 간소화:**
```cpp
// 평균 = (sum of (arr[i]/M*100)) / N
//      = (sum of arr[i]) * 100 / (M * N)

for (int i = 0; i < n; ++i)
    sum += arr[i];
result = sum * 100.0 / (mx * n);
```

**💡 하지만:**
- N ≤ 1000 → 성능 차이 미미
- **가독성이 더 중요!**
- 현재 코드도 충분히 명확하고 직관적

---

### 🎯 타입 변환 주의사항

```cpp
// ❌ 정수 나눗셈 주의
int a = 1, b = 2;
cout << a / b;  // 0 (정수 나눗셈)

// ✅ 실수 나눗셈
cout << (double)a / b;  // 0.5 (실수 나눗셈)
cout << a / (double)b;  // 0.5 (실수 나눗셈)

// ✅ 이 문제에서
cout << sum / (double)n;  // n을 double로 변환하여 실수 나눗셈
```

**핵심:**
- ★ 나눗셈 시 **한 쪽만 실수면** 결과도 실수
- 명시적 타입 변환으로 의도를 명확히!

---

**⏱️ 시간복잡도**: O(N) - 입력 순회 + 변환 순회
