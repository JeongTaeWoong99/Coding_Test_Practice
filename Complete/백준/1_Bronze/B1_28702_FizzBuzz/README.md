## 🔗 문제 링크

[백준 28702번 - FizzBuzz](https://www.acmicpc.net/problem/28702)

**난이도**: Bronze 1

---

## 🤔 접근법

FizzBuzz 문제에서 연속으로 출력된 3개의 문자열이 주어질 때, 다음에 올 문자열을 찾는 문제.

핵심은 **연속된 3개 중 최소 1개는 반드시 숫자**라는 점이다.

왜냐하면 FizzBuzz 패턴에서 문자열이 3개 연속으로 나올 수 없기 때문이다.

따라서 숫자를 찾아서 4번째 위치의 값을 계산한 후, FizzBuzz 규칙을 적용하면 된다.

---

## 💡 정답 풀이 방법

**알고리즘**: 문자열 처리 + 수학

**핵심 아이디어**:
```
1. 3개의 문자열을 입력받으면서 숫자를 찾는다
2. 숫자를 발견하면 `findNum = stoi(s) + 3 - i`로 4번째 값 계산
   - i=0일 때 발견 → 3칸 뒤 (+ 3)
   - i=1일 때 발견 → 2칸 뒤 (+ 2)
   - i=2일 때 발견 → 1칸 뒤 (+ 1)
3. findNum에 FizzBuzz 규칙 적용
   - 3과 5의 배수 → "FizzBuzz"
   - 3의 배수만 → "Fizz"
   - 5의 배수만 → "Buzz"
   - 둘 다 아님 → 숫자 출력
```

**시간 복잡도**: O(1)
- 입력은 항상 3개로 고정

**공간 복잡도**: O(1)
- 문자열 1개와 정수 1개만 사용

## 📊 예시 분석

### 예제 1: Fizz, Buzz, 11
```
i=0: "Fizz" → 문자열 (패스)
i=1: "Buzz" → 문자열 (패스)
i=2: "11" → 숫자 발견!
     findNum = 11 + (3 - 2) = 12
     12 % 3 == 0 && 12 % 5 != 0 → "Fizz"
```

### 예제 2: 980803, 980804, FizzBuzz
```
i=0: "980803" → 숫자 발견!
     findNum = 980803 + (3 - 0) = 980806
     980806 % 3 != 0 && 980806 % 5 != 0 → "980806"
```

## 🔍 왜 연속 3개 중 1개는 반드시 숫자인가?

FizzBuzz 패턴 (1~15):
```
1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz, 11, Fizz, 13, 14, FizzBuzz
```

**문자열이 연속으로 나오는 경우**:
- 최대 2개: (Fizz, Buzz), (Buzz, Fizz), (Fizz, 7), (14, FizzBuzz) 등
- 3개 연속: **수학적으로 불가능** (3과 5의 배수 규칙상)

따라서 연속된 3개 중 **반드시 1개 이상은 숫자**이다!
