## 🤔 접근법

문자열의 해시 값을 계산하는 문제.

주어진 수식을 그대로 구현하면 되지만, **L이 최대 50까지** 커질 수 있어 **오버플로우 주의**가 필요하다.

**핵심 아이디어**:
- 해시 함수: `H = Σ(a_i × r^i) % M` (r=31, M=1234567891)
- 단순 구현 시 31^50은 약 7.5 × 10^74로 오버플로우 발생
- **모듈러 연산을 매 단계마다 적용**하여 오버플로우 방지

---

## 💡 두 가지 풀이 방법

### 🥉 방법 1: STL pow 사용 (50점 - 부분 점수)

**코드**: `Answer(성공_50점).cpp.txt`

```cpp
ret += changeNum * pow(31, i);
```

**문제점**:
- `pow()` 함수는 실수 연산 → 정확도 이슈
- 31^50 계산 시 **오버플로우** 발생 (int 범위 초과)
- **모듈러 연산을 적용할 수 없음** (pow 결과에 직접 % 불가)
- L ≤ 5 (Small 케이스)만 통과

---

### 🥇 방법 2: 직접 거듭제곱 + 모듈러 연산 (100점 - 정답)

**코드**: `Answer(정답_100점).cpp.txt`

```cpp
long long power = 1;  // 31^i를 직접 관리

for (int i = 0; i < lenth; ++i)
{
    ret += (changeNum * power) % mode;  // 해시 값 누적
    ret %= mode;                         // 오버플로우 방지
    power = (power * 31) % mode;         // 다음 거듭제곱
}
```

**핵심 원리**:
1. **power 변수로 31^i 직접 계산** (31^0 = 1부터 시작)
2. **매 연산마다 % mode** 적용 → 값이 항상 mode 이하로 유지
3. **모듈러 연산의 분배 법칙**: `(a + b) % M = ((a % M) + (b % M)) % M`
4. **long long 사용**: 중간 계산값 오버플로우 방지

## 🔑 핵심 개념 정리

### 1️⃣ 왜 STL pow는 모듈러 연산이 안 되는가?

**❌ 잘못된 시도**:
```cpp
ret += (changeNum * pow(31, i)) % mode;
```

**문제점**:
- `pow(31, 50)` = 약 7.5 × 10^74
- 이미 계산 과정에서 오버플로우 발생
- % mode를 나중에 해봐야 이미 값이 깨진 상태

**✅ 올바른 방법**:
```cpp
// 미리 계산하지 말고, 곱하면서 매번 mod!
power = (power * 31) % mode;  // 31^i를 점진적으로 계산
```

### 2️⃣ "놀랍게도 소수이다!!"의 의미

**소수(Prime Number)**: 1과 자기 자신으로만 나누어떨어지는 수

**왜 놀랍나?**
1. **보기 좋은 패턴**: 1-2-3-4-5-6-7-8-9-1 (거의 연속 숫자)
2. **동시에 소수**: 이런 패턴이 소수인 경우는 매우 드묾
3. **크기**: 약 12억의 큰 수

**해시 함수에서 소수를 쓰는 이유**:
- ✅ **충돌 최소화**: 소수는 다른 수와 최대공약수가 1 (서로소)
- ✅ **주기 최대화**: 합성수는 패턴 반복, 소수는 긴 주기
- ✅ **수학적 안정성**: 모듈러 역원 계산 가능

**예시**:
```
M = 10 (합성수) 사용 시:
31^0 % 10 = 1
31^1 % 10 = 1  ← 모두 1로 끝남! (나쁜 분포)
31^2 % 10 = 1

M = 1234567891 (소수) 사용 시:
31^0 % M = 1
31^1 % M = 31
31^2 % M = 961   ← 고르게 분포!
31^3 % M = 29791
```

## 📋 정답 풀이 단계 (100점)

1. **입력 처리**: 문자열 길이 L, 문자 하나씩 입력

2. **초기화**:
   ```cpp
   long long ret = 0;     // 해시 값
   long long power = 1;   // 31^0 = 1
   const long long mode = 1234567891;
   ```

3. **반복문 (i = 0 ~ L-1)**:
   ```cpp
   for (int i = 0; i < lenth; ++i)
   {
       int changeNum = c - 'a' + 1;          // 알파벳 → 숫자 변환
       ret += (changeNum * power) % mode;    // a_i × 31^i 누적
       ret %= mode;                           // 오버플로우 방지
       power = (power * 31) % mode;           // 다음 거듭제곱 계산
   }
   ```

4. **출력**: 최종 해시 값 `ret`

## 🔍 예제 검증 (예제 1)

**입력**:
```
5
abcde
```

**계산 과정**:
```
i=0: c='a', changeNum=1, power=1
     ret = (0 + 1×1) % M = 1
     power = (1 × 31) % M = 31

i=1: c='b', changeNum=2, power=31
     ret = (1 + 2×31) % M = 63
     power = (31 × 31) % M = 961

i=2: c='c', changeNum=3, power=961
     ret = (63 + 3×961) % M = 2946
     power = (961 × 31) % M = 29791

i=3: c='d', changeNum=4, power=29791
     ret = (2946 + 4×29791) % M = 122110
     power = (29791 × 31) % M = 923521

i=4: c='e', changeNum=5, power=923521
     ret = (122110 + 5×923521) % M = 4739715
```

**출력**: `4739715` ✅
