## 🔗 문제 링크
[백준 2442번 - 별 찍기 - 5](https://www.acmicpc.net/problem/2442)

---

## 🤔 접근법
N개의 줄에 걸쳐 별을 피라미드 형태로 출력하는 문제.

각 줄마다 앞쪽에 공백을 출력하고, 이어서 별을 출력하면 된다.

---

## 💡 정답 풀이 방법

1. **입력 처리** : N 입력

2. **줄별 처리** : i번째 줄 (0부터 n-1까지)에서

3. **공백 출력** : 앞쪽 공백 `n-i-1`개 출력

4. **별 출력** : 별 `2*i+1`개 출력 (1, 3, 5, 7, ...)

---

**⏱️ 시간복잡도**: O(N²) - N개의 줄에서 각각 최대 2N개의 문자 출력
