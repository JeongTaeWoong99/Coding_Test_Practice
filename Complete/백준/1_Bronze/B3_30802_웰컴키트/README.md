## 🔗 문제 링크
[백준 30802번 - 웰컴 키트](https://www.acmicpc.net/problem/30802)

---

## 🤔 접근법
참가자들에게 티셔츠와 펜을 나눠주는 문제.

티셔츠는 T장 묶음으로만 주문 가능하고, 펜은 P자루 묶음 또는 낱개로 주문 가능하다.

티셔츠는 사이즈별로 올림 계산을 통해 최소 묶음 수를 구하고, 펜은 나눗셈의 몫과 나머지를 구한다.

---

## 💡 정답 풀이 방법

1. **입력 처리** : 참가자 수 N, 사이즈별 신청자 수 (6개), 묶음 크기 T와 P 입력

2. **티셔츠 주문 개수 계산**:
   - 각 사이즈별로 필요한 묶음 수 계산
   - `arr[i] / tSize` (몫) + `arr[i] % tSize > 0` (나머지 있으면 +1)
   - 6가지 사이즈 모두 합산

3. **펜 주문 개수 계산**:
   - 묶음 수 : `n / pSize` (몫)
   - 낱개 수 : `n % pSize` (나머지)

4. **결과 출력** : 티셔츠 묶음 수, 펜 묶음 수와 낱개 수 출력

---

**⏱️ 시간복잡도**: O(1) - 6가지 사이즈 순회 (상수 시간)
