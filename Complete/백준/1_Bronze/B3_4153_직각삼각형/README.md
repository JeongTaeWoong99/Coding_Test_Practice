## 🤔 접근법
주어진 세 변의 길이로 직각삼각형인지 판별하는 문제.

피타고라스 정리(a² + b² = c²)를 활용하여 직각삼각형 여부를 확인한다.

---

## 💡 정답 풀이 방법

1. **입력 처리** : 세 변의 길이 입력 (0 0 0이면 종료)

2. **정렬** : `sort()` 함수로 세 변을 오름차순 정렬 → 

   → ★ 가장 긴 변(빗변)이 `lines[2]`가 됨

3. **피타고라스 정리 확인**:
   - `a² + b² = c²` 인지 확인
   - `lines[0]² + lines[1]² = lines[2]²` 확인

4. **출력** : 직각삼각형이면 "right", 아니면 "wrong" 출력

---

**⏱️ 시간복잡도**: O(1) - 테스트케이스당 상수 시간 연산 (정렬은 3개 요소만 처리)
