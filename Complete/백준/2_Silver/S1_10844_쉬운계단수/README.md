## 🔗 문제 링크

[백준 10844번 - 쉬운 계단 수](https://www.acmicpc.net/problem/10844)

**난이도**: Silver 1

---

## 🤔 접근법

인접한 모든 자리의 차이가 1인 수를 "계단 수"라고 한다. 길이가 N인 계단 수가 총 몇 개 있는지 구하는 문제이다.

- 0으로 시작하는 수는 계단 수가 아니다.
- N은 1 ≤ N ≤ 100
- 결과를 1,000,000,000으로 나눈 나머지를 출력

**핵심은 동적 프로그래밍**으로 이전 길이의 계단 수를 활용하여 현재 길이의 계단 수를 계산하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : 동적 프로그래밍 (Dynamic Programming)

**핵심 아이디어**:
```
1. dp[i][j] = 길이가 i이고 마지막 자릿수가 j인 계단 수의 개수
2. 1자리 계단 수 초기화: dp[1][1~9] = 1 (0은 시작 불가)
3. 점화식:
   - j == 0: dp[i][0] = dp[i-1][1] (이전 자릿수는 1만 가능)
   - j == 9: dp[i][9] = dp[i-1][8] (이전 자릿수는 8만 가능)
   - 그 외: dp[i][j] = dp[i-1][j-1] + dp[i-1][j+1]
4. 각 계산마다 MOD 연산으로 오버플로 방지
5. 최종 답: dp[n][0] + dp[n][1] + ... + dp[n][9]
```

---

## 🔑 핵심 포인트

### 1️⃣ DP 테이블 정의

```cpp
int dp[101][10];  // dp[i][j] : 길이가 i이고 마지막 자릿수가 j인 계단 수의 개수
```

**✅ 핵심**: 2차원 DP 테이블 사용
- 첫 번째 차원: 계단 수의 길이 (1 ~ N)
- 두 번째 차원: 마지막 자릿수 (0 ~ 9)
- 값: 해당 조건을 만족하는 계단 수의 개수

### 2️⃣ 초기화 (Base Case)

```cpp
// 1자리 계단 수 초기화 (0은 시작할 수 없으므로 1~9만)
for(int i = 1; i <= 9; i++)
{
    dp[1][i] = 1;
}
```

**✅ 핵심**: 1자리 계단 수는 1~9까지 각 1개씩
- dp[1][0] = 0 (0으로 시작 불가)
- dp[1][1] ~ dp[1][9] = 1
- 총 9개

### 3️⃣ 점화식 (Recurrence Relation)

```cpp
for(int i = 2; i <= n; i++)
{
    for(int j = 0; j <= 9; j++)
    {
        if(j == 0)
        {
            // 끝자리가 0이면 이전 자릿수는 1만 가능
            dp[i][0] = dp[i - 1][1];
        }
        else if(j == 9)
        {
            // 끝자리가 9이면 이전 자릿수는 8만 가능
            dp[i][9] = dp[i - 1][8];
        }
        else
        {
            // 끝자리가 j일 경우, 이전 자릿수는 j-1 또는 j+1
            dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j + 1];
        }

        // 오버플로 방지
        dp[i][j] %= MOD;
    }
}
```

**✅ 핵심**: 계단 수의 조건 활용
- 인접한 자리의 차이가 1이어야 함
- 끝자리가 j라면, 이전 자릿수는 j-1 또는 j+1만 가능
- 0과 9는 경계 케이스 (한쪽 방향만 가능)

**예시**:
```
...34 → 끝자리 4는 이전 자릿수 3 또는 5에서 올 수 있음
...10 → 끝자리 0는 이전 자릿수 1에서만 올 수 있음
...89 → 끝자리 9는 이전 자릿수 8에서만 올 수 있음
```

### 4️⃣ 오버플로 방지

```cpp
#define MOD 1000000000

// 각 계산마다 MOD 연산
dp[i][j] %= MOD;

// 최종 결과 계산 시에도 MOD 연산
result = (result + dp[n][j]) % MOD;
```

**✅ 핵심**: 매번 MOD 연산 수행
- 계단 수는 기하급수적으로 증가
- int 범위 초과 방지
- 모듈러 연산의 분배 법칙: `(a + b) % c = ((a % c) + (b % c)) % c`

dp[2][4] = dp[1][3] + dp[1][5] = 1 + 1 = 2   → 34, 54
dp[2][5] = dp[1][4] + dp[1][6] = 1 + 1 = 2   → 45, 65
dp[2][6] = dp[1][5] + dp[1][7] = 1 + 1 = 2   → 56, 76
dp[2][7] = dp[1][6] + dp[1][8] = 1 + 1 = 2   → 67, 87
dp[2][8] = dp[1][7] + dp[1][9] = 1 + 1 = 2   → 78, 98
dp[2][9] = dp[1][8] = 1                       → 89

- 대칭 구조: dp[i][j] ≈ dp[i][9-j] (0과 9 제외 시 유사)

## ⏱️ 시간복잡도

**O(N × 10) = O(N)**

**분석**:
- 외부 루프: 길이 2부터 N까지 → O(N)
- 내부 루프: 끝자리 0부터 9까지 → O(10) = 상수
- 각 계산은 O(1)

**실제 계산**:
```
N ≤ 100
최악의 경우: 100 × 10 = 1,000 연산
O(1,000) << 10^8 (1초 기준)
```

**✅ 결론**: 충분히 시간 제한 내에 해결 가능

---

## 💾 공간복잡도

**O(N × 10) = O(N)**

**분석**:
- `dp[101][10]`: DP 테이블 → O(N × 10) = O(1,010)
- 기타 변수: `n`, `result`, `i`, `j` → O(1)

**총 공간**: O(N) ≈ **O(1,010)** (N=100일 때)

**💡 최적화 가능**:
- 현재 행만 필요하므로 `dp[2][10]`으로 줄일 수 있음 (공간 O(1))
- 하지만 N ≤ 100으로 작아서 최적화 불필요

## 🎯 핵심 교훈

### ✅ DP 문제 접근법

**1단계: 상태 정의**
```
dp[i][j] = 길이 i, 끝자리 j인 계단 수의 개수
```

**2단계: 초기값 설정**
```
dp[1][1~9] = 1 (1자리 계단 수)
```

**3단계: 점화식 도출**
```
dp[i][j] = dp[i-1][j-1] + dp[i-1][j+1]
(단, j=0 또는 j=9일 때 경계 처리)
```

**4단계: 계산 순서**
```
길이 1부터 N까지 순차적으로 계산
```

**5단계: 최종 답**
```
sum(dp[n][0~9])
```

### ✅ 경계 케이스 처리

**핵심 원칙**:
- 끝자리가 0일 때: 이전은 1만 가능
- 끝자리가 9일 때: 이전은 8만 가능
- 나머지: 양쪽에서 올 수 있음

**구현 팁**:
```cpp
if(j == 0) { /* 특수 처리 */ }
else if(j == 9) { /* 특수 처리 */ }
else { /* 일반 케이스 */ }
```

### ✅ 오버플로 방지

**문제 조건**:
- 결과를 10억으로 나눈 나머지 출력
- 계단 수는 매우 빠르게 증가

**해결책**:
```cpp
#define MOD 1000000000
dp[i][j] %= MOD;  // 매번 MOD 연산
```

**주의사항**:
- 덧셈 전후 모두 MOD 적용
- `int` 타입으로 충분 (MOD < 2^31)
