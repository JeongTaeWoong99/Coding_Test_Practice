## 🤔 접근법

배열에 정수 x(x ≠ 0)를 넣거나, 절댓값이 가장 작은 값을 출력하고 제거하는 연산을 지원하는 문제.

**핵심**: `pair<절댓값, 원본값>`을 최소 힙에 넣으면, pair의 비교 방식 덕분에 절댓값 오름차순 + 동일 절댓값 시 원본값 오름차순이 자동으로 해결됨!

---

## 💡 정답 풀이 방법

**알고리즘** : 우선순위 큐 (Priority Queue) - 최소 힙 + pair

**핵심 아이디어**:
```
1. priority_queue를 {절댓값, 원본값} pair의 최소 힙으로 선언
2. x가 0이 아니면 {abs(x), x}를 힙에 삽입
3. x가 0이면 힙의 top().second(원본값)를 출력 후 제거
4. 힙이 비어있을 때 0 출력
```

---

## 🔑 핵심 개념

### 1️⃣ pair를 이용한 복합 정렬

```cpp
// {절댓값, 원본값} pair - 최소 힙 선언
priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pQ;
```

**pair 비교 동작**:
- 1번째 요소(절댓값)가 작은 것이 먼저 나옴
- 1번째 요소가 같으면 2번째 요소(원본값)가 작은 것이 먼저 나옴

**예시**:
```
삽입 순서: 1, -1, 2, -2

힙에 저장되는 pair:
  {1, -1}, {1, 1}, {2, -2}, {2, 2}

top() 순서:
  {1, -1} → 출력: -1  (절댓값 1, 원본값 -1 < 1)
  {1,  1} → 출력:  1
  {2, -2} → 출력: -2  (절댓값 2, 원본값 -2 < 2)
  {2,  2} → 출력:  2
```

### 2️⃣ emplace vs push

```cpp
// push - pair 객체를 만든 후 복사
pQ.push(make_pair(abs(x), x));

// emplace - 직접 생성 (더 효율적)
pQ.emplace(abs(x), x);
```

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ 절댓값 힙에 원본값을 저장해야 함

```cpp
// ❌ 절댓값만 저장하면 원본값 복원 불가
pQ.emplace(abs(x));

// ✅ {절댓값, 원본값} pair로 저장
pQ.emplace(abs(x), x);
cout << pQ.top().second << '\n';  // second로 원본값 출력
```

### 2️⃣ 빈 힙 체크 필수

```cpp
// ❌ 빈 힙에서 top()/pop() 호출 시 런타임 에러!
cout << pQ.top().second << '\n';

// ✅ empty() 체크 후 접근
if (!pQ.empty()) { cout << pQ.top().second << '\n'; pQ.pop(); }
else cout << "0\n";
```

## ⏱️ 시간복잡도

**O(N log N)**

**분석**:
- N : 연산의 개수 (최대 100,000)
- 삽입 (`emplace`) : O(log N)
- 삭제 (`pop`) : O(log N)
- 최악의 경우 : N번 삽입/삭제 → O(N log N)

**시간 제한 체크**:
```
100,000 × log(100,000) ≈ 100,000 × 17 ≈ 170만 연산
170만 << 1억 (1초 기준) → 여유롭게 통과 ✅
```
