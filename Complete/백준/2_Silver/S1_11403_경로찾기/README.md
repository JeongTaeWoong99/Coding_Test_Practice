## 🔗 문제 링크

[백준 11403번 - 경로 찾기](https://www.acmicpc.net/problem/11403)

**난이도**: Silver 1

---

## 🤔 접근법

가중치 없는 방향 그래프에서 모든 정점 쌍 **(i, j)** 에 대해, i에서 j로 가는 **양수 길이의 경로가 존재하는지** 구하는 문제.

처음에는 각 정점에서 BFS를 돌리면 되겠다고 생각했지만, **사이클이 있는 경우 자기 자신에게 돌아오는 경로를 감지하지 못해 실패**했다.

올바른 풀이는 **플로이드-워셜 (Floyd-Warshall)** 알고리즘으로, 모든 정점 쌍 간 경로 존재 여부를 O(N³)에 구한다.

---

## ❌ BFS 실패 원인

### 왜 BFS로 안 되는가?

BFS는 시작점을 큐에 넣기 전에 `visited[start] = 1`로 마킹한다.

그런데 **사이클**이 있으면, BFS가 돌다가 다시 start로 돌아올 때 이미 방문 처리가 되어 있어서 `result[start][start]`를 1로 만들지 못한다.

**실패 예시** (예제 1 입력):
```
그래프 : 0 → 1 → 2 → 0  (사이클 존재)

BFS(start = 0) 실행 흐름:
  1. visited[0] = 1 로 초기화 (큐에 0 추가)
  2. 0 처리 → 1 방문 → result[0][1] = 1
  3. 1 처리 → 2 방문 → result[0][2] = 1
  4. 2 처리 → 0으로 가려 하지만 visited[0] == 1 → ❌ SKIP

결과 : result[0][0] = 0  (오답, 정답은 1)
```

**핵심**: BFS는 "시작점 자신으로 돌아오는 사이클" 감지 불가

## 💡 정답 풀이 방법

**알고리즘**: 플로이드-워셜 (Floyd-Warshall)

**핵심 아이디어**:
```
경유지 k를 거쳐서 i → j 로 갈 수 있는가?

dist[i][k] == 1  (i에서 k로 갈 수 있고)
dist[k][j] == 1  (k에서 j로 갈 수 있으면)
→ dist[i][j] = 1  (i에서 j로 갈 수 있다!)

k를 0부터 N-1까지 순서대로 시도하면,
점점 더 많은 중간 경로를 허용하면서 도달 가능 여부가 갱신됨
```

---

## 🔑 핵심 포인트

### 1️⃣ 플로이드-워셜 알고리즘이란?

모든 정점 쌍 (i, j) 에 대해 최단 경로(또는 경로 존재 여부)를 구하는 알고리즘.

**핵심 원리**: "경유지 k를 허용했을 때 i → j 경로가 생기는가?"

```
k = 0 허용 :  0을 중간에 경유할 수 있음
k = 1 허용 :  0, 1을 중간에 경유할 수 있음
k = 2 허용 :  0, 1, 2를 중간에 경유할 수 있음
...
k = N-1 허용 : 모든 정점을 경유할 수 있음
→ 최종적으로 모든 간접 경로까지 고려한 결과
```

### 2️⃣ 코드 동작 방식

```cpp
// 초기 상태: 입력으로 받은 인접 행렬 (직접 연결된 간선만 존재)
cin >> dist[i][j];

// 플로이드-워셜 3중 루프
for(int k = 0; k < n; k++)        // 경유 가능한 정점
    for(int i = 0; i < n; i++)     // 출발 정점
        for(int j = 0; j < n; j++) // 도착 정점
            if(dist[i][k] && dist[k][j])
                dist[i][j] = 1;
```

**⚠️ 중요**: k 루프가 반드시 가장 바깥에 있어야 함
- k가 안쪽에 있으면, 아직 갱신되지 않은 dist 값을 참조해서 오답 발생

### 3️⃣ 예제 1 동작 과정

**초기 상태 (인접 행렬 입력)**:
```
     j=0 j=1 j=2
i=0 [ 0   1   0 ]   0 → 1
i=1 [ 0   0   1 ]   1 → 2
i=2 [ 1   0   0 ]   2 → 0
```

**k=0 처리 (0을 경유)**:
```
dist[1][0] && dist[0][1] → dist[1][1] = 1   (1 → 0 → 1)
dist[2][0] && dist[0][1] → dist[2][1] = 1   (2 → 0 → 1)
```

**k=1 처리 (0,1을 경유)**:
```
dist[0][1] && dist[1][2] → dist[0][2] = 1   (0 → 1 → 2)
dist[2][1] && dist[1][2] → dist[2][2] = 1   (2 → 1 → 2)
```

**k=2 처리 (0,1,2를 경유)**:
```
dist[0][2] && dist[2][0] → dist[0][0] = 1   (0 → 2 → 0)
dist[1][2] && dist[2][0] → dist[1][0] = 1   (1 → 2 → 0)
dist[1][2] && dist[2][1] → dist[1][1] = 1   (1 → 2 → 1)
...
```

**최종 결과**:
```
1 1 1
1 1 1
1 1 1  ✅ 정답과 일치
```

**사이클 처리**: `dist[0][0] = 1`이 k=2 단계에서 자연스럽게 갱신됨
→ BFS에서 놓쳤던 사이클을 플로이드-워셜은 완벽하게 처리!

### 4️⃣ BFS vs 플로이드-워셜 비교

| 항목 | BFS (모든 정점 시작) | 플로이드-워셜 |
|------|-------------------|-------------|
| 시간복잡도 | O(N × (N + M)) | O(N³) |
| 자기 자신 도달 처리 | ❌ 사이클 감지 불가 | ✅ 자동 처리 |
| 구현 난이도 | 보통 | 간단 (3중 루프) |
| 이 문제 사용 가능? | ❌ 실패 | ✅ 정답 |

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ k 루프 순서

```cpp
❌ for(int i = 0; i < n; i++)
       for(int j = 0; j < n; j++)
           for(int k = 0; k < n; k++)  // k가 안쪽 → 오답!

✅ for(int k = 0; k < n; k++)          // k가 반드시 가장 바깥
       for(int i = 0; i < n; i++)
           for(int j = 0; j < n; j++)
```

**이유**: k가 안쪽에 있으면, k=2를 처리할 때 아직 k=1로 갱신된 경로를 반영하지 못한 상태에서 계산할 수 있음

### 2️⃣ BFS로 시도했을 때의 함정

```cpp
// BFS에서 이 코드가 문제
visited[start] = 1;   // start를 처음부터 방문 처리
q.emplace(start);

// → 나중에 다른 노드에서 start로 돌아올 때 이미 방문 처리됨
// → result[start][start] = 1 로 갱신되지 않음
```

## ⏱️ 시간복잡도

**O(N³)**

- 3중 루프 : N × N × N
- N ≤ 100 → 100³ = 1,000,000 연산
- 1초 제한에 여유롭게 통과 ✅

---

## 💾 공간복잡도

**O(N²)**

- `dist[101][101]`: 경로 존재 여부 행렬 → O(N²)

---

## 🎯 알고리즘 분류

- **그래프 이론**: 방향 그래프에서 경로 존재 여부
- **최단 경로**: 플로이드-워셜 (모든 쌍 경로 탐색)
- **플로이드-워셜**: 경유 정점을 하나씩 추가하며 도달 가능 여부 갱신
