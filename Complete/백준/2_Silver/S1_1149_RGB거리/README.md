## 🔗 문제 링크

[백준 1149번 - RGB거리](https://www.acmicpc.net/problem/1149)

**난이도**: Silver 1

---

## 🤔 접근법

N개의 집을 빨강(R), 초록(G), 파랑(B) 중 하나로 칠하되, **인접한 집은 같은 색을 쓸 수 없을 때** 최소 비용을 구하는 문제.

**핵심**: 각 집을 특정 색으로 칠했을 때의 누적 최솟값을 DP로 관리하면, O(N)에 해결 가능.

---

## 💡 정답 풀이 방법

**알고리즘** : 동적 프로그래밍 (Dynamic Programming) — **바텀업 (Bottom-Up)**

**방식**: 작은 문제(1번 집)부터 순서대로 계산하여 큰 문제(N번 집)로 쌓아 올리는 **바텀업(Bottom-Up)** 방식. 

재귀 없이 반복문으로 처리하므로 스택 오버플로 걱정 없음.

**핵심 아이디어**:
```
1. dp[i][j] = i번 집을 j색으로 칠할 때까지의 최소 비용
2. 1번 집 초기화: dp[1][j] = cost[1][j]
3. 점화식 (이전 집과 다른 색 2가지 중 최솟값 선택):
   - dp[i][0] = cost[i][0] + min(dp[i-1][1], dp[i-1][2])  // 빨강
   - dp[i][1] = cost[i][1] + min(dp[i-1][0], dp[i-1][2])  // 초록
   - dp[i][2] = cost[i][2] + min(dp[i-1][0], dp[i-1][1])  // 파랑
4. 최종 답: min(dp[n][0], dp[n][1], dp[n][2])
```

## 🔑 핵심 포인트

### 1️⃣ DP 테이블 정의

```cpp
int cost[1001][3]; // cost[i][j] : i번 집을 j색으로 칠하는 비용
int dp[1001][3];   // dp[i][j]   : i번 집을 j색으로 칠할 때까지의 최소 비용
```

**✅ 핵심**: 2차원 DP 테이블 사용
- 첫 번째 차원: 집 번호 (1 ~ N)
- 두 번째 차원: 색상 (0=빨강, 1=초록, 2=파랑)
- 값: 해당 집까지 조건을 만족하며 칠했을 때의 최소 비용

### 2️⃣ 초기화 (Base Case)

```cpp
// 1번 집은 이전 집 없으므로 비용 그대로
dp[1][0] = cost[1][0];
dp[1][1] = cost[1][1];
dp[1][2] = cost[1][2];
```

**✅ 핵심**: 1번 집은 제약 없이 각 색의 비용으로 초기화

### 3️⃣ 점화식 (Recurrence Relation)

```cpp
for (int i = 2; i <= n; ++i)
{
    // 이전 집과 다른 색 2가지 중 최솟값 + 현재 비용
    dp[i][0] = cost[i][0] + min(dp[i-1][1], dp[i-1][2]);
    dp[i][1] = cost[i][1] + min(dp[i-1][0], dp[i-1][2]);
    dp[i][2] = cost[i][2] + min(dp[i-1][0], dp[i-1][1]);
}
```

**✅ 핵심**: 인접 집 제약 활용
- i번 집을 0(빨강)으로 칠하면, i-1번 집은 1(초록) 또는 2(파랑)만 가능
- 나머지 색도 동일한 방식으로 처리

### 4️⃣ 최종 답

```cpp
cout << min({ dp[n][0], dp[n][1], dp[n][2] }) << "\n";
```

**✅ 핵심**: N번 집의 세 가지 색 중 최솟값이 정답
- C++17의 `min({ a, b, c })` initializer_list 활용

## 🔍 DP 테이블 예시 (예제 1)

```
입력:
3
26 40 83
49 60 57
13 89 99

cost 배열:
house 1: R=26, G=40, B=83
house 2: R=49, G=60, B=57
house 3: R=13, G=89, B=99

DP 계산:
dp[1]: R=26,  G=40,  B=83

dp[2][R] = 49 + min(40, 83)  = 49 + 40 = 89
dp[2][G] = 60 + min(26, 83)  = 60 + 26 = 86
dp[2][B] = 57 + min(26, 40)  = 57 + 26 = 83

dp[3][R] = 13 + min(86, 83)  = 13 + 83 = 96  ✅
dp[3][G] = 89 + min(89, 83)  = 89 + 83 = 172
dp[3][B] = 99 + min(89, 86)  = 99 + 86 = 185

결과: min(96, 172, 185) = 96
```

## ⏱️ 시간복잡도

**O(N)**

**상세 분석**:
```
1. 입력 처리: O(N × 3) = O(N)
2. DP 점화식: O(N × 3) = O(N)
   - 각 집마다 3가지 색에 대해 O(1) 연산
총합: O(N)
```

**시간 제한 체크**:
- N ≤ 1,000 (문제 조건), 시간 제한 0.5초
- **최악 3,000 연산** << **5,000만** → 여유롭게 통과 ✅

---

## 💾 공간복잡도

**O(N)**

**분석**:
- `cost[1001][3]`: 입력 비용 → O(N)
- `dp[1001][3]`: DP 테이블 → O(N)
- 총 공간: O(N) ≈ **O(6,000)**

**💡 최적화 가능**:
- 이전 행만 필요하므로 `dp[2][3]`으로 줄일 수 있음 (공간 O(1))
- 하지만 N ≤ 1,000으로 작아서 최적화 불필요
