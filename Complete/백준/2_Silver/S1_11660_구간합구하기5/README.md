## 🤔 접근법

N×N 표에서 (x1, y1) ~ (x2, y2) 구간의 합을 M번 구하는 문제.

단순 반복으로는 쿼리 1개당 O(N²), 전체 O(N² × M) = O(1024² × 100,000) → 시간 초과.

1D 누적합(행마다 누적)으로도 쿼리 1개당 O(N), 전체 O(N × M) = O(1024 × 100,000) ≈ 10^8 → 시간 초과.

**핵심:** 2D 누적합(Prefix Sum)으로 쿼리를 O(1)로 만들어야 한다.

---

## 💡 정답 풀이 방법

### 🎯 2D 누적합 (2D Prefix Sum)

1. **누적합 배열 구성** : `dp[i][j]` = (1,1) 부터 (i,j) 까지 모든 원소의 합

2. **포함-배제 원리** : 현재 칸의 값 + 위쪽 누적 + 왼쪽 누적 - 겹치는 부분 복원

3. **쿼리 처리** : 4개의 dp 값만으로 임의 구간의 합을 O(1) 계산

---

## 🔑 핵심 개념

### 📐 왜 2D 누적합이 필요한가?

| 방법 | 쿼리 1개 비용 | M개 전체 비용 | 결과 |
|------|------------|------------|------|
| 단순 합산 | O(N²) | O(N² × M) ≈ 10^11 | ❌ 시간 초과 |
| 1D 누적합 (행 순회) | O(N) | O(N × M) ≈ 10^8 | ❌ 시간 초과 |
| **2D 누적합** | **O(1)** | **O(N² + M) ≈ 10^6** | ✅ 통과 |

---

### 📐 누적합 배열 구성 원리 (포함-배제)

`dp[i][j]` 를 채울 때, 단순히 `dp[i][j] = dp[i-1][j] + dp[i][j-1] + 현재값` 을 하면 겹치는 영역이 두 번 더해진다.

```
dp[i-1][j]  →  (1,1)~(i-1,j) 영역
dp[i][j-1]  →  (1,1)~(i,j-1) 영역

두 영역의 합:
  ┌─────────┬─┐
  │         │ │
  │  겹침   │ │  ← dp[i-1][j-1] 이 두 번 포함됨!
  │         │ │
  ├─────────┘ │
  │           │
  └───────────┘
```

따라서 겹치는 `dp[i-1][j-1]` 을 한 번 빼줘야 정확한 값이 된다.

```cpp
dp[i][j] = 현재값 + dp[i-1][j] + dp[i][j-1] - dp[i-1][j-1]
```

---

### 📐 쿼리 처리 원리 (포함-배제)

구간 (x1,y1) ~ (x2,y2) 의 합을 구할 때:

```
전체 큰 사각형 dp[x2][y2]
  ┌───────────────────┐
  │  위쪽 제거        │
  │  dp[x1-1][y2]     │
  ├───────────────────┤
  │  왼쪽  │ 원하는  │
  │  제거  │ 구간    │
  │  dp    │         │
  │  [x2]  │         │
  │  [y1-1]│         │
  └────────┴─────────┘
```

위쪽을 빼고 왼쪽을 빼면, 왼쪽 위 코너 `dp[x1-1][y1-1]` 이 두 번 제거된다. 한 번 되돌려줘야 한다.

```
정답 = dp[x2][y2]
     - dp[x1-1][y2]    // 위쪽 제거
     - dp[x2][y1-1]    // 왼쪽 제거
     + dp[x1-1][y1-1]  // 두 번 제거된 왼쪽 위 복원
```

---

### 💻 핵심 코드

```cpp
// 누적합 구성 (포함-배제 원리)
dp[i][j] = temp + dp[i - 1][j] + dp[i][j - 1] - dp[i - 1][j - 1];

// 쿼리 처리 O(1)
int sumCnt = dp[x2][y2] - dp[x1 - 1][y2] - dp[x2][y1 - 1] + dp[x1 - 1][y1 - 1];
```

**✅ 핵심**: 1-indexed 배열 사용 → 경계 조건(i-1, j-1이 0일 때) 자동 처리

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ 1D 누적합으로 시도 시 시간 초과

```
O(N × M) = O(1024 × 100,000) = O(1.024 × 10^8) → 1초 제한 초과!
반드시 2D 누적합으로 쿼리를 O(1)로 만들어야 함
```

### 2️⃣ 행(x)과 열(y) 혼동

```cpp
// 문제 입력: x1 y1 x2 y2 (x = 행, y = 열)
cin >> x1 >> y1 >> x2 >> y2;  // ✅

// dp[행][열] 구조와 혼동하지 말 것
dp[x2][y2] - dp[x1-1][y2] - dp[x2][y1-1] + dp[x1-1][y1-1]  // ✅
```

### 3️⃣ 배열 크기 (1-indexed 사용)

```cpp
int dp[1025][1025];  // N ≤ 1024, 1-indexed이므로 1025 필요
```

## ⏱️ 시간복잡도

**O(N² + M)**

- 누적합 배열 구성: O(N²) = O(1,048,576) ≈ 10^6
- 쿼리 처리: O(1) × M = O(100,000)
- 총합: O(N² + M) ≈ **10^6** → 여유롭게 통과 ✅

---

## 💾 공간복잡도

**O(N²)**

- `dp[1025][1025]`: 2D 누적합 배열 → 약 4MB (256MB 제한 내 여유)
