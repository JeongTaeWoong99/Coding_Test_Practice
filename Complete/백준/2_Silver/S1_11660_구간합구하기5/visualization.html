2D 누적합(Prefix Sum) 시각화 — 예제 1번

① 입력 행렬 (N=4)

원본 arr[i][j]
arr[1][1]=1 arr[1][2]=2 arr[1][3]=3 arr[1][4]=4
arr[2][1]=2 arr[2][2]=3 arr[2][3]=4 arr[2][4]=5
arr[3][1]=3 arr[3][2]=4 arr[3][3]=5 arr[3][4]=6
arr[4][1]=4 arr[4][2]=5 arr[4][3]=6 arr[4][4]=7

② dp 배열 채우기 (포함-배제 원리)

완성된 dp
현재 계산 중
더하는 값 (+)
빼는 값 (−)
dp[i][j] (1-indexed, 0행/0열은 0)
▶ [다음] 버튼을 눌러 dp가 채워지는 과정을 확인하세요.

③ 쿼리 처리 — 각 쿼리 O(1)

원하는 구간
dp[x2][y2] (+)
빼는 dp (−)
다시 더하는 dp (+)
원본 행렬 (구간 하이라이트)
dp 배열 (사용하는 4개 셀)
