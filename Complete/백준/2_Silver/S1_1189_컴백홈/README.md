## 🔗 문제 링크

[백준 1189번 - 컴백홈](https://www.acmicpc.net/problem/1189)

**난이도**: Silver 1

---

## 🤔 접근법

R×C 맵에서 왼쪽 아래에서 시작하여 오른쪽 위(집)까지 **정확히 거리 K인 경로의 개수**를 구하는 문제.

- 한번 지나친 곳은 다시 방문하지 않음 (백트래킹)
- 'T'로 표시된 부분은 갈 수 없음

**핵심은 DFS + 백트래킹**으로 모든 가능한 경로를 탐색하면서, 거리가 정확히 K인 경우만 카운트하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : DFS (Depth-First Search) + 백트래킹 (Backtracking)

**핵심 아이디어**:
```
1. 시작점 (R-1, 0)에서 DFS 시작 (경로 길이 = 1)
2. 상하좌우 4방향으로 이동하며 재귀 탐색
3. 방문한 곳은 visited 배열로 표시하여 중복 방문 방지
4. 목적지 (0, C-1)에 도착했을 때 경로 길이가 K이면 카운트 증가
5. 재귀 반환 후 visited를 0으로 복원 (백트래킹)
```

---

## 🔑 핵심 포인트

### 1️⃣ 백트래킹 패턴

```cpp
for (int i = 0; i < 4; i++)
{
    int nY = y + dy[i];
    int nX = x + dx[i];

    // 유효성 검사
    if (nY < 0 || nY >= R || nX < 0 || nX >= C || visited[nY][nX]) continue;
    if (arr[nY][nX] == 'T') continue;

    visited[nY][nX] = 1;       // 방문 처리
    DFS(nY, nX, hap + 1);      // 재귀 호출
    visited[nY][nX] = 0;       // 백트래킹: 방문 해제 ⭐
}
```

**✅ 핵심**: 방문 → 재귀 → 방문 해제의 3단계 패턴
- 다른 경로에서 같은 위치를 다시 사용할 수 있도록 상태 복원
- 이것이 **백트래킹의 핵심**!

### 2️⃣ 경로 길이 추적

```cpp
void DFS(int y, int x, int hap)
{
    // hap: 현재까지의 경로 길이
    if (hap == K && y == 0 && x == C - 1)
    {
        ret++;  // 목적지 도착 + 거리 K → 카운트
        return;
    }

    // 재귀 시 경로 길이 +1
    DFS(nY, nX, hap + 1);
}
```

**✅ 핵심**: 매개변수 `hap`으로 경로 길이를 명시적으로 관리
- 목적지 도착 시 `hap == K` 조건 확인
- 재귀 호출마다 `hap + 1`로 경로 길이 증가

### 3️⃣ 시작점 처리

```cpp
// 시작점도 경로에 포함 (경로 길이 1로 시작)
visited[R - 1][0] = 1;
DFS(R - 1, 0, 1);
```

**✅ 핵심**: 시작점도 경로에 포함되므로 경로 길이 1로 시작
- visited 배열도 시작점을 1로 설정
- DFS 재귀에서 시작점을 다시 방문하지 않도록 방지

## ⏱️ 시간복잡도

**O(4^K)** (최악의 경우)

**분석**:
- 각 위치에서 최대 4방향 이동 가능
- 재귀 깊이 = K (경로 길이)
- 최악의 경우: 4^K개 경로 탐색

**실제로는**:
```
- R, C ≤ 5, K ≤ R×C ≤ 25
- visited 배열로 중복 방문 차단
- 'T' 장애물로 많은 경로가 조기 차단
- 실제 탐색 경로는 이론값보다 훨씬 적음

최악의 경우: K=25 → 4^25 (이론상)
하지만 실제로는 R×C=25 제약으로 불가능
실제 시간복잡도 ≈ O(4^K) with pruning
```

**✅ 결론**: R, C ≤ 5 제약 조건에서 충분히 시간 내 해결 가능

---

## 💾 공간복잡도

**O(R × C + K)**

**분석**:
- `arr[10][10]`: 맵 배열 → O(R × C)
- `visited[10][10]`: 방문 체크 배열 → O(R × C)
- 재귀 스택: 최대 깊이 K → O(K)

**총 공간**: O(R × C + K) ≈ **O(25 + 25) = O(50)** (최대값 기준)

---
**⏱️ 시간복잡도**: O(4^K) - 4방향 탐색, 재귀 깊이 K

**💾 공간복잡도**: O(R × C + K) - 맵 배열 + 재귀 스택
