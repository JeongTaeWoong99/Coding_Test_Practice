## 🔗 문제 링크

[백준 1389번 - 케빈 베이컨의 6단계 법칙](https://www.acmicpc.net/problem/1389)

**난이도**: Silver 1

---

## 🤔 접근법

N명의 유저와 M개의 친구 관계가 주어질 때, **케빈 베이컨 수가 가장 작은 사람**을 구하는 문제.

케빈 베이컨 수 = 나에서 **다른 모든 사람까지의 최단 거리의 합**.

**핵심은 BFS**로 각 사람을 시작점으로 전체 탐색을 반복하면서, 다른 모든 사람까지의 거리 합(케빈 베이컨 수)을 계산하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : BFS (Breadth-First Search) - 너비 우선 탐색

**핵심 아이디어**:
```
1. 모든 사람(1 ~ N)을 시작점으로 각각 BFS 수행
2. BFS 시 {노드 번호, 현재 거리} 쌍을 큐에 저장
3. 미방문 노드를 발견할 때마다 totalDist에 거리 누적
4. BFS 종료 후 totalDist = 현재 사람의 케빈 베이컨 수
5. 최솟값과 사람 번호를 갱신 (동일하면 번호 작은 쪽 유지)
```

---

## 🔑 핵심 포인트

### 1️⃣ BFS에서 거리 저장 방법

```cpp
queue<pair<int,int>> bfsQ; // {노드 번호, 현재 거리}

bfsQ.emplace(i, 0);        // 시작점 거리 0
visited[i] = true;

while (!bfsQ.empty())
{
    int curNum = bfsQ.front().first;
    int dist   = bfsQ.front().second;
    bfsQ.pop();

    for (int conected : v[curNum])
    {
        if (!visited[conected])
        {
            visited[conected] = true;
            bfsQ.emplace(conected, dist + 1); // 거리 1 증가
            totalDist += dist + 1;            // 케빈 베이컨 수 누적
        }
    }
}
```

**✅ 핵심**: pair를 사용해 노드와 거리를 함께 큐에 저장
- 새 노드를 발견할 때 `dist + 1`로 거리 계산
- 동시에 `totalDist`에 누적 → BFS 종료 후 케빈 베이컨 수 완성

### 2️⃣ 케빈 베이컨 수 = 모든 거리의 합

```
예시: 1번 사람의 케빈 베이컨 수
  1 → 3 : 1단계
  1 → 4 : 1단계
  1 → 2 : 2단계 (1→3→2)
  1 → 5 : 2단계 (1→4→5)
           ──────
  합계   : 6
```

**✅ 핵심**: 최대 거리(max)가 아닌 **모든 거리의 합(sum)**
- `totalDist +=`으로 누적해야 올바른 결과

### 3️⃣ 최솟값 갱신 (동일 번호 처리)

```cpp
if (totalDist < minCnt) // 같으면 갱신 안 함 → 번호 작은 쪽 유지
{
    minCnt    = totalDist;
    selectedN = i;
}
```

**✅ 핵심**: `<` 조건으로 동일한 케빈 베이컨 수일 때 먼저 저장된 작은 번호 유지

## ⏱️ 시간복잡도

**O(N × (N + M))**

**분석**:
- N명 각각을 시작점으로 BFS 수행: N번 반복
- BFS 한 번의 비용: O(N + M) (노드 + 간선 탐색)
- 전체: N × (N + M)

**실제 계산**:
```
N ≤ 100, M ≤ 5,000
최악의 경우: 100 × (100 + 5,000) = 510,000 연산
O(510,000) << 10^8 (2초 기준)
```

**✅ 결론**: 충분히 시간 제한(2초) 내에 해결 가능

---

## 💾 공간복잡도

**O(N + M)**

**분석**:
- `v[104]`: 인접 리스트 (간선 저장) → O(M)
- `visited[104]`: 방문 체크 배열 → O(N)
- `queue`: 최악의 경우 N개 노드 저장 → O(N)

**총 공간**: O(N + M) ≈ **O(5,100)** (N=100, M=5000일 때)
