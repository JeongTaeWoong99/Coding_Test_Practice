## 🔗 문제 링크

[백준 14888번 - 연산자 끼워넣기](https://www.acmicpc.net/problem/14888)

**난이도**: Silver 1

---

## 🤔 접근법

N개의 수와 N-1개의 연산자(+, -, ×, ÷)가 주어졌을 때, 수의 순서를 바꾸지 않고 연산자를 끼워넣어 만들 수 있는 **식의 최댓값과 최솟값**을 구하는 문제.

- 연산자 우선순위 무시, 앞에서부터 순차 계산
- 나눗셈은 정수 나눗셈 (몫만 취함)
- 음수 나눗셈: C++14 기준 (양수로 바꾼 뒤 몫 취하고 음수화)

**핵심은 백트래킹**으로 모든 가능한 연산자 조합을 탐색하면서, 각 결과의 최댓값과 최솟값을 갱신하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : 백트래킹 (Backtracking) + 브루트포스

**핵심 아이디어**:
```
1. 첫 번째 수부터 시작하여 재귀적으로 연산 수행
2. 각 연산자(+, -, ×, ÷)를 하나씩 사용하면서 다음 수와 계산
3. 연산자를 사용할 때마다 개수를 1 감소시켜 매개변수로 전달
4. 모든 수를 사용했을 때 (index == n-1) 최댓값/최솟값 갱신
5. 매개변수로 전달하므로 별도의 복구 과정 불필요 (자동 복구)
```

---

## 🔑 핵심 포인트

### 1️⃣ 백트래킹 패턴 (매개변수 전달 방식)

```cpp
void Back(int index, int cur, int plus, int minus, int mul, int div)
{
    // 기저 조건: 모든 수를 사용한 경우
    if(index == n - 1)
    {
        maxRet = max(cur, maxRet);   // 최댓값 갱신
        minRet = min(minRet, cur);   // 최솟값 갱신
        return;
    }

    // 각 연산자를 사용 가능한 경우 재귀 호출
    if(plus)  Back(index + 1, cur + arr[index + 1], plus - 1, minus, mul, div);
    if(minus) Back(index + 1, cur - arr[index + 1], plus, minus - 1, mul, div);
    if(mul)   Back(index + 1, cur * arr[index + 1], plus, minus, mul - 1, div);
    if(div)   Back(index + 1, cur / arr[index + 1], plus, minus, mul, div - 1);
}
```

**✅ 핵심**: 연산자 개수를 **매개변수로 전달** (Call by Value)
- `plus - 1`을 다음 재귀에 전달 → 현재 함수의 `plus`는 불변
- 재귀 반환 후에도 `plus`는 원래 값 유지 → **복구 불필요**
- 각 재귀 호출마다 독립적인 지역 변수 사용
- 이것이 **매개변수 전달 방식 백트래킹**!

**🔍 전역변수 방식과의 차이**:
```cpp
// ❌ 전역변수 방식 (복구 필요)
int plus, minus, mul, div;

void Back(int index, int cur)
{
    if(plus > 0)
    {
        plus--;  // 전역 변수 직접 변경
        Back(index + 1, cur + arr[index + 1]);
        plus++;  // ✅ 복구 필수!
    }
}

// ✅ 매개변수 전달 방식 (복구 불필요)
void Back(int index, int cur, int plus, ...)
{
    if(plus)  Back(index + 1, cur + arr[index + 1], plus - 1, ...);
    //                                              ^^^^^^^^
    //        새로운 값을 전달만, 현재 plus는 그대로!
    //        재귀 반환 후에도 plus는 원래 값 유지!
}
```


## 📊 재귀 동작 상세 분석

### 🎯 예제 입력
```
3
3 4 5
1 0 1 0
```

**해석**:
- 수: 3, 4, 5
- 연산자: + 1개, × 1개

### 🔍 가능한 모든 조합 탐색

```
Back(0, 3, 1, 0, 1, 0)  // index=0, cur=3
  │
  ├─ if(plus) → Back(1, 7, 0, 0, 1, 0)   // 3 + 4 = 7
  │               │
  │               └─ if(mul) → Back(2, 35, 0, 0, 0, 0)  // 7 × 5 = 35
  │                              └─ index == 2 → maxRet=35, minRet=35
  │
  └─ if(mul) → Back(1, 12, 1, 0, 0, 0)   // 3 × 4 = 12
                  │
                  └─ if(plus) → Back(2, 17, 0, 0, 0, 0)  // 12 + 5 = 17
                                 └─ index == 2 → maxRet=35, minRet=17
```

**최종 결과**:
- 3 + 4 × 5 = 35 (최댓값)
- 3 × 4 + 5 = 17 (최솟값)

## 🔑 핵심 이해 포인트

### ✅ 매개변수 전달 vs 참조 전달

| 방식 | 문법 | 원본 변경 | 복구 필요 | 예시 |
|-----|------|----------|----------|------|
| **값 복사** | `int x` | ❌ 불가능 | ❌ 불필요 | `Back(..., plus - 1, ...)` |
| **참조 전달** | `int& x` | ✅ 가능 | ✅ 필수 | `plus--; Back(...); plus++;` |

**현재 코드**:
```cpp
void Back(int index, int cur, int plus, ...)  // & 없음 = 값 복사
{
    if(plus)  Back(index + 1, cur + arr[index + 1], plus - 1, ...);
    //                                              ^^^^^^^^
    //        plus - 1의 "결과값"만 전달, 원본 plus는 불변!
}
```

### ✅ 왜 복구가 필요 없는가?

**값 복사 방식**:
```
함수 호출 시 매개변수의 "값"만 복사하여 새로운 지역 변수 생성
→ 각 재귀 호출마다 독립적인 변수 사용
→ 재귀 반환 후에도 원래 값 유지
→ 복구 불필요!
```

**참조 전달 방식** (비교용):
```
함수 호출 시 원본 변수의 "주소"를 전달
→ 모든 재귀 호출이 같은 변수 공유
→ 변경 시 원본이 직접 수정됨
→ 복구 필수!
```

## ⏱️ 시간복잡도

**O(4^N)** (최악의 경우)

**분석**:
- 각 위치에서 최대 4가지 연산자 선택 가능
- N-1번 연산 수행 → 재귀 깊이 N-1
- 최악의 경우: 4^(N-1) 개 경로 탐색

**실제로는**:
```
- N ≤ 11 (문제 조건)
- 각 연산자의 개수 제한으로 많은 경로 차단
- 실제 탐색 경로 << 4^N

최악: N=11 → 4^10 = 1,048,576 (약 100만)
→ 1초 제한에서 충분히 통과 가능 ✅
```

**📌 시간복잡도 예측 기준** (C++ 기준):
```
1초 제한 기준:
  - 10^6 (100만) 연산 : 안전 ✅
  - 10^7 (1천만) 연산 : 보통 통과 ✅
  - 10^8 (1억) 연산 : 통과 가능 ⚠️
  - 10^9 (10억) 연산 : 시간 초과 ❌

4^10 ≈ 10^6 → 완전 탐색 가능!
```

## 💾 공간복잡도

**O(N)**

**분석**:
- `arr[12]`: 수 배열 → O(N)
- 재귀 스택: 최대 깊이 N-1 → O(N)
- 전역 변수: `maxRet`, `minRet` → O(1)

**총 공간**: O(N) + O(N) + O(1) ≈ **O(N)**
