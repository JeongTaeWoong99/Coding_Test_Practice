## 🔗 문제 링크

[백준 14940번 - 쉬운 최단거리](https://www.acmicpc.net/problem/14940)

**난이도**: Silver 1

---

## 🤔 접근법

N×M 크기의 지도에서 **목표지점(2)까지의 최단 거리**를 모든 지점에 대해 구하는 문제.

- 0은 갈 수 없는 땅, 1은 갈 수 있는 땅, 2는 목표지점.
- 오직 가로와 세로로만 이동 가능.
- 원래 갈 수 없는 땅(0)은 0 출력, 갈 수 있지만 도달 불가능한 땅은 -1 출력.

**핵심은 목표지점(2)에서 역방향 BFS**로, 모든 칸까지의 최단거리를 한 번에 구하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : BFS (Breadth-First Search) - 너비 우선 탐색

**핵심 아이디어**:
```
1. 입력을 받으면서 dist 배열을 -1로 초기화, 목표지점(2) 좌표 저장
2. 목표지점에서 BFS 시작 (dist[sY][sX] = 0)
3. 4방향 탐색하며 벽(0)이 아니고 미방문(-1)인 칸의 거리 갱신
4. 출력 시 원래 벽(0)인 칸은 0, 나머지는 dist 값 그대로 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 역방향 BFS (목표지점에서 출발)

```cpp
queue<pair<int, int>> q;
dist[sY][sX] = 0;         // 목표지점 거리 = 0
q.emplace(sY, sX);
```

**✅ 핵심**: "모든 지점 → 목표"가 아닌 "목표 → 모든 지점"으로 탐색
- 각 지점에서 BFS를 돌리면 O(N²M²)으로 시간 초과
- 목표에서 한 번만 BFS를 돌리면 O(NM)으로 해결
- BFS는 가중치 없는 그래프에서 최단거리를 보장

### 2️⃣ dist 배열의 이중 용도

```cpp
dist[i][j] = -1;  // 초기값: 미방문 표시 + 도달 불가 표시

// BFS에서 방문 체크
if (dist[ny][nx] != -1) continue;  // 이미 방문

// 거리 갱신
dist[ny][nx] = dist[cy][cx] + 1;
```

**✅ 핵심**: dist 배열 하나로 3가지 역할 수행
- **-1**: 미방문 (BFS 후에도 -1이면 도달 불가)
- **0**: 목표지점 자체
- **양수**: 목표지점까지의 최단거리

### 3️⃣ 출력 처리 (벽 vs 도달 불가 구분)

```cpp
if (arr[i][j] == 0) cout << 0;    // 원래 갈 수 없는 땅 → 0
else                cout << dist[i][j]; // 갈 수 있는 땅 → 거리 or -1
```

**✅ 핵심**: 원래 벽(0)과 도달 불가(-1)를 구분
- `arr[i][j] == 0`: 원래부터 벽인 칸 → 무조건 0 출력
- `arr[i][j] != 0 && dist[i][j] == -1`: 갈 수 있지만 도달 불가 → -1 출력
- `arr[i][j] != 0 && dist[i][j] >= 0`: 도달 가능 → 거리 출력

---

## ⏱️ 시간복잡도

**O(N × M)**

**분석**:
- N × M 크기의 맵에서 각 칸을 최대 1번씩만 방문
- BFS는 dist 배열로 중복 방문 방지
- 각 칸마다 4방향 탐색 → O(4) = 상수

**실제 계산**:
```
- N, M ≤ 1000
- 최악의 경우: 1000 × 1000 = 1,000,000칸
- 각 칸마다 4방향 탐색 → 1,000,000 × 4 = 4,000,000 연산
- O(4 × 10^6) << 10^8 (1초 기준)
```

**✅ 결론**: 충분히 시간 제한(1초) 내에 해결 가능

---

## 💾 공간복잡도

**O(N × M)**

**분석**:
- `arr[1004][1004]`: 맵 배열 → O(N × M)
- `dist[1004][1004]`: 거리 배열 → O(N × M)
- `queue<pair<int, int>>`: 최악의 경우 모든 칸 저장 → O(N × M)

**총 공간**: O(N × M) ≈ **O(10^6)** (N=M=1000일 때)
