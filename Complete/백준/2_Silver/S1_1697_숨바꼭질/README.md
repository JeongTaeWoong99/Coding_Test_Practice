## 🔗 문제 링크

[백준 1697번 - 숨바꼭질](https://www.acmicpc.net/problem/1697)

**난이도**: Silver 1

---

## 🤔 접근법

수빈이(N)가 동생(K)을 찾는 **최소 시간**을 구하는 문제.

- 수빈이 위치 X에서 1초 후 X-1, X+1, 2*X 로 이동 가능.
- N, K 범위 : 0 ~ 100,000
- 가중치가 동일한(1초) 그래프에서 최단거리 → BFS가 최적.

**핵심은 1차원 좌표를 그래프로 보고, BFS로 최단 이동 횟수를 구하는 것!**

---

## 💡 정답 풀이 방법

**알고리즘** : BFS (Breadth-First Search) - 너비 우선 탐색

**핵심 아이디어**:
```
1. 시작 위치 N에서 BFS 시작 (visited[N] = 1)
2. 3가지 이동(X-1, X+1, X*2) 중 미방문 위치를 큐에 추가
3. K에 도달하면 즉시 visited[K] - 1 출력 (1부터 시작했으므로)
```

---

## 🔑 핵심 포인트

### 1️⃣ visited 배열의 이중 용도 (방문 체크 + 거리 저장)

```cpp
visited[n] = 1;     // 시작점: 1로 초기화 (0은 미방문 판별용)

visited[next] = visited[now] + 1;  // 거리 갱신

cout << visited[k] - 1;           // 출력 시 -1 (1부터 시작했으므로)
```

**✅ 핵심**: visited 배열 하나로 2가지 역할 수행
- **0**: 미방문 (방문 체크용)
- **양수**: 시작점으로부터의 거리 + 1

### 2️⃣ 3가지 이동을 범위 기반 for문으로 처리

```cpp
for (int next : {now - 1, now + 1, now * 2})
```

**✅ 핵심**: 초기화 리스트로 3가지 이동을 깔끔하게 처리
- 2차원 BFS의 `dy[], dx[]` 대신 1차원에 맞는 패턴
- 숨바꼭질 시리즈(12851, 13913)와 동일한 패턴

### 3️⃣ 조기 종료 (Early Return)

```cpp
if (next == k)
{
    cout << visited[k] - 1;
    return 0;
}
```

**✅ 핵심**: K에 처음 도달한 순간이 최단거리
- BFS는 레벨 순서로 탐색하므로, 처음 도달 = 최단거리 보장
- 나머지 탐색을 생략하여 시간 절약

---

## ⏱️ 시간복잡도

**O(MAX)**

**분석**:
- 0 ~ 200,000 범위의 각 위치를 최대 1번씩만 방문
- 각 위치마다 3가지 이동 탐색 → O(3) = 상수

**실제 계산**:
```
- MAX = 200,000
- 최악의 경우: 200,000 × 3 = 600,000 연산
- O(6 × 10^5) << 10^8 (2초 기준)
```

**✅ 결론**: 충분히 시간 제한(2초) 내에 해결 가능

---

## 💾 공간복잡도

**O(MAX)**

**분석**:
- `visited[200004]`: 방문 + 거리 배열 → O(MAX)
- `queue<int>`: 최악의 경우 모든 위치 저장 → O(MAX)

**총 공간**: O(MAX) ≈ **O(2 × 10^5)** (MAX=200,000일 때)
