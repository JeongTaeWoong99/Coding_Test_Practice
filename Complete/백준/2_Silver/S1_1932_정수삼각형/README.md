## 🔗 문제 링크

[백준 1932번 - 정수 삼각형](https://www.acmicpc.net/problem/1932)

**난이도**: Silver 1

---

## 🤔 접근법

크기 n인 정수 삼각형에서 맨 위에서 시작해 아래로 내려가며 선택한 수의 합이 최대가 되는 경로를 구하는 문제.

- 아래로 이동 시 현재 위치의 대각선 왼쪽 또는 오른쪽만 선택 가능
- n ≤ 500, 각 수는 0 이상 9999 이하

**핵심**: 각 위치까지의 최대 합을 DP로 저장하여, 마지막 줄에서 최댓값을 출력!

---

## 💡 정답 풀이 방법

**알고리즘** : 동적 프로그래밍 (Dynamic Programming)

**핵심 아이디어**:
```
1. dp[y][x] = 위치 (y, x)까지 내려왔을 때의 최대 합
2. 초기값: dp[0][0] = arr[0][0]
3. 점화식:
   - x == 0 (왼쪽 끝) : dp[y][0] = dp[y-1][0] + arr[y][0]
   - x == y (오른쪽 끝) : dp[y][y] = dp[y-1][y-1] + arr[y][y]
   - 그 외 (중간) : dp[y][x] = max(dp[y-1][x-1], dp[y-1][x]) + arr[y][x]
4. 최종 답: dp[n-1][0] ~ dp[n-1][n-1] 중 최댓값
```

---

## 🔑 핵심 포인트

### 1️⃣ DP 상태 정의

```cpp
int dp[504][504];  // dp[y][x] : (y, x)까지의 최대 합
```

**✅ 핵심**: 위치 (y, x)에 도달할 수 있는 경로는 두 가지뿐
- 바로 위 `(y-1, x)` 에서 내려오거나
- 위 왼쪽 대각선 `(y-1, x-1)` 에서 내려오거나

### 2️⃣ 경계 케이스 처리

```cpp
// 왼쪽 끝 : 위에서 직선으로만 올 수 있음
if (x == 0)
{
    dp[y][x] = dp[y-1][0] + arr[y][x];
}
// 오른쪽 끝 : 위 왼쪽 대각선에서만 올 수 있음
else if (x == y)
{
    dp[y][x] = dp[y-1][x-1] + arr[y][x];
}
// 중간 : 두 경로 중 최대
else
{
    dp[y][x] = max(dp[y-1][x-1], dp[y-1][x]) + arr[y][x];
}
```

**✅ 핵심**: 삼각형 양쪽 끝은 단방향, 중간은 두 방향에서 올 수 있음

### 3️⃣ 인덱스 단순화

```cpp
// sizeX 별도 추적 불필요 → 행 y의 유효 범위는 항상 0 ~ y
for (int x = 0; x <= y; ++x)
```

**✅ 핵심**: 삼각형의 y번째 행에는 y+1개의 원소 (0 ~ y 인덱스)

### 4️⃣ DP 예시 (예제 입력)

```
입력 삼각형:
    7
   3 8
  8 1 0
 2 7 4 4
4 5 2 6 5

DP 테이블:
    7
   10  15
  18  11  15
  20  25  19  19
  24  30  27  25  24

마지막 줄 최댓값: 30 ✅
경로: 7 → 3 → 8 → 7 → 5
```

## ⏱️ 시간복잡도

**O(N²)**

**분석**:
- 삼각형 전체 원소 수: 1 + 2 + ... + N = N(N+1)/2
- 각 원소를 한 번씩 처리 → O(N²)

**실제 계산**:
```
N ≤ 500
최악의 경우: 500 × 500 / 2 = 125,000 연산
O(125,000) << 10^8 (2초 기준)
```

**✅ 결론**: 충분히 시간 제한 내에 해결 가능

---

## 💾 공간복잡도

**O(N²)**

**분석**:
- `arr[504][504]`: 삼각형 원소 저장 → O(N²)
- `dp[504][504]`: DP 테이블 → O(N²)
