## 🔗 문제 링크

[백준 1991번 - 트리 순회](https://www.acmicpc.net/problem/1991)

**난이도**: Silver 1

---

## 🤔 접근법

이진 트리를 입력받아 **전위(Preorder) / 중위(Inorder) / 후위(Postorder)** 순회 결과를 출력하는 문제.

- 노드는 A~Z (최대 26개), 항상 A가 루트
- 자식이 없는 경우 `.` 으로 표현
- 각 노드를 인덱스 배열(`lc`, `rc`)로 관리하고 재귀로 순회

**핵심은 재귀 함수**로 순회 순서를 표현하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : 재귀 (Recursion) + 트리 순회

**핵심 아이디어**:
```
1. lc[i], rc[i] 배열로 각 노드의 왼쪽/오른쪽 자식 저장
2. '.' 입력 시 -1 저장 (자식 없음)
3. 루트 A = 인덱스 0, 항상 Preorder(0)부터 시작
4. 재귀 기저 조건: node == -1이면 즉시 반환
5. 순서만 바꿔서 세 가지 순회 함수 구현
```

---

## 🔑 핵심 포인트

### 1️⃣ 인덱스 배열로 트리 표현

```cpp
int lc[26];  // 왼쪽 자식 인덱스 (-1 = 없음)
int rc[26];  // 오른쪽 자식 인덱스 (-1 = 없음)

lc[idx] = (left  == '.') ? -1 : left  - 'A';
rc[idx] = (right == '.') ? -1 : right - 'A';
```

**✅ 핵심**: 알파벳 노드를 `문자 - 'A'`로 0~25 인덱스로 변환
- 배열 크기 26이면 충분
- `'.'`이면 -1로 저장하여 자식 없음 표시

### 2️⃣ 재귀 기저 조건

```cpp
void Preorder(int node)
{
    if (node == -1)
    {
        return;
    }
    // ...
}
```

**✅ 핵심**: `node == -1`이 자식 없음을 의미
- 리프 노드에서 재귀 자연스럽게 종료

### 3️⃣ 세 가지 순회 패턴

```
전위 (Preorder) : 루트 → 왼쪽 → 오른쪽
중위 (Inorder)  : 왼쪽 → 루트 → 오른쪽
후위 (Postorder): 왼쪽 → 오른쪽 → 루트
```

**✅ 핵심**: 루트 출력 위치만 다르고 나머지 구조는 동일

## 📊 순회 동작 분석

### 🎯 예제 입력
```
7
A B C
B D .
C E F
E . .
F . G
D . .
G . .
```

### 🔍 트리 구조
```
        A
       / \
      B   C
     /   / \
    D   E   F
             \
              G
```

### 📋 순회 결과
```
전위 : ABDCEFG
중위 : DBAECFG
후위 : DBEGFCA
```

## ⏱️ 시간복잡도

**O(N)** (N = 노드 개수, 최대 26)

**분석**:
- 모든 노드를 정확히 한 번씩 방문
- 각 노드에서 수행하는 연산: 출력 + 자식 재귀 → O(1)
- 총 시간: N개 노드 × O(1) = **O(N)**

---

## 💾 공간복잡도

**O(N)**

**분석**:
- `lc[26]`, `rc[26]`: 자식 인덱스 배열 → O(N)
- 재귀 스택: 트리 높이 최대 N → O(N)

---

**⏱️ 시간복잡도**: O(N) - 모든 노드를 한 번씩 방문

**💾 공간복잡도**: O(N) - 배열 저장 + 재귀 스택
