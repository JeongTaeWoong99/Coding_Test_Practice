## 🔗 문제 링크

[백준 1992번 - 쿼드트리](https://www.acmicpc.net/problem/1992)

**난이도**: Silver 1

---

## 🤔 접근법

흑백 영상을 압축하여 표현하는 쿼드트리 자료구조를 구현하는 문제.

- 영상의 모든 값이 같으면 해당 값(0 또는 1)을 출력
- 값이 섞여 있으면 4개 영역으로 분할하여 재귀적으로 압축
- 분할된 결과는 괄호로 묶어 표현

**핵심은 분할 정복(Divide and Conquer)**으로 영상을 재귀적으로 분할하여 압축하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : 분할 정복 (Divide and Conquer) + 재귀

**핵심 아이디어**:
```
1. 현재 영역이 모두 같은 값인지 확인
2. 모두 같으면 → 해당 값을 문자열로 반환
3. 다른 값이 있으면 → 4개 영역으로 분할
   - 왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래 순서
4. 각 영역의 결과를 괄호로 묶어서 연결
5. 재귀 기저 조건: 크기가 1이면 해당 위치의 값 반환
```

---

## 🔑 핵심 포인트

### 1️⃣ 재귀 함수 구조

```cpp
string Quard(int x, int y, int size)
{
    // 기저 조건: 크기가 1이면 해당 문자 반환
    if (size == 1) return {arr[y][x]};

    // 영역 검사 후 분할 또는 값 반환
}
```

**✅ 핵심**: 재귀 기저 조건을 먼저 처리
- size == 1일 때 더 이상 분할 불가
- 해당 위치의 문자를 바로 반환

### 2️⃣ 영역 동일성 검사

```cpp
char b = arr[y][x];  // 왼쪽 위 값을 기준으로 설정

for (int i = y; i < y + size; i++)
{
    for (int j = x; j < x + size; j++)
    {
        if (arr[i][j] != b)
        {
            // 다른 값 발견 → 4개 영역으로 분할
        }
    }
}

// 모든 값이 같으면 해당 값 반환
return {arr[y][x]};
```

**✅ 핵심**: 왼쪽 위 값(arr[y][x])을 기준으로 비교
- 다른 값이 하나라도 있으면 즉시 분할
- 모든 값이 같으면 루프 통과 후 해당 값 반환

### 3️⃣ 4개 영역 분할 순서

```cpp
ret += '(';
ret += Quard(x,             y,             size / 2); // 왼쪽 위
ret += Quard(x + size / 2,  y,             size / 2); // 오른쪽 위
ret += Quard(x,             y + size / 2,  size / 2); // 왼쪽 아래
ret += Quard(x + size / 2,  y + size / 2,  size / 2); // 오른쪽 아래
ret += ')';
```

**✅ 핵심**: Z자 순서로 4개 영역 분할
- 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래
- 각 영역의 크기는 현재 크기의 절반 (size / 2)
- 시작 좌표를 적절히 조정하여 각 영역 지정

### 4️⃣ 문자열 초기화 리스트 사용

```cpp
return {arr[y][x]};
```

**✅ 핵심**: 간결한 문자열 생성 방법
- `string(1, arr[y][x])` 대신 `{arr[y][x]}` 사용
- 더 간결하고 현대적인 C++11 스타일
- 성능은 동일 (컴파일러 최적화)

## 📊 재귀 동작 상세 분석

### 🎯 입력 예시
```
4
1111
1111
0011
0011
```

### 🔍 재귀 트리 전개

```
Quard(0, 0, 4): 영역 [0,0] ~ [3,3] 검사
  → arr[0][0] = '1', arr[2][0] = '0' → 다름! 분할

  ├─ Quard(0, 0, 2): 왼쪽 위 [0,0] ~ [1,1]
  │  → 모두 '1' → "1" 반환

  ├─ Quard(2, 0, 2): 오른쪽 위 [0,2] ~ [1,3]
  │  → 모두 '1' → "1" 반환

  ├─ Quard(0, 2, 2): 왼쪽 아래 [2,0] ~ [3,1]
  │  → 모두 '0' → "0" 반환

  └─ Quard(2, 2, 2): 오른쪽 아래 [2,2] ~ [3,3]
     → 모두 '1' → "1" 반환

최종 결과: "(1101)"
```

**✅ 핵심 원리**:
- 각 영역이 동일한 값이면 재귀 즉시 종료
- 다른 값이 있으면 계속 분할
- 최종 결과는 문자열 연결로 자동 생성

---

## ⏱️ 시간복잡도

**O(N²)** (N = 영상의 크기)

**분석**:
- 최악의 경우 모든 칸을 한 번씩 방문
- 각 재귀에서 영역 검사: O(size²)
- 전체 영역 크기 합: N² + (N²/4)×4 + (N²/16)×16 + ... = O(N²)

**예시**:
```
N = 64일 때:
- 첫 번째 검사: 64² = 4096
- 4개 영역 검사: (32²) × 4 = 4096
- 16개 영역 검사: (16²) × 16 = 4096
...
→ 총 시간복잡도는 O(N²)로 수렴
```

**✅ 결론**: N ≤ 64 제약 조건에서 충분히 시간 내 해결 가능

---

## 💾 공간복잡도

**O(N² + log N)**

**분석**:
- `arr[101][101]`: 영상 배열 → O(N²)
- 재귀 스택: 최대 깊이 log₂N → O(log N)
  - 예: N=64 → 깊이 = 6 (64 → 32 → 16 → 8 → 4 → 2 → 1)
- 문자열 반환 값: 최악의 경우 O(N²) (완전히 섞인 패턴)

**총 공간**: O(N² + log N) ≈ **O(N²)**

## 🎯 핵심 교훈

### ✅ 분할 정복의 특성

**문제 패턴**:
- 큰 문제를 작은 문제로 분할
- 각 작은 문제를 독립적으로 해결
- 결과를 합쳐서 최종 답 도출

### ✅ 재귀 기저 조건

```cpp
if (size == 1) return {arr[y][x]};
```

**중요성**:
- 재귀 종료 조건을 명확히 정의
- 기저 조건이 없으면 무한 재귀 발생
- 가장 작은 단위에서 바로 반환

### ✅ 좌표 시스템 이해

```cpp
arr[y][x]  // arr[행][열] = arr[세로][가로]
```

**주의사항**:
- 함수 매개변수: `Quard(int x, int y, int size)`
- 배열 접근: `arr[y][x]` (y가 먼저!)
- x는 열(가로), y는 행(세로)

### ✅ 문자열 연결 효율

```cpp
ret += '(';
ret += Quard(...);  // 재귀 결과를 바로 연결
ret += ')';
```

**장점**:
- 간결하고 읽기 쉬운 코드
- string의 += 연산자는 충분히 최적화됨
- 코테 환경에서 적절한 성능

---

**⏱️ 시간복잡도**: O(N²) - 모든 칸을 최대 한 번씩 방문

**💾 공간복잡도**: O(N² + log N) - 배열 저장 + 재귀 스택
