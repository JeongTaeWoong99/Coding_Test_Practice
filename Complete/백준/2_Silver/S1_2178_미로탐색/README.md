## 🔗 문제 링크

[백준 2178번 - 미로 탐색](https://www.acmicpc.net/problem/2178)

**난이도**: Silver 1

---

## 🤔 접근법

N×M 크기의 미로에서 (1, 1)에서 출발하여 (N, M)까지 이동할 때 **지나야 하는 최소 칸 수**를 구하는 문제.

- 1은 이동 가능한 칸, 0은 이동할 수 없는 칸
- 서로 인접한 칸으로만 이동 가능
- 시작 위치와 도착 위치도 칸 수에 포함

**핵심은 BFS**로 최단 경로를 탐색하면서, visited 배열에 각 칸까지의 거리를 누적하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : BFS (Breadth-First Search) - 너비 우선 탐색

**핵심 아이디어**:
```
1. 시작점 (0, 0)에서 BFS 시작, visited[0][0] = 1로 초기화
2. 큐에서 현재 위치를 꺼내 4방향으로 탐색
3. 유효한 위치(범위 내, 벽 아님, 미방문)이면 visited 값 갱신
4. visited[ny][nx] = visited[y][x] + 1 (이전 거리 + 1)
5. 큐에 새로운 위치 추가하여 탐색 계속
6. 최종적으로 visited[N-1][M-1] 출력 (도착점까지의 최단 거리)
```

---

## 🔑 핵심 포인트

### 1️⃣ BFS 기본 패턴

```cpp
queue<pair<int, int>> q;
visited[0][0] = 1;    // 시작 지점 거리 1로 초기화
q.emplace(0, 0);

while(!q.empty())
{
    pair<int, int> cur = q.front();
    q.pop();
    int y = cur.first;
    int x = cur.second;

    // 4방향 탐색
    for(int i = 0; i < 4; i++)
    {
        int ny = y + dY[i];
        int nx = x + dX[i];

        // 유효성 검사 후 거리 갱신 및 큐 추가
    }
}
```

**✅ 핵심**: BFS는 큐를 사용하여 레벨별로 탐색
- 시작점에서 가까운 위치부터 차례대로 방문
- 먼저 도착한 경로가 최단 경로 보장

### 2️⃣ 거리 누적 방식

```cpp
// 처음 방문할 때 거리 기록
visited[ny][nx] = visited[y][x] + 1;
q.emplace(ny, nx);
```

**✅ 핵심**: visited 배열을 이중 용도로 사용
- 방문 여부 체크: `visited[ny][nx]`가 0이 아니면 이미 방문
- 거리 저장: `visited[ny][nx]` 값이 시작점부터의 거리

**장점**:
- 별도의 distance 배열 불필요
- 메모리 효율적
- 코드 간결화

### 3️⃣ 입력 처리 (띄어쓰기 없는 숫자)

```cpp
for(int i = 0; i < N; i++)
{
    for(int j = 0; j < M; j++)
    {
        char c;
        cin >> c;
        arr[i][j] = c - '0';  // 문자 '0'/'1' → 정수 0/1 변환
    }
}
```

**✅ 핵심**: 입력이 띄어쓰기 없이 한 줄로 주어짐
- `char`로 한 글자씩 읽기
- `c - '0'`로 문자를 숫자로 변환
  - `'0' - '0' = 0`
  - `'1' - '0' = 1`

### 4️⃣ 유효성 검사

```cpp
if(ny < 0 || nx < 0 || ny >= N || nx >= M) continue;  // 범위 나감
if(arr[ny][nx] == 0)                       continue;  // 벽
if(visited[ny][nx])                        continue;  // 이미 방문
```

**✅ 핵심**: 3가지 조건을 모두 확인
1. **범위 체크**: 맵 밖으로 나가는지
2. **벽 체크**: 이동 불가능한 칸인지
3. **방문 체크**: 이미 방문한 칸인지

## 🔍 BFS vs DFS 선택 이유

### 왜 BFS를 사용하나?

| 알고리즘 | 특징 | 최단 경로 보장 |
|---------|------|---------------|
| **BFS** | 레벨별 탐색, 큐 사용 | ✅ 보장 (첫 도착 = 최단) |
| **DFS** | 깊이 우선 탐색, 스택/재귀 사용 | ❌ 미보장 (모든 경로 탐색 필요) |

**이 문제에서 BFS를 선택한 이유**:
```
1. 최단 경로를 구하는 문제
2. 가중치가 없는 그래프 (모든 이동 비용 = 1)
3. BFS는 첫 번째로 도착한 경로가 최단 경로 보장
4. DFS는 모든 경로를 탐색해야 하므로 비효율적
```

## ⏱️ 시간복잡도

**O(N × M)**

**분석**:
- N × M 크기의 맵에서 각 칸을 최대 1번씩만 방문
- BFS는 visited 배열로 중복 방문 방지
- 각 칸마다 4방향 탐색 → O(4) = 상수

**실제 계산**:
```
- N, M ≤ 100
- 최악의 경우: 100 × 100 = 10,000칸
- 각 칸마다 4방향 탐색 → 10,000 × 4 = 40,000 연산
- O(40,000) ≈ O(10^4) << 10^8 (1초 기준)
```

**✅ 결론**: 충분히 시간 제한(1초) 내에 해결 가능

---

## 💾 공간복잡도

**O(N × M)**

**분석**:
- `arr[104][104]`: 맵 배열 → O(N × M)
- `visited[104][104]`: 방문 및 거리 배열 → O(N × M)
- `queue<pair<int, int>>`: 최악의 경우 모든 칸 저장 → O(N × M)
- `dY[4]`, `dX[4]`: 방향 배열 → O(1) (상수)

**총 공간**: O(N × M) ≈ **O(10,000)** (N=M=100일 때)
