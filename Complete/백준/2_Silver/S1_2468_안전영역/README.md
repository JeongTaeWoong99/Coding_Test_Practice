## 🔗 문제 링크

[백준 2468번 - 안전 영역](https://www.acmicpc.net/problem/2468)

**난이도**: Silver 1

---

## 🤔 접근법

N×N 크기의 지역 정보가 주어졌을 때, **장마철에 내리는 비의 양에 따라 물에 잠기지 않는 안전한 영역의 최대 개수**를 구하는 문제.

### 📖 문제 지문 핵심 해석

#### 1️⃣ 물에 잠기는 기준

> "장마철에 내리는 비의 양에 따라 **일정한 높이 이하의 모든 지점은 물에 잠긴다**"

**중요!** 비의 높이가 `H`일 때:
- **높이 ≤ H** : 물에 잠김 (안전하지 않음) ❌
- **높이 > H** : 물에 잠기지 않음 (안전함) ✅

**예시**:
```
지역 높이: 6 8 2 6 2
비의 높이 H = 4

→ 높이 ≤ 4인 곳: 2, 2, 2 (물에 잠김)
→ 높이 > 4인 곳: 6, 8, 6 (안전 영역)
```

#### 2️⃣ 안전 영역의 정의

> "물에 잠기지 않는 지점들이 **위, 아래, 오른쪽, 왼쪽으로 인접**해 있으며 그 크기가 최대인 영역"

**핵심 포인트**:
- 상하좌우로 인접한 안전한 지점들의 집합 = 1개의 안전 영역
- 대각선은 인접하지 않음 (꼭짓점으로만 붙어 있는 경우 제외)
- BFS/DFS로 연결된 컴포넌트를 찾는 문제

#### 3️⃣ 예제로 이해하기

**입력 맵**:
```
6  8  2  6  2
3  2  3  4  6
6  7  3  3  2
7  2  5  3  6
8  9  5  2  7
```

**케이스 1: 비의 높이 = 4**
```
✅ 6  ✅ 8  ❌ 2  ✅ 6  ❌ 2
❌ 3  ❌ 2  ❌ 3  ❌ 4  ✅ 6
✅ 6  ✅ 7  ❌ 3  ❌ 3  ❌ 2
✅ 7  ❌ 2  ✅ 5  ❌ 3  ✅ 6
✅ 8  ✅ 9  ✅ 5  ❌ 2  ✅ 7

안전 영역 (높이 > 4):
1. (0,0)-(0,1)-(1,4)-(2,0)-(2,1)-(3,0) 연결 → 1개 영역
2. (0,3) 단독 → 1개 영역
3. (3,2) 단독 → 1개 영역
4. (3,4)-(4,4) 연결 → 1개 영역
5. (4,0)-(4,1)-(4,2) 연결 → 1개 영역

→ 총 5개 안전 영역 ✅
```

**케이스 2: 비의 높이 = 6**
```
❌ 6  ✅ 8  ❌ 2  ❌ 6  ❌ 2
❌ 3  ❌ 2  ❌ 3  ❌ 4  ❌ 6
❌ 6  ✅ 7  ❌ 3  ❌ 3  ❌ 2
✅ 7  ❌ 2  ❌ 5  ❌ 3  ❌ 6
✅ 8  ✅ 9  ❌ 5  ❌ 2  ✅ 7

안전 영역 (높이 > 6):
1. (0,1) 단독 → 1개 영역
2. (2,1) 단독 → 1개 영역
3. (3,0)-(4,0)-(4,1) 연결 → 1개 영역
4. (4,4) 단독 → 1개 영역

→ 총 4개 안전 영역 ✅
```

**케이스 3: 비의 높이 = 0 (아무것도 잠기지 않음)**
```
✅ 6  ✅ 8  ✅ 2  ✅ 6  ✅ 2
✅ 3  ✅ 2  ✅ 3  ✅ 4  ✅ 6
✅ 6  ✅ 7  ✅ 3  ✅ 3  ✅ 2
✅ 7  ✅ 2  ✅ 5  ✅ 3  ✅ 6
✅ 8  ✅ 9  ✅ 5  ✅ 2  ✅ 7

→ 모든 지점이 연결 → 1개 안전 영역 ✅
```

#### 4️⃣ 문제의 핵심 함정!

> "아무 지역도 물에 잠기지 않을 수도 있다" (노트)

**함정 포인트**:
- 비의 높이가 0 또는 맵의 최솟값보다 작은 경우
- 이 경우 전체가 1개의 안전 영역
- **반드시 고려해야 함!**

**해결 방법**:
```cpp
int ret = 1;  // 초기값 1로 설정 (아무것도 안 잠기는 경우)

// 비의 높이 1 ~ (최대높이-1)까지만 시도
for (int height = 1; height < maxHeight; height++)
{
    ret = max(ret, BFS(height));
}
```

### 🎯 접근 전략

**왜 모든 비의 높이를 시도해야 하는가?**

비의 높이에 따라 안전 영역 개수가 달라지므로:
```
비의 높이 = 0  → 1개
비의 높이 = 1  → ?개
비의 높이 = 2  → ?개
...
비의 높이 = 4  → 5개 (예제에서 최대!)
비의 높이 = 5  → ?개
비의 높이 = 6  → 4개
...
```

**따라서**:
1. **브루트포스**: 모든 가능한 비의 높이(0 ~ 최대 높이)를 시도
2. **BFS/DFS**: 각 높이마다 안전 영역 개수 세기
3. **최댓값 갱신**: 가장 많은 안전 영역 개수 저장

## 💡 정답 풀이 방법

**알고리즘** : 브루트포스 (Brute Force) + BFS (Breadth-First Search)

**핵심 아이디어**:
```
1. 입력을 받으면서 최대 높이를 저장
2. 비의 높이를 0부터 (최대높이-1)까지 하나씩 시도
3. 각 높이마다 BFS로 안전 영역 개수를 세기:
   - visited 배열 초기화
   - 높이 > 비의 높이인 지점을 시작점으로 BFS
   - 연결된 안전 지점들을 모두 방문 처리
   - 새로운 시작점을 찾을 때마다 안전 영역 개수 +1
4. 모든 높이 중에서 최대 안전 영역 개수를 출력
```

## 🔑 핵심 포인트

### 1️⃣ 비의 높이 범위 설정

```cpp
int ret = 1;  // 아무것도 안 잠기는 경우 (height = 0)

// 1부터 maxHeight-1까지 시도
for (int height = 1; height < maxHeight; height++)
{
    int safeAreas = BFS(height);
    ret = max(ret, safeAreas);
}
```

**✅ 핵심**:
- **초기값 1**: 비가 안 오거나 모든 지역이 안전한 경우
- **1 ~ (maxHeight-1)**: 의미 있는 비의 높이 범위
  - `height = 0`: 아무것도 안 잠김 → 초기값 1로 커버
  - `height = maxHeight`: 모든 것이 잠김 → 0개 (고려 불필요)

### 2️⃣ BFS 함수 구조

```cpp
int BFS(int height)
{
    memset(visited, 0, sizeof(visited));  // 매번 초기화 필수!

    int cnt = 0;  // 안전 영역 개수

    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n; j++)
        {
            // 안전 지점(height보다 큰 높이) && 미방문
            if (arr[i][j] > height && visited[i][j] == 0)
            {
                cnt++;  // 새로운 안전 영역 발견

                // BFS로 연결된 모든 안전 지점 방문 처리
                queue<pair<int, int>> q;
                q.push({i, j});
                visited[i][j] = 1;

                while (!q.empty())
                {
                    // 4방향 탐색하며 안전 영역 확장
                }
            }
        }
    }

    return cnt;
}
```

**✅ 핵심**:
- **visited 초기화**: 각 높이마다 새로운 탐색이므로 반드시 초기화
- **조건 체크**: `arr[i][j] > height` (등호 주의!)
- **카운팅 방식**: 새로운 시작점을 찾을 때마다 +1

### 3️⃣ BFS 탐색 조건

```cpp
for (int k = 0; k < 4; k++)
{
    int ny = cy + dy[k];
    int nx = cx + dx[k];

    // 범위 체크
    if (ny < 0 || ny >= n || nx < 0 || nx >= n) continue;

    // 이미 방문 || 물에 잠김 (높이 ≤ height)
    if (visited[ny][nx] || arr[ny][nx] <= height) continue;

    // 방문 처리 및 큐에 추가
    visited[ny][nx] = 1;
    q.push({ny, nx});
}
```

**✅ 핵심**:
- **물에 잠기는 조건**: `arr[ny][nx] <= height` (등호 포함!)
- **안전한 조건**: `arr[ny][nx] > height`

### 4️⃣ 등호 처리 주의!

**문제 지문**: "일정한 높이 **이하**의 모든 지점은 물에 잠긴다"

```cpp
// ❌ 잘못된 조건
if (arr[i][j] >= height) // 안전 영역

// ✅ 올바른 조건
if (arr[i][j] > height)  // 안전 영역
```

**예시**:
```
비의 높이 = 4, 지점의 높이 = 4
→ 4 ≤ 4 (이하) → 물에 잠김 ❌
→ 4 > 4? false → 안전하지 않음 ✅
```

## ⏱️ 시간복잡도

**O(maxHeight × N²)**

**분석**:
- 비의 높이 시도: O(maxHeight) ≈ O(100)
- 각 높이마다 BFS: O(N²) ≈ O(10,000)
- 총 시간: 100 × 10,000 = 1,000,000 연산

**실제 계산**:
```
- N ≤ 100 → N² = 10,000
- 높이 범위 ≤ 100 → 최대 100번 시도
- 100 × 10,000 = 1,000,000 연산
- O(10^6) << 10^8 (1초 기준)
```

**✅ 결론**: 충분히 시간 제한(1초) 내에 해결 가능

## 💾 공간복잡도

**O(N²)**

**분석**:
- `arr[104][104]`: 맵 배열 → O(N²)
- `visited[104][104]`: 방문 배열 → O(N²)
- `queue<pair<int, int>>`: 최악의 경우 모든 칸 저장 → O(N²)

**총 공간**: O(N²) ≈ **O(10,000)** (N=100일 때)
