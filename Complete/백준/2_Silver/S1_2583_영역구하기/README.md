## 🔗 문제 링크

[백준 2583번 - 영역 구하기](https://www.acmicpc.net/problem/2583)

**난이도**: Silver 1

---

## 🤔 접근법

M×N 크기의 모눈종이에 K개의 직사각형을 그린 후, **직사각형 내부를 제외한 나머지 부분이 몇 개의 분리된 영역으로 나누어지는지**와 **각 영역의 넓이**를 구하는 문제.

---

## 💡 정답 풀이 방법

**알고리즘**: BFS (Breadth-First Search) - 너비 우선 탐색

**핵심 아이디어**:
```
1. K개의 직사각형 좌표를 입력받아 arr[y][x] = 1로 표시
2. 모든 칸 (i, j)를 순회하며:
   - arr[i][j] == 0 && vit[i][j] == 0이면 새로운 영역 발견
   - BFS로 연결된 모든 빈 칸을 방문 처리하며 넓이 계산
   - 영역 개수 +1, 넓이를 벡터에 저장
3. 넓이 벡터를 오름차순 정렬
4. 영역 개수와 넓이들을 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 좌표계 변환

```cpp
// 문제 입력: (x1, y1, x2, y2)
cin >> x_1 >> y_1 >> x_2 >> y_2;

// 배열 표시: arr[y][x] = 1
for(int x = x_1; x < x_2; x++)
{
    for(int y = y_1; y < y_2; y++)
    {
        arr[y][x] = 1;  // 행(y), 열(x) 순서 주의!
    }
}
```

**✅ 핵심**: 문제의 (x, y)와 배열의 [y][x] 순서 주의
- **문제 좌표**: (x, y) = (가로, 세로)
- **배열 인덱스**: arr[y][x] = arr[세로][가로]
- **for문 순서**: x 먼저, y 나중에 (어느 쪽이든 상관없지만 범위 주의)

### 2️⃣ BFS 함수 구조

```cpp
int BFS(int y, int x)
{
    int areaCount = 1;  // 시작 칸 포함

    vit[y][x] = 1;
    queue<pair<int, int>> q;
    q.emplace(y, x);

    while(!q.empty())
    {
        int y = q.front().first;
        int x = q.front().second;
        q.pop();  // ⚠️ 필수! 없으면 무한 루프

        for (int i = 0; i < 4; i++)
        {
            int newY = y + dY[i];
            int newX = x + dX[i];

            // 범위 체크
            if (newY < 0 || newY >= N || newX < 0 || newX >= M) continue;

            // 직사각형 영역 또는 이미 방문
            if (arr[newY][newX] == 1 || vit[newY][newX] == 1) continue;

            areaCount++;
            vit[newY][newX] = 1;
            q.emplace(newY, newX);
        }
    }

    return areaCount;
}
```

**✅ 핵심**: q.pop() 누락 방지!
- `q.front()`로 요소를 가져온 후 **반드시 `q.pop()`으로 제거**
- 누락 시 무한 루프 발생 (디버깅 어려운 실수)
- areaCount는 시작 칸 포함하여 1부터 시작

### 3️⃣ 범위 체크 순서

```cpp
// 범위 체크
if (newY < 0 || newY >= N || newX < 0 || newX >= M) continue;

// 직사각형 영역 체크
if (arr[newY][newX] == 1) continue;

// 방문 체크
if (vit[newY][newX] == 1) continue;
```

**✅ 핵심**: 범위 체크를 먼저!
- **범위 체크 후** 배열 접근 (out of bounds 방지)
- **직사각형 체크**: arr[y][x] == 1인 칸은 제외
- **방문 체크**: 중복 방문 방지

### 4️⃣ 영역 탐색 메인 로직

```cpp
for(int i = 0; i < N; i++)
{
    for(int j = 0; j < M; j++)
    {
        // 빈 칸이면서 미방문
        if (arr[i][j] == 0 && vit[i][j] == 0)
        {
            ret++;                     // 영역 개수 증가
            v.emplace_back(BFS(i, j)); // 넓이 저장
        }
    }
}
```

**✅ 핵심**: 이중 조건 체크
- `arr[i][j] == 0`: 직사각형이 아닌 빈 칸
- `vit[i][j] == 0`: 아직 방문하지 않은 칸
- 두 조건을 모두 만족하는 칸이 새로운 영역의 시작점

### 5️⃣ 결과 정렬 및 출력

```cpp
// 넓이 오름차순 정렬
sort(v.begin(), v.end());

// 결과 출력
cout << ret << "\n";
for (int num : v)
    cout << num << " ";
```

**✅ 핵심**: 문제 요구사항 준수
- **오름차순 정렬**: `sort(v.begin(), v.end())`
- **첫째 줄**: 영역 개수
- **둘째 줄**: 각 영역의 넓이 (공백으로 구분)

## ⏱️ 시간복잡도

**O(M × N)**

**분석**:
1. **직사각형 표시**: O(K × 직사각형 평균 넓이)
   - 최악의 경우 O(K × M × N) (모든 칸을 K번 칠함)
   - 실제로는 훨씬 적음 (입력이 전체를 채우지 않음)
   - 문제 조건상 전체를 채우지 않으므로 O(M × N) 이하

2. **BFS 탐색**: O(M × N)
   - 모든 칸을 최대 1번씩 방문
   - 각 칸마다 4방향 탐색 → O(4) = 상수

3. **정렬**: O(영역 개수 × log(영역 개수))
   - 영역 개수 ≤ M × N
   - 실제로는 훨씬 적음
   - O(M × N)에 비해 무시 가능

**실제 계산**:
```
- M, N ≤ 100 → M × N = 10,000
- BFS가 지배적: O(10,000) = O(10^4)
- O(10^4) << 10^8 (1초 기준)
```

**✅ 결론**: 충분히 시간 제한(1초) 내에 해결 가능

## 💾 공간복잡도

**O(M × N)**

**분석**:
- `arr[104][104]`: 모눈종이 배열 → O(M × N)
- `vit[104][104]`: 방문 배열 → O(M × N)
- `queue<pair<int, int>>`: 최악의 경우 모든 칸 저장 → O(M × N)
- `vector<int> v`: 영역 넓이 저장 → O(영역 개수) ≤ O(M × N)

**총 공간**: O(M × N) ≈ **O(10,000)** (M=N=100일 때)
