## 🔗 문제 링크

[백준 2667번 - 단지번호붙이기](https://www.acmicpc.net/problem/2667)

**난이도**: Silver 1

---

## 🤔 접근법

N×N 크기의 지도에서 1(집이 있는 곳)과 0(집이 없는 곳)이 주어질 때, **연결된 집의 모임인 단지의 수와 각 단지에 속하는 집의 수를 오름차순으로 출력**하는 문제.

- 상하좌우로 인접한 집들이 연결되어 하나의 단지를 이룸.
- 대각선은 연결된 것으로 보지 않음.
- 연결된 컴포넌트(Connected Component)의 개수와 크기를 구하는 전형적인 그래프 탐색 문제.

**핵심은 BFS로 연결된 집들을 탐색**하면서, 방문하지 않은 집을 발견할 때마다 새로운 단지로 카운트하고 각 단지의 집 수를 기록하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : BFS (Breadth-First Search) - 너비 우선 탐색

**핵심 아이디어**:
```
1. N×N 배열의 모든 지점을 순회
2. 집이 있고(arr == 1) 방문하지 않은 지점을 발견하면 BFS 시작
3. BFS로 연결된 모든 집을 방문 처리하며 areaCnt 증가
4. BFS 완료 후 areaCnt를 areaV에 저장 (단지 1개 발견)
5. 모든 순회 완료 후 areaV를 오름차순 정렬 후 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 단지 카운트 패턴

```cpp
vector<int> areaV;  // 각 단지의 집 수 저장

for (int i = 0; i < n; ++i)
{
    for (int j = 0; j < n; ++j)
    {
        // 집이 있고 방문하지 않은 경우
        if (arr[i][j] == 1 && vit[i][j] == false)
        {
            int areaCnt = 1;  // 시작점 포함
            // BFS 시작...
            areaV.push_back(areaCnt);  // 단지 크기 저장
        }
    }
}
```

**✅ 핵심**: BFS 호출 횟수 = 단지 수, 각 BFS의 방문 횟수 = 단지 내 집 수

### 2️⃣ BFS 탐색 조건 순서

```cpp
// 범위 체크
if (newX < 0 || newX >= n || newY < 0 || newY >= n) continue;

// 집인지 체크 (0이면 빈집, skip)
if (arr[newY][newX] == 0) continue;

// 방문 했는지 체크
if (vit[newY][newX] == true) continue;

bfsQ.emplace(newY, newX);
vit[newY][newX] = true;
areaCnt++;
```

**✅ 핵심**: 3가지 조건을 순서대로 확인
1. **범위 체크**: 배열 밖으로 나가는지 (먼저 해야 배열 접근 안전)
2. **집 체크**: 집이 있는 위치인지
3. **방문 체크**: 이미 방문한 위치인지

### 3️⃣ 오름차순 정렬

```cpp
// 출력 전 반드시 정렬!
sort(areaV.begin(), areaV.end());

cout << (int)areaV.size() << '\n';
for (int curArea : areaV)
    cout << curArea << '\n';
```

**✅ 핵심**: 문제 조건 - "각 단지에 속하는 집의 수를 **오름차순으로** 정렬하여 출력"

### 4️⃣ 입력 처리 (띄어쓰기 없는 숫자)

```cpp
string s;
cin >> s;

for (int j = 0; j < n; ++j)
{
    arr[i][j] = s[j] - '0';  // 문자 '0'/'1' → 정수 0/1 변환
}
```

**✅ 핵심**: 입력이 공백 없이 한 줄로 주어지므로 string으로 읽어서 변환

## ⏱️ 시간복잡도

**O(N²)**

**분석**:
- N×N 배열의 각 칸을 최대 1번씩만 방문
- BFS는 vit 배열로 중복 방문 방지
- 각 칸마다 4방향 탐색 → O(4) = 상수

**실제 계산**:
```
- N ≤ 25
- 최악의 경우: 25 × 25 = 625칸
- 각 칸마다 4방향 탐색 → 625 × 4 = 2,500 연산
- O(2,500) << 10^8 (1초 기준)
```

**✅ 결론**: 충분히 시간 제한(1초) 내에 해결 가능

---

## 💾 공간복잡도

**O(N²)**

**분석**:
- `arr[30][30]`: 지도 배열 → O(N²)
- `vit[30][30]`: 방문 체크 배열 → O(N²)
- `areaV`: 최악의 경우 모든 칸이 단지 → O(N²)
- `queue<pair<int,int>>`: 최악의 경우 모든 칸 저장 → O(N²)

**총 공간**: O(N²) ≈ **O(625)** (N=25일 때)
