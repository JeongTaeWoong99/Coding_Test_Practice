## 🔗 문제 링크

[백준 9465번 - 스티커](https://www.acmicpc.net/problem/9465)

**난이도**: Silver 1

---

## 🤔 접근법

2×n 격자에 배치된 스티커에서, 스티커 하나를 떼면 상하좌우 4방향 스티커가 모두 찢어지는 제약 조건 하에 점수 합을 최대화하는 문제.

- 각 열에서 선택 가능한 상태: 아무것도 선택 안 함 / 위 선택 / 아래 선택
- 이전 열의 상태에 따라 현재 열의 선택이 제한됨
- **핵심은 동적 프로그래밍**으로 각 열의 3가지 상태를 전이시켜 최댓값을 구하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : 동적 프로그래밍 (Dynamic Programming)

**핵심 아이디어**:
```
1. dp[i][0] = 열 i에서 아무것도 선택 안 함
2. dp[i][1] = 열 i에서 위 스티커 선택
3. dp[i][2] = 열 i에서 아래 스티커 선택
4. 점화식:
   - dp[i][0] = max(dp[i-1][0], dp[i-1][1], dp[i-1][2])
   - dp[i][1] = max(dp[i-1][0], dp[i-1][2]) + sticker[0][i]  (이전 위 불가)
   - dp[i][2] = max(dp[i-1][0], dp[i-1][1]) + sticker[1][i]  (이전 아래 불가)
5. 최종 답: max(dp[n-1][0], dp[n-1][1], dp[n-1][2])
```

---

## 🔑 핵심 포인트

### 1️⃣ DP 상태 정의

```cpp
int dp[100001][3]; // dp[열][상태] : 0=선택없음, 1=위, 2=아래
```

**✅ 핵심**: 각 열에서 3가지 상태만 추적
- 같은 열의 위아래는 동시에 선택 불가 (변을 공유)
- 이전 열과 같은 행은 선택 불가 (변을 공유)

### 2️⃣ 점화식 (Recurrence Relation)

```cpp
dp[i][0] = max({dp[i-1][0], dp[i-1][1], dp[i-1][2]});
dp[i][1] = max(dp[i-1][0] , dp[i-1][2]) + sticker[0][i]; // 이전에 아무것도 or 아래
dp[i][2] = max(dp[i-1][0] , dp[i-1][1]) + sticker[1][i]; // 이전에 아무것도 or 위
```

**✅ 핵심**: 위를 선택하면 이전 열의 위 선택 불가, 아래도 마찬가지

### 3️⃣ 예제 검증 (n=5)

```
열:       0    1    2    3    4
위:      50   10  100   20   40
아래:    30   50   70   10   60

dp[0] = {0, 50, 30}
dp[1] = {50, 40, 100}
dp[2] = {100, 200, 120}
dp[3] = {200, 140, 210}
dp[4] = {210, 250, 260}

→ 정답: 260 ✅
```

## ⏱️ 시간복잡도

**O(T × N)**

**분석**:
- 테스트 케이스마다 열 n개를 순회: O(N)
- 각 열에서 상수 연산: O(1)
- T개의 테스트 케이스: O(T × N)

**시간 제한 체크**:
- N ≤ 100,000, T ≤ 적당한 수
- **100,000 연산** << **1억** → 여유롭게 통과 ✅

---

## 💾 공간복잡도

**O(N)**

**분석**:
- `sticker[2][100001]`: 입력 배열 → O(N)
- `dp[100001][3]`: DP 테이블 → O(N)
- 총 공간: O(N)
