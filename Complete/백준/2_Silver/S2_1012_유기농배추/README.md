## 🔗 문제 링크

[백준 1012번 - 유기농 배추](https://www.acmicpc.net/problem/1012)

**난이도**: Silver 2

---

## 🤔 접근법

M×N 크기의 배추밭에서 배추가 심어진 위치들이 주어질 때, **서로 인접한 배추들을 하나의 군집으로 묶어 총 몇 개의 군집이 있는지** 찾는 문제.

- 배추흰지렁이는 인접한 배추로 이동 가능 (상하좌우 4방향).
- 각 배추 군집마다 배추흰지렁이 1마리씩 필요.
- 연결된 컴포넌트(Connected Component)의 개수를 구하는 전형적인 그래프 탐색 문제.

**핵심은 BFS 또는 DFS로 연결된 배추들을 탐색**하면서, 방문하지 않은 배추를 발견할 때마다 카운트를 증가시키는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : BFS (Breadth-First Search) - 너비 우선 탐색

**핵심 아이디어**:
```
1. 배추밭 전체를 순회하면서 배추가 있고 방문하지 않은 위치 찾기
2. 해당 위치에서 BFS 시작 → 연결된 모든 배추 방문 처리
3. BFS 한 번 완료 = 배추 군집 1개 발견 → ret++
4. 모든 위치 순회 완료 후 ret 출력 (필요한 배추흰지렁이 마리 수)
```

---

## 🔑 핵심 포인트

### 1️⃣ 연결된 컴포넌트 개수 세기

```cpp
int ret = 0;  // 배추 군집 개수

for (int i = 0; i < M; i++)
{
    for (int j = 0; j < N; j++)
    {
        // 배추가 있고 방문하지 않은 위치 발견
        if (arr[i][j] == 1 && vit[i][j] == 0)
        {
            BFS(i, j);  // 연결된 모든 배추 방문 처리
            ret++;      // 새로운 배추 군집 발견!
        }
    }
}
```

**✅ 핵심**: BFS 호출 횟수 = 배추 군집 개수
- BFS 한 번에 연결된 배추들을 모두 방문 처리
- 방문하지 않은 배추를 발견할 때마다 새로운 군집

### 2️⃣ BFS 패턴

```cpp
queue<pair<int, int>> bfsQ;
vit[i][j] = 1;      // 시작점 방문 처리
bfsQ.emplace(i, j);

while (!bfsQ.empty())
{
    auto [currentY, currentX] = bfsQ.front();
    bfsQ.pop();

    // 4방향 탐색
    for (int k = 0; k < 4; k++)
    {
        int ny = currentY + dy[k];
        int nx = currentX + dx[k];

        // 유효성 검사
        if (ny < 0 || ny >= M || nx < 0 || nx >= N) continue;
        if (arr[ny][nx] == 0 || vit[ny][nx] == 1) continue;

        // 방문 처리 후 큐에 추가
        vit[ny][nx] = 1;
        bfsQ.emplace(ny, nx);
    }
}
```

**✅ 핵심**: 시작점 방문 처리 필수
- 시작점을 큐에 넣을 때 **반드시 방문 처리**
- 방문 처리 안 하면 중복 방문 발생 가능

### 3️⃣ 좌표 입력 처리

```cpp
// 문제에서 입력은 X Y 순서로 주어짐
// 하지만 배열은 arr[Y][X] 형태이므로 주의!

int y, x;
cin >> y >> x;  // 첫 번째 값을 y로, 두 번째 값을 x로 받음
arr[y][x] = 1;  // arr[첫번째인덱스][두번째인덱스]
```

**✅ 핵심**: 입력 순서와 배열 인덱스 매칭
- 문제: X(가로) Y(세로) 순서 입력
- 코드: 첫 번째 인덱스를 Y로, 두 번째를 X로 처리
- 범위 체크: `ny < M`, `nx < N`

### 4️⃣ 유효성 검사

```cpp
// 범위 체크
if (ny < 0 || ny >= M || nx < 0 || nx >= N) continue;

// 배추 없거나 이미 방문한 경우 스킵
if (arr[ny][nx] == 0 || vit[ny][nx] == 1) continue;
```

**✅ 핵심**: 3가지 조건 확인
1. **범위 체크**: 배추밭 밖으로 나가는지
2. **배추 체크**: 배추가 있는 위치인지
3. **방문 체크**: 이미 방문한 위치인지

### 5️⃣ 구조체 분해 (Structured Binding)

```cpp
// C++17 문법
auto [currentY, currentX] = bfsQ.front();

// 기존 방식
// pair<int, int> current = bfsQ.front();
// int currentY = current.first;
// int currentX = current.second;
```

**✅ 핵심**: 코드 간결성
- `auto [변수1, 변수2]`로 pair를 한 번에 분해
- 가독성 향상

## 🔍 BFS vs DFS 선택

| 알고리즘 | 특징 | 이 문제 적합성 |
|---------|------|---------------|
| **BFS** | 큐 사용, 레벨별 탐색 | ✅ 적합 (구현 간단) |
| **DFS** | 스택/재귀 사용, 깊이 우선 탐색 | ✅ 적합 (구현 간단) |

**이 문제에서 BFS/DFS 모두 가능한 이유**:
```
1. 최단 경로가 아닌 연결성만 확인
2. 방문 여부만 중요 (거리는 중요하지 않음)
3. 둘 다 시간복잡도 O(M×N)으로 동일
```

**BFS를 선택한 이유**:
- 큐를 사용한 반복문 구조로 스택 오버플로우 걱정 없음
- 디버깅이 상대적으로 쉬움

## ⏱️ 시간복잡도

**O(T × M × N)**

**분석**:
- T: 테스트 케이스 개수 (최대 50)
- M × N: 배추밭 크기 (각각 최대 50)
- 각 테스트 케이스마다:
  - 배추밭 전체 순회: O(M × N)
  - 각 칸마다 BFS 탐색: 최대 1번만 방문 → O(M × N)
  - 총 O(M × N)

**실제 계산**:
```
- T = 50, M = N = 50
- 각 테스트 케이스: 50 × 50 = 2,500칸
- 전체: 50 × 2,500 = 125,000 연산
- O(125,000) ≈ O(10^5) << 10^8 (1초 기준)
```

**✅ 결론**: 충분히 시간 제한(1초) 내에 해결 가능

---

## 💾 공간복잡도

**O(M × N)**

**분석**:
- `arr[54][54]`: 배추밭 배열 → O(M × N)
- `vit[54][54]`: 방문 체크 배열 → O(M × N)
- `queue<pair<int, int>>`: 최악의 경우 모든 칸 저장 → O(M × N)
- `dy[4]`, `dx[4]`: 방향 배열 → O(1) (상수)

**총 공간**: O(M × N) ≈ **O(2,500)** (M=N=50일 때)
