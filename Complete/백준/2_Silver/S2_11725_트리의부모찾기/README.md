## 🔗 문제 링크

[백준 11725번 - 트리의 부모 찾기](https://www.acmicpc.net/problem/11725)

**난이도**: Silver 2

---

## 🤔 접근법

루트가 없는 트리에서 **루트를 1번 노드로 정했을 때 각 노드의 부모를 구하는 문제**.

- 트리를 양방향 인접 리스트로 구성.
- 루트(1번)에서 BFS 탐색을 하면서, 방문 시 부모 노드를 기록.
- 2번부터 N번 노드의 부모를 순서대로 출력.

**핵심은 BFS로 루트부터 탐색하면서 `parent[next] = cur`를 기록하는 것!**

---

## 💡 정답 풀이 방법

**알고리즘** : BFS (Breadth-First Search) - 너비 우선 탐색

**핵심 아이디어**:
```
1. 양방향 인접 리스트 구성 (adj[u] ↔ adj[v])
2. 루트(1번)에서 BFS 시작, visited[1] = true
3. 큐에서 cur를 꺼내 인접 노드 next를 탐색
4. 미방문 next 발견 시 → visited[next] = true, parent[next] = cur
5. 2번 ~ N번 노드의 parent를 순서대로 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 양방향 인접 리스트 구성

```cpp
// 두 정점이 연결 → 양방향으로 저장
adj[u].push_back(v);
adj[v].push_back(u);
```

**✅ 핵심**: 루트 없는 트리이므로 양방향 저장
- BFS 탐색 시 어느 방향으로든 탐색 가능
- 방문 체크(visited)로 역방향 탐색 방지

### 2️⃣ BFS로 부모 기록

```cpp
for(int next : adj[cur])
{
    if(visited[next]) continue;

    visited[next] = true;   // 방문 처리
    parent[next]  = cur;    // cur가 next의 부모
    q.push(next);           // 큐에 추가
}
```

**✅ 핵심**: 처음 방문할 때의 방향이 부모-자식 관계
- BFS는 루트(1)에서 가까운 순서대로 탐색
- 처음 `next`를 발견한 `cur`가 `next`의 부모

### 3️⃣ 부모 출력

```cpp
for(int i = 2; i <= n; i++)
{
    cout << parent[i] << "\n";
}
```

**✅ 핵심**: 2번 ~ N번 노드 순서대로 출력
- 1번은 루트이므로 부모 없음 (출력 제외)

---

## ⏱️ 시간복잡도

**O(N)**

**분석**:
- 트리의 노드 수 N, 간선 수 N-1
- BFS로 모든 노드를 정확히 1번씩 방문
- 각 노드마다 인접 리스트 탐색 → 간선의 합 = O(N-1)

**실제 계산**:
```
- N ≤ 100,000
- 각 노드 1번 방문 → O(N) ≈ 10^5 << 10^8 (1초 기준)
```

**✅ 결론**: 충분히 시간 제한(1초) 내에 해결 가능

---

## 💾 공간복잡도

**O(N)**

**분석**:
- `vector<int> adj[100001]`: 인접 리스트 → O(N)
- `int parent[100001]`: 부모 배열 → O(N)
- `bool visited[100001]`: 방문 배열 → O(N)
- `queue<int>`: BFS 큐 → O(N)

**총 공간**: O(N) ≈ **O(100,000)**

## 🎯 알고리즘 분류

- **그래프 이론**: 트리를 인접 리스트로 모델링
- **그래프 탐색**: BFS로 부모 관계 탐색
- **트리**: 루트 지정 후 부모 찾기
- **너비 우선 탐색 (BFS)**: 레벨 순서로 탐색하여 부모 기록
