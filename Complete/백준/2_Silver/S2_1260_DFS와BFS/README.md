## 🔗 문제 링크
[백준 1260번 - DFS와 BFS](https://www.acmicpc.net/problem/1260)

**난이도**: Silver 2

---

## 🤔 접근법

그래프를 DFS와 BFS로 탐색한 결과를 출력하는 기본 그래프 탐색 문제.

방문할 수 있는 정점이 여러 개인 경우 **정점 번호가 작은 것을 먼저 방문**해야 하므로, 인접 리스트를 오름차순 정렬하는 것이 핵심.

DFS는 **재귀**, BFS는 **큐**로 구현.

---

## 💡 정답 풀이 방법

**알고리즘** : DFS (깊이 우선 탐색) + BFS (너비 우선 탐색)

1. **그래프 입력** : 양방향 간선을 인접 리스트(`vector<int> adj[]`)로 저장

2. **인접 리스트 정렬** : 정점 번호가 작은 것을 먼저 방문하기 위해 각 정점의 인접 리스트를 `sort()`로 오름차순 정렬

3. **DFS 탐색** : 시작 정점부터 재귀적으로 깊이 우선 탐색, `vit[]` 배열로 방문 체크

4. **방문 배열 초기화** : DFS 완료 후 `fill_n()`으로 visited 배열을 초기화하여 BFS에서 재사용

5. **BFS 탐색** : 큐를 사용해 너비 우선 탐색, **큐에 넣을 때** 방문 처리

---

## 🔑 핵심 개념

### 1️⃣ DFS (깊이 우선 탐색) - 재귀 방식

```cpp
void DFS(int cur)
{
    vit[cur] = true;         // 현재 정점 방문 처리
    cout << cur << " ";      // 방문 순서 출력

    for (int next : adj[cur])
    {
        if (vit[next]) continue; // 이미 방문한 정점 스킵
        DFS(next);               // 재귀 호출
    }
}
```

**동작 원리** :
- 현재 정점을 방문 처리하고 출력
- 인접 정점 중 미방문 정점을 재귀적으로 탐색
- 재귀 호출 스택이 DFS의 스택 역할 수행

### 2️⃣ BFS (너비 우선 탐색) - 큐 방식

```cpp
void BFS(int start)
{
    queue<int> bfsQ;
    vit[start] = true;      // 시작 정점 방문 처리
    bfsQ.emplace(start);    // 큐에 삽입

    while (!bfsQ.empty())
    {
        int cur = bfsQ.front(); // 현재 정점
        bfsQ.pop();
        cout << cur << " ";     // 방문 순서 출력

        for (int next : adj[cur])
        {
            if (vit[next]) continue; // 이미 방문한 정점 스킵
            vit[next] = true;        // 방문 처리
            bfsQ.emplace(next);      // 큐에 삽입
        }
    }
}
```

**동작 원리** :
- 시작 정점을 큐에 넣고 방문 처리
- 큐에서 꺼낸 정점의 인접 정점 중 미방문 정점을 큐에 삽입
- 가까운 정점부터 레벨 순서대로 탐색

### 3️⃣ BFS 방문 처리 시점

```cpp
// ✅ 큐에 넣을 때 방문 처리 (올바른 방법)
vit[next] = true;
bfsQ.emplace(next);

// ❌ 큐에서 꺼낼 때 방문 처리 (중복 삽입 발생)
int cur = bfsQ.front();
vit[cur] = true;  // 이미 큐에 중복으로 들어갈 수 있음!
```

**✅ 핵심** : BFS에서 방문 처리는 **큐에 삽입할 때** 해야 중복 방문을 방지할 수 있음

### 4️⃣ 인접 리스트 정렬

```cpp
for (int i = 1; i <= n; i++)
{
    sort(adj[i].begin(), adj[i].end());
}
```

**이유** : 문제에서 "방문할 수 있는 정점이 여러 개인 경우 정점 번호가 작은 것을 먼저 방문"이라는 조건이 있으므로, 인접 리스트를 오름차순 정렬

## 🔍 DFS vs BFS 비교

| 항목 | DFS (깊이 우선) | BFS (너비 우선) |
|-----|----------------|----------------|
| **자료구조** | 스택 (재귀 호출 스택) | 큐 |
| **탐색 순서** | 한 방향으로 끝까지 → 백트래킹 | 가까운 정점부터 레벨 순서 |
| **구현 방식** | 재귀 함수 | while + queue |
| **최단 경로** | 보장 ❌ | 보장 ✅ (가중치 없는 그래프) |
| **활용** | 경로 탐색, 백트래킹, 사이클 탐지 | 최단 거리, 레벨 탐색 |

---

**⏱️ 시간복잡도**: O(N + M) - N개 정점, M개 간선 (인접 리스트 기준)

**💾 공간복잡도**: O(N + M) - 인접 리스트 + 방문 배열 저장
