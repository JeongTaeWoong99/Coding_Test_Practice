## 🔗 문제 링크

[백준 14620번 - 꽃길](https://www.acmicpc.net/problem/14620)

**난이도**: Silver 2

---

## 🤔 접근법

N×N 화단에 3개의 꽃을 심는데, 각 꽃은 십자 모양(중심 1개 + 상하좌우 꽃잎 4개)으로 심어진다.

꽃잎끼리 겹치거나 화단 밖으로 나가면 안 되며, **최소 비용으로 3개의 꽃을 심는 문제**.

**핵심은 백트래킹으로 모든 가능한 위치 조합을 탐색**하되, 유효성 검사로 불가능한 경우를 빠르게 제외하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : 백트래킹 (Backtracking) + 완전 탐색

**핵심 아이디어**:
```
1. 화단의 모든 위치(i, j)를 순회하며 꽃을 심을 수 있는지 확인
2. Check() 함수로 중심과 4개 꽃잎 위치가 모두 유효한지 검증
3. SetFlower()로 꽃을 심고 비용 계산 + 방문 처리
4. 3개 꽃을 모두 심으면 최소 비용 갱신
5. EraseFlower()로 백트래킹 (다른 경우의 수 탐색 위해 상태 복원)
```

---

## 🔑 핵심 포인트

### 1️⃣ 백트래킹 패턴

```cpp
// 해당 위치에 꽃을 심을 수 있는지 확인
if(Check(i, j))
{
    // 꽃을 심고 재귀 호출 (비용 누적)
    Flower(cnt + 1, hap + SetFlower(i, j));

    // 백트래킹: 심었던 꽃 제거 (다른 경우의 수 탐색을 위해) ⭐
    EraseFlower(i, j);
}
```

**✅ 핵심**: 심기 → 재귀 → 제거의 3단계 패턴
- `SetFlower()`: 꽃을 심고 비용 반환, visited 배열 1로 설정
- 재귀 호출로 다음 꽃 심기
- `EraseFlower()`: visited 배열 0으로 복원 (백트래킹!)

### 2️⃣ 유효성 검사 (Check 함수)

```cpp
bool Check(int y, int x)
{
    // 1. 중심이 이미 사용된 위치인지 확인
    if(visited[y][x]) return 0;

    // 2. 상하좌우 4개 꽃잎 위치 확인
    for(int i = 0; i < 4; i++)
    {
        int ny = y + dy[i];
        int nx = x + dx[i];

        // 화단 밖 + 겹침 체크
        if(ny < 0 || ny >= N || nx < 0 || nx >= N || visited[ny][nx])
        {
            return 0;  // 하나라도 위반 시 심을 수 없음
        }
    }

    return 1;  // 모든 조건 만족
}
```

**✅ 핵심**: 중심 + 4개 꽃잎 모두 유효한지 검증
- 화단 범위 체크: `ny < 0 || ny >= N || nx < 0 || nx >= N`
- 겹침 체크: `visited[ny][nx]`
- **하나라도 조건 위반 시 즉시 false 반환**

### 3️⃣ 상태 관리 (SetFlower / EraseFlower)

```cpp
int SetFlower(int y, int x)
{
    int sum = 0;
    visited[y][x] = 1;  // 중심 방문 처리
    sum += arr[y][x];

    for(int i = 0; i < 4; i++)  // 4개 꽃잎
    {
        int ny = y + dy[i];
        int nx = x + dx[i];
        visited[ny][nx] = 1;      // 방문 처리
        sum += arr[ny][nx];       // 비용 누적
    }

    return sum;  // 총 5개 칸의 비용 반환
}

void EraseFlower(int y, int x)
{
    visited[y][x] = 0;  // 중심 방문 해제

    for(int i = 0; i < 4; i++)  // 4개 꽃잎
    {
        int ny = y + dy[i];
        int nx = x + dx[i];
        visited[ny][nx] = 0;  // 방문 해제
    }
}
```

**✅ 핵심**: SetFlower와 EraseFlower는 정확히 대칭 관계
- SetFlower: visited = 1, 비용 계산
- EraseFlower: visited = 0, 상태 복원
- **중심 + 4개 꽃잎 모두 처리**

## ⏱️ 시간복잡도

**O(N^2 × C(N^2, 3))** (이론상 최악의 경우)

C = 콤비네이션

**실제 분석**:
- N = 10 (최대값)
- 화단 크기 = 10 × 10 = 100칸
- 3개의 꽃을 심는 조합 ≈ C(100, 3) = 약 161,700가지
- 각 위치마다 Check() 함수 (O(4) = 상수)

**하지만 실제로는**:
```
- 많은 위치가 Check() 함수에서 조기 탈락
- 꽃은 십자 모양이므로 실제 가능한 중심 위치는 제한적
  (테두리 한 줄은 꽃잎이 화단 밖으로 나가므로 불가능)
- 유효한 조합 수는 이론값보다 훨씬 적음

실제 시간복잡도 ≈ O(10^6) 정도
```

**✅ 결론**: 충분히 시간 제한(2초) 내에 해결 가능

## 💾 공간복잡도

**O(N^2)**

**분석**:
- `arr[20][20]`: 화단 가격 배열 → O(N^2)
- `visited[20][20]`: 방문 체크 배열 → O(N^2)
- 재귀 스택: 최대 깊이 3 → O(1) (상수)

**총 공간**: O(N^2) ≈ **O(400)** (N=10일 때)
