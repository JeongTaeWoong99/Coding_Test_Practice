## 🔗 문제 링크

[백준 14627번 - 파닭파닭](https://www.acmicpc.net/problem/14627)

**난이도**: Silver 2

---

## 🤔 접근법

승균이는 S개의 파를 사서 C개의 파닭을 만들고, 남은 파로 라면을 끓이려 한다.

각 파닭에는 **같은 길이의 파**가 들어가야 하며, **가능한 한 많은 양의 파**를 넣고 싶어한다.

파닭에 넣을 파의 길이를 최대화하면서 C개의 파닭을 만든 후, **라면에 넣을 파의 양을 구하는 문제**.

**핵심은 이분 탐색(Parametric Search)**으로 파닭 하나당 넣을 수 있는 파의 최대 길이를 찾는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : 이분 탐색 (Binary Search) + 매개 변수 탐색 (Parametric Search)

**핵심 아이디어**:
```
1. 파닭 하나당 넣을 파의 길이를 이분 탐색으로 결정
2. Check() 함수로 특정 길이로 C개 이상의 파닭을 만들 수 있는지 검증
3. 가능하면 길이를 늘려보고 (lo = mid + 1), 불가능하면 줄임 (hi = mid - 1)
4. 최대 길이를 찾은 후, 전체 파 길이 - (파닭 1개당 길이 × C) = 라면에 넣을 파
```

---

## 🔑 핵심 포인트

### 1️⃣ 매개 변수 탐색 패턴

```cpp
ll lo = 1, hi = 1000000000;  // 파의 최소/최대 길이

while(lo <= hi)
{
    ll mid = (lo + hi) / 2;

    if(Check(mid))  // mid 길이로 C개 이상 만들 수 있으면
    {
        lo  = mid + 1;
        ret = mid;   // 가능한 최대 길이 갱신
    }
    else
    {
        hi = mid - 1;
    }
}
```

**✅ 핵심**: "최댓값의 최소화" 또는 "최솟값의 최대화" 문제는 매개 변수 탐색
- 파닭 하나당 파의 길이가 **클수록** 만들 수 있는 파닭 개수는 **감소**
- 파의 길이를 **이분 탐색으로 조정**하며 최적값 찾기

### 2️⃣ Check 함수 (결정 함수)

```cpp
bool Check(ll mid)
{
    ll cnt = 0;

    for(int i = 0; i < s; i++)
    {
        cnt += a[i] / mid;  // 각 파에서 만들 수 있는 파닭 개수
    }

    return cnt >= c;  // c개 이상 만들 수 있으면 true
}
```

**✅ 핵심**: mid 길이로 C개 이상의 파닭을 만들 수 있는지 확인
- 각 파를 mid 길이로 나눈 몫의 합 = 만들 수 있는 파닭 개수
- C개 이상 만들 수 있으면 true → 더 긴 길이를 시도해볼 수 있음
- C개 미만이면 false → 길이를 줄여야 함

### 3️⃣ 라면에 넣을 파의 양 계산

```cpp
cout << sum - ret * c << "\n";
```

**✅ 핵심**: 전체 파의 길이 - 파닭에 사용한 파의 길이
- `sum`: 모든 파의 길이 합
- `ret`: 파닭 하나당 넣을 파의 최대 길이
- `ret * c`: C개의 파닭에 사용한 총 파의 길이
- 나머지 = 라면에 넣을 파

### 4️⃣ long long 사용 필수

```cpp
typedef long long ll;

ll s, c, sum;
ll a[1000004];
ll ret;
```

**✅ 핵심**: 파의 길이 합이 int 범위를 초과할 수 있음
- 파의 개수 S: 최대 1,000,000
- 파의 길이 L: 최대 1,000,000,000
- 전체 합 sum: 최대 10^15 (int 범위: 약 2×10^9)
- **반드시 long long 사용!**

## 🔍 이분 탐색 동작 과정

**예제 입력**:
```
3 5
440
350
230
```

**이분 탐색 과정**:
```
초기: lo=1, hi=1000000000, sum=1020

1. mid=500000000
   → Check(500000000): 0개 (너무 긴 길이)
   → hi=499999999

2. mid=250000000
   → Check(250000000): 0개 (여전히 긴 길이)
   → hi=249999999

3. mid=125000000
   → Check(125000000): 3개 (부족)
   → hi=124999999

4. mid=175
   → Check(175): 2+2+1=5개 ✅
   → lo=176, ret=175

5. mid=176
   → Check(176): 2+1+1=4개 (부족)
   → hi=175

6. lo > hi → 종료
   → ret=175

결과: 1020 - 175*5 = 145 ✅
```

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ int 오버플로우

```cpp
❌ int sum = 0;  // 10^15 범위 초과!

✅ ll sum = 0;   // long long 필수
```

### 2️⃣ mid 계산 오버플로우 (이 문제는 괜찮지만 일반적으로)

```cpp
❌ ll mid = (lo + hi) / 2;  // lo+hi가 오버플로우 가능

✅ ll mid = lo + (hi - lo) / 2;  // 안전한 방법
```

### 3️⃣ 0으로 나누기 방지

```cpp
bool Check(ll mid)
{
    if(mid == 0) return false;  // 필요시 예외 처리
    // ...
}
```

이 문제는 `lo=1`로 시작하므로 mid가 0이 될 수 없지만, 다른 문제에서는 주의!

### 4️⃣ 전체 합 계산 누락

```cpp
for(int i = 0; i < s; i++)
{
    cin >> a[i];
    sum += a[i];  // 입력과 동시에 합 계산
}
```

## ⏱️ 시간복잡도

**O(S × log(최대파길이))**

**상세 분석**:
```
1. 이분 탐색 범위: 1 ~ 1,000,000,000
   → log₂(10^9) ≈ 30회 반복

2. 각 이분 탐색마다 Check() 함수 호출
   → Check()는 S개의 파를 순회: O(S)

3. 총 시간복잡도
   → O(S × log(10^9))
   → O(1,000,000 × 30)
   → O(30,000,000) ≈ O(3×10^7) ✅
```

**✅ 결론**: 충분히 시간 제한(2초) 내에 해결 가능

---

## 💾 공간복잡도

**O(S)**

**분석**:
- `a[1000004]`: 파의 길이 배열 → O(S)
- `s, c, sum, ret, lo, hi, mid`: 상수 변수 → O(1)

**총 공간**: O(S) ≈ **O(10^6)** (S=1,000,000일 때)

## 🎯 알고리즘 분류

- **이분 탐색(Binary Search)**: 파의 길이를 이분 탐색으로 결정
- **매개 변수 탐색(Parametric Search)**: "최댓값의 최소화" 또는 "최솟값의 최대화" 문제 유형
- **결정 문제(Decision Problem)**: Check() 함수로 가능 여부 판단
