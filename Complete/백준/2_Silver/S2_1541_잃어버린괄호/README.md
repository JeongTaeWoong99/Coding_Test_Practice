## 🤔 접근법

(문제를 보다 보니, -뒤를 다 뺄 수 있다는걸 발견함.)

양수와 `+`, `-`로 이루어진 식에서 괄호를 적절히 쳐서 **식의 값을 최소로** 만드는 문제.

**핵심 관찰**:
- `+`는 순리대로 가는 것이고, `-`를 어떻게 묶느냐가 관건
- `-` 뒤에 나오는 `+` 연산들은 괄호로 감싸면 전부 `-`로 바뀜!
- ★ 즉, **첫 번째 `-`가 나온 순간, 그 뒤의 모든 숫자는 빼기 처리**하면 최솟값

**예시**:
```
55-50+40 → 55-(50+40) → 55-90 = -35  ✅ 최솟값!
```

---

## 💡 정답 풀이 방법

### 🎯 방법: 그리디 (Greedy)

1. **문자열을 한 글자씩 순회**하며 숫자를 파싱


2. **연산자 or 끝**을 만나면 → 파싱된 숫자 처리
   - 아직 `-`를 못 만났으면 → **더하기**
   - `-`를 만난 적 있으면 → **빼기**


3. **`-`를 처음 만나면 플래그 ON** → 이후 모든 숫자를 빼기

---

## 🔑 핵심 개념

### 1️⃣ 왜 첫 `-` 이후 전부 빼면 최솟값인가?

```
a - b + c + d - e + f

괄호 적용:
a - (b + c + d) - (e + f)
= a - b - c - d - e - f

→ '-' 뒤의 '+'는 괄호로 감싸면 전부 '-'가 됨!
→ 따라서 첫 '-' 이후의 모든 숫자를 빼는 것이 최적
```

### 2️⃣ 문자열에서 숫자 파싱 (num = num * 10 + (s[i] - '0'))

문자열 `"50"`을 숫자 `50`으로 조립하는 과정:

```
처음    : num = 0
'5' 읽기 : num = 0 * 10 + ('5' - '0') = 0 + 5  = 5
'0' 읽기 : num = 5 * 10 + ('0' - '0') = 50 + 0 = 50  ✅
```

**원리 분해**:

| 부분 | 역할 | 예시 |
|------|------|------|
| `s[i] - '0'` | 문자 → 숫자 변환 (ASCII 차이) | `'5' - '0'` = 53 - 48 = **5** |
| `num * 10` | 기존 숫자를 왼쪽으로 한 자리 밀기 | 5 → **50** |
| `+ 새 숫자` | 1의 자리에 새 숫자 추가 | 50 + 0 = **50** |

**더 큰 숫자 예시** (`"123"`):
```
num = 0
'1' : num = 0  * 10 + 1 = 1
'2' : num = 1  * 10 + 2 = 12
'3' : num = 12 * 10 + 3 = 123  ✅
```

### 3️⃣ 동작 과정 시뮬레이션

```
입력: "55-50+40"

i=0: '5' → num = 5
i=1: '5' → num = 55
i=2: '-' → result += 55 = 55, isMinus = true, num = 0
i=3: '5' → num = 5
i=4: '0' → num = 50
i=5: '+' → result -= 50 = 5, num = 0     ← isMinus이므로 빼기!
i=6: '4' → num = 4
i=7: '0' → num = 40
i=8: 끝  → result -= 40 = -35            ← isMinus이므로 빼기!

결과: -35 ✅
```

## ⏱️ 시간복잡도

**O(N)**

**상세 분석**:
```
1. 문자열 순회: O(N)
   - N = 문자열 길이 (최대 50)
   - 각 문자마다 O(1) 연산

총합: O(N)
```

**시간 제한 체크**:
- N ≤ 50 (문제 조건)
- **50 연산** << **1억** → 여유롭게 통과 ✅

---

## 💾 공간복잡도

**O(N)** - 문자열 저장

**분석**:
- `s`: 입력 문자열 - O(N)
- `result`, `num`, `isMinus`: 상수 변수 - O(1)

## 🎯 알고리즘 분류

- **그리디(Greedy)**: 첫 `-` 이후 모든 숫자를 빼는 탐욕적 선택
- **문자열 파싱(String Parsing)**: 문자열에서 숫자를 한 글자씩 조립
- **수학(Math)**: 괄호의 성질을 이용한 최솟값 도출
