## 🔗 문제 링크

[백준 15663번 - N과 M (9)](https://www.acmicpc.net/problem/15663)

**난이도**: Silver 2

---

## 🤔 접근법

N개의 자연수(중복 가능) 중에서 M개를 골라 길이 M인 수열을 만드는 문제.

같은 값이 여러 번 등장할 수 있고, **중복 수열은 한 번만 출력**해야 한다.

**핵심은 입력을 정렬하고, 같은 깊이에서 같은 값을 두 번 시도하지 않는 것!**

---

## 💡 정답 풀이 방법

**알고리즘**: 백트래킹 (Backtracking) / next_permutation

**핵심 아이디어**:
```
1. 입력을 정렬하여 같은 값이 인접하도록 만들기
2. 같은 깊이에서 이전에 사용한 값과 동일하면 건너뛰기 (중복 수열 제거)
3. visited[] 배열로 같은 인덱스를 두 번 사용하지 않도록 방지
4. m개를 모두 선택하면 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 두 방법 비교 (Answer 파일 2개)

이 문제는 **2가지 방식**으로 풀 수 있다:

#### 방법 1 : 백트래킹 (Answer(백트래킹).cpp.txt)

```cpp
int prev = -1; // 같은 깊이에서 이전에 사용한 값
for (int i = 0; i < n; i++)
{
    if (visited[i])    continue; // 이미 사용한 인덱스
    if (v[i] == prev)  continue; // 같은 깊이에서 같은 값 → 중복 수열 방지

    visited[i] = true;
    seq.push_back(v[i]);
    prev = v[i]; // ← 핵심: 현재 값을 기억해서 다음 반복에서 중복 차단

    Back(depth + 1);

    visited[i] = false;
    seq.pop_back();
}
```

**✅ 장점**:
- 중복 수열을 처음부터 생성하지 않음 (가지치기)
- 추가 메모리 없음
- 빠름

**⚠️ 단점**:
- `prev` 변수와 `visited[]` 두 가지를 동시에 관리해야 해서 약간 복잡

---

#### 방법 2 : next_permutation (Answer(next_permutation).cpp.txt)

```cpp
set<vector<int>> result; // 중복 수열 자동 제거 + 사전순 정렬

do
{
    // 전체 순열의 앞 m개만 잘라서 저장
    result.insert(vector<int>(v.begin(), v.begin() + m));
} 
while (next_permutation(v.begin(), v.end()));

for (const auto& seq : result)
{
    for (int x : seq) 
        cout << x << " ";
    cout << "\n";
}
```

**✅ 장점**:
- 구현이 매우 간단
- `set`이 중복 제거와 사전순 정렬을 자동으로 처리
- 로직을 직관적으로 이해하기 쉬움

**⚠️ 단점**:
- N개의 전체 순열(최대 8! = 40,320가지)을 모두 생성한 후 처리
- `set<vector<int>>` 삽입/조회가 O(M log K) (K는 결과 수)
- 백트래킹보다 느리고 메모리를 더 씀

### 2️⃣ 이전 N과 M 문제들과의 차이점

```
N과 M (1~4) : 1~N 고유한 숫자를 사용
N과 M (9)   : 입력에 중복값이 존재할 수 있음
              → 같은 수열이 나오면 한 번만 출력해야 함
```

---

### 3️⃣ 중복 제거 원리 (백트래킹)

```
정렬된 배열: [1, 7, 9, 9]
                       ↑  ↑
                    idx2  idx3 (값이 동일)

depth=0에서 idx2(값=9) 처리 완료 → prev = 9
depth=0에서 idx3(값=9) 시도 → v[3] == prev(9) → SKIP!

결과: [9,1], [9,7], [9,9]는 idx2로만 시작, idx3는 건너뜀
```

**✅ 핵심**: `prev`는 같은 깊이(depth)에서만 유효, 지역변수로 선언하기 때문에 다음 재귀 깊이에서는 다시 -1로 초기화됨

---

### 4️⃣ 어떤 방법을 선택해야 하는가?

| 상황 | 추천 방법 |
|------|-----------|
| 빠른 구현이 필요할 때 | next_permutation |
| 입력 크기가 크거나 시간 제한이 엄격할 때 | 백트래킹 |
| N, M이 작고 (N ≤ 8) 시간 여유가 있을 때 | 둘 다 통과 가능 |
| 일반화 / 응용이 필요할 때 | 백트래킹 (조건 변경 용이) |

**📌 이 문제의 경우**: N ≤ 8이므로 두 방법 모두 통과 가능하지만, **백트래킹이 정석**이며 더 효율적이다.

## ⏱️ 시간복잡도

**백트래킹**: O(N! / (N-M)!) with pruning
- 최악의 경우 N=8, M=8 → 8! = 40,320
- 중복 제거로 실제 탐색 수는 훨씬 적음

**next_permutation**: O(N! × M log K)
- N개의 모든 순열 생성: O(N!)
- 각 순열에서 앞 M개를 set에 삽입: O(M log K)
- K : 유일한 수열의 개수

---

## 💾 공간복잡도

**백트래킹**: O(N + M)
- `visited[8]` 배열: O(N)
- `seq` 벡터: O(M)
- 재귀 스택: O(M)

**next_permutation**: O(K × M)
- `set<vector<int>>` : K개의 수열, 각 길이 M
- K : 유일한 수열의 개수 (최대 P(N,M))
