## 🔗 문제 링크

[백준 15666번 - N과 M (12)](https://www.acmicpc.net/problem/15666)

**난이도**: Silver 2

---

## 🤔 접근법

N개의 자연수(중복 가능) 중에서 M개를 골라 **비내림차순(오름차순 허용, 같은 값 허용)** 수열을 만드는 문제.

같은 수를 여러 번 골라도 되며, **중복 수열은 한 번만 출력**해야 한다.

**핵심은 입력을 정렬하고, start 인덱스를 넘겨 비내림차순을 보장하며, 같은 깊이에서 같은 값을 두 번 시도하지 않는 것!**

---

## 💡 정답 풀이 방법

**알고리즘**: 백트래킹 (Backtracking)

**핵심 아이디어**:
```
1. 입력을 정렬하여 같은 값이 인접하도록 만들기
2. Back(depth, start) — start 인덱스부터 탐색 (비내림차순 보장)
3. 재귀 시 i+1이 아닌 i를 전달 (같은 값 재선택 허용 = 중복 선택)
4. 같은 깊이에서 이전에 사용한 값과 동일하면 건너뛰기 (중복 수열 제거)
5. m개를 모두 선택하면 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 두 방법 비교 (Answer 파일 2개)

이 문제는 **2가지 방식**으로 풀 수 있다:

#### 방법 1 : set 방식 (Answer(set방식).cpp.txt)

```cpp
set<vector<int>> setV; // 중복 수열 자동 제거 + 사전순 정렬

void Back(int depth, int start)
{
    if (depth == m)
    {
        setV.emplace(curV); // set이 중복 제거 처리
        return;
    }

    for (int i = start; i < n; ++i)
    {
        curV.push_back(idx[i]);
        Back(depth + 1, i); // i → 재선택 허용
        curV.pop_back();
    }
}
```

**✅ 장점**:
- 구현이 단순하고 직관적
- `set`이 중복 제거와 사전순 정렬을 자동으로 처리

**⚠️ 단점**:
- 중복 수열을 생성한 후 나중에 set에서 걸러냄 (불필요한 탐색 발생)
- `set<vector<int>>` 삽입 비용 O(M × log K) 누적
- 모든 수열을 메모리에 저장

---

#### 방법 2 : prev 방식 최적화 (Answer(prev방식_최적화).cpp.txt)

```cpp
void Back(int depth, int start)
{
    if (depth == m)
    {
        for (int x : curV) cout << x << " ";
        cout << "\n";
        return;
    }

    int prev = -1; // 같은 깊이에서 직전 선택값

    for (int i = start; i < n; ++i)
    {
        if (idx[i] == prev) continue; // 중복 수열 생성 자체를 차단

        prev = idx[i];

        curV.push_back(idx[i]);
        Back(depth + 1, i); // i → 재선택 허용
        curV.pop_back();
    }
}
```

**✅ 장점**:
- 중복 수열을 처음부터 생성하지 않음 (가지치기)
- `set` 없이 즉시 출력 → 메모리 추가 불필요
- 더 빠름

**⚠️ 단점**:
- `prev` 변수 관리를 신경 써야 함 (지역변수이므로 깊이마다 독립적)

### 2️⃣ N과 M (9) vs N과 M (12) 차이점

```
N과 M (9)  : 같은 인덱스를 두 번 사용 불가 (visited[] 필요)
              → Back(depth+1) 재귀 시 visited[] 로 방문 체크

N과 M (12) : 같은 수를 여러 번 골라도 됨 (visited[] 불필요)
              → Back(depth+1, i) 재귀 시 i를 그대로 전달 (i+1 아님)
```

| 항목 | N과 M (9) | N과 M (12) |
|------|-----------|------------|
| 중복 선택 | ❌ 불가 | ✅ 허용 |
| visited[] | ✅ 필요 | ❌ 불필요 |
| 재귀 인자 | `Back(depth+1)` + `visited` | `Back(depth+1, i)` |
| 비내림차순 | ❌ (순열) | ✅ (조합 형태) |

---

### 3️⃣ 중복 제거 원리 (prev 방식)

```
정렬된 배열: [2, 4, 4], M=1

depth=0, start=0
  i=0 → idx[0]=2, prev=2 → 출력: 2
  i=1 → idx[1]=4, prev=4 → 출력: 4
  i=2 → idx[2]=4, idx[2]==prev(4) → SKIP! ✅

결과: "2", "4" (중복 없음)
```

**✅ 핵심**: `prev`는 같은 깊이에서만 유효 — 지역변수로 선언되어 다음 재귀 깊이에서는 -1로 초기화됨

---

### 4️⃣ 어떤 방법을 선택해야 하는가?

| 상황 | 추천 방법 |
|------|-----------|
| 빠른 구현이 필요할 때 | set 방식 |
| 입력 크기가 크거나 시간 제한이 엄격할 때 | prev 방식 |
| N, M이 작고 (N ≤ 8) 시간 여유가 있을 때 | 둘 다 통과 가능 |
| 일반화 / 응용이 필요할 때 | prev 방식 (조건 변경 용이) |

**📌 이 문제의 경우**: N ≤ 8이므로 두 방법 모두 통과 가능하지만, **prev 방식이 정석**이며 더 효율적이다.

## ⏱️ 시간복잡도

**set 방식**: O(N^M × M log K)
- 전체 수열 탐색: O(N^M) (비내림차순이므로 실제로는 훨씬 적음)
- 각 수열을 set에 삽입: O(M log K) (K : 유일한 수열의 개수)

**prev 방식**: O(C(N+M-1, M))
- 중복 조합의 수만큼 탐색 (불필요한 탐색 없음)
- 최악: N=8, M=8 → C(15,8) = 6,435

---

## 💾 공간복잡도

**set 방식**: O(K × M)
- `set<vector<int>>` : K개의 수열, 각 길이 M
- K : 유일한 수열의 개수

**prev 방식**: O(M)
- `curV` 벡터: O(M)
- 재귀 스택: O(M)
