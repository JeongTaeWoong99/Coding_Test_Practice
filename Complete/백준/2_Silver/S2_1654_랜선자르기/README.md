## 🔗 문제 링크
[백준 1654번 - 랜선 자르기](https://www.acmicpc.net/problem/1654)

**난이도**: Silver 2

---

## 🤔 접근법

(이분 탐색으로 풀 수 있는 문제.)

K개의 랜선을 잘라서 N개의 같은 길이 랜선을 만들 때, **최대 길이**를 구하는 문제.

랜선 길이가 최대 2^31-1까지이므로, 모든 길이를 하나씩 시도하면 시간 초과.

**핵심:** "이 길이로 자르면 N개 이상 만들 수 있나?"를 **이분 탐색**으로 판별하는 **매개 변수 탐색** 문제!

---

## 💡 정답 풀이 방법

**알고리즘** : 이분 탐색 (Binary Search) / 매개 변수 탐색 (Parametric Search)

1. **탐색 범위 설정** : `lef = 1`, `rit = 가장 긴 랜선 길이`

2. **중간값으로 판별** : `mid = (lef + rit) / 2`로 잘랐을 때 N개 이상 만들 수 있는지 확인

3. **범위 축소** :
   - `cnt >= N` → 더 긴 길이 가능 → `lef = mid + 1`, `maxRet = mid` 갱신
   - `cnt < N` → 길이 줄여야 함 → `rit = mid - 1`

4. **종료** : `lef > rit`이 되면 `maxRet`이 정답

---

## 🔑 핵심 포인트

### 1️⃣ long long 필수

```cpp
long long lenth[10004];       // 길이가 2^31-1까지
long long mid, lef, rit, cnt; // 이분 탐색 변수도 long long
```

**이유:**
- 랜선 길이가 최대 2^31-1 = 2,147,483,647
- `int` 범위(약 21억)의 경계값이라 `(lef + rit)` 계산 시 오버플로우 발생
- 반드시 `long long` 사용!

### 2️⃣ 이분 탐색 핵심 3가지

```cpp
// ① 중간값 계산 : (lef + rit) / 2  ← /2 빠뜨리면 안 됨!
mid = (lef + rit) / 2;

// ② 범위 축소 : +1, -1 필수 (무한루프 방지)
lef = mid + 1;
rit = mid - 1;

// ③ 종료 조건 : lef <= rit
while (lef <= rit)
```

### 3️⃣ 답 저장 방식

```cpp
if (cnt >= n)
{
    maxRet = mid;  // ★ cnt(갯수)가 아니라 mid(길이)를 저장!
    lef = mid + 1;
}
```

**주의:** 구하는 답은 "몇 개 만들 수 있는지"가 아니라 **"최대 길이"**이므로 `mid`를 저장

## 🚨 주의할 점

### ❌ 흔한 실수들

```cpp
❌ int lenth[10004];           // int 오버플로우!
✅ long long lenth[10004];     // long long 필수

❌ mid = lef + rit;            // /2 빠뜨림!
✅ mid = (lef + rit) / 2;      // 이분 탐색 중간값

❌ rit = 1000000;              // 범위 부족! (최대 21억)
✅ rit = max(lenth[i], rit);   // 입력값 기준으로 설정

❌ maxRet = max(cnt, maxRet);  // 갯수를 저장하면 안 됨!
✅ maxRet = mid;               // 길이를 저장해야 함
```

## ⏱️ 시간복잡도

**O(K × log(max_length))**

**상세 분석**:
```
1. 이분 탐색 범위: 1 ~ max(랜선 길이)
   → 최대 2^31-1 ≈ 2×10^9
   → log₂(2×10^9) ≈ 31회 반복

2. 각 이분 탐색마다 K개 랜선 순회: O(K)

3. 총 시간복잡도
   → O(K × log(2×10^9))
   → O(10,000 × 31)
   → O(310,000) ≈ O(3×10^5) ✅
```

**✅ 결론**: 시간 제한(2초) 내에 충분히 해결 가능

---

## 💾 공간복잡도

**O(K)**

**분석**:
- `lenth[10004]`: 랜선 길이 배열 → O(K)
- `k, n, mid, lef, rit, cnt, maxRet`: 상수 변수 → O(1)

**총 공간**: O(K) ≈ **O(10^4)** (K=10,000일 때)
