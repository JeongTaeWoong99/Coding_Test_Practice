## 🤔 접근법

N×M 크기의 집터에서 모든 땅의 높이를 동일하게 만드는 '땅 고르기' 작업을 해야 한다.

- 블록 제거 (인벤토리에 넣기): **2초**
- 블록 놓기 (인벤토리에서 꺼내기): **1초**
- 인벤토리에 초기 블록 B개 보유

**최소 시간과 그때의 땅 높이를 구하는 문제**.

같은 시간이면 높이가 가장 높은 것을 출력.

**핵심은 브루트포스로 모든 가능한 높이(0~256)를 시도**하며, 각 높이에서의 소요 시간을 계산하여 최소를 찾는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : 브루트포스 (Brute Force)

**핵심 아이디어**:
```
1. 목표 높이를 0부터 256까지 전부 시도
2. 각 높이에 대해 제거/놓기 블록 수 계산
3. 인벤토리 블록이 충분한지 검증
4. 시간 계산 후 최소 시간 갱신 (같으면 높이 높은 쪽)
```

**📁 풀이 2가지**:

| 파일 | 방식 | 결과 |

| `Answer(성공_브루트포스+계수정렬).cpp.txt` | 계수정렬 최적화 | 2020KB / 12ms |

## 🔑 핵심 포인트

### 1️⃣ 브루트포스 탐색 (기본)

```cpp
// ★ 원본 맵 입력
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        cin >> ar[i][j];

// 브루트포스(모든 높이 비교)
for (int curHeight = 0; curHeight <= 256; curHeight++)
{
    int removBlk = 0;
    int placeBlk = 0;

    // ★ 원본 배열과 모든 높이에 대해 비교
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
        {
            int diff = ar[i][j] - curHeight;

            if (diff > 0) removBlk += diff; // 현재가 높으면 제거
            else          placeBlk -= diff; // 현재가 낮으면 채우기
        }
}
```

**✅ 핵심**: 높이 범위가 0~256으로 작아서 완전 탐색 가능
- `diff > 0` : 현재 높이가 목표보다 높음 → 블록 제거
- `diff < 0` : 현재 높이가 목표보다 낮음 → 블록 놓기 (`-diff`로 양수 변환)

### 2️⃣ 인벤토리 검증

```cpp
// 제거한 블록 + 보유 블록 >= 놓아야 할 블록
if (removBlk + b < placeBlk) continue;
```

**✅ 핵심**: 블록이 부족하면 해당 높이는 불가능
- 제거한 블록은 인벤토리에 추가됨
- 총 사용 가능 블록 = `removBlk + b`

### 3️⃣ 시간 계산 및 최소 갱신

```cpp
int time = removBlk * 2 + placeBlk * 1;

// 같은 시간이면 높이가 높은 쪽 선택
if (time <= minTime)
{
    minTime   = time;
    goalHight = curHeight;
}
```

**✅ 핵심**: `<=` 비교로 같은 시간이면 자동으로 높이 큰 쪽 선택
- 0부터 오름차순으로 탐색하므로, `<=`이면 나중에 나온 (더 높은) 높이로 갱신

## ⚡ 최적화 : 계수정렬 (Counting Sort)

### 🔍 기본 풀이의 비효율

기본 브루트포스에서는 **목표 높이마다 N×M 배열 전체를 순회**한다.

```
목표 높이 0일 때 : ar[0][0], ar[0][1], ... ar[499][499] 전부 비교
목표 높이 1일 때 : ar[0][0], ar[0][1], ... ar[499][499] 전부 비교
...
목표 높이 256일 때 : ar[0][0], ar[0][1], ... ar[499][499] 전부 비교

→ 257 × 500 × 500 = 64,250,000번 연산
```

하지만 실제로 필요한 정보는 **"높이 h인 칸이 몇 개인가?"** 뿐이다.

### 💡 계수정렬로 최적화

```cpp
// ★ 계수정렬 : 높이별 칸 개수 세기
int h;
for (int i = 0; i < n; i++)
{
    for (int j = 0; j < m; j++)
    {
        cin >> h;
        num[h]++;  // num[높이] = 해당 높이인 칸의 개수
    }
}
```

**입력 단계에서 `num[h]`에 높이별 개수를 세놓으면**, 원본 배열 `ar[504][504]` 자체가 불필요하다.

### ⭐ 핵심 변경점

```cpp
// 기본 : N×M 배열 전체 순회
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
    {
        int diff = ar[i][j] - curHeight;
        if (diff > 0) removBlk += diff;
        else          placeBlk -= diff;
    }

// 최적화 : 0~256만 순회
for (int i = 0; i <= 256; i++)
{
    if (num[i] == 0) continue;          // ★ 해당 높이 칸 없으면 스킵
    int diff = i - curHeight;
    if (diff > 0) removBlk += diff * num[i]; // ★ (차이 × 칸 수)로 한번에 계산
    else          placeBlk -= diff * num[i];
}
```

**✅ 핵심**:
- `diff * num[i]` : 높이 `i`인 칸이 `num[i]`개이므로, 한 번에 모든 칸의 블록 수 계산
- `num[i] == 0` : 해당 높이의 칸이 없으면 아예 스킵
- 내부 루프가 `N×M` → `257`로 대폭 감소

### 📊 비교 시각화

```
기본 브루트포스                        계수정렬 최적화
───────────────────                   ───────────────────
ar[504][504] 사용 (1MB)               num[257] 사용 (1KB)

목표 높이마다:                         목표 높이마다:
  for i = 0 ~ N                         for i = 0 ~ 256
    for j = 0 ~ M                         if num[i] == 0 → 스킵
      칸 하나씩 비교                        (차이 × 개수)로 한번에

내부 루프: N × M = 250,000             내부 루프: 최대 257
총 연산: 257 × 250,000                 총 연산: 257 × 257
       = 64,250,000                           = 66,049
```

## ⏱️ 시간복잡도

### 기본 브루트포스

**O(257 × N × M)**

**분석**:
- 높이 범위: 0 ~ 256 (257가지)
- 각 높이마다 N × M 배열 전체 순회
- 총: O(257 × N × M)

**실제 계산**:
```
N = 500, M = 500 (최대)
257 × 500 × 500 = 64,250,000 ≈ 6.4 × 10^7
6.4 × 10^7 < 10^8 (1초 기준)
→ 시간 제한(1초, 추가 시간 없음) 내 통과 ✅
```

### 계수정렬 최적화

**O(N × M + 257²)**

**분석**:
- 입력 시 계수정렬: O(N × M)
- 브루트포스 비교: O(257 × 257) = O(66,049)
- 총: O(N × M + 66,049)

**실제 계산**:
```
N = 500, M = 500 (최대)
입력: 500 × 500 = 250,000
비교: 257 × 257 = 66,049
총: 316,049 ≈ 3.2 × 10^5

기본 대비 약 200배 빠름 ⚡
```
