## 🔗 문제 링크

[백준 1874번 - 스택 수열](https://www.acmicpc.net/problem/1874)

**난이도**: Silver 2

---

## 🤔 접근법

(언제나 문제를 이해하는게 제일  어렵다. 문제를 이해하면 쉽다)

1부터 n까지의 수를 스택에 넣었다가 뽑아서 주어진 수열을 만들 수 있는지 판단하는 문제.

**핵심 제약 조건**:
- push는 **반드시 오름차순** (1, 2, 3, ... n 순서)으로만 가능
- 한 번 push한 숫자는 다시 push할 수 없음

**핵심**: 목표 숫자가 나올 때까지 push하고, 스택의 top이 목표와 같으면 pop. top이 목표와 다르면 불가능!

---

## 💡 정답 풀이 방법

**알고리즘**: 스택 (Stack) + 시뮬레이션

**핵심 아이디어**:
```
1. 목표 숫자(target)가 입력되면

2. 현재까지 push한 숫자(cur)부터 target까지 모두 push

3. 스택의 top이 target과 같으면 pop

4. top이 target과 다르면 "NO" 출력 후 종료

5. 모든 숫자를 성공적으로 처리하면 연산 결과 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 왜 불가능한 경우가 생기는가?

```
수열: [1, 2, 5, 3, 4]

target=1: push(1) → pop → [1] ✅

target=2: push(2) → pop → [2] ✅

target=5: push(3,4,5) → pop → [5] ✅
          스택 상태: [3, 4]
          
target=3: top=4 ≠ 3 → ❌ 불가능!
```

**이유**: 3을 꺼내려면 4를 먼저 꺼내야 하는데, 4는 3보다 나중에 나와야 함!

### 2️⃣ cur 변수의 역할

```cpp
int cur = 1;  // 다음에 push할 숫자

while (cur <= target)
{
    stk.push(cur);
    cur++;
    
    result += "+\n";
}
```

**✅ 핵심**:
- `cur`은 "다음에 push할 수 있는 가장 작은 숫자"
- 한 번 증가하면 절대 감소하지 않음 (오름차순 push 보장)
- `cur > target`이면 더 이상 push할 필요 없음

### 3️⃣ 스택 top 검사

```cpp
if (!stk.empty() && stk.top() == target)
{
    stk.pop();
    
    result += "-\n";
}
else
{
    possible = false;  // 불가능!
    break;
}
```

**✅ 핵심**:
- target까지 모두 push한 후, top이 target이어야 pop 가능
- top ≠ target이면 해당 수열은 만들 수 없음

### 4️⃣ 결과 저장 방식

```cpp
string result;  // 연산 결과 저장

result += "+";
result += "\n";
```

**✅ 장점**:
- 매번 출력하지 않고 문자열에 저장
- 불가능한 경우 바로 "NO"만 출력 가능
- 입출력 최적화로 빠른 실행

## 📊 예제 분석

### 예제 1: 수열 [4, 3, 6, 8, 7, 5, 2, 1]

| target | 동작 | 스택 상태 | 연산 |
|--------|------|-----------|------|
| 4 | push(1,2,3,4), pop | [1,2,3] | ++++- |
| 3 | pop | [1,2] | - |
| 6 | push(5,6), pop | [1,2,5] | ++- |
| 8 | push(7,8), pop | [1,2,5,7] | ++- |
| 7 | pop | [1,2,5] | - |
| 5 | pop | [1,2] | - |
| 2 | pop | [1] | - |
| 1 | pop | [] | - |

**결과**: 가능 ✅

### 예제 2: 수열 [1, 2, 5, 3, 4]

| target | 동작 | 스택 상태 | 연산 |
|--------|------|-----------|------|
| 1 | push(1), pop | [] | +- |
| 2 | push(2), pop | [] | +- |
| 5 | push(3,4,5), pop | [3,4] | +++- |
| 3 | top=4 ≠ 3 | ❌ | NO |

**결과**: 불가능 ❌

## ⏱️ 시간복잡도 분석

**전체 시간복잡도**: **O(n)**

**분석**:
- 각 숫자는 최대 1번 push, 최대 1번 pop
- push 총 횟수: n번
- pop 총 횟수: n번
- 총 연산: 2n = **O(n)**

**시간 제한 체크**:
- n ≤ 100,000
- 약 200,000 연산 << 2억 (2초 기준) → **여유롭게 통과** ✅

## 💾 공간복잡도

**O(n)**
- `stack<int> stk`: 최대 n개 저장 - O(n)
- `string result`: 최대 2n개 문자 - O(n)
