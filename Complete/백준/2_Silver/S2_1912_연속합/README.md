## 🔗 문제 링크

[백준 1912번 - 연속합](https://www.acmicpc.net/problem/1912)

**난이도**: Silver 2

---

## 🤔 접근법

(너무 어렵게 생각함. 의외로 쉽게 풀 수 있음.)

n개의 정수로 이루어진 수열에서 연속된 몇 개의 수를 선택하여 구할 수 있는 합 중 **가장 큰 합**을 구하는 문제.

**핵심**: Kadane's Algorithm (카데인 알고리즘)을 활용한 동적 계획법으로 O(N)에 해결.

---

## 💡 정답 풀이 방법

### 🎯 방법: Kadane's Algorithm

1. **연속합 누적**: 현재 수를 연속합에 계속 추가

2. **최댓값 갱신**: 매 단계마다 최댓값 갱신

3. **음수 처리**: 연속합이 음수가 되면 0으로 초기화 (새로 시작)

**시간복잡도**: O(N) - 한 번의 순회로 해결

---

## 🔑 핵심 개념

### 🔍 Kadane's Algorithm 원리

```cpp
for(int i = 0; i < n; i++)
{
    cin >> newNum;

    curSum += newNum;           // 현재 수를 연속합에 추가
    maxRet = max(maxRet, curSum); // 최댓값 갱신

    if(curSum < 0)              // 음수가 되면 초기화
        curSum = 0;
}
```

**동작 과정 예시**:
```
입력: [10, -4, 3, 1, 5, 6, -35, 12, 21, -1]

i=0: newNum=10  → curSum=10,  maxRet=10
i=1: newNum=-4  → curSum=6,   maxRet=10
i=2: newNum=3   → curSum=9,   maxRet=10
i=3: newNum=1   → curSum=10,  maxRet=10
i=4: newNum=5   → curSum=15,  maxRet=15
i=5: newNum=6   → curSum=21,  maxRet=21
i=6: newNum=-35 → curSum=-14, maxRet=21 → curSum=0 (초기화!)
i=7: newNum=12  → curSum=12,  maxRet=21
i=8: newNum=21  → curSum=33,  maxRet=33 ✅
i=9: newNum=-1  → curSum=32,  maxRet=33

결과: 33 (12 + 21)
```

### 🧠 왜 이 알고리즘이 작동하는가?

**핵심 아이디어**:
- 현재까지의 합이 **음수가 되면 버리고 새로 시작**하는 것이 항상 유리함
- 음수인 부분을 포함하면 다음 양수 구간의 합을 감소시키기 때문

**예시**:
```
[..., -10, 5, 3, ...]

Case 1 (음수 포함): -10 + 5 + 3 = -2
Case 2 (새로 시작):      5 + 3 = 8  ✅ 더 큼!

→ 음수가 되면 초기화하는 것이 항상 최선
```

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ 초기값 설정 오류

```cpp
❌ int maxRet = 0;  // 모든 수가 음수일 때 틀림!

✅ int maxRet = -1001;  // 가능한 최소값보다 작게 설정
```

**이유**:
- 수의 범위: -1,000 ~ 1,000
- 모든 수가 음수인 경우 (예: [-1, -2, -3, -4, -5])
- 정답은 -1이지만, maxRet=0으로 초기화하면 0을 출력하게 됨!

**예제 3번 확인**:
```
입력: [-1, -2, -3, -4, -5]
정답: -1 (가장 큰 수 하나만 선택)
```

### 2️⃣ curSum 초기화 타이밍

```cpp
✅ maxRet = max(maxRet, curSum);  // 먼저 최댓값 갱신!

✅ if(curSum < 0)                 // 그 다음 초기화
      curSum = 0;
```

**순서가 중요한 이유**:
- 최댓값 갱신을 먼저 해야 모든 경우를 체크
- 초기화를 먼저 하면 중요한 값을 놓칠 수 있음

### 3️⃣ 음수만 있는 경우 처리

```cpp
// 모든 수가 음수일 때
curSum은 항상 0으로 초기화되지만,
maxRet은 처음 한 번은 갱신됨 (첫 번째 수)

예: [-1, -2, -3]
i=0: curSum=-1, maxRet=-1 ✅ → curSum=0
i=1: curSum=-2, maxRet=-1    → curSum=0
i=2: curSum=-3, maxRet=-1    → curSum=0

결과: -1 ✅ (올바른 답)
```

## 🔬 알고리즘 상세 분석

### 💡 동적 계획법 관점

Kadane's Algorithm은 동적 계획법의 일종:

**점화식**:
```
dp[i] = max(arr[i], dp[i-1] + arr[i])

→ 현재 위치에서 시작 vs 이전 합에 추가
```

**최적화된 형태** (공간복잡도 O(1)):
```cpp
curSum = max(0, curSum) + newNum;  // 음수면 0으로 초기화
maxRet = max(maxRet, curSum);
```

---

## ⏱️ 시간복잡도

**O(N)**

**상세 분석**:
```
1. 입력 처리: O(N)
   - N개의 수를 순회하며 입력

2. Kadane's Algorithm: O(N)
   - 한 번의 순회로 최대 연속합 계산
   - 각 단계마다 O(1) 연산만 수행

총합: O(N) + O(N) = O(N)
```

**시간 제한 체크**:
- N ≤ 100,000 (문제 조건)
- **10만 연산** << **1억** → 여유롭게 통과 ✅

---

## 💾 공간복잡도

**O(1)** - 상수 공간만 사용

**분석**:
- `curSum`: 현재 연속합 - O(1)
- `maxRet`: 최댓값 - O(1)
- `newNum`: 입력 임시 저장 - O(1)
- 배열 사용 없음! (입력을 바로바로 처리)

**장점**: 메모리 효율적 (DP 배열 불필요)
