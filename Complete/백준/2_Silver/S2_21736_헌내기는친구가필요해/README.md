## 🔗 문제 링크

[백준 21736번 - 헌내기는 친구가 필요해](https://www.acmicpc.net/problem/21736)

**난이도**: Silver 2

---

## 🤔 접근법

N×M 크기의 캠퍼스에서 도연이(I)의 위치에서 출발하여, **만날 수 있는 사람(P)의 수**를 구하는 문제.

- 상하좌우 4방향으로 이동 가능하며, 벽(X)은 통과할 수 없다.
- 빈 공간(O)과 사람(P)은 이동 가능.
- 아무도 만나지 못하면 "TT"를 출력.

**핵심은 BFS로 도연이 위치에서 시작하여 도달 가능한 모든 칸을 탐색**하면서, 사람(P)을 만날 때마다 카운트하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : BFS (Breadth-First Search) - 너비 우선 탐색

**핵심 아이디어**:
```
1. 캠퍼스를 입력받으면서 도연이(I)의 시작 위치를 저장
2. 시작 위치에서 BFS 탐색 시작
3. 4방향 탐색 시 벽(X)이면 스킵, 그 외(O/P)는 이동
4. P를 만나면 cnt++ (사람 카운트)
5. 탐색 완료 후 cnt가 0이면 "TT", 아니면 cnt 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 조건 분기 간소화

```cpp
// 범위 벗어나는지 체크
if (newY < 0 || newY >= n || newX < 0 || newX >= m) continue;

// 이미 방문했는지 체크
if (vit[newY][newX] == true) continue;

// 'X'는 벽 체크
if (arr[newY][newX] == 'X') continue;

// 'O'는 빈 공간 or 'P'는 사람 경우
bfsQ.emplace(newY,newX);  // 새 탐색 위치 넣기
vit[newY][newX] = true;         // 방문 체크

// 'P'인 경우만 cnt++
if (arr[newY][newX] == 'P')
    cnt++;
```

**✅ 핵심**: 벽(X)만 걸러내면 O와 P 모두 이동 가능
- O와 P는 **이동 + 방문 체크** 동작이 동일
- P일 때만 추가로 cnt++ 처리
- 불필요한 else if 분기를 제거하여 코드 간소화

### 2️⃣ BFS 기본 패턴

```cpp
queue<pair<int,int>> bfsQ;
bfsQ.emplace(sY, sX);     // 시작 위치
vit[sY][sX] = true;       // 방문 체크

while (!bfsQ.empty())
{
    int curY = bfsQ.front().first;
    int curX = bfsQ.front().second;
    bfsQ.pop();

    for (int i = 0; i < 4; ++i)
    {
        int newY = curY + dirY[i];
        int newX = curX + dirX[i];
        // 유효성 검사 후 큐에 추가
    }
}
```

**✅ 핵심**: 시작점 방문 처리 필수
- 시작점을 큐에 넣을 때 **반드시 방문 처리**
- 방문 처리 안 하면 중복 방문 발생 가능

### 3️⃣ 결과 출력 조건

```cpp
if (cnt == 0) cout << "TT";
else          cout << cnt;
```

**✅ 핵심**: 아무도 만나지 못한 경우 "TT" 출력
- 숫자 0이 아닌 문자열 "TT"를 출력해야 함

## ⏱️ 시간복잡도

**O(N × M)**

**분석**:
- N × M 크기의 캠퍼스 입력: O(N × M)
- BFS 탐색: 각 칸을 최대 1번만 방문 → O(N × M)
- 총 시간복잡도: O(N × M)

**실제 계산**:
```
- N = M = 600 (최대값)
- 600 × 600 = 360,000칸
- O(360,000) ≈ O(3.6 × 10^5) << 10^8 (1초 기준)
```

**✅ 결론**: 충분히 시간 제한(1초) 내에 해결 가능

---

## 💾 공간복잡도

**O(N × M)**

**분석**:
- `arr[604][604]`: 캠퍼스 배열 → O(N × M)
- `vit[604][604]`: 방문 체크 배열 → O(N × M)
- `queue<pair<int, int>>`: 최악의 경우 모든 칸 저장 → O(N × M)
- `dirX[4]`, `dirY[4]`: 방향 배열 → O(1) (상수)

**총 공간**: O(N × M) ≈ **O(360,000)** (N=M=600일 때)
