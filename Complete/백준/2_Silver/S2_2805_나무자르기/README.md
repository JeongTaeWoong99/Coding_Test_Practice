## 🔗 문제 링크

[백준 2805번 - 나무 자르기](https://www.acmicpc.net/problem/2805)

**난이도**: Silver 2

---

## 🤔 접근법

N개의 나무가 있고, 절단기 높이 H를 설정하면 H보다 높은 나무들의 윗부분이 잘린다.

**적어도 M미터의 나무를 얻기 위한 H의 최댓값**을 구하는 문제.

**핵심**:
- H가 높을수록 → 얻는 나무 양 **적음**
- H가 낮을수록 → 얻는 나무 양 **많음**
- **단조성(Monotonic)** 이 있으므로 → **이분 탐색** 적용!

---

## 💡 정답 풀이 방법

**알고리즘** : 이분 탐색 (Binary Search) / 매개변수 탐색 (Parametric Search)

**핵심 아이디어**:
```
1. 절단기 높이 H의 범위: 0 ~ 가장 높은 나무
2. 특정 H로 잘랐을 때 얻는 나무 양 계산
3. M 이상이면 H를 높여보고, M 미만이면 H를 낮춤
4. M 이상을 만족하는 H의 최댓값이 정답
```

---

## 🔑 핵심 개념

### 1️⃣ 이분 탐색 조건

```cpp
while (lo <= hi)
{
    long long mid = (lo + hi) / 2;
    long long wood = GetWood(mid);

    if (wood >= m)      // M 이상 얻을 수 있으면
    {
        ret = mid;      // 정답 후보 저장
        lo = mid + 1;   // 더 높은 H 탐색 (최댓값 찾기)
    }
    else                // M 미만이면
    {
        hi = mid - 1;   // 더 낮은 H로
    }
}
```

**✅ 핵심**: `wood >= m`일 때 `ret`에 저장하고 더 큰 값 탐색!

### 2️⃣ 나무 얻는 양 계산

```cpp
long long GetWood(long long mid)
{
    long long sum = 0;

    for (int i = 0; i < n; ++i)
    {
        if (ar[i] > mid)
            sum += ar[i] - mid;  // mid보다 높은 부분만 획득
    }

    return sum;
}
```

**시각화**:
```
나무: 20, 15, 10, 17  |  H = 15로 자르면
                      |
  20 ████             |    ████ → 5m 획득
  17 ███              |    ██   → 2m 획득
  15 ██ ──────────────|─── 절단선 (H=15)
  10 █                |    (안 잘림)
                      |
                      |  총: 5 + 0 + 0 + 2 = 7m
```

### 3️⃣ long long 필수!

| 변수 | 최대값 | 타입 |
|------|--------|------|
| N | 1,000,000 | int |
| M | 2,000,000,000 | **long long** |
| 나무 높이 | 1,000,000,000 | **long long** |
| 잘린 나무 합 | N × 높이 = 10^15 | **long long** ⚠️ |

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ int 오버플로우

```cpp
❌ int sum = 0;           // 10^15까지 가능 → 오버플로우!
   for (...) sum += ar[i] - mid;

✅ long long sum = 0;     // long long 사용
```

### 2️⃣ 탐색 범위 설정

```cpp
❌ long long hi = 1000000000;  // 불필요하게 큰 범위

✅ long long hi = maxHeight;   // 가장 높은 나무가 상한
```

### 3️⃣ 정답 조건 방향

```cpp
// "M 이상" 얻을 수 있는 H의 "최댓값"
if (wood >= m)
{
    ret = mid;      // 정답 후보
    lo = mid + 1;   // 더 큰 H 탐색 (최댓값이니까!)
}
```

## ⏱️ 시간복잡도

**O(N × log(maxHeight))**

**분석**:
- 이분 탐색: log₂(10⁹) ≈ 30회
- 각 탐색마다 GetWood(): O(N)
- 총: O(N × 30) = O(30N)

**실제 계산**:
```
N = 1,000,000 (최대)
30 × 1,000,000 = 3천만 연산
3천만 << 1억 → 1초 여유롭게 통과 ✅
```

---

## 💾 공간복잡도

**O(N)**

**분석**:
- `ar[1000004]`: 나무 높이 배열 → O(N)
- 기타 변수: O(1)

## 🎯 알고리즘 분류

- **이분 탐색 (Binary Search)**: 정렬된 범위에서 조건 만족하는 값 탐색
- **매개변수 탐색 (Parametric Search)**: "가능한가?"를 판별하는 결정 문제로 변환
