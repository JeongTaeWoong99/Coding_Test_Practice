## 🔗 문제 링크

[백준 30804번 - 과일 탕후루](https://www.acmicpc.net/problem/30804)

**난이도**: Silver 2

---

## 🤔 접근법

(풀긴 했는데, 코드 구조가 매끄럽지 못했음. 다음에 다시 풀어볼 예정.)

N개의 과일이 꽂혀있는 탕후루에서, **앞쪽과 뒤쪽에서 과일을 빼서 두 종류 이하의 과일만 남기는 문제**.

남은 과일의 개수가 최대가 되도록 해야 한다.

**핵심은 투 포인터(슬라이딩 윈도우)**로 과일 종류가 2개 이하인 가장 긴 연속 구간을 찾는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : 투 포인터 (Two Pointer) + 슬라이딩 윈도우 (Sliding Window)

**핵심 아이디어**:
```
1. left, right 두 포인터로 구간 [left, right]을 관리
2. right를 오른쪽으로 한 칸씩 확장하며 과일 추가
3. 구간 내 과일 종류가 3개 이상이면 left를 오른쪽으로 이동하며 과일 제거
4. 매 단계마다 구간 길이의 최댓값 갱신
```

---

## 🔑 핵심 포인트

### 1️⃣ 투 포인터 패턴

```cpp
int lef = 0;

for(int right = 0; right < n; right++)
{
    // 오른쪽 과일 추가
    if(cnt[arr[right]] == 0)
        kinds++;
    cnt[arr[right]]++;

    // 종류가 3 이상이면 왼쪽에서 제거
    while(kinds > 2)
    {
        cnt[arr[lef]]--;
        if(cnt[arr[lef]] == 0)
            kinds--;
        lef++;
    }

    // 최대 길이 갱신
    ans = max(ans, right - lef + 1);
}
```

**✅ 핵심**: right는 매번 1씩 증가, left는 종류가 초과될 때만 증가
- `cnt[]` 배열로 각 과일 종류별 개수 추적
- `kinds` 변수로 현재 구간 내 과일 종류 수 관리
- 과일 개수가 0이 되면 kinds 감소, 0에서 1이 되면 kinds 증가

### 2️⃣ 과일 종류 카운팅

```cpp
int cnt[10];       // 1 <= s <= 9 (각 과일 종류별 개수)
int kinds = 0;     // 현재 구간 내 과일 종류 수
```

**✅ 핵심**: 과일 종류가 1~9로 제한되어 있어 크기 10짜리 배열로 충분
- `cnt[arr[right]] == 0` → 새로운 종류의 과일 등장
- `cnt[arr[lef]] == 0` → 해당 종류의 과일이 구간에서 완전히 사라짐

### 3️⃣ "앞뒤에서 빼기" = "연속 부분 배열의 최대 길이"

```
원래 문제: 앞에서 a개, 뒤에서 b개를 빼서 남은 구간 최대화
→ 변환: 2종류 이하 과일로 이루어진 연속 부분 배열의 최대 길이
```

**✅ 핵심**: 문제를 변환하면 전형적인 슬라이딩 윈도우 문제가 됨
- 앞뒤에서 빼는 것 = 가운데 연속 구간을 남기는 것
- 가장 긴 유효 구간을 찾으면 됨

## ⏱️ 시간복잡도

**O(N)**

**분석**:
- right 포인터: 0부터 N-1까지 1번 순회 → O(N)
- left 포인터: 0부터 최대 N-1까지 이동 (절대 감소하지 않음) → O(N)
- 각 원소가 최대 한 번 추가되고 한 번 제거됨

**실제 계산**:
```
- N = 200,000 (최대값)
- 총 연산: 약 2N = 400,000
- O(4×10^5) << 10^8 (1초 기준)
```

**✅ 결론**: 충분히 시간 제한(2초) 내에 해결 가능

---

## 💾 공간복잡도

**O(N)**

**분석**:
- `arr[200001]`: 과일 배열 → O(N)
- `cnt[10]`: 과일 종류별 개수 → O(1) (상수)
- `n, ans, kinds, lef, right`: 상수 변수 → O(1)

**총 공간**: O(N) ≈ **O(200,000)** (N=200,000일 때)

## 🎯 알고리즘 분류

- **투 포인터(Two Pointer)**: left/right 포인터로 구간 관리
- **슬라이딩 윈도우(Sliding Window)**: 구간을 이동하며 최적값 탐색
- **구현(Implementation)**: 과일 종류 카운팅
