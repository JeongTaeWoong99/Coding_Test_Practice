## 🔗 문제 링크

[백준 1003번 - 피보나치 함수](https://www.acmicpc.net/problem/1003)

**난이도**: Silver 3

---

## 🤔 접근법

피보나치 함수를 재귀로 호출할 때, `fibonacci(0)`과 `fibonacci(1)`이 각각 몇 번 호출되는지 구하는 문제.

단순 재귀로 호출 횟수를 세면 시간 초과 → **DP**로 해결!

**핵심**: 호출 횟수 자체도 **피보나치 점화식**을 따른다!

---

## 💡 정답 풀이 방법

**알고리즘**: 다이나믹 프로그래밍 (전처리)

**핵심 아이디어**:
```
1. 피보나치 수열을 미리 dp[0]~dp[40]까지 계산 (전처리)

2. 0 호출 횟수 = fib(n-1), 1 호출 횟수 = fib(n)

3. n=0일 때는 예외 처리 (1, 0)
```

---

## 🔑 핵심 포인트

### 1️⃣ 호출 횟수의 패턴 발견

재귀 호출 트리를 분석하면:

```
fib(3) 호출 시:
                    fib(3)
                   /      \
              fib(2)      fib(1) → "1" 출력
             /      \
        fib(1)    fib(0) → "0" 출력
           ↓
      "1" 출력

결과: 0은 1번, 1은 2번 출력
```

| n | 0 호출 횟수 | 1 호출 횟수 |
|---|-----------|-----------|
| 0 | 1 | 0 |
| 1 | 0 | 1 |
| 2 | 1 | 1 |
| 3 | 1 | 2 |
| 4 | 2 | 3 |
| 5 | 3 | 5 |
| 6 | 5 | 8 |

**💡 발견**: 호출 횟수도 피보나치 점화식을 따름!

```cpp
cnt0[n] = cnt0[n-1] + cnt0[n-2]  // 피보나치!
cnt1[n] = cnt1[n-1] + cnt1[n-2]  // 피보나치!
```

### 2️⃣ 피보나치 수열과의 관계

```
피보나치: 0, 1, 1, 2, 3, 5, 8, 13, 21 ...
인덱스:   0  1  2  3  4  5  6   7   8

cnt0:     1, 0, 1, 1, 2, 3, 5,  8, 13 ...  ← fib(n-1)
cnt1:     0, 1, 1, 2, 3, 5, 8, 13, 21 ...  ← fib(n)
```

**✅ 결론**:
- `0 호출 횟수 = fib(n-1)` (n >= 1)
- `1 호출 횟수 = fib(n)`
- n = 0일 때는 예외: `(1, 0)`

### 3️⃣ 전처리로 효율성 향상

```cpp
// ★ 전처리 : 피보나치 수열을 미리 계산 (한 번만!)
for(int i = 2; i <= 40; i++)
    dp[i] = dp[i - 1] + dp[i - 2];
```

**✅ 핵심**:
- 테스트케이스마다 계산하지 않고, 미리 한 번만 계산
- 쿼리당 O(1)로 즉시 응답 가능

### 4️⃣ n=0 예외 처리

```cpp
if(n == 0)
    cout << "1 0\n";        // fib(-1)은 없으므로 예외 처리
else
    cout << dp[n - 1] << " " << dp[n] << "\n";
```

**✅ 핵심**: `dp[n-1]`에서 n=0이면 `dp[-1]` → 배열 범위 오류!

---

## 🆚 효율성 비교

| 방식 | 전처리 | 쿼리당 | 총 시간 |
|-----|-------|-------|--------|
| 매번 계산 | 없음 | O(N) | O(T × N) |
| **전처리** | O(40) | **O(1)** | **O(40 + T)** |

**예시** (T=100, 각 N=40):
- 매번 계산: 100 × 40 = 4,000번 연산
- 전처리: 40 + 100 = 140번 연산 (약 28배 빠름!)

---

## ⏱️ 시간복잡도

**전체 시간복잡도**: **O(40 + T)** ≈ **O(T)**

**상세 분석**:
```
1. 전처리 : O(40) = O(1)
   - 피보나치 수열 40개 계산

2. 쿼리 처리 : O(T)
   - T개의 테스트케이스
   - 각 쿼리 O(1)

총합 : O(40 + T) ≈ O(T)
```

**시간 제한 체크**:
- T ≤ 입력 횟수, N ≤ 40
- 쿼리당 O(1) → 매우 효율적 ✅

---

## 💾 공간복잡도

**O(1)** (상수 공간)
- `dp[41]` : 고정 크기 배열 (41개)
- N의 크기와 무관하게 일정

---

**⏱️ 시간복잡도**: O(T)

**💾 공간복잡도**: O(1)
