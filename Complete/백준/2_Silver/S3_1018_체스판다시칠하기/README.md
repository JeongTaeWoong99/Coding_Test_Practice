## 🔗 문제 링크

[백준 1018번 - 체스판 다시 칠하기](https://www.acmicpc.net/problem/1018)

**난이도**: Silver 3

---

## 🤔 접근법

(엄청 코드가 길게 품. 정답 코드로 컴팩트하게 풀 수 있음.)

M×N 크기의 보드에서 8×8 크기의 체스판을 잘라내는데, **다시 칠해야 하는 정사각형의 최소 개수**를 구하는 문제.

- 체스판은 두 가지 패턴만 가능: W로 시작 또는 B로 시작
- 모든 가능한 8×8 시작점을 순회하며 브루트포스로 해결

**핵심**: W시작 패턴과의 불일치 개수를 세면, B시작 패턴 불일치는 `64 - 불일치개수`로 바로 계산 가능!

---

## 💡 정답 풀이 방법

**알고리즘** : 브루트포스 (Brute Force) - 완전 탐색

**핵심 아이디어**:
```
1. 모든 가능한 8×8 시작점 (startY, startX) 순회

2. 각 시작점에서 W시작 패턴과 비교하여 불일치 개수 계산

3. min(현재 선택 최소값, 불일치개수, 64-불일치개수)로 두 패턴 중 최적 선택

4. 전체 최솟값 갱신
```

---

## 🔑 핵심 포인트

### 1️⃣ 체스판 패턴의 수학적 규칙

```cpp
// (curY + curX) 값에 따라 색상 결정
char expected = (curY + curX) % 2 == 0 ? 'W' : 'B';
```

**체스판 패턴 (W시작 기준)**:
```
(0,0)=W  (0,1)=B  (0,2)=W  (0,3)=B ...
(1,0)=B  (1,1)=W  (1,2)=B  (1,3)=W ...
(2,0)=W  (2,1)=B  (2,2)=W  (2,3)=B ...
```

**✅ 핵심**: `(y + x) % 2`로 기대 색상 계산
- 짝수: W
- 홀수: B

### 2️⃣ 두 패턴 동시 처리

```cpp
// W시작 패턴 불일치 : isDifferent개
// B시작 패턴 불일치 : 64 - isDifferent개
minCnt = min({minCnt, isDifferent, 64 - isDifferent});
```

★ **✅ 핵심**: W와 B 패턴은 정확히 반대!
- W시작과 64칸 불일치 → B시작과 0칸 불일치
- 한 번만 세고 두 패턴 모두 확인 가능

### 3️⃣ 시작점 범위 제한

```cpp
for(int startY = 0; startY <= n - 8; startY++)
{
    for(int startX = 0; startX <= m - 8; startX++)
```

**✅ 핵심**: `n - 8`, `m - 8`로 범위 제한
- 8×8 보드가 필요하므로 시작점은 `(0, 0)` ~ `(n-8, m-8)`
- 정확히 8×8일 경우 시작점은 `(0, 0)` 하나만 존재

### 4️⃣ 3중 min을 활용한 최솟값 갱신

```cpp
minCnt = min({minCnt, isDifferent, 64 - isDifferent});
```

**✅ 핵심**: `min({a, b, c})` 문법
- 중괄호 `{}`로 여러 값을 한 번에 비교
- 기존 최솟값, W패턴 불일치, B패턴 불일치 중 가장 작은 값 선택

## ⏱️ 시간복잡도

**O((N-7) × (M-7) × 64)** ≈ **O(N × M)**

**분석**:
```
1. 시작점 순회: (N-7) × (M-7) ≈ 43 × 43 = 1,849개 (최대)
2. 각 시작점에서 8×8 검사: 64칸
3. 총 연산: 1,849 × 64 ≈ 118,336번
```

**✅ 결론**: 약 12만 연산으로 시간 제한(2초) 내에 충분히 해결 가능

---

## 💾 공간복잡도

**O(N × M)**

**분석**:
- `board[54]`: string 배열 → O(N × M)
- `n, m, minCnt, isDifferent`: 정수 변수 → O(1)

**총 공간**: O(N × M) ≈ **O(2,500)** (N=M=50일 때)
