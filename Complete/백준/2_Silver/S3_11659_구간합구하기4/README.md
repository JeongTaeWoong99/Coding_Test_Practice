## 🔗 문제 링크

[백준 11659번 - 구간 합 구하기 4](https://www.acmicpc.net/problem/11659)

**난이도**: Silver 3

---

## 🤔 접근법

수 N개가 주어졌을 때, i번째 수부터 j번째 수까지 합을 구하는 문제.

단순 반복문으로는 O(N × M)으로 시간 초과 발생.

**핵심**: **누적합(Prefix Sum)**으로 O(1)에 구간 합 계산!

---

## 💡 정답 풀이 방법

**알고리즘**: 누적합 (Prefix Sum)

**핵심 아이디어**:
```
1. 누적합 배열 생성 (1-indexed)
   - arr[i] = arr[i-1] + 입력값
   - arr[i]는 1번째부터 i번째까지의 합

2. 구간 합 계산
   - i부터 j까지의 합 = arr[j] - arr[i-1]
   - O(1)에 즉시 계산 가능!

3. M개의 쿼리 처리
   - 각 쿼리마다 arr[b] - arr[a-1] 출력
```

---

## 🔑 핵심 개념

### 📐 누적합(Prefix Sum) 원리

```
입력: 5 4 3 2 1

누적합 배열:
  arr[0] = 0  (초기값)
  arr[1] = 5
  arr[2] = 5 + 4 = 9
  arr[3] = 9 + 3 = 12
  arr[4] = 12 + 2 = 14
  arr[5] = 14 + 1 = 15

구간 합 계산:
  1~3까지 합 = arr[3] - arr[0] = 12 - 0 = 12  ✅
  2~4까지 합 = arr[4] - arr[1] = 14 - 5 = 9   ✅
  5~5까지 합 = arr[5] - arr[4] = 15 - 14 = 1  ✅
```

### 🎯 1-indexed를 사용하는 이유

```cpp
// 1-indexed 사용 시 (권장)
arr[b] - arr[a - 1]  // a=1일 때도 arr[0]이 있어서 안전

// 0-indexed 사용 시
arr[b] - (a > 0 ? arr[a - 1] : 0)  // 조건문 필요
```

**✅ 장점**:
- 경계 조건 처리가 간단
- `arr[0] = 0`으로 초기화되어 a=1일 때도 자연스럽게 처리

### 📊 예제 추적

```
입력:
5 3
5 4 3 2 1
1 3
2 4
5 5

누적합 배열: [0, 5, 9, 12, 14, 15]

쿼리 1: 1~3 → arr[3] - arr[0] = 12 - 0 = 12
쿼리 2: 2~4 → arr[4] - arr[1] = 14 - 5 = 9
쿼리 3: 5~5 → arr[5] - arr[4] = 15 - 14 = 1
```

## ⏱️ 시간복잡도

**O(N + M)**
- 누적합 배열 생성: O(N)
- M개 쿼리 처리: O(M) (쿼리당 O(1))

---

## 💾 공간복잡도

**O(N)**
- `arr[100001]`: 누적합 배열

---

## 🎯 알고리즘 분류

- **누적 합 (Prefix Sum)**: 구간 합을 O(1)에 계산하는 기법
