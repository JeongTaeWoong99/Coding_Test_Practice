## 🔗 문제 링크

[백준 11726번 - 2×n 타일링](https://www.acmicpc.net/problem/11726)

**난이도**: Silver 3

---

## 🤔 접근법

2×n 크기의 직사각형을 1×2, 2×1 타일로 채우는 방법의 수를 구하는 문제.

**규칙 발견**:
```
dp[1] = 1
dp[2] = 2
dp[3] = 3
dp[4] = 5
dp[5] = 8
...
dp[9] = 55
```

**핵심**: **피보나치 수열**과 동일한 점화식! → **바텀업 DP**로 해결!

---

## 💡 정답 풀이 방법

**알고리즘**: Bottom-up DP (반복문 + 메모이제이션)

**점화식 유도**:
- n번째 칸을 채울 때:
  - 세로 타일(1×2) 1개 놓으면 → 나머지는 `dp[n-1]` 가지
  - 가로 타일(2×1) 2개 놓으면 → 나머지는 `dp[n-2]` 가지

```
dp[n] = dp[n-1] + dp[n-2]
```

**핵심 아이디어**:
```
1. 베이스 케이스 설정
   - dp[1] = 1 (세로 1개)
   - dp[2] = 2 (세로 2개 or 가로 2개)

2. i = 3부터 n까지 dp 테이블 채우기
   - dp[i] = (dp[i-1] + dp[i-2]) % 10007

3. dp[n] 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 모듈러 연산 위치 (⚠️ 맞왜틀 주의!)

```cpp
// ❌ 틀린 코드 (오버플로우 발생)
dp[i] = dp[i - 1] + dp[i - 2];
cout << dp[n] % 10007;

// ✅ 정답 코드 (매 단계 모듈러)
dp[i] = (dp[i - 1] + dp[i - 2]) % 10007;
cout << dp[n];
```

**이유**:
- 피보나치 수열은 기하급수적으로 증가
- n=100만 되어도 `long long` 범위 초과!
- 매 단계 모듈러 연산으로 오버플로우 방지

**수학적 원리**:
```
(A + B) % M = ((A % M) + (B % M)) % M
```

### 2️⃣ 점화식의 시각적 이해

```
n=1: |ㅣ|          → 1가지

n=2: |ㅣ|ㅣ| or |==|   → 2가지

n=3: 마지막에 세로 1개 → dp[2]의 경우 +
     마지막에 가로 2개 → dp[1]의 경우
     = 2 + 1 = 3가지

n=4: dp[3] + dp[2] = 3 + 2 = 5가지
```

### 3️⃣ DP 배열 갱신 과정

```
dp[1] = 1
dp[2] = 2
dp[3] = (2 + 1)   % 10007 = 3
dp[4] = (3 + 2)   % 10007 = 5
dp[5] = (5 + 3)   % 10007 = 8
dp[6] = (8 + 5)   % 10007 = 13
dp[7] = (13 + 8)  % 10007 = 21
dp[8] = (21 + 13) % 10007 = 34
dp[9] = (34 + 21) % 10007 = 55  ✅ 예제 정답
```

## 🆚 다른 접근법

### 탑다운 DP (메모이제이션 + 재귀)

```cpp
int solve(int n)
{
    if (n <= 2) return n;
    if (dp[n] != -1) return dp[n];

    return dp[n] = (solve(n-1) + solve(n-2)) % 10007;
}
```

**바텀업 vs 탑다운**:
- 이 문제는 둘 다 O(N)으로 동일
- 바텀업이 재귀 오버헤드 없어서 약간 더 빠름 ✅

---

## ⏱️ 시간복잡도

**O(N)**
- N = 입력값 (최대 1,000)
- 반복문으로 3부터 N까지 순회
- 각 i마다 상수 시간 연산 O(1)

## 💾 공간복잡도

**O(N)**

## 🎯 알고리즘 분류

- **피보나치 수열**: dp[n] = dp[n-1] + dp[n-2] 형태
