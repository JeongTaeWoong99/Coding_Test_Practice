## 🔗 문제 링크
[백준 11727번 - 2×n 타일링 2](https://www.acmicpc.net/problem/11727)

**난이도**: Silver 3

---

## 🤔 접근법

2×n 직사각형을 1×2, 2×1, 2×2 타일로 채우는 방법의 수를 구하는 문제.

**핵심**: 이전 문제(11726번 2×n 타일링)의 변형으로, 2×2 타일이 추가되어 점화식이 달라짐.

직접 작은 값들을 계산해보며 규칙 파악:
- dp[1] = 1 (세로 1개)
- dp[2] = 3 (가로 2개, 세로 2개, 2×2 1개)
- dp[3] = 5
- dp[4] = 11

---

## 💡 정답 풀이 방법

**알고리즘** : 다이나믹 프로그래밍 (DP) - 바텀업 메모이제이션

**핵심 아이디어**:
```
1. dp[i] : 2×i 크기 직사각형을 채우는 방법의 수
2. 점화식 : dp[i] = dp[i-1] + dp[i-2] * 2
3. 매 계산마다 % 10007로 오버플로우 방지
```

---

## 🔑 핵심 개념

### 1️⃣ 점화식 유도

**i번째 칸을 채우는 방법**:

1. **마지막에 세로 타일(1×2) 1개 추가** → dp[i-1]가지
```
□□□■
□□□■
```

2. **마지막에 가로 타일(2×1) 2개 추가** → dp[i-2]가지
```
□□■■
□□■■
```

3. **마지막에 2×2 타일 1개 추가** → dp[i-2]가지
```
□□▣▣
□□▣▣
```

**따라서**: `dp[i] = dp[i-1] + dp[i-2] + dp[i-2] = dp[i-1] + 2 * dp[i-2]`

### 2️⃣ 11726번과의 비교

| 문제 | 사용 가능한 타일 | 점화식 |
|-----|---------------|--------|
| 11726 (2×n 타일링) | 1×2, 2×1 | dp[i] = dp[i-1] + dp[i-2] |
| 11727 (2×n 타일링 2) | 1×2, 2×1, **2×2** | dp[i] = dp[i-1] + **2** × dp[i-2] |

→ 2×2 타일이 추가되어 `dp[i-2]`가 2배가 됨!

### 3️⃣ 초기값 설정

```cpp
dp[0] = 0;  // 사용하지 않음
dp[1] = 1;  // 세로 1개
dp[2] = 3;  // 가로 2개, 세로 2개, 2×2 1개
```

### 4️⃣ 모듈러 연산

```cpp
dp[i] = (dp[i - 2] * 2 + dp[i - 1]) % 10007;
```

- 결과가 매우 커질 수 있으므로 매 계산마다 나머지 연산 적용
- 모듈러 덧셈/곱셈 성질: `(a + b) % m = ((a % m) + (b % m)) % m`

## 📊 예제 분석

### 🎯 n = 2인 경우

```
방법 1: 세로 2개     방법 2: 가로 2개     방법 3: 2×2 1개
  ■□                  ■■                  ■■
  ■□                  ■■                  ■■
```

**결과**: 3가지

### 🎯 n = 8인 경우

```
dp[1] = 1
dp[2] = 3
dp[3] = 1 + 3×2 = 7 → 7 % 10007 = 7 (계산 오류, 실제: 1×2 + 3 = 5)
```

실제 계산:
- dp[3] = dp[2] + 2 × dp[1] = 3 + 2 × 1 = 5
- dp[4] = dp[3] + 2 × dp[2] = 5 + 2 × 3 = 11
- dp[5] = dp[4] + 2 × dp[3] = 11 + 2 × 5 = 21
- dp[6] = dp[5] + 2 × dp[4] = 21 + 2 × 11 = 43
- dp[7] = dp[6] + 2 × dp[5] = 43 + 2 × 21 = 85
- dp[8] = dp[7] + 2 × dp[6] = 85 + 2 × 43 = **171**

**결과**: 171

## 🚨 주의사항

### 1️⃣ 오버플로우 방지

```cpp
❌ dp[i] = dp[i - 2] * 2 + dp[i - 1];  // 나중에 % 연산 → 오버플로우 위험

✅ dp[i] = (dp[i - 2] * 2 + dp[i - 1]) % 10007;  // 매번 % 연산
```

### 2️⃣ 배열 크기

```cpp
✅ const int MAX_N = 1004;  // n ≤ 1000이므로 여유 있게 설정
```

### 3️⃣ 11726번 코드 재활용 시 주의

```cpp
❌ dp[i] = dp[i-1] + dp[i-2];       // 11726번 점화식 (틀림!)

✅ dp[i] = dp[i-1] + 2 * dp[i-2];  // 11727번 점화식 (정답!)
```
