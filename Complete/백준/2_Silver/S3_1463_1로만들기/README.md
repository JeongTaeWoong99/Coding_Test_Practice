## 🔗 문제 링크

[백준 1463번 - 1로 만들기](https://www.acmicpc.net/problem/1463)

**난이도**: Silver 3

---

## 🤔 접근법

정수 N에 대해 3가지 연산을 사용하여 1로 만들 때, 최소 연산 횟수를 구하는 문제.

사용 가능한 연산:
- N이 3으로 나누어떨어지면, 3으로 나눔
- N이 2로 나누어떨어지면, 2로 나눔
- 1을 뺌

**핵심**: **동적 계획법(DP)**으로 각 숫자까지의 최소 연산 횟수를 저장!

---

## 💡 정답 풀이 방법

**알고리즘**: Bottom-up DP (반복문 + 메모이제이션)

**핵심 아이디어**:
```
1. dp[1] = 0으로 초기화 (1은 이미 1이므로 0번 연산)

2. i = 2부터 n까지 순회하며 dp 배열 채우기:
   - 무조건: dp[i] = min(dp[i], dp[i-1] + 1)  // -1 연산
   - i가 2로 나누어떨어지면: dp[i] = min(dp[i], dp[i/2] + 1)
   - i가 3으로 나누어떨어지면: dp[i] = min(dp[i], dp[i/3] + 1)

3. dp[n] 출력 (최소 연산 횟수)
```

---

## 🔑 핵심 포인트

### 1️⃣ INF 초기화가 필요한 이유

```cpp
fill_n(dp, 1000004, INF);
```

**✅ 핵심**:
- `min(dp[i], dp[i-1] + 1)` 형태로 비교하기 때문
- dp[i]가 0으로 초기화되어 있으면 항상 0이 선택됨
- INF로 초기화해야 올바른 최솟값 비교 가능

### 2️⃣ DP 배열 갱신 과정 (n = 10 예시)

**초기화**:
```
dp[0] = 0, dp[1] = 0 (1을 1로 만드는 연산 횟수는 0)
나머지는 모두 INF
```

**진행 과정**:

```
i = 2:
  - dp[2] = min(INF, dp[1] + 1) = 1  // -1 연산
  - 2 % 2 == 0 → dp[2] = min(1, dp[1] + 1) = 1  // /2 연산
  → dp[2] = 1

i = 3:
  - dp[3] = min(INF, dp[2] + 1) = 2  // -1 연산
  - 3 % 3 == 0 → dp[3] = min(2, dp[1] + 1) = 1  // /3 연산
  → dp[3] = 1

i = 6:
  - dp[6] = min(INF, dp[5] + 1) = 4  // -1 연산
  - 6 % 2 == 0 → dp[6] = min(4, dp[3] + 1) = 2  // /2 연산
  - 6 % 3 == 0 → dp[6] = min(2, dp[2] + 1) = 2  // /3 연산
  → dp[6] = 2

i = 10:
  - dp[10] = min(INF, dp[9] + 1) = 3  // -1 연산
  - 10 % 2 == 0 → dp[10] = min(3, dp[5] + 1) = 3  // /2 연산
  → dp[10] = 3
```

**최종 dp 배열 상태 (1~10)**:
```
dp[1]  = 0
dp[2]  = 1  (2 → 1)
dp[3]  = 1  (3 → 1)
dp[4]  = 2  (4 → 2 → 1)
dp[5]  = 3  (5 → 4 → 2 → 1)
dp[6]  = 2  (6 → 3 → 1)
dp[7]  = 3  (7 → 6 → 3 → 1)
dp[8]  = 3  (8 → 4 → 2 → 1)
dp[9]  = 2  (9 → 3 → 1)
dp[10] = 3  (10 → 9 → 3 → 1)
```

### 3️⃣ 점화식의 의미

```cpp
// 1을 뺐을 때
dp[i] = min(dp[i], dp[i - 1] + 1);

// 2로 나눴을 때
if (i % 2 == 0)
    dp[i] = min(dp[i], dp[i / 2] + 1);

// 3으로 나눴을 때
if (i % 3 == 0)
    dp[i] = min(dp[i], dp[i / 3] + 1);
```

**✅ 핵심**:
- `dp[i]` = i를 1로 만드는 최소 연산 횟수
- 세 가지 연산 중 최솟값을 선택
- `-1 연산`은 항상 가능하므로 무조건 먼저 계산

### 4️⃣ 그리디가 안 되는 이유

```
N = 10 예시:
- 그리디 (가능하면 큰 수로 나누기): 10 → 5 → 4 → 2 → 1 (4번)
- 최적해: 10 → 9 → 3 → 1 (3번)

그리디 실패!
→ DP로 모든 경우를 고려해야 함
```

## ⏱️ 시간복잡도

**O(N)**
- N = 입력 값 (최대 1,000,000)
- 반복문으로 2부터 N까지 순회
- 각 i마다 상수 시간 연산 O(1)

**시간 제한 체크**:
- N ≤ 1,000,000
- O(N) = 1,000,000 연산
- 시간 제한 0.15초 내 충분히 통과 ✅
