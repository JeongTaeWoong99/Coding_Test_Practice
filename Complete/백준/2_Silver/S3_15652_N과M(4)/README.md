## 🔗 문제 링크
[백준 15652번 - N과 M (4)](https://www.acmicpc.net/problem/15652)

**난이도**: Silver 3

---

## 🤔 접근법

1부터 N까지 자연수 중 M개를 고르되, **같은 수를 여러 번 선택 가능**하고 **비내림차순**이어야 하는 수열을 출력하는 문제.

N과 M 시리즈 중 **중복 허용 + 비내림차순** 조합.

**핵심**: DFS에서 다음 탐색 시작 인덱스를 `i+1`이 아닌 `i`로 넘겨 같은 수를 다시 선택할 수 있도록 처리.

---

## 💡 정답 풀이 방법

**알고리즘**: DFS (백트래킹)

```
1. DFS(depth, start) 호출
2. depth == m 이면 수열 출력 후 return
3. start부터 n까지 반복하며 arr[depth]에 저장
4. DFS(depth + 1, i) 재귀 호출 → i부터 시작해 중복 허용
```

---

## 🔑 핵심 포인트

### N과 M 시리즈 비교

| 문제 | 중복 허용 | 순서 조건 |
|-----|---------|---------|
| N과 M (1) | ❌ | 없음 (증가 순서) |
| N과 M (2) | ❌ | 비내림차순 |
| N과 M (3) | ✅ | 없음 |
| **N과 M (4)** | **✅** | **비내림차순** |

### 핵심 코드

```cpp
// N과 M (3): DFS(depth + 1, i + 1) → 중복 허용 X
// N과 M (4): DFS(depth + 1, i)     → 중복 허용 O ⭐
DFS(depth + 1, i); // i부터 시작 → 같은 수 다시 선택 가능
```

**비내림차순 보장 원리**:
- `start`를 현재 선택한 `i`로 넘기므로 항상 `i` 이상의 수만 선택됨
- → 자연스럽게 A[k] ≤ A[k+1] 조건 만족

---

## ⏱️ 시간복잡도

**O(C(N+M-1, M))** - 중복 조합의 경우의 수

**분석**:
- N, M ≤ 8 제약 조건에서 최대 경우의 수는 C(15, 8) = 6435
- 실제 탐색은 매우 적어 시간 내 충분히 해결 가능

---

**⏱️ 시간복잡도**: O(C(N+M-1, M)) - 중복 조합

**💾 공간복잡도**: O(M) - 재귀 스택 깊이
