## 🔗 문제 링크
[백준 15654번 - N과 M (5)](https://www.acmicpc.net/problem/15654)

**난이도**: Silver 3

---

## 🤔 접근법

N개의 자연수 중 M개를 골라 만들 수 있는 모든 수열을 출력하는 문제.

N과 M (1)과 동일하지만, **1~N 대신 주어진 N개의 수**를 사용한다는 차이점이 있음.

**핵심**: 입력 배열을 정렬 후 DFS + visited 배열로 중복 없는 순열 생성.

---

## 💡 정답 풀이 방법

**알고리즘**: DFS (백트래킹)

```
1. N개의 수를 입력받아 정렬 (사전순 출력 보장)
2. DFS(depth) 호출
3. depth == m 이면 수열 출력 후 return
4. 0~n-1 인덱스 순회하며 visited[i]가 false인 수 선택
5. visited[i] = true → 재귀 → visited[i] = false (백트래킹)
```

---

## 🔑 핵심 포인트

### N과 M 시리즈 비교

| 문제 | 입력 | 중복 허용 | 순서 조건 |
|-----|------|---------|---------|
| N과 M (1) | 1~N | ❌ | 없음 (증가 순서) |
| N과 M (2) | 1~N | ❌ | 비내림차순 |
| N과 M (3) | 1~N | ✅ | 없음 |
| N과 M (4) | 1~N | ✅ | 비내림차순 |
| **N과 M (5)** | **주어진 N개** | **❌** | **없음** |

### 핵심 코드

```cpp
sort(nums, nums + n); // 정렬로 사전순 보장

// visited로 중복 방지, 정렬된 순서대로 탐색 → 사전순 자동 보장
if(!visited[i])
{
    visited[i] = true;
    arr[depth]  = nums[i];
    DFS(depth + 1);
    visited[i] = false; // 백트래킹
}
```

**사전순 보장 원리**:
- 입력 배열을 미리 정렬하면 DFS 탐색 순서가 곧 사전순

---

## ⏱️ 시간복잡도

**O(N! / (N-M)!)** - 순열의 경우의 수

**분석**:
- N, M ≤ 8 제약 조건에서 최대 경우의 수는 8! = 40320
- 실제 탐색은 매우 적어 시간 내 충분히 해결 가능

---

**⏱️ 시간복잡도**: O(N! / (N-M)!) - 순열

**💾 공간복잡도**: O(M) - 재귀 스택 깊이
