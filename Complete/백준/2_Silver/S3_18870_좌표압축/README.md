## 🔗 문제 링크

[백준 18870번 - 좌표 압축](https://www.acmicpc.net/problem/18870)

**난이도**: Silver 3

---

## 🤔 접근법

N개의 좌표에 대해 **좌표 압축**을 수행하는 문제.

- X'i = Xi보다 작은 **서로 다른** 좌표의 개수
- 즉, 정렬했을 때 중복 제거 후 몇 번째인지를 구하면 됨

**핵심은 정렬 + 중복 제거 후, 원래 값이 몇 번째 인덱스에 있는지 이분탐색으로 찾는 것!**

---

## 💡 정답 풀이 방법

**알고리즘** : 정렬 + 중복 제거 + 이분 탐색 (lower_bound)

**핵심 아이디어**:
```
1. 원본 배열(origin)을 복사해두고, v를 오름차순 정렬
2. unique + erase로 연속된 중복 제거
3. origin[i]가 정렬+중복제거된 v에서 몇 번째인지 lower_bound로 탐색
4. lower_bound 결과 - v.begin() = 압축된 좌표값
```

---

## 🔑 핵심 포인트

### 1️⃣ 정렬 → unique → erase 패턴

```cpp
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
```

**✅ 핵심**: 반드시 **정렬 후** unique를 사용해야 함
- `unique`는 **연속된 중복만** 제거하는 함수
- 정렬하지 않으면 떨어져 있는 중복값을 인식하지 못함

```
정렬 전: [2, 4, -10, 4, -9]
unique:  [2, 4, -10, 4, -9]  ← 4가 떨어져 있어 제거 안됨! ❌

정렬 후: [-10, -9, 2, 4, 4]
unique:  [-10, -9, 2, 4]     ← 연속된 4가 제거됨 ✅
```

#### 📖 unique 함수 상세

```cpp
unique(v.begin(), v.end())
//     ─────────  ───────
//     첫번째 매개변수: 탐색 시작 위치 (iterator)
//     두번째 매개변수: 탐색 끝 위치 (iterator)
```

**동작 방식**: 연속된 중복 원소를 벡터 **뒤쪽으로 밀어냄**
- 실제로 원소를 삭제하지 않음!
- 유효한 원소들을 앞쪽에 모아두고, **쓰레기 영역의 시작 iterator**를 반환

```
호출 전: [-10, -9, 2, 4, 4]
                           ↑ 연속 중복

호출 후: [-10, -9, 2, 4, | 4]
         ─── 유효 영역 ──  ─ 쓰레기
                           ↑ unique가 반환하는 iterator (여기부터 쓰레기)
```

**반환값**: 쓰레기 영역의 시작 iterator (= 유효한 마지막 원소 다음 위치)

#### 📖 erase 함수 상세

```cpp
v.erase(unique(v.begin(), v.end()), v.end())
//      ──────────────────────────  ───────
//      첫번째 매개변수: 삭제 시작 위치 (= unique의 반환값, 쓰레기 시작)
//      두번째 매개변수: 삭제 끝 위치 (= 벡터의 끝)
```

**동작 방식**: 첫번째 ~ 두번째 범위의 원소를 실제로 삭제

```
erase 전: [-10, -9, 2, 4, | 4]
          ─── 유효 영역 ──  ─ 삭제 대상

erase 후: [-10, -9, 2, 4]  ← 쓰레기 영역이 실제로 제거됨!
```

#### 📖 전체 흐름 정리

```
1. sort   → [-10, -9, 2, 4, 4]         중복을 연속으로 모음
2. unique → [-10, -9, 2, 4, | 4]       연속 중복을 뒤로 밀고, 쓰레기 시작점 반환
3. erase  → [-10, -9, 2, 4]            쓰레기 영역 실제 삭제
```

**⚠️ unique만 쓰면 안 되는 이유**: unique는 삭제하지 않고 뒤로 밀기만 함!
- 벡터의 `size()`가 그대로이므로, `erase`로 실제 삭제해줘야 함


```
★☆★ 백터에서 unique를 통해서 중복되는 값들을 위로 밀어내고, 밀어져 있는 백터의 중복 시작 위치부터, 끝까지를 삭제하면, 중복이 사라진 백터 완성!
```

### 2️⃣ lower_bound로 인덱스 계산

```cpp
lower_bound(v.begin(), v.end(), origin[i]) - v.begin()
```

**✅ 핵심**: 정렬+중복제거된 벡터에서의 위치 = 자신보다 작은 서로 다른 값의 개수
- `lower_bound`: 정렬된 범위에서 해당 값 **이상**인 첫 번째 iterator 반환
- `- v.begin()`: iterator를 인덱스(int)로 변환
- 이분 탐색 기반이라 O(log N)

```
v (정렬+중복제거): [-10, -9, 2, 4]
                     0    1   2  3

lower_bound(2) → idx 2   (2보다 작은 서로 다른 값: -10, -9 = 2개) ✅
lower_bound(4) → idx 3   (4보다 작은 서로 다른 값: -10, -9, 2 = 3개) ✅
```

### 3️⃣ origin 벡터로 원래 순서 보장

```cpp
origin = v;       // 정렬 전에 복사
sort(v.begin(), v.end());
```

**✅ 핵심**: 정렬하면 원래 순서가 사라지므로, 미리 복사해둬야 함
- `origin[i]`: 입력 순서대로 접근하여 출력 순서 보장

## ⏱️ 시간복잡도

**O(N log N)**

**분석**:
- 정렬: O(N log N)
- unique + erase: O(N)
- lower_bound × N번: O(N log N)
- 전체: O(N log N)

**실제 계산**:
```
- N ≤ 1,000,000
- O(N log N) ≈ 1,000,000 × 20 = 20,000,000 연산
- O(2 × 10^7) << 10^8 (2초 기준)
```

**✅ 결론**: 충분히 시간 제한(2초) 내에 해결 가능

---

## 💾 공간복잡도

**O(N)**

**분석**:
- `v`: 정렬 + 중복 제거용 벡터 → O(N)
- `origin`: 원본 순서 보존용 벡터 → O(N)

**총 공간**: O(N) ≈ **O(10^6)** (N=1,000,000일 때)
