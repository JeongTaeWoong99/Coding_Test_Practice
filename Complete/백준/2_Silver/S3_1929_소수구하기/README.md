## 🔗 문제 링크

[백준 1929번 - 소수 구하기](https://www.acmicpc.net/problem/1929)

**난이도**: Silver 3

---

## 🤔 접근법

M이상 N이하의 소수를 모두 출력하는 문제.

**핵심**: 단순히 각 숫자마다 소수 판별하면 시간 초과. 

**에라토스테네스의 체**를 활용하여 한 번에 소수를 걸러내야 함.

---

## 💡 정답 풀이 방법

**알고리즘**: 에라토스테네스의 체 (Sieve of Eratosthenes)

**핵심 아이디어**:
```
1. 2부터 N까지 모든 수를 소수로 가정 (isPrime = true)
2. 0과 1은 소수가 아니므로 false 처리
3. 2부터 √N까지 순회하며:
   - 현재 수가 소수면, 그 수의 배수를 모두 소수에서 제외
   - i의 배수 제거 시 i*i부터 시작 (i*2, i*3, ... i*(i-1)은 이미 제거됨)
4. M부터 N까지 순회하며 소수만 출력
```

---

## 🔑 핵심 개념

### 1️⃣ 에라토스테네스의 체 원리

**기본 아이디어**: 소수의 배수는 소수가 아니다!

```cpp
// 에라토스테네스의 체
for (int i = 2; i * i <= n; i++)
{
    if (!isPrime[i]) continue;  // 이미 제거된 수는 스킵

    for (int j = i * i; j <= n; j += i)  // i의 배수 제거
        isPrime[j] = false;
}
```

### 2️⃣ 왜 i*i 부터 시작하는가?

**핵심 최적화**: i×j (j < i)는 이미 j단계에서 제거되었음!

| i | 시작점 | 이유 |
|---|--------|------|
| 2 | 2×2=4 | 2×1=2는 자기 자신 |
| 3 | 3×3=9 | 3×2=6은 이미 2의 배수로 제거됨 |
| 5 | 5×5=25 | 5×2, 5×3, 5×4는 이미 2, 3의 배수로 제거됨 |
| 7 | 7×7=49 | 7×2~7×6은 이미 제거됨 |

### 3️⃣ 왜 √N까지만 검사하는가?

**수학적 원리**: N = a × b 일 때, a와 b 중 하나는 반드시 √N 이하

```
예: N = 100
- 100 = 2 × 50 (2 ≤ √100 = 10)
- 100 = 4 × 25 (4 ≤ 10)
- 100 = 5 × 20 (5 ≤ 10)
- 100 = 10 × 10 (10 = √100)

√N보다 큰 약수는 √N보다 작은 약수의 짝!
→ √N까지만 검사하면 모든 합성수 제거 가능
```

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ 0과 1은 소수가 아님!

```cpp
❌ fill_n(&isPrime[0], 1000001, true);  // 0, 1도 true가 됨!

✅ fill_n(&isPrime[0], 1000001, true);
   isPrime[0] = isPrime[1] = false;  // 반드시 처리!
```

**이유**: M=1일 때 1이 출력되면 틀림!

### 2️⃣ bool 배열 사용 권장

❌ int arr[1000001];  // ~4MB 메모리

## ⏱️ 시간복잡도

**O(N log log N)** - 에라토스테네스의 체

**분석**:
```
- 2의 배수 제거: N/2번
- 3의 배수 제거: N/3번
- 5의 배수 제거: N/5번
- ...

총합 = N × (1/2 + 1/3 + 1/5 + 1/7 + ...) = N × Σ(1/p) ≈ N log log N
```

**비교**:

| 방법 | 시간복잡도 | N=1,000,000 기준 |
|------|------------|------------------|
| 단순 소수 판별 | O(N√N) | ~10억 연산 ❌ |
| 에라토스테네스 체 | O(N log log N) | ~2천만 연산 ✅ |

## 💾 공간복잡도

- `bool isPrime[1000001]` : ~1MB
