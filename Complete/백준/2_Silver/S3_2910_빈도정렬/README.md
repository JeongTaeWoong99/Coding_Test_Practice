## 🤔 접근법

숫자 수열을 빈도순으로 정렬하는 문제.

**핵심**: 등장 횟수가 많은 숫자를 앞에 배치하고, 횟수가 같으면 먼저 등장한 숫자를 앞에 배치.

빈도수와 등장 순서를 모두 고려한 커스텀 정렬이 필요.

---

## 💡 정답 풀이 방법

**알고리즘**: 정렬 + 맵(Map) + 커스텀 비교 함수

**핵심 아이디어**:
```
1. Map으로 각 숫자의 빈도수 카운트
2. 최초 등장 위치를 별도 Map으로 저장
3. {빈도수, 값} 쌍을 벡터에 저장
4. 커스텀 비교 함수로 정렬
5. 빈도수만큼 숫자 출력
```

## 🔑 핵심 개념

### 1️⃣ 두 개의 Map 활용

```cpp
map<int, int> mp;          // 빈도수 저장
map<int, int> mp_first;    // 최초 등장 위치 저장 (1-based)

for(int i = 0; i < N; i++)
{
    cin >> arr[i];
    mp[arr[i]]++;          // 빈도수 증가

    if(mp_first[arr[i]] == 0)  // 처음 나온 경우만
        mp_first[arr[i]] = i + 1;  // 위치 저장
}
```

**✅ 핵심**:
- `mp[arr[i]]++`: 키가 없으면 자동으로 0으로 초기화된 후 1 증가
- `mp_first[arr[i]] == 0`: 처음 등장하는지 확인 (map은 없는 키 접근 시 0 반환)
- `i + 1`: 1-based 인덱싱으로 저장 (0은 "미등장"을 의미)

### 2️⃣ {빈도수, 값} 쌍으로 변환

```cpp
vector<pair<int, int>> v;  // {빈도수, 값}

for(auto it : mp)
    v.emplace_back(it.second, it.first);
    // it.first = 숫자 값
    // it.second = 빈도수
```

**✅ 핵심**: 정렬을 위해 빈도수를 first에, 값을 second에 저장

### 3️⃣ 커스텀 비교 함수

```cpp
bool CMP(pair<int,int> a, pair<int, int> b)
{
    // 빈도수가 같다면 → 먼저 등장한 숫자가 앞에 오도록
    // → a가 b보다 작으면 a를 앞에 → ☆ 등장 순서 mp_first가 작아야, 먼저 나왔다는 뜻
    if(a.first == b.first)
        return mp_first[a.second] < mp_first[b.second];

    // 빈도수가 다르면 → 더 자주 등장한 숫자가 앞에 오도록
    // → a가 b보다 크면 a를 앞에 → 빈도수가 더 높은걸 앞에
    return a.first > b.first;
}
```

**✅ 정렬 기준**:
1. **1순위**: 빈도수 내림차순 (`a.first > b.first`)
2. **2순위**: 최초 등장 위치 오름차순 (`mp_first[a.second] < mp_first[b.second]`)

<br>

### 🔑 커스텀 비교 함수 동작 원리

#### 💡 return true/false의 의미

```cpp
bool CMP(A a, A b)
{
    return [조건];
}
```

**핵심 규칙**:
- `return true` → **"a를 b보다 앞에 배치"**
- `return false` → **"b를 a보다 앞에 배치"**

<br>

#### 📊 정렬 방향 결정

**🔹 오름차순 (작은 것이 앞으로)**
```cpp
return a < b;  // a가 b보다 작으면 a를 앞에
// 결과: [1, 2, 5, 8]
```

**🔹 내림차순 (큰 것이 앞으로)**
```cpp
return a > b;  // a가 b보다 크면 a를 앞에
// 결과: [8, 5, 2, 1]
```

<br>

#### 🎯 이 문제에서의 적용

**1순위: 빈도수 내림차순**
```cpp
return a.first > b.first;
```
- `a.first > b.first`가 true → a의 빈도수가 더 큼 → **a를 앞에**
- 빈도수가 **높은** 것을 앞에 배치 (내림차순)

**2순위: 등장 순서 오름차순**
```cpp
return mp_first[a.second] < mp_first[b.second];
```
- `mp_first[a.second] < mp_first[b.second]`가 true → a가 먼저 등장 → **a를 앞에**
- **먼저** 등장한 것을 앞에 배치 (오름차순)

<br>

#### 📋 비교 결과 요약표

| 조건 | return 값 | 의미 | 배치 결과 |
|------|----------|------|----------|
| `a.first > b.first` | **true** | a의 빈도수가 더 큼 | **a를 b보다 앞에** |
| `a.first > b.first` | **false** | b의 빈도수가 더 크거나 같음 | **b를 a보다 앞에** |
| `mp_first[a] < mp_first[b]` | **true** | a가 먼저 등장 | **a를 b보다 앞에** |
| `mp_first[a] < mp_first[b]` | **false** | b가 먼저 등장하거나 같음 | **b를 a보다 앞에** |

### 4️⃣ 빈도수만큼 출력

```cpp
for(auto i : v)
{
    for(int j = 0; j < i.first; j++)  // i.first = 빈도수
    {
        cout << i.second << " ";      // i.second = 숫자 값
    }
}
```

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ Map의 자동 초기화 활용

```cpp
✅ mp[arr[i]]++;  // 키가 없으면 0으로 자동 초기화 후 증가

❌ if (mp.find(arr[i]) != mp.end())
      mp[arr[i]]++;
   else
      mp[arr[i]] = 1;  // 불필요한 코드
```

**이유**: C++ map은 없는 키에 접근하면 자동으로 0으로 초기화됨!

### 2️⃣ 1-based 인덱싱으로 "미등장" 구분

```cpp
✅ if(mp_first[arr[i]] == 0)  // 0은 미등장을 의미
      mp_first[arr[i]] = i + 1;  // 1부터 시작

❌ if(mp_first.find(arr[i]) == mp_first.end())  // 복잡함
      mp_first[arr[i]] = i;  // 0이 첫 등장과 구분 안 됨
```

**이유**:
- map은 없는 키 접근 시 0 반환
- 인덱스 0과 "미등장"을 구분하기 위해 1-based 사용

### 3️⃣ 빈도수를 pair의 first에 배치

```cpp
✅ v.emplace_back(it.second, it.first);  // {빈도수, 값}

❌ v.emplace_back(it.first, it.second);  // {값, 빈도수}
```

**이유**:
- `sort()`는 기본적으로 first를 먼저 비교
- 빈도수 기준 정렬이 우선이므로 first에 배치

### 4️⃣ 커스텀 비교 함수에서 전역 map 참조

```cpp
✅ bool CMP(pair<int,int> a, pair<int, int> b)
   {
       if(a.first == b.first)
           return mp_first[a.second] < mp_first[b.second];
       return a.first > b.first;
   }

❌ // mp_first를 매개변수로 전달하려 하면 복잡해짐
```

**이유**: 전역 변수로 선언하면 비교 함수에서 간단히 참조 가능

## ⏱️ 시간복잡도 분석

**전체 시간복잡도**: **O(N log N + M log M)**

### 🔍 단계별 분석

**1단계: 빈도수 카운트**
```cpp
for(int i = 0; i < N; i++)
{
    mp[arr[i]]++;          // O(log M) - M은 서로 다른 숫자 개수(레드 블랙 트리)
    if(mp_first[arr[i]] == 0)
        mp_first[arr[i]] = i + 1;  // O(log M)
}
```
- N번 반복
- 각 반복마다 map 삽입: O(log M)
- **시간복잡도**: **O(N log M)**

**2단계: 벡터 변환**
```cpp
for(auto it : mp)
    v.emplace_back(it.second, it.first);
```
- M개 원소 순회
- **시간복잡도**: **O(M)**

**3단계: 정렬**
```cpp
sort(v.begin(), v.end(), CMP);
```
- M개 원소 정렬
- **시간복잡도**: **O(M log M)**

**4단계: 출력**
```cpp
for(auto i : v)
    for(int j = 0; j < i.first; j++)
        cout << i.second << " ";
```
- 총 N개 숫자 출력
- **시간복잡도**: **O(N)**

**전체**: **O(N log M + M log M + N) ≈ O(N log N + M log M)**

### 📊 제한 사항 검증

- N ≤ 1,000 (숫자 개수)
- M ≤ N (서로 다른 숫자 개수)
- 최악: N log N + N log N = 2 × 1,000 × 10 ≈ **20,000**
- 20,000 << 100,000,000 (1억) → **여유롭게 통과** ✅

## 🔑 핵심: map 자동 초기화

### 💡 map의 operator[] 동작 원리

```cpp
map<int, int> mp;

// 키가 없는 경우
int value = mp[100];  // 키 100이 없으면 mp[100] = 0 자동 생성
cout << value;        // 출력: 0

// mp[arr[i]]++ 동작 과정
mp[arr[i]]++;
// 1. mp에서 키 arr[i] 검색
// 2. 없으면 mp[arr[i]] = 0으로 자동 생성
// 3. mp[arr[i]]++ 실행 → 0에서 1로 증가
```

### ⚡ 주의사항

```cpp
✅ 빈도수 카운팅: mp[key]++ 사용 (자동 초기화 활용)

❌ 존재 여부 확인: if (mp[key]) → 부작용 발생!
   → mp.find(key) != mp.end() 또는 mp.count(key) 사용

✅ 이 문제에서는:
   if(mp_first[arr[i]] == 0)  // 없으면 0 반환, 존재 확인용으로 사용
```
