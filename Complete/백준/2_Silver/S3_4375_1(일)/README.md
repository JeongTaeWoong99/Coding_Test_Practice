[백준 4375번 - 1](https://www.acmicpc.net/problem/4375)

## 🤔 접근법

2와 5로 나누어떨어지지 않는 정수 n이 주어질 때, 각 자릿수가 모두 1로만 이루어진 n의 배수를 찾는 문제.

예를 들어, n=3이면 111 (3의 배수), n=7이면 111111 (7의 배수)을 찾아야 한다.

**핵심**:
- 모든 자릿수가 1인 수를 직접 만들면 숫자가 너무 커짐 (오버플로우)
- **모듈러 연산의 성질**을 활용하여 나머지만 추적

---

## 💡 정답 풀이 방법

**알고리즘**: 모듈러 연산 + 브루트포스

**핵심 아이디어**:
```
1. 1, 11, 111, 1111, ... 을 직접 만들지 않고 나머지만 추적
2. 다음 수 = (현재 나머지 × 10 + 1) % n
3. 나머지가 0이 될 때까지 반복
4. 자릿수를 카운트하여 출력
```

**시간 복잡도**: O(n)
- 최악의 경우 n번 반복
- n ≤ 10,000이므로 충분히 빠름

**공간 복잡도**: O(1)
- 변수 몇 개만 사용

## 🔑 핵심 포인트

### 1️⃣ 모듈러 연산의 성질

```cpp
// 일반적인 방법 (오버플로우 발생!)
int num = 1;
while (num % n != 0) 
{
    num = num * 10 + 1;  // 111...1 (너무 커짐!)
}
```

**❌ 문제점**:
- 1111111111... 같은 큰 수는 int, long long도 표현 불가
- n=9901일 때 답이 12자리 → 직접 계산 불가능

```cpp
// 모듈러 연산 활용 (올바른 방법!)
int cnt = 1;  // 나머지만 저장
while (cnt % n != 0) 
{
    cnt = (cnt * 10 + 1) % n;  // 나머지만 추적
}
```

**✅ 핵심**:
- `(a × b + c) % n = ((a % n) × b + c) % n`
- 나머지만 유지하면서 다음 수 계산
- 실제 큰 수를 만들지 않아도 됨

### 2️⃣ 다음 수 계산 공식

```cpp
cnt = ((cnt * 10) + 1) % n;
```

**동작 원리**:
```
n = 3일 때:
cnt = 1      → 1  % 3 = 1 (자릿수 1)
cnt = 1*10+1 = 11 % 3 = 2 (자릿수 2)
cnt = 2*10+1 = 21 % 3 = 0 (자릿수 3) → 답: 3
```

**의미**:
- 현재 나머지에 10을 곱하고 1을 더함
- 이는 뒤에 1을 추가하는 것과 동일
- 나머지만 유지하여 오버플로우 방지

### 3️⃣ while(cin >> n) 패턴

```cpp
while (cin >> n)  // 입력이 있을 때까지 계속 읽음
{
    // 처리
}
```

**특징**:
- 입력 개수가 명시되지 않은 경우
- EOF(End of File)까지 계속 입력
- Windows: `Ctrl+Z` + Enter로 종료
- Linux/Mac: `Ctrl+D`로 종료

## 📊 예제 동작 과정 (n=7)

**입력**: `7`

**목표**: 111111 (7의 배수, 6자리)

```
┌─────┬─────┬──────────────┬────────┬─────────┐
│ 단계 │ cnt │ 계산 과정    │ cnt%7  │ 자릿수   │
├─────┼─────┼──────────────┼────────┼─────────┤
│ 1   │ 1   │ 1 % 7        │ 1      │ 1       │
│ 2   │ 11  │ (1*10+1)%7   │ 4      │ 2       │
│ 3   │ 41  │ (4*10+1)%7   │ 6      │ 3       │
│ 4   │ 61  │ (6*10+1)%7   │ 5      │ 4       │
│ 5   │ 51  │ (5*10+1)%7   │ 2      │ 5       │
│ 6   │ 21  │ (2*10+1)%7   │ 0 ✅   │ 6       │
└─────┴─────┴──────────────┴────────┴─────────┘

답: 6 (111111은 7로 나누어떨어짐)
```

**검증**:
```
111111 ÷ 7 = 15873 (정확히 나누어떨어짐!)
```

## 🔍 모듈러 연산 원리 상세 분석

### 📐 왜 나머지만 추적해도 되는가?

**수학적 근거**:
```
어떤 수 X를 n으로 나눈 나머지 = X % n

X = 111...1 (k자리)
다음 수 Y = 111...11 (k+1자리) = X * 10 + 1

Y % n = (X * 10 + 1) % n
      = ((X % n) * 10 + 1) % n  ← 모듈러 연산의 성질
```

**예시 (n=7, k=3 → k=4)**:
```
X = 111, X % 7 = 6
Y = 1111 = 111 * 10 + 1 = 1111

직접 계산:
Y % 7 = 1111 % 7 = 5

나머지만 이용:
Y % 7 = (6 * 10 + 1) % 7 = 61 % 7 = 5 ✅
→ 결과 동일!
```

### 🧮 모듈러 연산의 핵심 성질

```cpp
(a + b) % n = ((a % n) + (b % n)) % n
(a × b) % n = ((a % n) × (b % n)) % n
```

**적용**:
```cpp
// 다음 수 = (현재 나머지 × 10 + 1) % n
cnt = ((cnt % n) * 10 + 1) % n
    = ((cnt * 10) + 1) % n  // cnt는 이미 % n 된 상태
```

## 🎯 핵심 교훈

### ✅ 큰 수 처리 패턴

**문제 상황**:
- 111111111... 같은 수는 직접 계산 불가능
- long long도 표현 범위 제한 있음

**해결책**:
- **나머지만 추적**
- 모듈러 연산의 성질 활용
- 실제 큰 수를 만들지 않음

### ✅ 모듈러 연산 활용

```cpp
// ❌ 오버플로우 위험
int num = 1;
while (num % n != 0) {
    num = num * 10 + 1;  // 너무 커질 수 있음
}

// ✅ 안전한 방법
int cnt = 1;
while (cnt % n != 0) {
    cnt = (cnt * 10 + 1) % n;  // 항상 작은 값 유지
}
```

### ✅ 입력 패턴

```cpp
// 입력 개수 명시
int T;
cin >> T;
while(T--) { ... }

// 입력 개수 미명시 (이 문제)
while(cin >> n) { ... }  // EOF까지 계속 읽음
```
