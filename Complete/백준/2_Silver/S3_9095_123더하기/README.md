## 🔗 문제 링크

[백준 9095번 - 1, 2, 3 더하기](https://www.acmicpc.net/problem/9095)

**난이도**: Silver 3

---

## 🤔 접근법

(바텀업 DP 방식이 가장 효율적!)

정수 N을 1, 2, 3의 합으로 나타내는 방법의 수를 구하는 문제.

**핵심**: **동적 계획법(DP)**으로 각 숫자를 만드는 경우의 수를 저장!

**점화식 유도**:
- N을 만들 때 마지막에 1을 더하는 경우 → `dp[N-1]`
- N을 만들 때 마지막에 2를 더하는 경우 → `dp[N-2]`
- N을 만들 때 마지막에 3을 더하는 경우 → `dp[N-3]`

```
dp[N] = dp[N-1] + dp[N-2] + dp[N-3]
```

---

## 💡 정답 풀이 방법

**알고리즘**: Bottom-up DP (반복문 + 전처리)

**핵심 아이디어**:
```
1. 베이스 케이스 설정
   - dp[0] = 1 (아무것도 안 더해서 0을 만드는 방법 = 1가지)
   - dp[1] = 1 (1)
   - dp[2] = 2 (1+1, 2)
   - dp[3] = 4 (1+1+1, 1+2, 2+1, 3)

2. i = 4부터 10까지 dp 테이블 채우기
   - dp[i] = dp[i-1] + dp[i-2] + dp[i-3]

3. 테스트케이스마다 dp[n] 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 점화식의 의미

```cpp
dp[i] = dp[i-1] + dp[i-2] + dp[i-3];
```

**의미**:
- `dp[i-1]`: 마지막에 **1**을 더해서 i를 만드는 경우의 수
- `dp[i-2]`: 마지막에 **2**를 더해서 i를 만드는 경우의 수
- `dp[i-3]`: 마지막에 **3**을 더해서 i를 만드는 경우의 수

### 2️⃣ DP 배열 갱신 과정

```
dp[0] = 1
dp[1] = 1
dp[2] = 2
dp[3] = 4
dp[4] = dp[3] + dp[2] + dp[1] = 4 + 2 + 1 = 7
dp[5] = dp[4] + dp[3] + dp[2] = 7 + 4 + 2 = 13
dp[6] = dp[5] + dp[4] + dp[3] = 13 + 7 + 4 = 24
dp[7] = dp[6] + dp[5] + dp[4] = 24 + 13 + 7 = 44
dp[8] = dp[7] + dp[6] + dp[5] = 44 + 24 + 13 = 81
dp[9] = dp[8] + dp[7] + dp[6] = 81 + 44 + 24 = 149
dp[10] = dp[9] + dp[8] + dp[7] = 149 + 81 + 44 = 274
```

### 3️⃣ 트리보나치 수열

이 점화식은 **트리보나치(Tribonacci) 수열**과 동일한 형태!

```
피보나치:   F(n) = F(n-1) + F(n-2)
트리보나치: T(n) = T(n-1) + T(n-2) + T(n-3)
```

### 4️⃣ 전처리의 장점

```cpp
// 테스트케이스 입력 전에 dp 테이블을 미리 채움
for (int i = 4; i <= 10; ++i)
    dp[i] = dp[i-1] + dp[i-2] + dp[i-3];
```

**✅ 장점**:
- 테스트케이스마다 계산하지 않음
- 쿼리당 O(1)로 즉시 응답

## 🆚 다른 접근법

### 탑다운 DP (메모이제이션)

```cpp
int solve(int n)
{
    if (n <= 0) return (n == 0) ? 1 : 0;
    if (dp[n] != -1) return dp[n];

    return dp[n] = solve(n-1) + solve(n-2) + solve(n-3);
}
```

### 완전탐색 (브루트포스)

```cpp
int solve(int remain)
{
    if (remain == 0) return 1;
    if (remain < 0)  return 0;

    return solve(remain-1) + solve(remain-2) + solve(remain-3);
}
```

**N ≤ 10**이므로 완전탐색도 가능하지만, **바텀업 DP가 가장 효율적**!

## ⏱️ 시간복잡도

**O(N + T)**
- N = 최대 입력값 (10)
- T = 테스트케이스 수
- 전처리: O(N), 쿼리당 O(1)
