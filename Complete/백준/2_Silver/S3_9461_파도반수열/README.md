## 🔗 문제 링크

[백준 9461번 - 파도반 수열](https://www.acmicpc.net/problem/9461)

**난이도**: Silver 3

---

## 🤔 접근법

(바텀업 dp로 해결.)

삼각형이 나선 모양으로 배치될 때, N번째 삼각형의 변의 길이를 구하는 문제.

**파도반 수열**: P(1)~P(10) = 1, 1, 1, 2, 2, 3, 4, 5, 7, 9

**핵심**: 규칙을 찾아 **점화식**을 세우고 **DP**로 해결!

**점화식 유도**:
```
P(N) = P(N-2) + P(N-3)
```

---

## 💡 정답 풀이 방법

**알고리즘**: Bottom-up DP (반복문 + 전처리)

**핵심 아이디어**:
```
1. 베이스 케이스 설정 (0-indexed 사용)
   - dp[0] = 1 (P(1))
   - dp[1] = 1 (P(2))
   - dp[2] = 1 (P(3))

2. i = 3부터 100까지 dp 테이블 채우기
   - dp[i] = dp[i-2] + dp[i-3]

3. 테스트케이스마다 dp[n-1] 출력 (인덱스 보정)
```

---

## 🔑 핵심 포인트

### 1️⃣ 점화식 발견

수열의 패턴을 분석:

```
P(1)  = 1
P(2)  = 1
P(3)  = 1
P(4)  = 2 = P(2) + P(1) = 1 + 1
P(5)  = 2 = P(3) + P(2) = 1 + 1
P(6)  = 3 = P(4) + P(3) = 2 + 1
P(7)  = 4 = P(5) + P(4) = 2 + 2
P(8)  = 5 = P(6) + P(5) = 3 + 2
P(9)  = 7 = P(7) + P(6) = 4 + 3
P(10) = 9 = P(8) + P(7) = 5 + 4
```

**점화식**: `P(N) = P(N-2) + P(N-3)` (N ≥ 4)

### 2️⃣ ⚠️ int 오버플로우 주의!

**이 문제의 함정!**

```cpp
int dp[104];       // ❌ 틀림! (오버플로우)
long long dp[104]; // ✅ 정답!
```

**이유**:
- N ≤ 100이고, P(100)은 매우 큰 수
- P(100) ≈ 2,686,725,038,695 (약 2.7조)
- int 최대값 ≈ 2,147,483,647 (약 21억)
- **P(100)은 int 범위를 약 1,250배 초과!**

| N | P(N) | int 범위 |
|---|------|----------|
| 50 | 176,418,891 | ✅ OK |
| 60 | 3,329,199,741 | ❌ 초과! |
| 100 | 2,686,725,038,695 | ❌ 훨씬 초과! |

### 3️⃣ 인덱스 보정

```cpp
cout << dp[temp - 1] << '\n';  // P(N) = dp[N-1]
```

**✅ 이유**:
- 문제: P(1), P(2), P(3), ... (1-indexed)
- 배열: dp[0], dp[1], dp[2], ... (0-indexed)
- P(N) = dp[N-1]

### 4️⃣ 피보나치와의 비교

| 수열 | 점화식 | 참조하는 이전 항 |
|-----|--------|----------------|
| 피보나치 | F(N) = F(N-1) + F(N-2) | 2개 |
| 트리보나치 | T(N) = T(N-1) + T(N-2) + T(N-3) | 3개 |
| **파도반** | P(N) = P(N-2) + P(N-3) | 2개 (N-1 제외) |

## ⏱️ 시간복잡도

**O(N + T)**
- N = 최대 입력값 (100)
- T = 테스트케이스 수
- 전처리: O(N), 쿼리당 O(1)

**O(N)**
