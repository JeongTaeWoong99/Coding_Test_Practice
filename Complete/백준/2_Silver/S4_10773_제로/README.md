## 🤔 접근법

스택을 활용한 전형적인 구현 문제.

재현이가 숫자를 부를 때마다 장부에 기록하고, 0을 외치면 가장 최근에 쓴 수를 지우는 문제.

**핵심**: 0이 아니면 스택에 push, 0이면 pop하여 최근 수를 제거!

---

## 💡 정답 풀이 방법

**알고리즘**: 스택(Stack) 활용

**핵심 아이디어**:
```
1. K개의 정수를 순서대로 입력받음
2. 0이 아닌 정수는 스택에 push
3. 0이면 스택에서 pop (가장 최근에 쓴 수 제거)
4. 모든 입력 처리 후 스택에 남은 수들의 합을 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 스택을 활용한 기본 연산

```cpp
stack<int> stk;

for (int i = 0; i < n; ++i)
{
    cin >> temp;

    if (temp != 0) stk.push(temp);  // 0이 아니면 스택에 추가
    else           stk.pop();       // 0이면 최근 수 제거
}
```

**✅ 핵심**:
- 0이 아닌 수는 스택에 저장
- 0이면 가장 최근 수를 제거 (LIFO 구조)
- 스택의 후입선출 특성을 활용

### 2️⃣ 스택에 남은 수들의 합 계산

```cpp
// 스택에 남아있는 모든 수의 합 계산
while (!stk.empty())
{
    cnt += stk.top();
    stk.pop();
}
```

**✅ 핵심**: 스택이 빌 때까지 순회
- `stk.top()`으로 현재 값을 가져와 합산
- `stk.pop()`으로 스택에서 제거
- 최종적으로 남은 모든 수의 합 계산

## 📊 동작 예시

### 🎯 예제 1: 입력 [3, 0, 4, 0]

```
입력 처리:
  시작: []
  3 입력: [3]           (0이 아님 → push)
  0 입력: []            (0 → pop) ⭐
  4 입력: [4]           (0이 아님 → push)
  0 입력: []            (0 → pop) ⭐

최종 스택: []
합계: 0
```

### 🎯 예제 2: 입력 [1, 3, 5, 4, 0, 0, 7, 0, 0, 6]

```
입력 처리:
  시작: []
  1 입력: [1]           (0이 아님 → push)
  3 입력: [1, 3]        (0이 아님 → push)
  5 입력: [1, 3, 5]     (0이 아님 → push)
  4 입력: [1, 3, 5, 4]  (0이 아님 → push)
  0 입력: [1, 3, 5]     (0 → pop) ⭐
  0 입력: [1, 3]        (0 → pop) ⭐
  7 입력: [1, 3, 7]     (0이 아님 → push)
  0 입력: [1, 3]        (0 → pop) ⭐
  0 입력: [1]           (0 → pop) ⭐
  6 입력: [1, 6]        (0이 아님 → push)

최종 스택: [1, 6]
합계: 1 + 6 = 7
```

## ⏱️ 시간복잡도

**O(K)**

**분석**:
- K: 정수의 개수 (1 ≤ K ≤ 100,000)
- K개의 정수를 순회하며 각각:
  - 스택 push/pop 연산: O(1)
  - 총 O(K)
- 스택의 모든 원소 합산: O(K) (최악의 경우 모든 수가 남아있음)

**총합**: O(K) + O(K) = **O(K)**

---

## 💾 공간복잡도

**O(K)**

**분석**:
- `stack<int> stk`: 최악의 경우 모든 수를 저장 → O(K)
  - 예: 0이 한 번도 입력되지 않은 경우
- 최대 K = 100,000개의 정수 저장
