## 🔗 문제 링크

[백준 11047번 - 동전 0](https://www.acmicpc.net/problem/11047)

**난이도**: Silver 4

---

## 🤔 접근법

N종류의 동전으로 K원을 만들 때 필요한 **최소 동전 개수**를 구하는 문제.

**핵심**: 동전이 **배수 관계**이므로 **그리디** 적용 가능!
- 큰 동전부터 최대한 사용하면 최적해 보장

---

## 💡 정답 풀이 방법

**알고리즘**: 그리디 (Greedy)

```
1. 큰 동전부터 순회
2. 현재 동전으로 만들 수 있는 최대 개수(몫) 사용
3. 나머지 금액으로 갱신
4. K가 0이면 종료
```

---

## 🔑 핵심 포인트

### 1️⃣ 그리디가 성립하는 이유

> **"Ai는 Ai-1의 배수"** 조건이 핵심!

- 500원 1개 = 100원 5개 (항상 큰 동전이 유리)
- 배수 관계가 아니면 그리디 불가 (예: 1, 3, 4원으로 6원 만들기)

### 2️⃣ 최적화 포인트

| 항목 | 원본 | 최적화 |
|-----|-----|--------|
| 정렬 | `sort()` 사용 | ❌ 불필요 (입력이 이미 오름차순!) |
| 자료구조 | `vector` | 고정 배열 `int arr[10]` |
| 나눗셈 | `k/num` 2번 계산 | 변수에 1번만 저장 |
| 순회 | 정방향 (내림차순 정렬 후) | **역방향** (`n-1 → 0`) |

---

## 📊 시간복잡도

**O(N)** - N개의 동전을 한 번씩 순회

- N ≤ 10이므로 매우 여유로움
- 정렬 제거 시 O(N log N) → O(N) 개선
