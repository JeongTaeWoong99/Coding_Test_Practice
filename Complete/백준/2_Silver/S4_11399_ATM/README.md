## 🔗 문제 링크

[백준 11399번 - ATM](https://www.acmicpc.net/problem/11399)

**난이도**: Silver 4

---

## 🤔 접근법

N명이 ATM 앞에 줄 서 있을 때, **각 사람이 돈을 인출하는데 필요한 시간의 합**의 최솟값을 구하는 문제.

**핵심**: 시간이 짧은 사람부터 먼저 → **그리디** (오름차순 정렬)

---

## 💡 정답 풀이 방법

**알고리즘**: 그리디 (Greedy) + 정렬

```
1. 인출 시간 오름차순 정렬
2. 각 사람의 대기시간 누적 합 계산
3. 총합 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ 그리디가 성립하는 이유

> 시간이 짧은 사람이 먼저 인출하면 뒤에 기다리는 모든 사람의 대기시간이 줄어듦!

**예시**: `[3, 1, 4, 3, 2]` → 정렬 후 `[1, 2, 3, 3, 4]`
- 1번: 1분
- 2번: 1+2 = 3분
- 3번: 1+2+3 = 6분
- 4번: 1+2+3+3 = 9분
- 5번: 1+2+3+3+4 = 13분
- **총합**: 32분

### 2️⃣ 최적화: 2중 for문 → 단일 for문

**관찰**: `P[i]`는 총 `(n - i)`번 더해짐!

| 방식 | 코드 | 시간복잡도 |
|-----|------|-----------|
| 2중 for문 | `for i` → `for j=0 to i` → `cnt += v[j]` | O(N²) |
| **가중치 곱셈** | `ans += arr[i] * (n - i)` | **O(N)** |

```cpp
// 2중 for문 (원본)
for (int i = 0; i < n; ++i)
    for (int j = 0; j <= i; ++j)
        cnt += v[j];

// 단일 for문 (최적화)
for (int i = 0; i < n; ++i)
    ans += arr[i] * (n - i);
```

---

## 📊 시간복잡도

**O(N log N)** - 정렬이 지배적

- 정렬: O(N log N)
- 합 계산: O(N) (최적화) / O(N²) (2중 for문)
- N ≤ 1,000이므로 두 방식 모두 통과 가능

---

**⏱️ 시간복잡도**: O(N log N)

**💾 공간복잡도**: O(N)
