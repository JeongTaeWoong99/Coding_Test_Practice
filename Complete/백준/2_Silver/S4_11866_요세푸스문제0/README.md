## 🔗 문제 링크

[백준 11866번 - 요세푸스 문제 0](https://www.acmicpc.net/problem/11866)

**난이도**: Silver 4

---

## 🤔 접근법

N명의 사람이 원을 이루며 앉아있고, 순서대로 K번째 사람을 제거하는 요세푸스 문제.

한 사람이 제거되면 남은 사람들로 원을 이루어 계속 진행.

**핵심**: 큐(Queue)의 FIFO 특성을 활용하여 원형 회전을 시뮬레이션!

---

## 💡 정답 풀이 방법

**알고리즘**: 큐(Queue) 시뮬레이션

**핵심 아이디어**:
```
1. 큐에 1부터 N까지 순서대로 삽입

2. 큐가 빌 때까지 반복:
   - K-1번 회전 (맨 앞을 맨 뒤로 이동)
   - K번째 사람(맨 앞) 출력 및 제거

3. 제거 순서를 <3, 6, 2, 7, 5, 1, 4> 형식으로 출력
```

**시간복잡도**: O(N × K)
- N명을 모두 제거
- 각 제거마다 K-1번 회전
- 각 회전은 O(1) 연산 (push, pop)

**공간복잡도**: O(N)
- 큐에 최대 N명 저장

---

## 🔑 핵심 포인트

### 1️⃣ 큐 초기화

```cpp
queue<int> que;

// 1 ~ n까지 큐에 넣기
for (int i = 1; i <= n; ++i)
    que.push(i);
```

**✅ 핵심**:
- 1번부터 N번까지 순서대로 원에 배치
- 1번이 맨 앞 (큐의 front)

---

### 2️⃣ K번째 사람을 맨 앞으로 회전

```cpp
// K-1번 회전 (K번째 원소가 맨 앞으로 오도록)
for (int i = 1; i < k; ++i)
{
    que.push(que.front());  // 맨 앞을 뒤로 이동
    que.pop();              // 맨 앞 제거
}
```

**✅ 핵심**:
- K-1번 회전하면 K번째 사람이 맨 앞에 위치
- `que.push(que.front())`: 맨 앞 사람을 맨 뒤로 이동
- `que.pop()`: 이미 뒤로 보낸 사람을 앞에서 제거

**예시 (N=7, K=3)**:
```
초기: [1, 2, 3, 4, 5, 6, 7]

1차 제거:
  회전 1회: [2, 3, 4, 5, 6, 7, 1]  (1을 뒤로)
  회전 2회: [3, 4, 5, 6, 7, 1, 2]  (2를 뒤로)
  제거: 3 → [4, 5, 6, 7, 1, 2]

2차 제거:
  회전 1회: [5, 6, 7, 1, 2, 4]  (4를 뒤로)
  회전 2회: [6, 7, 1, 2, 4, 5]  (5를 뒤로)
  제거: 6 → [7, 1, 2, 4, 5]

3차 제거:
  회전 1회: [1, 2, 4, 5, 7]  (7을 뒤로)
  회전 2회: [2, 4, 5, 7, 1]  (1을 뒤로)
  제거: 2 → [4, 5, 7, 1]

4차 제거:
  회전 1회: [5, 7, 1, 4]  (4를 뒤로)
  회전 2회: [7, 1, 4, 5]  (5를 뒤로)
  제거: 7 → [1, 4, 5]

5차 제거:
  회전 1회: [4, 5, 1]  (1을 뒤로)
  회전 2회: [5, 1, 4]  (4를 뒤로)
  제거: 5 → [1, 4]

6차 제거:
  회전 1회: [4, 1]  (1을 뒤로)
  회전 2회: [1, 4]  (4를 뒤로)
  제거: 1 → [4]

7차 제거:
  회전 0회 (K-1=2이지만 사람이 1명)
  제거: 4 → []

결과: <3, 6, 2, 7, 5, 1, 4>
```

---

### 3️⃣ K번째 사람 출력 및 제거

```cpp
// K번째 사람 출력 및 제거
cout << que.front();
que.pop();

// 남아 있으면 구분자 출력
if (!que.empty())
    cout << ", ";
```

**✅ 핵심**:
- K-1번 회전 후 맨 앞이 K번째 사람
- 출력 후 큐에서 제거
- 마지막 사람이 아니면 ", " 출력

---

### 4️⃣ 출력 형식

```cpp
cout << "<";

while (!que.empty())
{
    // ... 제거 로직 ...

    cout << que.front();
    que.pop();

    if (!que.empty())
        cout << ", ";
}

cout << ">";
```

**✅ 핵심**:
- 시작: `<`
- 각 숫자: `숫자`
- 구분자: `, ` (마지막 제외)
- 끝: `>`
- 최종 형식: `<3, 6, 2, 7, 5, 1, 4>`

## 📊 다른 풀이 방법 비교

### 🔸 방법 1: Queue (현재 풀이) - 추천! ⭐⭐⭐⭐⭐

**시간복잡도**: O(N × K)

**장점**:
- ✅ 구현이 매우 간단
- ✅ STL queue 사용으로 안정적
- ✅ 원형 구조를 자연스럽게 표현
- ✅ 코드가 짧고 이해하기 쉬움

**단점**:
- ❌ K가 매우 클 때 다소 느릴 수 있음

**이 문제에 최적**:
- N ≤ 1,000, K ≤ 1,000
- 최악: 1,000 × 1,000 = 1,000,000번 연산
- 시간 제한 2초 → 충분히 통과 ✅

---

### 🔸 방법 2: List (STL) - 비추천 ⭐⭐

**시간복잡도**: O(N × K)

**장점**:
- ✅ erase가 O(1)
- ✅ Iterator로 원형 이동 가능

**단점**:
- ❌ 코드가 복잡함 (iterator 관리, 원형 처리)
- ❌ 시간복잡도는 큐와 동일
- ❌ 실수하기 쉬움

---

### 🔸 방법 3: Segment Tree - 오버킬 ⭐

**시간복잡도**: O(N log N)

**장점**:
- ✅ N이 매우 큰 경우(10^5 이상) 유리

**단점**:
- ❌ 구현이 매우 복잡 (100줄 이상)
- ❌ 이 문제(N ≤ 1,000)에서는 불필요
- ❌ 코딩 테스트에서 시간 낭비

---

### 🔸 방법 4: 수학 공식 - 이 문제에는 부적합 ❌

**요세푸스 마지막 생존자 공식**:
```cpp
J(n) = (J(n-1) + k) % n
```

**문제점**:
- ❌ **마지막 생존자만** 구할 수 있음
- ❌ 이 문제는 **모든 제거 순서** 출력 필요
- ❌ 사용 불가

## ⏱️ 시간복잡도

**전체 시간복잡도**: **O(N × K)**

**상세 분석**:
```
1. 큐 초기화: O(N)
   - 1부터 N까지 삽입

2. N번 제거 반복:
   - 각 제거마다 K-1번 회전: O(K)
   - 출력 및 제거: O(1)
   - N번 반복: O(N × K)

총합: O(N) + O(N × K) = O(N × K)
```

**시간 제한 체크**:
- N ≤ 1,000, K ≤ 1,000
- 최악: 1,000 × 1,000 = 1,000,000번
- 시간 제한 2초 → 충분히 통과 가능 ✅

---

## 💾 공간복잡도

**O(N)**

**분석**:
- `queue<int> que`: 최대 N명 저장
- 공간 사용량: N × sizeof(int) = N × 4바이트

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ 출력 형식 정확히 지키기

```cpp
❌ cout << que.front() << ", ";  // 마지막에도 ", " 출력됨!

✅ cout << que.front();
   que.pop();
   if (!que.empty())
       cout << ", ";
```

**이유:**
- 마지막 숫자 뒤에는 ", "를 출력하면 안 됨
- `<3, 6, 2, 7, 5, 1, 4>` (O)
- `<3, 6, 2, 7, 5, 1, 4, >` (X)

---

### 2️⃣ K-1번 회전 (K번 아님!)

```cpp
❌ for (int i = 0; i < k; ++i)  // K번 회전 → K+1번째 사람 제거!

✅ for (int i = 1; i < k; ++i)  // K-1번 회전 → K번째 사람 제거
```

**이유:**
- K번째 사람을 맨 앞으로 옮기려면 K-1번 회전 필요
- 예: 3번째 사람 → 2번 회전하면 맨 앞으로

---

### 3️⃣ 큐가 빌 때까지 반복

```cpp
✅ while (!que.empty())  // 큐가 빌 때까지
```

**이유:**
- 모든 사람을 제거할 때까지 반복
- N명 모두 출력해야 함

## 🎯 핵심 정리

**큐로 요세푸스 문제를 해결하는 핵심**:

1. **원형 구조 표현**: 맨 앞을 맨 뒤로 이동
2. **K번째 사람**: K-1번 회전 후 맨 앞
3. **제거 후 계속**: 남은 사람들로 원 유지
4. **출력 형식**: `<숫자, 숫자, ..., 숫자>` 정확히

**코딩 테스트 철칙**:
> "더 빠른 알고리즘보다 확실하게 통과하는 간단한 풀이가 낫다!"

큐를 사용한 O(N × K) 풀이가 이 문제의 **정석 풀이**입니다! ✅
