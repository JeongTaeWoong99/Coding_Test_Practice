## 🔗 문제 링크

[백준 17219번 - 비밀번호 찾기](https://www.acmicpc.net/problem/17219)

**난이도**: Silver 4

---

## 🤔 접근법

사이트 주소와 비밀번호를 저장하고, 주어진 사이트의 비밀번호를 찾는 문제.

N개의 사이트-비밀번호 쌍이 주어지고, M개의 사이트에 대한 비밀번호를 출력해야 함.

**핵심**: **해시맵**을 사용하여 O(1) 시간에 비밀번호 조회!

---

## 💡 정답 풀이 방법

**알고리즘**: 해시맵 (unordered_map)

**핵심 아이디어**:
```
1. unordered_map<string, string>으로 사이트 → 비밀번호 매핑
2. 쿼리마다 해시맵에서 O(1)로 비밀번호 조회
3. 결과 출력
```

---

## 🔑 핵심 포인트

### 1️⃣ unordered_map으로 key-value 저장

```cpp
unordered_map<string, string> pw;  // 사이트 주소 → 비밀번호

for(int i = 0; i < n; i++)
{
    cin >> site >> password;
    pw[site] = password;  // O(1) 평균
}
```

**✅ 핵심**:
- `unordered_map`은 해시 테이블 기반으로 평균 O(1) 삽입/조회
- `map`은 Red-Black Tree 기반으로 O(log N) 삽입/조회
- 이 문제에서는 정렬이 필요 없으므로 `unordered_map`이 더 효율적!

### 2️⃣ 비밀번호 조회

```cpp
for(int i = 0; i < m; i++)
{
    cin >> query;
    cout << pw[query] << "\n";  // O(1) 평균
}
```

**✅ 핵심**:
- 문제 조건에서 "반드시 이미 저장된 사이트 주소가 입력된다"고 보장
- 따라서 `find()` 없이 바로 `operator[]`로 접근 가능

---

## 🆚 map vs unordered_map 비교

| 항목 | map | unordered_map |
|-----|-----|---------------|
| **내부 구조** | Red-Black Tree | 해시 테이블 |
| **삽입** | O(log N) | O(1) 평균 |
| **조회** | O(log N) | O(1) 평균 |
| **정렬** | 자동 정렬됨 | 정렬 안 됨 |

**📊 실제 성능 비교**:

| 자료구조 | 메모리 | 시간 |
|---------|--------|------|
| `map` | 16680 KB | 192 ms |
| `unordered_map` | 16448 KB | **92 ms** ⭐ |

**결론**: 정렬이 필요 없는 단순 조회 문제 → `unordered_map` 사용!

## ⏱️ 시간복잡도

**전체 시간복잡도**: **O(N + M)**

**상세 분석**:
```
1. 사이트-비밀번호 저장 : O(N)
   - N번 반복
   - 각 삽입 O(1) 평균

2. 쿼리 처리 : O(M)
   - M번 반복
   - 각 조회 O(1) 평균

총합 : O(N + M)
```

**시간 제한 체크**:
- N, M ≤ 100,000
- 최대 200,000 연산
- **20만 연산** < **1억** → 시간 내 통과 가능 ✅
