## 🤔 접근법

(형변환만 신경쓰면, 쉽게 풀기 가능)

solved.ac의 난이도 결정 방식을 구현하는 문제.

사용자들이 제출한 난이도 의견을 바탕으로 **30% 절사평균**을 계산하여 문제의 난이도를 결정.

30% 절사평균이란 위에서 15%, 아래에서 15%를 제외하고 평균을 계산하는 방식.

**핵심**: 정렬 후 상위/하위 15%를 제외하고 평균을 구하며, 모든 계산에서 **반올림**을 적용!

---

## 💡 정답 풀이 방법

**알고리즘**: 수학, 구현, 정렬

**핵심 아이디어**:
```
1. 난이도 의견이 0개면 난이도는 0
2. 의견을 오름차순으로 정렬
3. n × 15%를 반올림하여 제외할 인원 수 계산
4. 상위/하위에서 제외할 인원을 빼고 평균 계산
5. 평균을 반올림하여 최종 난이도 결정
```

---

## 🔑 핵심 포인트

### 1️⃣ 제외 인원 수 계산 (반올림)

```cpp
// 15% 제외 인원 수 계산 (반올림)
eraseNum = round(15.0 / 100.0 * n);
```

**✅ 핵심**:
- n의 15%를 계산하여 반올림
- 예: n = 5 → 15% = 0.75 → 반올림 = 1명
- 예: n = 10 → 15% = 1.5 → 반올림 = 2명
- 위, 아래에서 각각 `eraseNum`명을 제외

### 2️⃣ 절사평균 계산

```cpp
// 앞 뒤로 eraseNum 만큼 제외한 합 구하기
for (int i = eraseNum; i < v.size() - eraseNum; ++i)
    sum += v[i];

// 평균 계산 후 반올림 (30% 절사평균)
lastAver = round(sum / (n - eraseNum * 2));
```

**✅ 핵심**:
- 정렬된 배열에서 앞 `eraseNum`개, 뒤 `eraseNum`개 제외
- 남은 의견들의 합을 구해 평균 계산
- 평균을 `round()`로 반올림하여 최종 난이도 결정

### 3️⃣ n = 0 예외 처리

```cpp
// 난이도 의견 개수가 0이면 0을 반환
if (n == 0)
{
    cout << '0';
    return 0;
}
```

**✅ 핵심**: 의견이 없으면 난이도는 0
- 문제 조건: "아직 아무 의견이 없다면 문제의 난이도는 0으로 결정"
- 예외 처리 필수!

## 📊 동작 예시

### 🎯 예제 1: n = 5, 의견 = [1, 5, 5, 7, 8]

```
1. 정렬: [1, 5, 5, 7, 8]
2. 제외 인원: 5 × 15% = 0.75 → 반올림 = 1명
3. 제외 후: [5, 5, 7] (앞 1개, 뒤 1개 제외)
4. 평균: (5 + 5 + 7) / 3 = 17 / 3 = 5.666...
5. 반올림: 6

최종 난이도: 6 ✅
```

### 🎯 예제 2: n = 10, 의견 = [1, 13, 12, 15, 3, 16, 13, 12, 14, 15]

```
1. 정렬: [1, 3, 12, 12, 13, 13, 14, 15, 15, 16]
2. 제외 인원: 10 × 15% = 1.5 → 반올림 = 2명
3. 제외 후: [12, 12, 13, 13, 14, 15] (앞 2개, 뒤 2개 제외)
4. 평균: (12 + 12 + 13 + 13 + 14 + 15) / 6 = 79 / 6 = 13.166...
5. 반올림: 13

최종 난이도: 13 ✅
```

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ 반올림을 두 번 해야 함!

```cpp
❌ eraseNum = (int)(15.0 / 100.0 * n);  // 그냥 버림 → 틀림!

✅ eraseNum = round(15.0 / 100.0 * n);          // 반올림 필수! ⭐
    lastAver = round(sum / (n - eraseNum * 2));  // 평균도 반올림! ⭐
```

**이유:**
- 문제 조건: "제외되는 사람의 수는 위, 아래에서 각각 **반올림**한다"
- 문제 조건: "계산된 평균도 정수로 **반올림**된다"
- 두 곳 모두 `round()` 필수!

### 2️⃣ n = 0 예외 처리

```cpp
❌ 예외 처리 없이 바로 계산 → 0으로 나누기 에러!

✅ if (n == 0)
   {
       cout << '0';
       return 0;
   }
```

**이유:**
- n = 0일 때 `sum / (n - eraseNum * 2)` → 0으로 나누기 에러
- 문제 조건상 n = 0이면 난이도는 0

### 3️⃣ double 타입 사용

```cpp
❌ int sum;  // int로 평균 계산 → 소수점 버림 → 반올림 불가!

✅ double sum;  // double로 평균 계산 → 소수점 유지 → 반올림 가능!
```

**이유:**
- `round()`는 소수점을 기준으로 반올림
- `int sum`으로 계산하면 이미 소수점이 버려져서 반올림이 의미 없음
- 반드시 `double` 타입으로 평균 계산!

### 4️⃣ 입출력 최적화

```cpp
✅ ios_base::sync_with_stdio(0);cin.tie(0);cout.tie(0);
```

**이유:**
- n ≤ 300,000
- 최대 30만 개의 의견 입력
- 입출력 최적화 권장

## ⏱️ 시간복잡도

**전체 시간복잡도**: **O(n log n)**

**상세 분석**:
```
1. n개의 의견 입력 : O(n)

2. 정렬 : O(n log n)

3. 절사평균 계산 : O(n)
   - 반복문으로 합 계산 : O(n)

총합 : O(n) + O(n log n) + O(n) = O(n log n)
```

**시간 제한 체크**:
- n ≤ 300,000
- n log n ≈ 300,000 × 18 ≈ 5,400,000
- **540만 연산** < **1억** → 시간 내 통과 가능 ✅

## 🔄 관련 문제 패턴

### ✅ 절사평균 (Trimmed Mean)

**개념**:
- 극단적인 값들을 제외하고 평균을 계산
- 이상치(outlier)의 영향을 최소화
- 통계학에서 자주 사용되는 기법

**30% 절사평균**:
- 상위 15% + 하위 15% = 총 30% 제외
- 나머지 70%의 평균 계산
- 올림픽 채점 방식과 유사

**핵심 구현**:
```
1. 데이터 정렬
2. 제외할 비율 계산 (반올림)
3. 상위/하위 제외 후 평균 계산
4. 평균 반올림
```
