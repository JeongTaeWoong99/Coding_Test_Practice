## 🔗 문제 링크

[백준 2839번 - 설탕 배달](https://www.acmicpc.net/problem/2839)

**난이도**: Silver 4

---

## 🤔 접근법

(그리디로 풀었는데, DP로도 가능은 함. 하지만, 이 문제에서는 그리디가 더 효율적)

N킬로그램의 설탕을 3kg 봉지와 5kg 봉지를 사용하여 배달하는 문제.

**목표**: 최대한 적은 봉지를 사용하여 정확히 N kg을 만들기.

**핵심**: 5kg 봉지를 최대한 많이 사용하는 것이 봉지 개수를 최소화하는 전략!

**두 가지 접근법**:
- **그리디 (추천)**: 5kg 봉지를 최대한 사용하며 3kg씩 감소
- **DP**: 0kg부터 N kg까지 모든 경우의 최소 봉지 수 계산

---

## 💡 정답 풀이 방법

### 🎯 방법 1: 그리디 알고리즘 (추천) ⭐

**핵심 전략**: 5kg 봉지를 최대한 많이 사용하기 위해 3kg씩 빼면서 확인

**알고리즘**:
```
1. N이 5로 나누어떨어지는지 확인
2. 나누어떨어지면 → 5kg 봉지만 사용하여 종료
3. 나누어떨어지지 않으면 → 3kg 봉지 1개 사용 (N -= 3)
4. 1~3 반복
5. N < 0이 되면 → 불가능 (-1 출력)
```

**예시 (N = 11)**:
```
11 % 5 = 1 (X) → 3kg 사용 → N = 8, 봉지 = 1
8  % 5 = 3 (X) → 3kg 사용 → N = 5, 봉지 = 2
5  % 5 = 0 (O) → 5kg 사용 → N = 0, 봉지 = 3 ✅
```

**시간복잡도**: O(N/3) - 최악의 경우 약 1,666번 반복 (N=5000)

---

### 🎯 방법 2: DP (다이나믹 프로그래밍)

**핵심 아이디어**: Bottom-up 방식으로 0kg부터 N kg까지 모든 무게의 최소 봉지 수 계산

**알고리즘**:
```
1. dp[0] = 0 (0kg은 봉지 0개)

2. dp[i] = -1 (불가능한 상태로 초기화)

3. 각 무게 weight에 대해:
   - weight + 3 가능하면 → dp[weight + 3] 갱신
   - weight + 5 가능하면 → dp[weight + 5] 갱신
   
4. dp[N] 출력
```

**예시 (N = 11)**:
```
dp[0]  = 0
dp[3]  = 1 (0 + 3kg)
dp[5]  = 1 (0 + 5kg)
dp[6]  = 2 (3 + 3kg)
dp[8]  = 2 (3 + 5kg)
dp[9]  = 3 (6 + 3kg 또는 3 + 3 + 3kg)
dp[10] = 2 (5 + 5kg)
dp[11] = 3 (6 + 5kg 또는 8 + 3kg) ✅
```

**시간복잡도**: O(N) - 정확히 N번 반복

## 🔑 핵심 포인트

### 1️⃣ 그리디의 핵심 - 5kg 우선 전략

```cpp
while (sugar >= 0)
{
    if (sugar % 5 == 0)  // 5kg 봉지로 정확히 나눔
    {
        bagCnt += sugar / 5;  // 남은 설탕을 모두 5kg 봉지로
        cout << bagCnt << "\n";
        return 0;
    }

    sugar  -= 3;  // 3kg 봉지 1개 사용
    bagCnt++;
}
```

**✅ 핵심**:
- 5kg 봉지가 더 크므로, 5kg를 많이 쓸수록 봉지 개수 감소
- 3kg씩 빼면서 5로 나누어떨어지는 시점을 찾음
- while 조건 `sugar >= 0`: 음수가 되면 불가능한 경우

---

### 2️⃣ DP의 핵심 - Bottom-up 방식

```cpp
for (int weight = 0; weight <= n; weight++)
{
    if (dp[weight] == -1) continue;  // 불가능한 무게는 스킵

    // 3kg 봉지 추가
    if (weight + 3 <= n)
    {
        if (dp[weight + 3] == -1)
            dp[weight + 3] = dp[weight] + 1;
        else
            dp[weight + 3] = min(dp[weight + 3], dp[weight] + 1);
    }

    // 5kg 봉지 추가
    if (weight + 5 <= n)
    {
        if (dp[weight + 5] == -1)
            dp[weight + 5] = dp[weight] + 1;
        else
            dp[weight + 5] = min(dp[weight + 5], dp[weight] + 1);
    }
}
```

**✅ 핵심**:
- 작은 무게부터 차례대로 계산
- 각 무게에서 3kg 또는 5kg을 추가하여 다음 무게 갱신
- 최소값 유지: 이미 계산된 값이 있으면 더 작은 값으로 갱신

---

### 3️⃣ 불가능한 경우 판별

**그리디**:
```cpp
// sugar < 0 이면 정확히 만들 수 없음
cout << "-1\n";
```

**DP**:
```cpp
cout << dp[n] << "\n";  // dp[n]이 -1이면 불가능
```

**불가능한 경우**: N = 4, 7 등 (3과 5의 조합으로 만들 수 없음)

---

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ while 조건은 `>= 0`

```cpp
❌ while (sugar > 0)  // N=5일 때 무한루프!

✅ while (sugar >= 0)  // sugar == 0도 확인해야 함
```

**이유**:
- N이 5의 배수일 때 sugar가 정확히 0이 됨
- `sugar > 0`이면 0을 확인하지 못하고 종료

## ⏱️ 시간복잡도 분석

### 🎯 그리디 알고리즘

**시간복잡도**: **O(N/3)**

**상세 분석**:
```
최악의 경우: N = 5000이고, 5로 나누어떨어지지 않는 경우
- 3kg씩 빼므로 최대 N/3 = 1,666번 반복
- 각 반복마다 O(1) 연산
- 총합: 약 1,666번 연산
```

**평균 케이스**:
- 대부분 경우 N/6 정도 반복 (평균적으로 절반)
- 5의 배수인 경우: O(1) - 즉시 종료

---

### 🎯 DP 알고리즘

**시간복잡도**: **O(N)**

**상세 분석**:
```
모든 경우: 0부터 N까지 정확히 N번 반복
- for문 N번 반복
- 각 반복마다 O(1) 연산 (배열 접근, 비교, 갱신)
- 총합: N번 연산
```

---

## 💾 공간복잡도

### 그리디
**O(1)** - 상수 공간만 사용
- `sugar`, `bagCnt` 변수 2개

### DP
**O(N)** - dp 배열 사용
- `dp[5004]`: 최대 20KB 메모리 사용

### 🎯 결론: N이 커질수록 그리디가 압도적으로 유리!

**✅ 그리디의 장점** (N이 클 때):
- **시간**: 평균 3~4배 빠름 (O(N/3) vs O(N))
- **메모리**: N에 무관하게 O(1) - 상수 공간
- **확장성**: N이 억 단위여도 문제없음
- **구현**: 코드가 간결하고 직관적

**✅ DP의 장점**:
- **안정성**: 모든 경우를 체계적으로 계산
- **확장성**: 봉지 종류가 늘어나도 쉽게 확장 가능
- **명확성**: 작은 문제부터 해결하는 명확한 로직
