## 🤔 접근법

문자열에서 숫자를 추출하여 비내림차순으로 정렬하는 문제.

**핵심**: 문자열 파싱 + 앞의 0 제거 + 큰 숫자 처리 + 커스텀 정렬

숫자가 최대 100자리까지 가능하므로 int가 아닌 string으로 처리해야 함.

---

## 💡 정답 풀이 방법

**알고리즘**: 문자열 파싱 + 정렬

**핵심 아이디어**:
```
1. 문자열을 순회하며 숫자인지 판단
2. 연속된 숫자를 하나의 숫자로 묶음
3. 앞의 0 제거 (단, "000"은 "0"으로)
4. 큰 숫자 처리를 위해 string으로 저장
5. 커스텀 비교 함수로 정렬 (길이 우선 → 사전순)
6. 결과 출력
```

---

## 🔑 핵심 개념

### 1️⃣ 문자열 파싱 최적화

**기존 방식**: 이중 처리 (for문 + 마지막 처리)
```cpp
for (char c : temp)
{
    // 숫자 처리...
}
// ❌ 마지막 숫자 처리 (중복 코드)
if (!numberS.empty()) { ... }
```

**최적화**: 가상 문자 추가
```cpp
temp += 'a';  // 마지막에 가상의 문자 추가

for (char c : temp)
{
    if (c >= '0' && c <= '9')
        numberS += c;
    else
    {
        if (!numberS.empty())
        {
            // 앞의 0 제거 후 저장
            int idx = 0;
            while (idx < numberS.size() - 1 && numberS[idx] == '0')
                idx++;
            v.push_back(numberS.substr(idx));
            numberS = "";
        }
    }
}
```

**✅ 핵심**: 문자열 끝에 가상의 문자를 추가하여 마지막 숫자도 자동 처리

### 2️⃣ 앞의 0 제거

```cpp
int idx = 0;
while (idx < numberS.size() - 1 && numberS[idx] == '0')
    idx++;

v.push_back(numberS.substr(idx));
```

**✅ 주의사항**:
- `idx < numberS.size() - 1`: "000"을 "0"으로 만들기 위해
- `numberS[idx] == '0'`: 앞에서부터 0이 아닌 숫자 찾기
- `substr(idx)`: idx부터 끝까지 잘라내기

**예시**:
```
"007" → idx = 2 → "7"
"000" → idx = 2 → "0"  (마지막 한 자리는 남김)
"123" → idx = 0 → "123"
```

### 3️⃣ 큰 숫자 처리

**문제 조건**: 숫자는 최대 100자리까지 가능

**해결책**: string으로 저장
```cpp
vector<string> v;  // int가 아닌 string 사용
```

**비교 함수**:
```cpp
bool CMP(string a, string b)
{
    if (a.size() != b.size())
        return a.size() < b.size();  // 길이가 다르면 짧은 게 작음
    return a < b;  // 길이가 같으면 사전순 비교
}
```

**✅ 정렬 기준**:
1. **1순위**: 길이 오름차순 (짧은 게 작은 수)
2. **2순위**: 사전순 오름차순

**예시**:
```
"9" < "10" < "100" < "1000"  (길이 우선)
"123" < "456" < "789"        (사전순)
```

## 📊 예제 분석

### 🎯 예제 입력 1

```
2
lo3za4
01
```

**처리 과정**:

**1단계: "lo3za4" 처리**
```
l (문자) → 숫자 없음
o (문자) → 숫자 없음
3 (숫자) → numberS = "3"
z (문자) → numberS = "3" → v에 추가, numberS 초기화
a (문자) → 숫자 없음
4 (숫자) → numberS = "4"
a (가상) → numberS = "4" → v에 추가
```
**결과**: v = ["3", "4"]

**2단계: "01" 처리**
```
0 (숫자) → numberS = "0"
1 (숫자) → numberS = "01"
a (가상) → numberS = "01" → 앞의 0 제거 → "1" → v에 추가
```
**결과**: v = ["3", "4", "1"]

**3단계: 정렬**
```
정렬 전: ["3", "4", "1"]
정렬 후: ["1", "3", "4"]  (길이 같으므로 사전순)
```

**4단계: 출력**
```
1
3
4
```

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ int 범위 초과

```cpp
❌ vector<int> v;  // 최대 100자리 숫자 처리 불가!

✅ vector<string> v;  // string으로 처리
```

**이유**: int는 최대 21억 (10자리), 문제는 100자리까지 가능

### 2️⃣ 0 처리

```cpp
❌ if (c >= '1' && c <= '9')  // '0'을 빠뜨림!

✅ if (c >= '0' && c <= '9')  // '0'도 포함
```

**이유**: "silos0"에서 0도 숫자로 인식해야 함

### 3️⃣ 앞의 0 제거 시 모든 자리가 0인 경우

```cpp
❌ while (numberS[idx] == '0')  // "000" → 빈 문자열!

✅ while (idx < numberS.size() - 1 && numberS[idx] == '0')
```

**이유**: "000"은 "0"으로 출력해야 하므로 최소 1자리는 남겨야 함

### 4️⃣ 마지막 숫자 누락

```cpp
❌ for (char c : temp) { ... }
   // 줄이 숫자로 끝나면 마지막 숫자 저장 안 됨!

✅ temp += 'a';  // 가상 문자 추가로 자동 처리
   for (char c : temp) { ... }
```

### 5️⃣ 정렬 기준 오류

```cpp
❌ sort(v.begin(), v.end());  // 사전순만 적용
   // "9" > "100" (사전순)

✅ sort(v.begin(), v.end(), CMP);  // 길이 우선
   // "9" < "100" (길이 우선)
```

## ⏱️ 시간복잡도 분석

**전체 시간복잡도**: **O(N × L + M log M)**

### 🔍 단계별 분석

**1단계: 문자열 파싱**
```cpp
for (int i = 0; i < n; i++)  // N줄
{
    for (char c : temp)      // 각 줄 최대 100자
    {
        // O(1) 연산
    }
}
```
- N줄, 각 줄 최대 L자 (L ≤ 100)
- **시간복잡도**: **O(N × L)**

**2단계: 정렬**
```cpp
sort(v.begin(), v.end(), CMP);
```
- M개 숫자 (M ≤ N × L)
- **시간복잡도**: **O(M log M)**

**전체**: **O(N × L + M log M) ≈ O(M log M)**

### 📊 제한 사항 검증

- N ≤ 100 (줄 개수)
- L ≤ 100 (각 줄 길이)
- M ≤ 10,000 (최악: 모든 문자가 숫자)
- 최악: 10,000 log 10,000 ≈ 10,000 × 13 ≈ **130,000**
- 130,000 << 100,000,000 (1억) → **여유롭게 통과** ✅

## 💾 공간복잡도

**O(M × D)**

**사용 메모리**:
- `v`: 숫자 저장 벡터 - O(M) (M은 숫자 개수)
- 각 숫자 최대 D자리 (D ≤ 100)
- **총합**: O(M × D)
