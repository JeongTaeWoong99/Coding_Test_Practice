## 🔗 문제 링크

[백준 3986번 - 좋은 단어](https://www.acmicpc.net/problem/3986)

**난이도**: Silver 4

---

## 🤔 접근법

스택을 활용한 괄호 매칭 문제의 변형.

A와 B만으로 이루어진 단어에서 같은 글자끼리 쌍을 지을 수 있는지 확인하는 문제.

선이 교차하지 않으면서 모든 글자를 정확히 한 번씩 짝지을 수 있으면 '좋은 단어'.

**핵심**: 연속된 같은 문자를 제거하면서 스택이 비면 좋은 단어!

---

## 💡 정답 풀이 방법

**알고리즘**: 스택(Stack) 활용

**핵심 아이디어**:
```
1. 문자열을 순회하면서 각 문자를 스택과 비교
2. 스택이 비어있거나 top이 현재 문자와 다르면 push
3. 스택 top이 현재 문자와 같으면 pop (쌍을 이루므로 제거)
4. 순회 후 스택이 비어있으면 좋은 단어 (모든 문자가 쌍을 이룸)
```

---

## 🔑 핵심 포인트

### 1️⃣ 스택을 활용한 문자 매칭

```cpp
stack<char> stk;

for(char current : S)
{
    // 스택이 비어있지 않고, 맨 위 값이 같으면
    // 넣지 말고, 바로 스택 탑과 함께 제거해주기
    if(!stk.empty() && stk.top() == current)
        stk.pop();
    // 다르면 넣어주기
    else
        stk.push(current);
}
```

**✅ 핵심**:
- 같은 문자가 연속으로 나오면 즉시 제거 (쌍을 이룸)
- 스택이 비어있거나 다른 문자면 push
- 괄호 매칭 문제와 동일한 패턴

### 2️⃣ 매번 새로운 스택 초기화

```cpp
for(int i = 0; i < N; i++)
{
    cin >> S;

    // 새 스택 (매번 초기화 필요)
    stack<char> stk;

    // ...
}
```

**✅ 핵심**: 각 단어마다 독립적으로 판별
- 스택을 반복문 안에서 생성하여 자동 초기화
- 이전 단어의 결과가 다음 단어에 영향을 주지 않음

### 3️⃣ 좋은 단어 판별

```cpp
// 남아있는 스택이 없음 => 좋은 단어
if(stk.empty()) RET++;
```

**✅ 핵심**: 스택이 비어야 좋은 단어
- 모든 문자가 쌍을 이루면 스택이 비게 됨
- 스택에 문자가 남아있으면 짝이 없는 문자가 존재

## 📊 동작 예시

### 🎯 예제 1: "ABAB" (나쁜 단어)

```
문자열: A B A B
스택 변화:
  시작: []
  A 처리: [A]              (스택 비어있음 → push)
  B 처리: [A, B]           (top과 다름 → push)
  A 처리: [A, B, A]        (top과 다름 → push)
  B 처리: [A, B, A, B]     (top과 다름 → push)

최종: [A, B, A, B] → 스택이 비어있지 않음 → 나쁜 단어 ❌
```

### 🎯 예제 2: "AABB" (좋은 단어)

```
문자열: A A B B
스택 변화:
  시작: []
  A 처리: [A]              (스택 비어있음 → push)
  A 처리: []               (top과 같음 → pop) ⭐
  B 처리: [B]              (스택 비어있음 → push)
  B 처리: []               (top과 같음 → pop) ⭐

최종: [] → 스택이 비어있음 → 좋은 단어 ✅
```

### 🎯 예제 3: "ABBA" (좋은 단어)

```
문자열: A B B A
스택 변화:
  시작: []
  A 처리: [A]              (스택 비어있음 → push)
  B 처리: [A, B]           (top과 다름 → push)
  B 처리: [A]              (top과 같음 → pop) ⭐
  A 처리: []               (top과 같음 → pop) ⭐

최종: [] → 스택이 비어있음 → 좋은 단어 ✅
```

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ 스택 비어있는지 확인 필수

```cpp
❌ if(stk.top() == current)  // 스택이 비어있으면 런타임 에러!
    stk.pop();

✅ if(!stk.empty() && stk.top() == current)  // 비어있는지 먼저 확인!
    stk.pop();
```

**이유:**
- 첫 번째 문자를 처리할 때 스택이 비어있음
- `stk.top()` 호출 시 런타임 에러 발생
- 반드시 `!stk.empty()` 조건 먼저 체크!

### 2️⃣ 매번 새로운 스택 사용

```cpp
❌ stack<char> stk;  // 반복문 밖에서 선언 → 이전 단어의 영향 받음!
   for(int i = 0; i < N; i++)
   {
       cin >> S;
       // ...
   }

✅ for(int i = 0; i < N; i++)
   {
       cin >> S;
       stack<char> stk;  // 매번 새로운 스택! ⭐
       // ...
   }
```

**이유:**
- 각 단어는 독립적으로 판별해야 함
- 스택을 재사용하면 이전 단어의 문자가 남아있을 수 있음

### 3️⃣ 입출력 최적화

```cpp
✅ ios_base::sync_with_stdio(false);
   cin.tie(NULL);
```

**이유:**
- N ≤ 100, 단어 길이 합 ≤ 1,000,000
- 최대 100만 개의 문자 처리 가능
- 입출력 최적화 필요

## ⏱️ 시간복잡도

**전체 시간복잡도**: **O(총 문자 개수)**

**상세 분석**:
```
1. N개의 단어 입력 : O(N)
2. 각 단어의 문자 순회 : O(단어 길이)
   - 스택 push/pop : O(1)
   - 전체 문자 개수 : 최대 1,000,000

총합 : O(총 문자 개수) ≤ O(1,000,000)
```

**시간 제한 체크**:
- 1초 제한 → 1억 연산 가능
- 100만 연산 < 1억 → 시간 내 통과 가능 ✅

---

## 💾 공간복잡도

**O(L)** - L은 가장 긴 단어의 길이
- `stk` : 최악의 경우 단어의 모든 문자를 담을 수 있음
  - 예: "AAABBB" → [A, A, A, B, B, B] (최대 6개)
- 최대 길이 : 100,000

## 🔄 관련 문제 패턴

### ✅ 괄호 매칭 문제와의 유사성

**괄호 매칭**:
```
"(())" → 좋은 괄호
1. '(' push
2. '(' push
3. ')' → top이 '(' → pop
4. ')' → top이 '(' → pop
→ 스택이 비면 올바른 괄호
```

**좋은 단어**:
```
"AABB" → 좋은 단어
1. 'A' push
2. 'A' → top이 'A' → pop
3. 'B' push
4. 'B' → top이 'B' → pop
→ 스택이 비면 좋은 단어
```

### ✅ 핵심 공통점

- **연속된 쌍을 찾아서 제거**
- **스택으로 짝 맞추기**
- **모두 제거되면 조건 만족**
