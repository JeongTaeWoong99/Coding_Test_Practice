## 🔗 문제 링크

[백준 4949번 - 균형잡힌 세상](https://www.acmicpc.net/problem/4949)

**난이도**: Silver 4

---

## 🤔 접근법

주어진 문자열에서 소괄호 `()` 와 대괄호 `[]` 의 균형이 잘 맞춰져 있는지 판단하는 문제.

- 모든 여는 괄호는 같은 종류의 닫는 괄호와만 짝을 이뤄야 함.
- 모든 닫는 괄호는 자신과 짝을 이룰 수 있는 여는 괄호가 존재해야 함.
- 짝을 이루는 두 괄호 사이의 문자열도 균형이 잡혀야 함.

**핵심은 스택을 사용**하여 여는 괄호를 저장하고, 닫는 괄호가 나올 때마다 스택의 top과 매칭하는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : 스택 (Stack)

**핵심 아이디어**:
```
1. 한 줄씩 입력받아 처리 (getline 사용, 공백 포함)
2. 온점 하나(".")만 있으면 종료
3. 문자열의 각 문자를 순회하며:
   - 여는 괄호 '(', '[': 스택에 push
   - 닫는 괄호 ')', ']': 스택의 top과 짝이 맞는지 확인 후 pop
   - 스택이 비었거나 짝이 맞지 않으면 실패 (ok = false)
4. 순회 완료 후 ok == true && 스택이 비어있으면 "yes", 아니면 "no"
```

---

## 🔑 핵심 포인트

### 1️⃣ 입력 처리 (getline 사용)

```cpp
// 공백을 포함한 한 줄 전체 입력
while (getline(cin, s))
{
    if (s == ".") break;  // 종료 조건
}
```

**✅ 핵심**: `cin >> s`가 아닌 `getline(cin, s)` 사용
- `cin >> s`: 공백을 기준으로 단어 단위로 입력 (❌)
- `getline(cin, s)`: 개행 문자까지 한 줄 전체 입력 (✅)
- 문제에서 주어진 문장은 공백을 포함하므로 반드시 getline 사용

### 2️⃣ 스택 기본 패턴

```cpp
stack<char> st;
bool ok = true;  // 균형 여부 플래그

for (char c : s)
{
    // 여는 괄호는 스택에 저장
    if (c == '(' || c == '[')
    {
        st.push(c);
    }
    // 닫는 괄호는 스택의 top과 매칭 확인
    else if (c == ')' || c == ']')
    {
        // 유효성 검사 후 pop
    }
}
```

**✅ 핵심**: 여는 괄호는 무조건 push, 닫는 괄호는 검증 후 pop
- 스택은 가장 최근에 들어온 여는 괄호를 기억
- 닫는 괄호가 나오면 가장 최근 여는 괄호와 짝을 맞춤

### 3️⃣ 닫는 괄호 검증 로직

```cpp
// 닫는 소괄호 ')'
if (c == ')')
{
    // 스택이 비었거나 top이 '('가 아니면 실패
    if (st.empty() || st.top() != '(')
    {
        ok = false;
        break;  // 더 이상 검사할 필요 없음
    }
    st.pop();
}

// 닫는 대괄호 ']'
if (c == ']')
{
    // 스택이 비었거나 top이 '['가 아니면 실패
    if (st.empty() || st.top() != '[')
    {
        ok = false;
        break;
    }
    st.pop();
}
```

**✅ 핵심**: 두 가지 실패 케이스
1. **스택이 비어있음** (`st.empty()`): 닫는 괄호에 대응하는 여는 괄호가 없음
   - 예: `")))"`
2. **괄호 종류가 다름** (`st.top() != '('`): 괄호 짝이 맞지 않음
   - 예: `"([)]"` → `(` 후 `[`, 그 다음 `)` 나오면 top은 `[`이므로 실패

### 4️⃣ ok 플래그의 필요성

```cpp
bool ok = true;  // 균형 여부 플래그

// 검사 중 문제 발견 시 ok = false로 설정하고 break
if (st.empty() || st.top() != '(')
{
    ok = false;
    break;  // 루프 탈출
}

// 최종 판단
if (ok && st.empty()) cout << "yes" << '\n';
else                  cout << "no"  << '\n';
```

**✅ 핵심**: ok 플래그가 필요한 이유
- **중간 실패 감지**: 괄호 검사 중 오류 발견 시 `ok = false`로 기록
- **break와의 차이**: break는 루프만 탈출, ok는 실패 상태를 기억
- **최종 판단**: `ok && st.empty()` 두 조건 모두 만족해야 성공
  - `ok == true`: 모든 닫는 괄호의 짝이 올바름
  - `st.empty()`: 모든 여는 괄호가 닫힘

**반례 (ok 없으면 틀리는 경우)**:
```
입력: ")))"    → 닫는 괄호만 있음
ok 없음: break로 탈출 → st.empty() 판단만 하면 true → "yes" ❌
ok 있음: ok = false → "no" ✅
```

### 5️⃣ 최종 판단 조건

```cpp
// 두 조건 모두 만족해야 균형잡힌 문자열
if (ok && st.empty()) cout << "yes" << '\n';
else                  cout << "no"  << '\n';
```

**✅ 핵심**: 두 가지 조건 필요
1. **ok == true**: 모든 괄호 짝이 올바름 (종류 일치)
2. **st.empty()**: 스택이 비어있음 (개수 일치)

**케이스별 분석**:
```
"()"         → ok=true, st.empty()=true  → "yes" ✅
"((("        → ok=true, st.empty()=false → "no"  ✅ (여는 괄호만 있음)
")))"        → ok=false, st.empty()=?    → "no"  ✅ (닫는 괄호만 있음)
"([)]"       → ok=false, st.empty()=?    → "no"  ✅ (짝이 맞지 않음)
" ."         → ok=true, st.empty()=true  → "yes" ✅ (괄호가 없어도 균형)
```

## ⏱️ 시간복잡도

**O(N × L)**

**분석**:
- N: 입력 줄의 개수
- L: 각 줄의 길이 (최대 100)
- 각 줄마다:
  - 문자열 순회: O(L)
  - 각 문자마다 스택 연산 (push/pop/top): O(1)
  - 총 O(L)

**실제 계산**:
```
- 최악의 경우: 줄의 개수 제한 없음 (입력 종료 조건까지)
- 각 줄 최대 길이: 100
- 각 줄마다: O(100) 연산
- 충분히 시간 제한(1초) 내에 해결 가능
```

**✅ 결론**: 효율적인 O(L) 선형 시간 알고리즘

## 💾 공간복잡도

**O(L)**

**분석**:
- `string s`: 한 줄의 문자열 저장 → O(L)
- `stack<char> st`: 최악의 경우 모든 여는 괄호 저장 → O(L)
  - 예: `"(((((((..."`
- 매번 새로운 줄마다 초기화되므로 누적되지 않음

**총 공간**: O(L) ≈ **O(100)** (L=100일 때)
