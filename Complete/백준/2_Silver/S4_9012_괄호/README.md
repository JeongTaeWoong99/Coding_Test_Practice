## 🔗 문제 링크

[백준 9012번 - 괄호](https://www.acmicpc.net/problem/9012)

**난이도**: Silver 4

---

## 🤔 접근법

괄호 문자열이 올바른 괄호 문자열(VPS)인지 판별하는 문제.

'('와 ')'만으로 구성된 괄호 문자열에서 짝이 올바르게 맞는지 확인.

**핵심**: 스택을 활용하여 '('를 만나면 push, ')'를 만나면 pop하여 짝을 맞춤!

---

## 💡 정답 풀이 방법

**알고리즘**: 스택(Stack) 활용

**핵심 아이디어**:
```
1. 문자열을 순회하면서 각 문자를 스택과 비교
2. '('를 만나면 스택에 push
3. ')'를 만나면:
   - 스택이 비어있지 않고 top이 '('이면 pop (짝을 이룸)
   - 그 외의 경우 push (짝을 이루지 못함)
4. 순회 후 스택이 비어있으면 VPS (모든 괄호가 짝을 이룸)
```

---

## 🔑 핵심 포인트

### 1️⃣ 스택을 활용한 괄호 매칭

```cpp
stack<char> stk;

for (char c : S)
{
    // 비어있지 않고, 맨 위가 ')'일 때 => 무엇이든지 넣기
    if (!stk.empty() && stk.top() == ')')
    {
        stk.push(c);
    }
    // 비어있지 않고, 맨 위가 '('이면, ')'일 때 => 넣지 말고 pop
    else if (!stk.empty() && stk.top() == '(' && c == ')')
    {
        stk.pop();
    }
    // 넣기
    else
    {
        stk.push(c);
    }
}
```

**✅ 핵심**:
- '('를 만나면 스택에 push (짝을 기다림)
- ')'를 만나고 top이 '('이면 pop (짝을 이룸)
- ')'를 만나고 top이 ')'이거나 스택이 비어있으면 push (짝을 이루지 못함)

### 2️⃣ 매번 새로운 스택 초기화

```cpp
for (int i = 0; i < N; i++)
{
    cin >> S;

    // 새 스택 (매번 초기화 필요)
    stack<char> stk;

    // ...
}
```

**✅ 핵심**: 각 테스트 케이스마다 독립적으로 판별
- 스택을 반복문 안에서 생성하여 자동 초기화
- 이전 테스트 케이스의 결과가 다음에 영향을 주지 않음

### 3️⃣ VPS 판별

```cpp
// 남아있는 스택이 없음 => VPS
if (stk.empty()) cout << "YES" << '\n';
else             cout << "NO"  << '\n';
```

**✅ 핵심**: 스택이 비어야 VPS
- 모든 괄호가 짝을 이루면 스택이 비게 됨
- 스택에 괄호가 남아있으면 짝이 없는 괄호가 존재

## 📊 동작 예시

### 🎯 예제 1: "(()())()" (VPS)

```
문자열: ( ( ) ( ) ) ( )
스택 변화:
  시작: []
  '(' 처리: [(]               (push)
  '(' 처리: [(, (]            (push)
  ')' 처리: [(]               (top='(' → pop) ⭐
  '(' 처리: [(, (]            (push)
  ')' 처리: [(]               (top='(' → pop) ⭐
  ')' 처리: []                (top='(' → pop) ⭐
  '(' 처리: [(]               (push)
  ')' 처리: []                (top='(' → pop) ⭐

최종: [] → 스택이 비어있음 → VPS ✅
```

### 🎯 예제 2: "((()())" (VPS 아님)

```
문자열: ( ( ( ) ( ) )
스택 변화:
  시작: []
  '(' 처리: [(]               (push)
  '(' 처리: [(, (]            (push)
  '(' 처리: [(, (, (]         (push)
  ')' 처리: [(, (]            (top='(' → pop) ⭐
  '(' 처리: [(, (, (]         (push)
  ')' 처리: [(, (]            (top='(' → pop) ⭐
  ')' 처리: [(]               (top='(' → pop) ⭐

최종: [(] → 스택이 비어있지 않음 → VPS 아님 ❌
```

### 🎯 예제 3: "())(()" (VPS 아님)

```
문자열: ( ) ) ( ( )
스택 변화:
  시작: []
  '(' 처리: [(]               (push)
  ')' 처리: []                (top='(' → pop) ⭐
  ')' 처리: [)]               (스택 비어있음 → push) ⭐
  '(' 처리: [), (]            (push)
  '(' 처리: [), (, (]         (push)
  ')' 처리: [), (]            (top='(' → pop) ⭐

최종: [), (] → 스택이 비어있지 않음 → VPS 아님 ❌
```

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ 스택 비어있는지 확인 필수

```cpp
❌ if (stk.top() == '(')  // 스택이 비어있으면 런타임 에러!
    stk.pop();

✅ if (!stk.empty() && stk.top() == '(')  // 비어있는지 먼저 확인!
    stk.pop();
```

**이유:**
- 첫 번째 문자를 처리할 때 스택이 비어있음
- `stk.top()` 호출 시 런타임 에러 발생
- 반드시 `!stk.empty()` 조건 먼저 체크!

### 2️⃣ 매번 새로운 스택 사용

```cpp
❌ stack<char> stk;  // 반복문 밖에서 선언 → 이전 테스트의 영향 받음!
   for (int i = 0; i < N; i++)
   {
       cin >> S;
       // ...
   }

✅ for (int i = 0; i < N; i++)
   {
       cin >> S;
       stack<char> stk;  // 매번 새로운 스택! ⭐
       // ...
   }
```

**이유:**
- 각 테스트 케이스는 독립적으로 판별해야 함
- 스택을 재사용하면 이전 테스트의 괄호가 남아있을 수 있음

### 3️⃣ ')'가 먼저 나오는 경우 처리

```cpp
❌ if (stk.top() == '(' && c == ')')  // 스택이 비어있으면 에러!
    stk.pop();

✅ if (!stk.empty() && stk.top() == '(' && c == ')')
    stk.pop();
   else
    stk.push(c);  // ')'가 먼저 나오면 push (VPS 아님 표시)
```

**이유:**
- ")()" 같은 경우 첫 ')'는 짝이 없음
- 스택이 비어있으면 push하여 최종 결과를 "NO"로 만듦

## ⏱️ 시간복잡도

**전체 시간복잡도**: **O(T × L)**

**상세 분석**:
```
1. T개의 테스트 케이스 입력 : O(T)
2. 각 문자열의 문자 순회 : O(L) - L은 문자열 길이
   - 스택 push/pop : O(1)
   - 각 문자당 O(1) 연산

총합 : O(T × L)
     ≤ O(T × 50)  (문제 조건: 문자열 길이 ≤ 50)
```

**시간 제한 체크**:
- 1초 제한 → 1억 연산 가능
- T × 50 < 1억 → 시간 내 통과 가능 ✅

---

## 💾 공간복잡도

**O(L)** - L은 문자열의 길이
- `stk` : 최악의 경우 문자열의 모든 '('를 담을 수 있음
  - 예: "(((((" → [(, (, (, (, (] (5개)
- 최대 길이 : 50

## 🔄 관련 문제 패턴

### ✅ 괄호 매칭의 기본 원리

**스택을 활용한 괄호 매칭**:
```
1. 여는 괄호 '(' → 스택에 push (짝을 기다림)
2. 닫는 괄호 ')' → 스택에서 pop (짝을 이룸)
3. 최종 스택이 비어있으면 → 올바른 괄호
4. 스택에 괄호가 남아있으면 → 올바르지 않은 괄호
```

**핵심**: 후입선출(LIFO) 구조로 가장 최근의 여는 괄호와 짝을 맞춤!
