## 🔗 문제 링크

[백준 10709번 - 기상캐스터](https://www.acmicpc.net/problem/10709)

**난이도**: Silver 5

## 🤔 접근법

JOI시의 각 구역에 구름이 도달하는 시간을 예측하는 시뮬레이션 문제.

H × W 크기의 격자에서 구름은 매 분마다 1칸씩 동쪽(오른쪽)으로 이동한다.

각 구역에 대해 지금부터 몇 분 후 처음으로 구름이 오는지 계산하는 문제.

**핵심**: 왼쪽에서 오른쪽으로 순회하며 구름의 전파 시간을 계산하되, **각 칸을 최대 1번만 방문**하여 O(H × W)로 해결

---

## 💡 정답 풀이 방법

**알고리즘**: 시뮬레이션(Simulation) + 구현

**핵심 아이디어**:
```
1. 입력 단계: 구름(c)은 0, 빈 칸(.)은 -1로 초기화
2. 처리 단계: 각 행을 왼쪽에서 오른쪽으로 순회
   - 구름(0)을 만나면 오른쪽 빈 칸들에 거리(1, 2, 3, ...)를 채움
   - while 내부에서 j++를 사용해 이미 처리한 칸을 건너뜀
3. 출력 단계: 배열 출력 (초기 구름=0, 구름 도달=거리, 영원히 없음=-1)
```

## 🔑 핵심 포인트

### 1️⃣ 입력과 처리의 분리

**입력 단계**:
```cpp
for(int i = 0; i < n; i++)
{
    cin >> s;
    for(int j = 0; j < m; j++)
    {
        if(s[j] == '.')arr[i][j] = -1; // .은 -1으로 시작함.
        else           arr[i][j] =  0; // C는 0으로 시작함.
    }
}
```

**✅ 장점**:
- 데이터 수집과 로직 처리를 명확히 분리
- 디버깅 시 어느 단계에서 문제인지 파악 용이
- 코드 가독성 향상

### 2️⃣ 중복 방문 방지 - j++ 활용

**핵심 코드**:
```cpp
for(int i = 0; i < n; i++)
{
    for(int j = 0; j < m; j++)
    {
        if(arr[i][j] == 0)  // 구름 발견
        {
            int cnt = 1;

            // 오른쪽 빈 칸들에 거리 채우기
            while(arr[i][j + 1] == -1)
            {
                arr[i][j + 1] = cnt++;  // 거리 증가하며 채우기
                j++;  // ⭐ 핵심: 외부 루프의 j도 증가 (중복 방문 방지!)
            }
        }
    }
}
```

**⭐ 핵심**: `j++`를 통해 이미 처리한 칸을 건너뜀

**동작 과정**: `"c..c...."`를 처리할 때
```
j=0: arr[0][0]=0 (구름 발견)
  → arr[0][1]=-1? Yes → arr[0][1]=1, j=1
  → arr[0][2]=-1? Yes → arr[0][2]=2, j=2
  → arr[0][3]=-1? No (다음 구름 위치) → while 종료, j=2

j=3: (j=1,2는 건너뜀!) arr[0][3]=0 (구름 발견)
  → arr[0][4]=-1? Yes → arr[0][4]=1, j=4
  ...

결과: [0, 1, 2, 0, 1, 2, 3, 4]
```

**✅ 효과**: 각 칸을 정확히 1번만 방문 → O(H × W) 달성!

### 3️⃣ while 조건의 안전성

```cpp
while(arr[i][j + 1] == -1)  // j + 1은 항상 유효한가?
```

**✅ 안전한 이유**:
- 문제 조건: JOI시 외부에서 구름이 들어오지 않음
- 맨 오른쪽 칸이 구름이어도 `arr[i][m]`은 초기화되지 않았으므로 -1이 아님
- 배열 크기를 `[104][104]`로 여유 있게 선언했으므로 경계 초과 없음

**안전한 배열 크기 설정**:
```cpp
int arr[104][104];  // H, W ≤ 100이므로 충분히 안전
```

### 4️⃣ 초기값의 의미

| 값 | 의미 | 시점 |
|---|------|-----|
| `0` | 현재 구름이 있음 | 초기 상태 |
| `-1` | 구름이 도달하지 않음 (아직 미처리 또는 영원히 없음) | 초기 상태 / 최종 상태 |
| `1, 2, 3, ...` | 구름이 도달하기까지의 시간(분) | 처리 후 |

**✅ 핵심**: -1은 두 가지 의미를 가짐
1. **처리 전**: 아직 체크하지 않은 빈 칸
2. **처리 후**: 구름이 영원히 도달하지 않는 칸

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ 배열 경계 초과 주의

```cpp
❌ int arr[100][100];  // H=100, W=100일 때 arr[99][100] 접근 시 범위 초과!

✅ int arr[104][104];  // 여유 있게 설정하여 arr[i][j+1] 안전하게 접근
```

**이유**:
- `arr[i][j + 1]`에서 j가 최대값(m-1)일 때 j+1=m이 되어 경계 초과 가능
- 배열 크기를 여유 있게 설정하면 안전

### 2️⃣ j++ 누락 시 시간복잡도 폭발

```cpp
❌ while(arr[i][j + 1] == -1)
   {
       arr[i][j + 1] = cnt++;
       // j++ 누락! → 같은 칸을 여러 번 처리
   }

✅ while(arr[i][j + 1] == -1)
   {
       arr[i][j + 1] = cnt++;
       j++;  // 필수! 중복 방문 방지
   }
```

**결과**:
- j++ 없으면: O(H × W²) → 시간 초과 가능
- j++ 있으면: O(H × W) → 최적

### 3️⃣ 초기값 설정 실수

```cpp
❌ if(s[j] == 'c')arr[i][j] = 0;
   // 빈 칸을 초기화하지 않음 → 쓰레기 값!

✅ if(s[j] == '.')arr[i][j] = -1;  // 빈 칸은 -1로 명시적 초기화
   else           arr[i][j] =  0;  // 구름은 0으로 초기화
```

**이유**:
- 전역 변수는 자동으로 0으로 초기화되지만, 명시적 초기화가 안전
- -1을 체크하는 로직이므로 반드시 -1로 초기화 필요

### 4️⃣ cnt 초기값 설정

```cpp
❌ int cnt = 0;  // 잘못! → 첫 칸이 0이 되어 구름과 혼동

✅ int cnt = 1;  // 올바름! → 1분 후부터 시작
```

**이유**:
- 구름(c)의 위치는 0분
- 구름의 오른쪽 첫 칸은 1분 후 도달
- cnt=1부터 시작해야 올바른 시간 계산

## 📊 시간복잡도 분석

**전체 시간복잡도**: **O(H × W)**

**상세 분석**:
```
1. 입력 단계: O(H × W)
   - H개의 행, 각 행마다 W개의 문자 처리

2. 처리 단계: O(H × W)
   - 외부 이중 반복문: O(H × W)
   - while 내부의 j++로 인해 각 칸을 최대 1번만 방문
   - 총 방문 횟수: H × W번

3. 출력 단계: O(H × W)
   - H × W개의 칸 출력

총합: O(H × W)
```

**시간 제한 체크**:
- H, W ≤ 100 (문제 조건)
- 100 × 100 = 10,000 연산 << 1억 → 매우 여유롭게 통과 ✅
