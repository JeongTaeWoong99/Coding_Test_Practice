## 🤔 접근법

N번째 종말의 수를 찾는 브루트포스 문제.

"종말의 수"는 6이 적어도 3개 이상 연속으로 들어가는 수를 의미한다.
- 1번째 종말의 수: 666
- 2번째 종말의 수: 1666
- 3번째 종말의 수: 2666
- ...

666부터 시작하여 모든 수를 순회하며 "666"이 포함되는지 확인하는 문제.

**핵심**: 두 가지 방법으로 해결 가능
1. **문자열 메서드 사용**: `to_string()` + `find()` (직관적, 느림)
2. **수학적 계산 사용**: `% 1000`, `/ 10` (효율적, 빠름)

## 🔑 핵심 포인트

### 1️⃣ 방법 1 : 문자열 메서드 사용 (Answer(성공_메서드 사용).cpp.txt)

**핵심 코드**:
```cpp
while (true)
{
    // curNum을 스트링으로 바꾼 후, 666이 들어가 있는지 확인
    if (to_string(curNum).find("666") != string::npos)
    {
        posNum++;  // 몇번째로 나오는지 체크 증가
    }

    // 찾음
    if (posNum == n)
    {
        cout << curNum << "\n";
        break;
    }

    curNum++;  // 다음 숫자 찾기
}
```

**✅ 장점**:
- 직관적이고 이해하기 쉬움
- `to_string()`, `find()` 같은 STL 메서드 활용
- 코드가 짧고 간결함

**❌ 단점**:
- 매번 문자열 변환 오버헤드 발생
- 문자열 생성/해제로 메모리 할당 비용
- 실행 시간: 60ms

**⚠️ 주의사항 - find() 반환값**:
```cpp
❌ if (to_string(curNum).find("666"))  // 잘못! 666이면 0 반환 → false

✅ if (to_string(curNum).find("666") != string::npos)  // 올바름!
```

**이유**:
- `find()`는 **찾은 위치(인덱스)**를 반환 (0부터 시작)
- 맨 앞에서 찾으면 **0**을 반환 → `if (0)`은 false!
- 못 찾으면 `string::npos` 반환
- 따라서 `!= string::npos`로 비교해야 정확함

| 숫자 | to_string() | find("666") 반환값 | if (반환값) | if (반환값 != npos) |
|------|-------------|-------------------|------------|---------------------|
| 666 | "666" | **0** (맨 앞) | **false** ❌ | **true** ✅ |
| 1666 | "1666" | **1** (1번 인덱스) | **true** ✅ | **true** ✅ |
| 123 | "123" | **npos** (못 찾음) | **true** | **false** ✅ |

### 2️⃣ 방법 2 : 수학적 계산 (Answer(정답_수학적 계산).cpp.txt)

**핵심 코드**:
```cpp
for(int i = 666; ; i++)
{
    temp = i;

    // 현재 숫자(i)에 "666"이 연속으로 포함되어 있는지 확인
    while(temp >= 666)
    {
        // temp의 뒤 3자리(% 1000)가 666인지 확인
        if(temp % 1000 == 666)
        {
            cnt++;  // 종말의 수 발견
            break;
        }

        // 앞자리로 이동 (맨 뒤 자리 제거)
        temp /= 10;
    }

    // N번째 종말의 수를 찾았으면 출력 후 종료
    if(n == cnt)
    {
        cout << i << "\n";
        break;
    }
}
```

**✅ 장점**:
- 문자열 변환 없이 순수 수학 연산만 사용
- 메모리 할당/해제 오버헤드 없음
- 실행 시간: 12ms (5배 빠름!)

**❌ 단점**:
- 알고리즘 이해 난이도가 높음
- 초보자가 떠올리기 어려움

**🔍 알고리즘 상세 분석**:

**예시 1: 66666에서 666 찾기**
```
i = 66666

1단계: temp = 66666
       66666 % 1000 = 666 ✅ 찾음!
       cnt++ → break

2단계: cnt == n 확인 → 출력
```

**예시 2: 16660에서 666 찾기**
```
i = 16660

1단계: temp = 16660
       16660 % 1000 = 660 ❌ (666 아님)
       temp = 16660 / 10 = 1666

2단계: temp = 1666
       1666 % 1000 = 666 ✅ 찾음!
       cnt++ → break

3단계: cnt == n 확인 → 출력
```

**예시 3: 123에서 666 찾기**
```
i = 123

1단계: temp = 123
       123 < 666 → while 종료 (666 없음)

2단계: cnt == n 확인 → 다음 숫자로 (i++)
```

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ find() 반환값 오해

```cpp
❌ if (to_string(curNum).find("666"))
   // 666일 때 find()가 0을 반환 → if (0) → false → 놓침!

✅ if (to_string(curNum).find("666") != string::npos)
   // string::npos가 아니면 찾은 것
```

**반례**:
```
입력: 1
출력: 666 (정답)

❌ if (find("666")) 사용 시:
   - curNum = 666 → find() = 0 → if (0) = false → 건너뜀
   - curNum = 1666 → find() = 1 → if (1) = true → posNum = 1
   - 결과: 1666 출력 (오답!)

✅ if (find("666") != npos) 사용 시:
   - curNum = 666 → find() = 0 → 0 != npos → true → posNum = 1
   - 결과: 666 출력 (정답!)
```

### 2️⃣ 전역 변수 초기화

```cpp
✅ int n;           // 전역 변수: 자동으로 0 초기화
✅ int posNum;      // 전역 변수: 자동으로 0 초기화
✅ int curNum = 666; // 666부터 시작

❌ int main() {
       int posNum;  // 지역 변수: 쓰레기 값! 초기화 필수!
   }
```

### 3️⃣ while(temp >= 666) 조건의 의미

```cpp
while(temp >= 666)  // 왜 666?
```

**이유**:
- 666보다 작은 수는 절대 "666"을 포함할 수 없음
- 예: temp = 66 → 66 < 666 → while 종료 (더 이상 체크 불필요)
- 최적화: 불필요한 반복 방지

## 📊 시간복잡도 분석

### 방법 1 (메서드 사용)

**시간복잡도**: **O(N × M)** (M = 자릿수)

```
1. while 반복: N번째 종말의 수를 찾을 때까지 반복
   - 최악의 경우: 약 N × 1000 번 반복 (종말의 수 밀도 고려)

2. to_string() + find(): O(M) (M = 자릿수)
   - 숫자 → 문자열 변환: O(M)
   - find("666"): O(M)

총합: O(N × M)
```

**실제 실행 시간**: 60ms

---

### 방법 2 (수학적 계산)

**시간복잡도**: **O(N × log M)** (M = 자릿수)

```
1. for 반복: N번째 종말의 수를 찾을 때까지 반복
   - 최악의 경우: 약 N × 1000 번 반복

2. while 반복 (temp /= 10): O(log M)
   - M 자리 수 → log M 번 반복
   - 예: 66666 (5자리) → 5번 반복

총합: O(N × log M)
```

**실제 실행 시간**: 12ms (5배 빠름!)

| 방법 | 시간복잡도 | 실제 시간 | 이유 |
|------|-----------|----------|------|
| **메서드 사용** | O(N × M) | 60ms | 문자열 변환/생성/검색 오버헤드 |

- N번째 종말의 수는 대략 N × 1000 이하

## 🎓 학습 포인트

### 1️⃣ STL find() 함수의 반환값 이해

- `find()`는 **위치를 반환** (0부터 시작)
- 찾으면: 인덱스 (0 이상)
- 못 찾으면: `string::npos` (최대값, 보통 -1)
- **주의**: `if (find("666"))` 형태는 위험! (0일 때 false)

### 2️⃣ 문자열 vs 수학적 계산 트레이드오프

| 기준 | 문자열 메서드 | 수학적 계산 |
|------|-------------|-----------|
| **가독성** | 높음 (직관적) | 중간 (이해 필요) |
| **구현 난이도** | 쉬움 | 중간 |
| **실행 속도** | 느림 (60ms) | 빠름 (12ms) |
| **메모리 효율** | 낮음 (문자열 생성) | 높음 (정수만 사용) |
| **추천 상황** | 빠른 구현, 연습 | 최적화, 대용량 데이터 |

### 3️⃣ 코딩테스트 전략

- **시간 제한 여유로움** → 방법 1 (직관적, 빠른 구현)
- **시간 제한 빡빡함** → 방법 2 (최적화, 효율적)
- **실전 팁**: 먼저 방법 1로 빠르게 구현하고, 시간 초과 시 방법 2로 최적화

### 4️⃣ 디버깅 팁

- `find()` 사용 시 반드시 `!= string::npos` 체크
- 전역 변수 활용하여 초기화 실수 방지
- 작은 예제(n=1, 2, 3)로 먼저 테스트
