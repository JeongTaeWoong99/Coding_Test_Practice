## 🔗 문제 링크

[백준 14469번 - 소가 길을 건너간 이유 3](https://www.acmicpc.net/problem/14469)

**난이도**: Silver 4

---

## 🤔 접근법

**(※ 검문이 끝나는 시간을 구하는 문제. 시간은 계속 흘러가고, 종료가 몇초에 되는지 구하는 문제이다. = realTime)**

**(※ 라인 스위핑 문제 = 이어 붙이기)**

N마리의 소가 농장 문을 통과하기 위해 검문을 받아야 하는데, 한 번에 한 마리씩만 검문받을 수 있다.

각 소는 **도착 시간**과 **검문 소요 시간**이 다르며, 먼저 도착한 소가 우선적으로 검문을 받는다.

모든 소가 농장에 입장하는 데 걸리는 **최소 시간**을 구하는 문제.

**핵심** : 도착 시간 순으로 정렬한 뒤, 각 소의 검문 시작 시간을 계산하는 **그리디 알고리즘** + **정렬** 문제

---

## 💡 정답 풀이 방법

**알고리즘**: 그리디(Greedy) + 정렬(Sorting)

**핵심 아이디어**:
```
1. 소들을 도착 시간 순으로 정렬
2. 첫 번째 소는 도착 즉시 검문 시작
3. 이후 소들은 max(이전 소 검문 종료 시간, 현재 소 도착 시간)부터 검문 시작
4. 마지막 소의 검문 종료 시간이 답
```

---

## 🔑 핵심 포인트

### 1️⃣ 도착 시간 순 정렬

```cpp
vector<pair<int, int>> cows(N); // first : 도착 시간, second : 검문 시간

// 입력
for (int i = 0; i < N; i++)
    cin >> cows[i].first >> cows[i].second;

// 도착 시간 순으로 정렬
sort(cows.begin(), cows.end());
```

**✅ 핵심**: pair는 기본적으로 first를 기준으로 오름차순 정렬
- `sort(cows.begin(), cows.end())`만으로 도착 시간 순 정렬 완료
- 먼저 도착한 소부터 처리해야 대기 시간 최소화

### 2️⃣ 검문 시간 계산

```cpp
// 첫 번째 소는 바로 검문 시작 가능
int realTime = cows[0].first + cows[0].second;

// 두 번째 소부터는 이전 소와의 관계 고려
for (int i = 1; i < N; i++)
{
    // 검문 시작 시간 = max(이전 소 검문 종료 시간, 현재 소 도착 시간)
    realTime  = max(realTime, cows[i].first);
    // 검문 종료 시간 = 검문 시작 시간 + 검문 소요 시간
    realTime += cows[i].second;
}
```

**✅ 핵심**: 두 가지 경우를 고려
1. **이전 소 검문이 끝나지 않음**: `realTime > cows[i].first`
   - 현재 소는 대기 후 검문 시작
   - 검문 시작: `realTime`
2. **이전 소 검문이 이미 끝남**: `realTime <= cows[i].first`
   - 현재 소는 도착 즉시 검문 시작
   - 검문 시작: `cows[i].first`

### 3️⃣ 예제 진행 과정

**입력**:
```
3
2 1
8 3
5 7
```

**정렬 후**: `(2,1), (5,7), (8,3)`

    입력:
    3
    2 1
    8 3
    5 7

    정렬 후: (2,1), (5,7), (8,3)

    1️⃣ 첫 번째 소 (2초 도착, 1초 검문):
       - 도착: 2초
       - 검문 시작: 2초 (바로 시작 가능)
       - 검문 종료: 2 + 1 = 3초
       - realTime = 3

    2️⃣ 두 번째 소 (5초 도착, 7초 검문):
       - 도착: 5초
       - 검문 시작: max(3, 5) = 5초 (이전 소 종료 시간 vs 도착 시간)
       - 검문 종료: 5 + 7 = 12초
       - realTime = 12

    3️⃣ 세 번째 소 (8초 도착, 3초 검문):
       - 도착: 8초
       - 검문 시작: max(12, 8) = 12초 (이전 소 종료 시간이 더 늦으므로 대기)
       - 검문 종료: 12 + 3 = 15초
       - realTime = 15

    답: 15
    */

**진행**:

| 소 | 도착 시간 | 검문 시간 | 검문 시작 | 검문 종료 |
|----|----------|----------|----------|----------|
| 1번 | 2초 | 1초 | 2초 | **3초** |
| 2번 | 5초 | 7초 | max(3, 5) = 5초 | **12초** |
| 3번 | 8초 | 3초 | max(12, 8) = 12초 | **15초** |

**답**: 15초

**상세 설명**:
1. **1번 소**: 2초에 도착 → 바로 검문 시작 → 3초에 입장 완료
2. **2번 소**: 5초에 도착 → 1번 소는 이미 끝남(3초) → 5초부터 검문 시작 → 12초에 입장 완료
3. **3번 소**: 8초에 도착 → 2번 소가 아직 검문 중(12초 종료) → 12초까지 대기 → 15초에 입장 완료

## 🚨 "맞왜틀" 방지 포인트

### 1️⃣ 정렬 필수!

```cpp
❌ 정렬 없이 입력 순서대로 처리 → 틀림!
✅ sort(cows.begin(), cows.end()) → 도착 시간 순 정렬
```

**이유:**
- 먼저 도착한 소부터 처리해야 함
- 정렬하지 않으면 나중에 도착한 소를 먼저 처리하는 오류 발생

**반례**:
```
2
10 5
5 5

❌ 정렬 안 함: (10,5) → (5,5) → 10 + 5 + 5 = 20
✅ 정렬 함: (5,5) → (10,5) → max(10, 10) + 5 = 15
```

### 2️⃣ realTime 업데이트 순서

```cpp
❌ realTime += cows[i].second;
   realTime = max(realTime, cows[i].first); // 순서 틀림!

✅ realTime = max(realTime, cows[i].first);
   realTime += cows[i].second;             // 올바른 순서
```

**이유:**
- 먼저 검문 **시작 시간**을 결정한 뒤
- 그 시작 시간에 검문 **소요 시간**을 더해야 함

### 3️⃣ 첫 번째 소 처리

```cpp
❌ for (int i = 0; i < N; i++)  // 모든 소를 동일하게 처리 → 복잡함

✅ int realTime = cows[0].first + cows[0].second;
   for (int i = 1; i < N; i++) // 두 번째 소부터 처리
```

**이유:**
- 첫 번째 소는 무조건 도착 즉시 검문 시작 가능
- 별도로 처리하면 코드가 간결해짐

## 📊 시간복잡도 분석

**전체 시간복잡도**: **O(N log N)**

**상세 분석**:
```
1. 입력 처리 : O(N)
   - N마리의 소 정보 입력

2. 정렬 : O(N log N)
   - sort() 함수는 퀵소트/머지소트 기반

3. 검문 시간 계산 : O(N)
   - N번 반복하며 각 소의 검문 시간 계산

총합 : O(N) + O(N log N) + O(N) = O(N log N)
```

**시간 제한 체크**:
- N ≤ 100 (문제 조건)
- N log N ≈ 100 × 7 ≈ 700
- **700 연산** << **1억** → 시간 내 여유롭게 통과 ✅

## 🎯 알고리즘 분류

- **그리디(Greedy)**: 도착 시간 순으로 처리하는 것이 최적
- **정렬(Sorting)**: 도착 시간 기준 오름차순 정렬
- **라인 스위핑(Line Sweeping)**: 시간 순서대로 이벤트 처리(= 이어 붙이기)
