## 🤔 접근법

패스워드 품질 검증 문제.

주어진 3가지 조건을 모두 만족하는지 검사하는 구현 문제.

**핵심**: 문자열을 순회하며 각 조건을 체크하되, 순서와 초기화에 유의해야 함.

---

## 💡 정답 풀이 방법

**알고리즘**: 구현, 문자열

**핵심 아이디어**:
```
1. 3가지 조건을 flag로 관리 (flag1, flag2, flag3)
2. 문자열을 한 글자씩 순회하며 조건 검사
3. 모음/자음 연속 카운트는 해당 타입이 나올 때마다 증가, 다른 타입이 나오면 0으로 초기화
4. 이전 문자와 현재 문자를 비교하여 연속 여부 체크 (ee, oo는 예외)
5. 모든 조건을 만족하면 acceptable, 하나라도 불만족하면 not acceptable
```

**3가지 조건**:
1. 모음(a,e,i,o,u) 하나를 반드시 포함
2. 모음 3개 또는 자음 3개 연속 금지
3. 같은 글자 연속 2번 금지 (단, ee와 oo는 허용)

## 🔑 핵심 개념

### 1️⃣ 전역 변수 vs 지역 변수

**전역 변수의 장점**:
- 자동으로 0/false로 초기화
- 초기화 실수 방지
- 코드 간결화

**C++ 초기화 규칙**:

| 변수 종류 | 선언만 했을 때 |
|---------|-------------|
| **전역 변수** | ✅ 자동으로 0 초기화 |
| **지역 변수** | ❌ 쓰레기 값 (랜덤) |

**예시**:
```cpp
char global_c;    // 자동으로 '\0' (0)
int main() 
{
    char local_c; // 쓰레기 값! 초기화 필수!
}
```

### 2️⃣ '\0'의 의미

**`'\0'` = NULL 문자 (ASCII 0)**

| 표기 | 의미 | ASCII 값 |
|-----|------|---------|
| `'\0'` | NULL 문자 | 0 |
| `' '` | 공백 (스페이스) | 32 |
| `'\n'` | 줄바꿈 | 10 |

**왜 `'\0'`을 사용하는가?**
```cpp
char previousC = '\0';  // "아직 이전 문자가 없음"을 표현

if (previousC == c && ...)  // 첫 반복: '\0' != 'a' → false (정상)
```

### 3️⃣ 조건 3번 로직의 핵심

**❌ 처음 작성한 잘못된 코드**:
```cpp
if (prviousC && (prviousC != 'e' && prviousC != 'o') && c == prviousC)
```

**문제점**:
- "이전 문자가 e나 o가 아닐 때만" 체크
- "eee", "ooo" 같은 경우를 체크하지 못함!

**✅ 올바른 코드**:
```cpp
if (previousC == c && c != 'e' && c != 'o')
```

**논리**:
1. `previousC == c` → 같은 글자가 연속 2번 옴
2. `c != 'e' && c != 'o'` → 그 글자가 'e'나 'o'가 아닐 때만 거부

**반례 분석**:
```
"aa"  → previousC='a', c='a' → c != 'e' && c != 'o' → 거부 ✅
"eee" → previousC='e', c='e' → c == 'e' → 허용 (조건 2번에서 거부됨) ✅
"ieee"→ "ee"는 허용 → acceptable ✅
```

### 4️⃣ 모음/자음 카운트 로직

**❌ 처음 작성한 잘못된 코드**:
```cpp
if (c == 'a' || c == 'e' || ...)  // 모음일 때
{
    count3_M = 0;  // 모음 카운트 초기화
    ++count3_J;    // ❌ 자음 카운트 증가 (반대!)
}
```

**✅ 올바른 코드**:
```cpp
if (c == 'a' || c == 'e' || ...)  // 모음일 때
{
    consonant_cnt = 0;  // 자음 카운트 초기화
    ++vowel_cnt;        // ✅ 모음 카운트 증가
}
```

**원리**:
```
문자열: "aaa"
1번째 'a': vowel_cnt=1, consonant_cnt=0
2번째 'a': vowel_cnt=2, consonant_cnt=0
3번째 'a': vowel_cnt=3, consonant_cnt=0 → 거부!

문자열: "abc"
'a': vowel_cnt=1, consonant_cnt=0
'b': vowel_cnt=0, consonant_cnt=1
'c': vowel_cnt=0, consonant_cnt=2
```

## 🐛 "맞왜틀" 디버깅 과정

### 문제 : 지역 변수 초기화 누락

**증상**: 랜덤하게 틀리는 경우 발생 가능

**원인**:
```cpp
char prviousC;  // 초기화 안함 → 쓰레기 값
```

**해결**:
```cpp
char previousC = '\0';  // 명시적 초기화
```

**또는 전역 변수로 선언** (자동 초기화):
```cpp
char previousC;  // 전역: 자동으로 '\0'
```

**교훈**: C++ 지역 변수는 반드시 초기화!
