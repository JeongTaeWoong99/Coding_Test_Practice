## 🤔 접근법

2048 게임 시뮬레이션 문제.

최대 5번 이동해서 만들 수 있는 가장 큰 블록을 찾는 문제.

**핵심**:
- 백트래킹으로 모든 경우의 수(4^5 = 1024가지) 탐색
- 보드 회전으로 4방향(상하좌우)을 하나의 Move 함수로 처리
- 블록 합치기 규칙 정확히 구현 (이미 합쳐진 블록은 재합침 불가)

---

## 💡 정답 풀이 방법

### 🎯 알고리즘: 백트래킹 + 시뮬레이션

**1. 보드 회전(Rotate)**
- 시계방향으로 90도 회전
- 4번 회전하면 상/우/하/좌 모든 방향 처리 가능
- `temp[i][j] = board[N - 1 - j][i]` 공식 사용

**2. 블록 이동(Move)**
- 왼쪽으로 블록을 이동시키는 함수
- `cnt` 변수로 "현재 채울 위치" 관리
- 3가지 경우 처리:
  1. `temp[i][cnt] == 0`: 빈 칸이면 값 저장
  2. `temp[i][cnt] == 현재값`: 같은 값이면 합치고 `cnt++`
  3. `temp[i][cnt] != 현재값`: 다른 값이면 `cnt++` 후 저장

**3. 백트래킹(GO)**
- 5번 이동할 때까지 재귀 호출
- 각 단계에서 4방향 모두 시도
- 5번 이동 완료 시 최대값 갱신

## 🔑 핵심 개념

### 1️⃣ Move 함수 - cnt의 역할

**cnt는 "다음에 채울 위치"를 가리킵니다.**

```cpp
    for(int i = 0; i < N; i++)
    {
        int cnt = 0;  // 현재 채울 위치

        for(int j = 0; j < N; j++)
        {
            // 빈 칸은 건너뜀
            if(currentBoard[i][j] == 0) continue;

            // 현재 위치가 비어있으면 값 추가
            if(temp[i][cnt] == 0)
            {
                temp[i][cnt] = currentBoard[i][j];
            }
            // 현재 위치와 같은 값이면 합침
            else if(temp[i][cnt] == currentBoard[i][j])
            {
                temp[i][cnt] *= 2;
                cnt++;
            }
            // 다른 값이면 다음 위치에 추가
            else
            {
                cnt++;
                temp[i][cnt] = currentBoard[i][j];
            }
        }
    }
```

**핵심 포인트**:
- `temp[i][cnt]`를 항상 확인하고 수정
- 합친 후 `cnt++`로 재합침 방지
- 다른 값일 때도 `cnt++`로 다음 칸으로 이동

---

### 2️⃣ 테스트 케이스로 이해하기

**입력**: `[2, 2, 4, 0]`

| j | currentBoard[0][j] | temp[0] | cnt | 동작 |
|---|-------------------|---------|-----|------|
| 0 | 2 | [2, 0, 0, 0] | 0 | temp[0]에 2 저장 |
| 1 | 2 | [4, 0, 0, 0] | 1 | 2==2 합침! cnt++ |
| 2 | 4 | [4, 4, 0, 0] | 1 | temp[1]에 4 저장 |
| 3 | 0 | [4, 4, 0, 0] | 1 | 건너뜀 |

**결과**: `[2, 2, 4, 0]` → `[4, 4, 0, 0]`

---

### 3️⃣ 재합침 방지 원리

**입력**: `[2, 2, 2, 0]`

**문제 규칙**: *"한 번의 이동에서 이미 합쳐진 블록은 또 다른 블록과 다시 합쳐질 수 없다."*

| j | currentBoard[0][j] | temp[0] | cnt | 설명 |
|---|-------------------|---------|-----|------|
| 0 | 2 | [2, 0, 0, 0] | 0 | 첫 번째 2 저장 |
| 1 | 2 | [4, 0, 0, 0] | 1 | 합침! **cnt=1로 이동** |
| 2 | 2 | [4, 2, 0, 0] | 1 | cnt=1이므로 temp[1]에 저장 |

**결과**: `[2, 2, 2, 0]` → `[4, 2, 0, 0]`

✅ `cnt++` 덕분에 이미 합쳐진 `temp[0]`에 다시 접근하지 않음!

---

### 4️⃣ 보드 회전으로 4방향 처리

```
원본 보드:     90도 회전:    180도 회전:   270도 회전:
[2, 4]        [0, 2]        [8, 0]        [4, 8]
[0, 8]        [8, 4]        [4, 2]        [2, 0]

왼쪽 이동 = 원본에 Move
위쪽 이동 = 90도 회전 후 Move
오른쪽 이동 = 180도 회전 후 Move
아래쪽 이동 = 270도 회전 후 Move
```

**장점**: Move 함수 하나로 4방향 모두 처리!

---

### 5️⃣ 배열 초기화의 중요성

```cpp
❌ int temp[24][24];           // 쓰레기 값!
✅ int temp[24][24] = {0};     // 0으로 초기화

❌ int temp[24][24];
   // temp[i][cnt] == 0 체크가 쓰레기 값과 비교됨!

✅ int temp[24][24] = {0};
   // 모든 값이 0이므로 정상 동작
```

**이유**: Move 함수가 `temp[i][cnt] == 0` 조건에 의존하기 때문!

## 🚨 주의사항

### 2️⃣ 배열 복사

```cpp
int cpy[24][24];
memcpy(cpy, currentBoard, sizeof(cpy));  // 보드 복사
Move(cpy);                                // 복사본에 이동
GO(here + 1, cpy);                        // 재귀 호출
```

**이유**: 원본 보드를 보존해야 다음 방향 시도 가능!

### 3️⃣ memset vs 중괄호 초기화

```cpp
// Rotate 함수
int temp[24][24] = {0};  // ✅ 간단하고 명확

// Move 함수
int temp[24][24] = {0};  // ✅ 이것도 가능

// 또는
int temp[24][24];
memset(temp, 0, sizeof(temp));  // ✅ 명시적
```

둘 다 가능하지만, **반드시 초기화 필수!**

## 📊 시간복잡도 분석

### 📌 전체 시간복잡도: O(4^5 × N^2) = O(1024 × N^2)

**변수**:
- N: 보드 크기 (1 ≤ N ≤ 20)
- 이동 횟수: 최대 5번
- 각 단계마다 4방향 시도

**단계별 복잡도**:
1. **GO 함수 (백트래킹)**: O(4^5) = O(1024)
   - 5번 이동, 각 단계마다 4방향 = 4^5가지

2. **Move 함수**: O(N^2)
   - N개 행 순회
   - 각 행마다 N개 열 순회

3. **Rotate 함수**: O(N^2)
   - N×N 배열 회전

4. **Counting 함수**: O(N^2)
   - N×N 배열 순회

**최악의 경우** (N=20):
```
1024 × (20 × 20) = 1024 × 400 = 409,600 ≈ 40만 연산
```

**✅ 결과**: 40만 << 1억 → **여유롭게 통과!**
