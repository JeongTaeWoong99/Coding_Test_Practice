## 🔗 문제 링크

[백준 14867번 - 물통](https://www.acmicpc.net/problem/14867)

**난이도**: Gold 2

---

## 🤔 접근법

두 개의 물통에 물을 채우고 비우는 작업을 반복하여 목표 상태에 도달하는 **최소 작업 수**를 구하는 문제.

가능한 연산은 **6가지**:
1. Fill A: A 물통을 가득 채움
2. Fill B: B 물통을 가득 채움
3. Empty A: A 물통을 비움
4. Empty B: B 물통을 비움
5. Move B → A: B에서 A로 물을 옮김
6. Move A → B: A에서 B로 물을 옮김

**핵심은 (A의 물 양, B의 물 양)을 상태로 보고 BFS로 최단 거리를 탐색**하는 것!

💡 **왜 map을 사용하는가?**
- 상태 공간이 **희소(sparse)** 하다! (조밀하지 않음)
- 물통 용량이 최대 100,000이므로 2차원 배열은 100,000 × 100,000 = 10^10 → 메모리 초과
- 실제 도달 가능한 상태는 훨씬 적음 → map으로 필요한 상태만 저장

---

## 💡 정답 풀이 방법

**알고리즘**: BFS (너비 우선 탐색) + map (희소 상태 저장)

**핵심 아이디어**:
```
1. (0, 0) 상태에서 시작
2. 각 상태에서 6가지 연산을 수행하여 다음 상태로 이동
3. 방문하지 않은 상태만 큐에 추가
4. 목표 상태 (c, d)에 도달하면 거리 반환
5. 도달 불가능하면 -1 반환
```

**시간 복잡도**: O(상태 수 × log(상태 수))
- 각 상태에서 6가지 연산 수행
- map 연산은 O(log N)

**공간 복잡도**: O(상태 수)
- map에 도달 가능한 상태만 저장

## 🔑 핵심 포인트

### 1️⃣ 희소(Sparse) 상태 공간

```cpp
map<pair<int, int>, int> m;  // 상태 → 거리 + 1
```

**왜 배열이 아닌 map인가?**
- 물통 용량: 최대 100,000
- 배열로 표현: `visited[100000][100000]` → **10^10 바이트** → 불가능!
- 하지만 실제 도달 가능한 상태는 훨씬 적음
- map으로 필요한 상태만 저장 → 효율적

**"조밀조밀 상태값 X, 희소하다!"**
- 상태 공간이 넓지만, 실제 사용하는 상태는 적음
- 이런 경우 map이 효율적

### 2️⃣ 거리 저장 트릭

```cpp
m[{x, y}] = d + 1;  // 거리 0과 미방문(0) 구분 위해 +1
```

**왜 +1을 하는가?**
- map의 기본값은 0
- 거리가 0인 상태와 미방문 상태를 구분하기 위해 +1
- 출력 시 -1 보정: `m[{aFid, bFid}] - 1`

### 3️⃣ 🎯 Move 연산 공식 시각화

```cpp
// 5. Move B → A : B에서 A로 물을 옮김
Enqueue(min(cA + cB, aCap), max(0, cA + cB - aCap), dist);

// 6. Move A → B : A에서 B로 물을 옮김
Enqueue(max(0, cA + cB - bCap), min(cA + cB, bCap), dist);
```


#### 📊 Move B → A 시각화 (B에서 A로 물 옮기기)

**상황**: 현재 A에 `cA`, B에 `cB`만큼의 물이 있음

```
┌─────────────────────────────────────────────────────────────┐
│                      Move B → A                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   BEFORE                         AFTER                      │
│   ┌─────┐     ┌─────┐           ┌─────┐     ┌─────┐        │
│   │     │     │     │           │█████│     │     │        │
│   │     │     │█████│   ───►    │█████│     │░░░░░│        │
│   │█████│     │█████│           │█████│     │░░░░░│        │
│   └──A──┘     └──B──┘           └──A──┘     └──B──┘        │
│    (cA)        (cB)              (?)          (?)          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**핵심 원리**: 물의 총량은 항상 보존됨! → `cA + cB`

**경우 1**: A에 남은 공간 ≥ B의 물
- B의 물을 **모두** A로 옮길 수 있음
- A의 새 물 양 = `cA + cB`
- B의 새 물 양 = `0`

**경우 2**: A에 남은 공간 < B의 물
- A가 **꽉 찰 때까지만** 옮김
- A의 새 물 양 = `aCap` (가득 참)
- B의 새 물 양 = `cA + cB - aCap` (남은 물)

**공식 도출**:
```
A의 새 물 양 = min(cA + cB, aCap)     ← 총량과 A용량 중 작은 값
B의 새 물 양 = max(0, cA + cB - aCap) ← A를 채우고 남은 물 (음수면 0)
```

**예시**:
```
aCap = 5, bCap = 7
현재: cA = 2, cB = 6  (총량 = 8)

경우: 8 > 5 이므로 A가 꽉 참
→ A = min(8, 5) = 5
→ B = max(0, 8 - 5) = 3

결과: (2, 6) → (5, 3)
```

#### 📊 Move A → B 시각화 (A에서 B로 물 옮기기)

```
┌─────────────────────────────────────────────────────────────┐
│                      Move A → B                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   BEFORE                         AFTER                      │
│   ┌─────┐     ┌─────┐           ┌─────┐     ┌─────┐        │
│   │     │     │     │           │     │     │█████│        │
│   │█████│     │░░░░░│   ───►    │░░░░░│     │█████│        │
│   │█████│     │█████│           │░░░░░│     │█████│        │
│   └──A──┘     └──B──┘           └──A──┘     └──B──┘        │
│    (cA)        (cB)              (?)          (?)          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**경우 1**: B에 남은 공간 ≥ A의 물
- A의 물을 **모두** B로 옮길 수 있음
- A의 새 물 양 = `0`
- B의 새 물 양 = `cA + cB`

**경우 2**: B에 남은 공간 < A의 물
- B가 **꽉 찰 때까지만** 옮김
- A의 새 물 양 = `cA + cB - bCap` (남은 물)
- B의 새 물 양 = `bCap` (가득 참)

**공식 도출**:
```
A의 새 물 양 = max(0, cA + cB - bCap) ← B를 채우고 남은 물 (음수면 0)
B의 새 물 양 = min(cA + cB, bCap)     ← 총량과 B용량 중 작은 값
```

**예시**:
```
aCap = 5, bCap = 7
현재: cA = 4, cB = 5  (총량 = 9)

경우: 9 > 7 이므로 B가 꽉 참
→ A = max(0, 9 - 7) = 2
→ B = min(9, 7) = 7

결과: (4, 5) → (2, 7)
```

---

#### 📋 Move 공식 요약

| 연산 | 받는 물통의 새 물 양 | 보내는 물통의 새 물 양 |
|-----|---------------------|----------------------|
| B → A | `min(cA + cB, aCap)` | `max(0, cA + cB - aCap)` |
| A → B | `max(0, cA + cB - bCap)` | `min(cA + cB, bCap)` |

**패턴**:
- **받는 쪽**: `min(총량, 용량)` - 총량과 용량 중 작은 값
- **보내는 쪽**: `max(0, 총량 - 상대용량)` - 상대방 채우고 남은 물

---

### 4️⃣ 6가지 연산의 상태 전이

```cpp
// Fill: 가득 채움
Enqueue(aCap, cB, dist);   // Fill A
Enqueue(cA, bCap, dist);   // Fill B

// Empty: 비움
Enqueue(0, cB, dist);      // Empty A
Enqueue(cA, 0, dist);      // Empty B

// Move: 옮기기 (위에서 설명한 공식)
Enqueue(min(cA + cB, aCap), max(0, cA + cB - aCap), dist);  // B → A
Enqueue(max(0, cA + cB - bCap), min(cA + cB, bCap), dist);  // A → B
```

## 📊 예시 실행 흐름

**입력**: `3 7 3 2`
- A 용량 = 3, B 용량 = 7
- 목표: A = 3, B = 2

**BFS 탐색 과정**:
```
(0,0) → Fill B → (0,7)
(0,7) → Move B→A → (3,4)
(3,4) → Empty A → (0,4)
(0,4) → Move B→A → (3,1)
(3,1) → Empty A → (0,1)
(0,1) → Move B→A → (1,0)
(1,0) → Fill B → (1,7)
(1,7) → Move B→A → (3,5)
(3,5) → Empty A → (0,5)
(0,5) → Move B→A → (3,2) ✅ 목표 도달!
```

**최소 작업 수**: 9

## 🚨 주의사항

1. **map 사용 필수**: 상태 공간이 희소하므로 배열 대신 map 사용
2. **거리 +1 트릭**: 미방문(0)과 거리 0을 구분하기 위해 +1
3. **목표 도달 체크**: BFS 진행 중 목표 상태 방문 시 즉시 반환
4. **도달 불가능 케이스**: 모든 상태 탐색 후에도 목표에 못 도달하면 -1
