## 💡 핵심 아이디어

### 🔑 시뮬레이션 + DFS

**문제 조건:**
```
T번 회전하는 동안:
  1. xi의 배수인 원판들을 di 방향으로 ki칸 회전
  2. 인접하면서 같은 수가 있는가?
     - 있으면: 모두 0으로 제거
     - 없으면: 평균 계산 후 평균보다 큰 수는 -1, 작은 수는 +1
  3. 모든 회전 완료 후 남은 수의 합 출력
```

**인접의 정의:**
- 같은 원판 내: 좌우 인접 (**원형 연결**, 0번과 m-1번 연결)
- 다른 원판 간: 위아래 인접 (같은 위치)

**알고리즘 흐름:**
```
1. n개의 원판 입력 (각 원판은 m개의 숫자)
2. T번 반복:
   a. 회전: x의 배수 원판들을 d 방향으로 k칸 회전
   b. DFS로 인접한 같은 숫자 찾기
   c. 인접한 같은 숫자가 있으면:
      → 모두 0으로 제거
   d. 인접한 같은 숫자가 없으면:
      → 평균 계산 후 ±1 조정
3. 최종적으로 남은 숫자들의 합 출력
```

**시간 복잡도**: O(T × N × M)
- T = 회전 횟수 (최대 50)
- N = 원판 개수 (최대 50)
- M = 원판 숫자 개수 (최대 50)
- 각 회전마다 DFS: O(N × M)
- 전체: 50 × 50 × 50 = 125,000번 연산

**공간 복잡도**: O(N × M)
- arr 배열: O(N × M)
- vit 배열: O(N × M)
- 재귀 스택: O(N × M)

### 1️⃣ STL rotate를 이용한 원판 회전

```cpp
void Rota(int y, int dir, int k)
{
    // 현재 원판을 벡터에 복사
    vector<int> v;
    for (int i = 0; i < m; i++)
        v.push_back(arr[y][i]);

    // 회전 (STL rotate 사용)
    if (dir == 1)  // 반시계
    {
        rotate(v.begin(), v.begin() + k, v.end());
    }
    else  // 시계
    {
        rotate(v.begin(), v.begin() + m - k, v.end());
    }

    // 회전된 결과를 배열에 다시 저장
    for (int i = 0; i < m; i++)
    {
        arr[y][i] = v[i];
    }
}
```

**✅ STL rotate 핵심 이해:**

**rotate(first, mid, last):**
- **mid가 가리키는 원소가 맨 앞(first)으로 오도록 회전**

**시각화 예제** (배열: `[1, 2, 3, 4, 5, 6]`, m=6, k=2):

**반시계 k칸:**
```cpp
rotate(v.begin(), v.begin() + 2, v.end());

원본:  [1, 2, 3, 4, 5, 6]
        ↑     ↑
     first  mid (인덱스 2)

mid(3)가 맨 앞으로 → [3, 4, 5, 6, 1, 2]
                      ↑ 이 값이 맨 앞으로!

결과: 반시계 방향 2칸 = 왼쪽으로 2칸
```

**시계 k칸:**
```cpp
rotate(v.begin(), v.begin() + (m - 2), v.end());
// = rotate(v.begin(), v.begin() + 4, v.end());

원본:  [1, 2, 3, 4, 5, 6]
        ↑           ↑
     first       mid (인덱스 4)

mid(5)가 맨 앞으로 → [5, 6, 1, 2, 3, 4]
                      ↑ 이 값이 맨 앞으로!

결과: 시계 방향 2칸 = 오른쪽으로 2칸
```

**💡 핵심 정리:**

| 방향 | 코드 | mid 위치 | 의미 |
|-----|------|---------|------|
| **반시계** | `rotate(begin, begin+k, end)` | k번째 원소 | "k번째가 맨 앞으로" = 왼쪽으로 k칸 |
| **시계** | `rotate(begin, begin+(m-k), end)` | (m-k)번째 원소 | "(m-k)번째가 맨 앞으로" = 오른쪽으로 k칸 |

**이해하기 쉬운 방법:**
- 반시계: "3번째를 맨 앞으로" → 왼쪽 2칸 밀기
- 시계: "뒤에서 2번째를 맨 앞으로" → 오른쪽 2칸 

★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★

※★ 반시계는 앞쪽(0번)에서 시작해서, -> 방향으로 k번째가 앞(0번)으로 와야하니, begin + k

※★ 시계는 맨뒤(m = 전체길이)에서 시작해서, <- 방향으로 k번째가 앞(으로) 와야하니, begin+(m-k)

### 2️⃣ 원형 연결 처리 (핵심!)

```cpp
void DFS(int y, int x)
{
    for (int i = 0; i < 4; i++)
    {
        int ny = y + dy[i];
        int nx = (x + dx[i] + m) % m;  // ☆ 원형 연결 처리

        // 원판 범위 체크
        if (ny < 0 || ny >= n) continue;

        // 이미 방문
        if (vit[ny][nx]) continue;

        // 인접한 칸이 같은 숫자면
        if (arr[y][x] == arr[ny][nx])
        {
            vit[y][x]   = 1;    // 현재 위치 방문 체크
            vit[ny][nx] = 1;    // 인접 위치 방문 체크
            
            flag = false;       // 인접한 같은 수 발견
            
            DFS(ny, nx);        // 재귀 탐색
        }
    }
}
```

**✅ 원형 연결 공식: `(x + dx[i] + m) % m`**

**왜 `+m`을 해주는가?** => 음수 처리를 위해서!!!!

**📊 경우의 수 분석:**

**케이스 1: 오른쪽으로 이동 (+1)**
```
m = 6 (인덱스 0~5)
현재 x = 5 (마지막)
dx[i] = +1 (오른쪽)

방법 1: (5 + 1) % 6 = 0 ✅
방법 2: (5 + 1 + 6) % 6 = 12 % 6 = 0 ✅

→ 둘 다 작동함!
```

**케이스 2: 왼쪽으로 이동 (-1) ← 핵심!**
```
m = 6 (인덱스 0~5)
현재 x = 0 (처음)
dx[i] = -1 (왼쪽)

방법 1: (0 + (-1)) % 6 = -1 % 6 = -1 ❌
        C++에서 음수 모듈로는 음수 결과!

방법 2: (0 + (-1) + 6) % 6 = 5 % 6 = 5 ✅
        +m을 해주면 음수가 양수로 변환!
```

**🔧 C++ 음수 모듈로 문제:**

```cpp
// C++의 음수 모듈로 동작
-1 % 6 = -1  (❌ 원하는 값은 5)
-2 % 6 = -2  (❌ 원하는 값은 4)

// +m을 하면 해결
(-1 + 6) % 6 = 5 ✅
(-2 + 6) % 6 = 4 ✅
```

**📐 모든 경우의 수:**

| 현재 위치 | 방향 | dx[i] | 공식 (x + dx + m) % m | 결과 |
|---------|------|-------|---------------------|------|
| x = 0 | 왼쪽 | -1 | (0 + (-1) + 6) % 6 | 5 ✅ |
| x = 0 | 오른쪽 | +1 | (0 + 1 + 6) % 6 | 1 ✅ |
| x = 5 | 왼쪽 | -1 | (5 + (-1) + 6) % 6 | 4 ✅ |
| x = 5 | 오른쪽 | +1 | (5 + 1 + 6) % 6 | 0 ✅ |

**+m 없이 계산하면:**

| 현재 위치 | 방향 | dx[i] | 공식 (x + dx) % m | 결과 |
|---------|------|-------|------------------|------|
| x = 0 | 왼쪽 | -1 | (0 + (-1)) % 6 | **-1 ❌** |
| x = 0 | 오른쪽 | +1 | (0 + 1) % 6 | 1 ✅ |
| x = 5 | 왼쪽 | -1 | (5 + (-1)) % 6 | 4 ✅ |
| x = 5 | 오른쪽 | +1 | (5 + 1) % 6 | 0 ✅ |

→ **음수가 나오는 경우를 대비**하기 위해 `+m`이 필요합니다!

**💡 핵심 정리:**

```cpp
// ❌ 잘못된 공식 (음수 처리 안 됨)
int nx = (x + dx[i]) % m;

// ✅ 올바른 공식 (음수도 처리됨)
int nx = (x + dx[i] + m) % m;
```

**이유:** C++에서 음수 % 양수는 음수가 나오므로, `+m`을 해서 항상 양수로 만든 후 모듈로 연산!

**💭 본질적으로 이해하기: 모듈러 연산 vs if-else**

사실 `(x + dx[i] + m) % m` 공식은 다음 if-else 로직을 **수학적으로 압축한 것**입니다:

```cpp
// ❌ 직관적이지만 긴 방법 (if-else)
int nx = x + dx[i];

if (nx == -1)       // 왼쪽 경계를 넘어감
{
    nx = m - 1;     // 맨 오른쪽으로
}
else if (nx == m)   // 오른쪽 경계를 넘어감
{
    nx = 0;         // 맨 왼쪽으로
}

// ✅ 수학적으로 압축된 방법 (모듈러 연산)
int nx = (x + dx[i] + m) % m;
```

**왜 같은 결과가 나올까?**

```
케이스 1: 왼쪽 넘어감 (x=0, dx=-1)
  if-else: nx = 0 + (-1) = -1 → nx = m-1 = 5
  모듈러:   nx = (0 + (-1) + 6) % 6 = 5 % 6 = 5 ✅

케이스 2: 오른쪽 넘어감 (x=5, dx=+1)
  if-else: nx = 5 + 1 = 6 → nx = 0
  모듈러:   nx = (5 + 1 + 6) % 6 = 12 % 6 = 0 ✅

케이스 3: 정상 범위 (x=2, dx=+1)
  if-else: nx = 2 + 1 = 3 (조건 통과)
  모듈러:   nx = (2 + 1 + 6) % 6 = 9 % 6 = 3 ✅
```

**핵심 정리:**
- **원형 연결의 본질**: 왼쪽 끝(`-1`)은 오른쪽 끝(`m-1`)과 연결, 오른쪽 끝(`m`)은 왼쪽 끝(`0`)과 연결
- **if-else 방식**: 직관적이지만 코드가 길고 경계 조건마다 처리 필요
- **모듈러 연산**: 수학적으로 압축하여 한 줄로 모든 경우 처리
- **`+m`의 역할**: 음수를 양수로 만들어 모듈로 연산이 올바르게 작동하도록 보장

**💡 어느 방식을 선택할까?**
- **코딩테스트**: 모듈러 연산 (간결하고 빠름)
- **실무/가독성**: 상황에 따라 if-else도 좋음 (의도가 명확)

### 3️⃣ 매 회전마다 인접 체크 및 처리

```cpp
// T번 회전 및 처리
for (int i = 0; i < T; i++)
{
    cin >> x >> d >> k;

    // x의 배수인 원판들을 회전
    for (int j = x - 1; j < n; j += x)
    {
        Rota(j, d, k);
    }

    // 인접한 같은 숫자 찾아서 제거
    // 제거할 숫자가 없으면 평균 조정
    if (FindAndRemove())  // true면 인접한 같은 수 없음

        AdjustByAverage();
    }
}
```

**✅ 핵심**:
- **매 회전마다** 인접 체크 및 처리 수행
- 모든 회전이 끝난 후가 아님!
- `FindAndRemove()` 반환값:
  - `true`: 인접한 같은 수 없음 → 평균 조정
  - `false`: 인접한 같은 수 있음 → 이미 제거됨

### 4️⃣ 평균 계산 후 ±1 조정

```cpp
void AdjustByAverage()
{
    int sum = 0;
    int cnt = 0;

    // 0이 아닌 숫자들의 합과 개수 계산
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            if (arr[i][j] == 0) continue;

            sum += arr[i][j];
            cnt++;
        }
    }

    // 평균 계산
    double avg = (double)sum / (double)cnt;

    // 평균과 비교하여 ±1 조정
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            if (arr[i][j] == 0) continue;

            if ((double)arr[i][j] > avg)       // 평균보다 크면
            {
                arr[i][j]--;
            }
            else if ((double)arr[i][j] < avg)  // 평균보다 작으면
            {
                arr[i][j]++;
            }
        }
    }
}
```

**✅ 핵심**:
- 0이 아닌 숫자들만 평균 계산에 포함
- 평균과 같은 수는 그대로 유지
- double 타입으로 캐스팅하여 정확한 비교

**예시:**
```
배열: [0, 3, 5, 0, 2, 4]
평균: (3+5+2+4) / 4 = 14/4 = 3.5

3 < 3.5 → 3+1 = 4
5 > 3.5 → 5-1 = 4
2 < 3.5 → 2+1 = 3
4 > 3.5 → 4-1 = 3

결과: [0, 4, 4, 0, 3, 3]
```

### 5️⃣ DFS로 인접한 같은 숫자 찾기

```cpp
bool FindAndRemove()
{
    // true  = 인접한 같은 수 없음,
    // false = 인접한 같은 수 있음
    flag = true;
    memset(vit, 0, sizeof(vit));

    // 모든 칸 탐색
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            if (arr[i][j] == 0) continue;       // 이미 제거된 숫자
            if (vit[i][j])      continue;       // 이미 방문

            DFS(i, j);
        }
    }

    // 방문한 칸(=인접한 같은 숫자)을 0으로 제거
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            if (vit[i][j])
            {
                arr[i][j] = 0;
            }
        }
    }

    return flag;
}
```

**✅ 핵심**:
- `flag`를 `true`로 초기화 (인접한 같은 수 없다고 가정)
- DFS에서 인접한 같은 수를 찾으면 `flag = false`로 변경
- 방문 배열을 이용해 인접한 같은 숫자를 모두 표시
- 탐색 완료 후 한 번에 0으로 제거
- `flag` 반환: true면 평균 조정, false면 이미 제거됨
