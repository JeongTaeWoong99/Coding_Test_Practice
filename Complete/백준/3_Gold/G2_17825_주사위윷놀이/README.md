## 🤔 접근법

윷놀이 게임판에서 주사위 값에 따라 말을 이동시켜 최대 점수를 얻는 문제.

**핵심**:
- 백트래킹으로 모든 경우의 수 탐색 (4^10 = 1,048,576가지)
- 게임판을 그래프로 모델링 (인접 리스트)
- 파란색 칸과 빨간색 칸의 이동 규칙 정확히 구현
- 같은 칸에 2개의 말이 동시에 있을 수 없음 (도착 칸 제외)

**주요 아이디어**:
- 각 칸을 고유한 인덱스 번호로 표현
- 파란색 화살표는 `graph[i][1]`, 빨간색 화살표는 `graph[i][0]`
- 말이 도착 칸(100번)에 있으면 더 이상 이동하지 않음
- 백트래킹으로 10턴 동안 4개 말 중 하나를 선택하는 모든 경우 시도

## 💡 정답 풀이 방법

### 🎯 알고리즘: 백트래킹 + 시뮬레이션

**1. 게임판 그래프 구조화**
```cpp
// 각 칸을 노드로, 이동 경로를 간선으로 표현
// 외곽 경로: 0 → 1 → 2 → ... → 20 → 100
// 지름길 3개:
//   5번 칸: 5 → 21 → 22 → 23 → 24 (중앙 합류)
//   10번 칸: 10 → 27 → 28 → 24 (중앙 합류)
//   15번 칸: 15 → 29 → 30 → 31 → 24 (중앙 합류)
// 중앙 경로: 24 → 25 → 26 → 20 → 100
```

**파란색 칸 처리**:
- `graph[here].size() >= 2`: 연결된 경로가 2개 이상 (빨간선 + 파란선)
- `graph[here][0]`: 빨간색 화살표 (기본 경로)
- `graph[here][1]`: 파란색 화살표 (지름길)
- setMap()에서 빨간선 먼저 추가, 파란선 나중에 추가

**2. 말 이동 로직**
```cpp
int move(int currentPos, int moveCount)
{
    // 1. 도착 칸이면 그대로 유지
    if(currentPos == 100) return 100;

    // 2. 파란색 칸에서 출발하면 파란선으로 진입
    if(graph[currentPos].size() >= 2)
    {
        currentPos = graph[currentPos][1];
        moveCount--;
    }

    // 3. 남은 이동 횟수만큼 빨간선으로 이동
    while(moveCount > 0)
    {
        currentPos = graph[currentPos][0];
        if(currentPos == 100) break;
        moveCount--;
    }

    return currentPos;
}
```

**3. 중복 위치 체크**
```cpp
bool isOccupied(int targetPos, int currentHorseIdx)
{
    if(targetPos == 100) return false; // 도착 칸은 중복 허용

    for(int i = 0; i < 4; i++)
    {
        if(i == currentHorseIdx) continue;
        if(horses[i] == targetPos) return true; // 다른 말이 있으면 선택 불가
    }

    return false;
}
```

**4. 백트래킹**
```cpp
int go(int currentTurn)
{
    if(currentTurn == TOTAL_TURNS) return 0; // 10턴 종료

    int maxScore = 0;

    // 4개 말 중 하나 선택
    for(int horseIdx = 0; horseIdx < 4; horseIdx++)
    {
        int originalPos = horses[horseIdx];
        int newPos = move(originalPos, dice[currentTurn]);

        if(isOccupied(newPos, horseIdx)) continue; // 이미 말이 있으면 스킵

        horses[horseIdx] = newPos;                    // 말 이동
        maxScore = max(maxScore, go(currentTurn + 1) + cellScore[newPos]);
        horses[horseIdx] = originalPos;               // 백트래킹 (원상복구)
    }

    return maxScore;
}
```

## 🔑 핵심 포인트

### 1️⃣ 게임판 인덱싱 전략

**외곽 경로** (0~20):
```
0(시작) → 1(2점) → 2(4점) → ... → 20(40점) → 100(도착)
```

**지름길 경로**:
```
5번 지름길:  21(13점) → 22(16점) → 23(19점) → 24(25점)
10번 지름길: 27(22점) → 28(24점) → 24(25점)
15번 지름길: 29(28점) → 30(27점) → 31(26점) → 24(25점)
중앙 경로:   24(25점) → 25(30점) → 26(35점) → 20(40점)
```

**✅ 핵심**:
- 각 칸마다 고유한 인덱스 번호 부여
- 같은 점수여도 다른 칸이면 다른 인덱스 (예: 외곽 12번 칸=24점, 지름길 28번 칸=24점)
- 중앙 합류 지점(24번 인덱스)은 모든 지름길이 모이는 곳

### 2️⃣ 파란색 칸 판별

```cpp
// setMap()에서 간선 추가 순서:
add(5, 6);  // 빨간선 먼저 (graph[5][0] = 6)
add(5, 21); // 파란선 나중에 (graph[5][1] = 21)

// move() 함수에서:
if(graph[currentPos].size() >= 2)  // 경로가 2개 이상이면 파란색 칸
{
    currentPos = graph[currentPos][1]; // 파란선으로 진입
}
```

**✅ 핵심**:
- 파란색 칸은 `graph[i].size() >= 2`로 판별
- 빨간선(기본 경로)을 먼저 추가하고, 파란선(지름길)을 나중에 추가
- 파란색 칸에서 **출발할 때만** 파란선 타기 (이동 중에는 빨간선만)

### 3️⃣ "말이 이동을 마치는 칸에 다른 말이 있으면 그 말은 고를 수 없다"

**의미**:
- 이동하려는 말을 선택할 수 없다는 뜻
- 같은 칸에 2개의 말이 동시에 있을 수 없음 (도착 칸 제외)

**예시**:
```
현재 상황:
- 말 A: 10번 칸
- 말 B: 12번 칸
- 주사위: 2

❌ 말 A 선택: 10 + 2 = 12번 칸 → 말 B가 있음 → 선택 불가
✅ 말 B 선택: 12 + 2 = 14번 칸 → 비어있음 → 선택 가능
```

**✅ 핵심**:
- 먼저 있던 말(B)은 움직일 수 있음
- 나중에 들어오려는 말(A)을 선택할 수 없음
- 도착 칸(100번)은 여러 말이 함께 있을 수 있음

### 4️⃣ Queue를 활용한 이동 구현

```cpp
queue<int> q;
q.push(currentPos);
int nextPos;

while(!q.empty())
{
    int currentCell = q.front();
    q.pop();
    nextPos = graph[currentCell][0]; // 빨간선으로 이동
    q.push(nextPos);

    if(nextPos == 100) break;
    moveCount--;
    if(moveCount == 0) break;
}
```

**✅ 핵심**:
- Queue로 moveCount만큼 순차적으로 이동
- 도착 칸(100번)에 도달하면 즉시 중단
- 이동 횟수가 0이 되면 중단

**🔍 왜 Queue를 사용하는가?**
- 그래프 탐색 방식으로 경로 이동 구현
- 현재 칸 → 다음 칸 순서대로 처리
- 코드 구조가 명확하고 확장 가능

## 📊 시간복잡도 분석

### 📌 전체 시간복잡도: O(4^10 × N) ≈ O(1,000,000 × 54)

**변수**:
- 턴 수: 10번
- 각 턴마다 말 선택: 4가지 (말 4개)
- 이동 함수: O(5) (최대 5칸 이동)
- 게임판 크기: N = 54개 칸

**단계별 복잡도**:
1. **go 함수 (백트래킹)**: O(4^10) = O(1,048,576)
   - 10번 이동, 각 단계마다 4개 말 중 선택 = 4^10가지

2. **move 함수**: O(5)
   - 주사위 값은 최대 5
   - 최대 5번 반복

3. **isOccupied 함수**: O(4)
   - 4개 말 확인

**최악의 경우**:
```
1,048,576 × (5 + 4) = 1,048,576 × 9 ≈ 9,437,184 ≈ 940만 연산
```

**✅ 결과**: 940만 << 1억 → **여유롭게 통과!**

**🔍 실제 실행 시간**:
- 가지치기(isOccupied)로 실제 탐색 경우의 수 감소
- 실제 실행 시간: 약 0.1~0.2초

## 🚨 주의사항

### 1️⃣ 도착 칸 처리

```cpp
if(currentPos == 100) return 100; // 도착 칸이면 더 이상 이동하지 않음
if(targetPos == 100) return false; // 도착 칸은 중복 허용
```

**핵심**:
- 도착 칸에 있는 말은 더 이상 이동하지 않음
- 도착 칸에는 여러 말이 함께 있을 수 있음

### 2️⃣ 백트래킹 원상복구

```cpp
int originalPos = horses[horseIdx];     // 저장
horses[horseIdx] = newPos;              // 변경
maxScore = max(maxScore, ...);          // 재귀 호출
horses[horseIdx] = originalPos;         // 복구
```

**핵심**:
- 재귀 호출 후 반드시 원래 상태로 복구
- 복구하지 않으면 다음 시도에 영향을 줌

### 3️⃣ 인덱스 번호 매핑

```
외곽 경로:
- 0번: 시작 칸 (0점)
- 1~20번: 2점~40점 (2씩 증가)
- 100번: 도착 칸 (0점)

지름길:
- 21~23번: 5번 지름길
- 27~28번: 10번 지름길
- 29~31번: 15번 지름길
- 24~26번: 중앙 경로
```

**핵심**:
- 각 칸의 인덱스와 점수를 정확히 매핑
- 문제의 게임판 그림과 일치시키기

### 4️⃣ 파란색 칸 이동 규칙

**"말이 파란색 칸에서 이동을 시작하면 파란색 화살표를 타야 한다"**

```cpp
// ✅ 올바른 구현
if(graph[currentPos].size() >= 2)  // 출발 위치가 파란색 칸이면
{
    currentPos = graph[currentPos][1]; // 파란선으로 진입
    moveCount--;
}

// ❌ 잘못된 구현
while(moveCount > 0)
{
    if(graph[currentPos].size() >= 2)  // 이동 중에 파란선 타기 (X)
        currentPos = graph[currentPos][1];
}
```

**핵심**:
- 파란색 칸에서 **출발할 때만** 파란선을 탐
- 이동 중간에 파란색 칸을 거쳐도 빨간선으로 계속 이동
