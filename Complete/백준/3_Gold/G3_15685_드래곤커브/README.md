## 🤔 접근법

(for문으로 그때 그때 처리 하려다가 시간초과남...)

(미리 패턴을 구해놓고, 문제를 풀어야 시간 초과도 안나고, 쉽게 풀이 가능)

(코딩테스트에는 잘 안나오고, 알고리즘 대회에서 많이 나오는 유형이라는데, 완전히 접근을 잘못함...)

드래곤 커브는 **기하학적 패턴을 이용한 시뮬레이션** 문제.

드래곤 커브의 핵심 규칙:
- 0세대: 시작점에서 시작방향으로 한 칸 이동 (길이 1의 선분)
- K세대: K-1세대를 **끝점 기준으로 시계방향 90도 회전**시켜 끝점에 붙임

문제의 핵심은 **각 세대의 드래곤 커브를 방향 시퀀스로 표현**하고, 이를 **미리 계산**하여 활용하는 것입니다.

**알고리즘 분류**: 구현, 시뮬레이션, **기하**

---

## 💡 정답 풀이 방법

**알고리즘** : 전처리 + 시뮬레이션 (기하)

**핵심 아이디어**:
```
1. 모든 시작방향(0~3)과 세대(0~10)의 드래곤 커브 패턴을 미리 생성
2. 각 드래곤 커브를 방향 시퀀스(vector)로 표현
3. 입력된 드래곤 커브를 격자판에 그림
4. 1×1 정사각형의 네 꼭짓점이 모두 드래곤 커브 위에 있는지 체크
```

**K세대 생성 규칙**:
```
K세대 = [K-1세대를 역순으로 +1 (시계방향 90도)] + [K-1세대 그대로]
```

## 🔑 핵심 포인트

### 1️⃣ 기하학적 패턴의 이해

드래곤 커브의 생성 과정을 **방향의 시퀀스**로 표현할 수 있습니다.

**방향 정의**:
- 0: 오른쪽 (→), x+1
- 1: 위 (↑), y-1
- 2: 왼쪽 (←), x-1
- 3: 아래 (↓), y+1

**시계방향 90도 회전**:
```
0(→) + 1 = 1(↑)
1(↑) + 1 = 2(←)
2(←) + 1 = 3(↓)
3(↓) + 1 = 0(→)  (mod 4)
```

**✅ 핵심**: 방향에 +1 하면 시계방향 90도 회전!

### 2️⃣ MakeDragon() - 드래곤 커브 패턴 전처리 (핵심!)

```cpp
void MakeDragon()
{
    // 4가지 시작 방향에 대해
    for(int i = 0; i < 4; i++)
    {
        dragon[i][0].push_back(i);            // 0세대
        dragon[i][1].push_back((i + 1) % 4);  // 1세대 추가 부분(0~3 나가지 범위 나가지 않도록 % 4 필수)

        // 2세대부터 10세대까지 생성
        for(int j = 2; j <= 10; j++)
        {
            int n = dragon[i][j - 1].size();

            // [새로 추가되는 부분] : 이전 세대를 역순으로 +1 (시계방향 90도)
            for(int k = n - 1; k >= 0; k--)
            {
                dragon[i][j].push_back((dragon[i][j - 1][k] + 1) % 4);
            }

            // [기존 부분] : 이전 세대 그대로 복사
            for(int k = 0; k < n; k++)
            {
                dragon[i][j].push_back(dragon[i][j - 1][k]);
            }
        }
    }
}
```

**✅ 핵심**:
- `dragon[시작방향][세대]`에 해당 드래곤 커브의 방향 시퀀스를 저장
- K세대는 K-1세대를 기반으로 재귀적으로 생성
- 전처리로 모든 경우를 미리 계산하여 시간 절약

### 3️⃣ 드래곤 커브 생성 예시 (시작 방향 0(→))

#### 📐 0세대
```
패턴: [0]
의미: 오른쪽으로 한 칸

시작점 (0,0)
(0,0) → (1,0)
     0(→)
```

#### 📐 1세대
```
패턴: [1, 0]
생성 과정:
  - 새로운 부분: 0세대 역순으로 +1 → [0+1] = [1]
  - 기존 부분: [0]
  - 결과: [1, 0]

시각화:
(0,0) → (1,0)
        ↑
      (1,1)
```

#### 📐 2세대
```
패턴: [2, 1, 1, 0]
생성 과정:
  - 1세대: [1, 0]
  - 새로운 부분: [1, 0]을 역순으로 +1
    → [0+1, 1+1] = [1, 2]
    → 역순이므로 [2, 1]
  - 기존 부분: [1, 0]
  - 결과: [2, 1] + [1, 0] = [2, 1, 1, 0]

시각화:
      (0,1) ← (1,1)
        ↑       ↑
      (0,0) → (1,0)
```

#### 📐 3세대
```
패턴: [3, 2, 2, 1, 2, 1, 1, 0]
생성 과정:
  - 2세대: [2, 1, 1, 0]
  - 새로운 부분: [2, 1, 1, 0]을 역순으로 +1
    → [0+1, 1+1, 1+1, 2+1] = [1, 2, 2, 3]
    → 역순이므로 [3, 2, 2, 1]
  - 기존 부분: [2, 1, 1, 0]
  - 결과: [3, 2, 2, 1] + [2, 1, 1, 0] = [3, 2, 2, 1, 2, 1, 1, 0]
```

#### 🔍 패턴 요약

| 세대 | 패턴 | 길이 (2^n) |
|-----|------|-----------|
| 0세대 | [0] | 1 |
| 1세대 | [1, 0] | 2 |
| 2세대 | [2, 1, 1, 0] | 4 |
| 3세대 | [3, 2, 2, 1, 2, 1, 1, 0] | 8 |
| 4세대 | [...] | 16 |
| ... | ... | ... |
| 10세대 | [...] | 1024 |

**✅ 핵심 관찰**:
- K세대의 길이 = 2^K
- K세대 = (K-1세대 역순 +1) + (K-1세대)
- **역순으로 순회하는 이유**: 끝점에서 시작점으로 거꾸로 가면서 90도 회전
- **+1을 하는 이유**: 시계방향 90도 회전

### 4️⃣ 왜 역순으로 +1 인가? (기하학적 이해)

드래곤 커브는 **끝점을 기준으로 시계방향 90도 회전**합니다.

```
끝점에서 보면:
  기존 커브를 반대 방향으로 추적 → 역순
  각 방향을 시계방향 90도 회전 → +1 (mod 4)
```

**예시**: 0세대 [0(→)]를 끝점 기준으로 회전
```
1. 끝점에서 시작점으로: 0(→)의 반대는 2(←)
2. 시계방향 90도 회전: 2(←) + 1 = 3(↓)... 아니다!
   실제로는 끝점에서 시작하므로:
   0(→)의 역방향 추적 + 90도 = 1(↑)
```

**더 직관적인 설명**:
```
0세대: ─ (끝점이 오른쪽)
1세대: 끝점을 중심으로 90도 회전시키면
       ┐ 모양이 됨
       │
       ─
```

### 5️⃣ GO() 함수 - 드래곤 커브 그리기

```cpp
void GO(int x, int y, int d, int g)
{
    a[x][y] = 1;  // 시작점 표시

    // 0세대부터 g세대까지 순차적으로 그림
    for(int i = 0; i <= g; i++)
    {
        // 현재 세대의 방향 시퀀스를 따라 이동
        for(int dir : dragon[d][i])
        {
            x += dx[dir];
            y += dy[dir];
            a[x][y] = 1;
        }
    }
}
```

**✅ 핵심**:
- 미리 계산된 `dragon[d][i]` 패턴을 사용
- 0세대부터 g세대까지 **순차적으로** 방향을 따라 이동
- 각 세대는 이전 세대를 포함하므로 모든 점을 정확히 그림

**⚠️ 주의**:
- 1세대는 0세대 + 추가 부분이지만, `dragon[d][1]`에는 **추가 부분만** 저장됨
- 따라서 0세대부터 g세대까지 **모두** 그려야 완전한 g세대 드래곤 커브가 됨

### 6️⃣ 정사각형 카운팅

```cpp
for(int i = 0; i <= 100; i++)
{
    for(int j = 0; j <= 100; j++)
    {
        // (i,j)를 왼쪽 위 꼭짓점으로 하는 1×1 정사각형
        if(a[i][j] && a[i + 1][j] && a[i + 1][j + 1] && a[i][j + 1])
            cnt++;
    }
}
```

**✅ 핵심**:
- 왼쪽 위 꼭짓점 (i, j) 기준으로 체크
- 네 꼭짓점이 모두 드래곤 커브 위에 있어야 카운트

**정사각형 꼭짓점**:
```
(i, j)     ─── (i, j+1)
  │              │
  │              │
(i+1, j)   ─── (i+1, j+1)
```

## 🔍 시간복잡도 분석

### MakeDragon() - 전처리

**시간복잡도**: O(4 × Σ(j=0 to 10) 2^j) = O(4 × 2^11) ≈ **O(8,192)**

**분석**:
- 4가지 시작 방향
- 각 세대 j의 길이: 2^j
- 0세대부터 10세대까지 합: 2^0 + 2^1 + ... + 2^10 = 2^11 - 1

### GO() - 드래곤 커브 그리기

**시간복잡도**: O(N × 2^g) ≈ **O(20 × 1,024) = O(20,480)**

**분석**:
- N개의 드래곤 커브 (N ≤ 20)
- 각 드래곤 커브는 0세대부터 g세대까지 그림
- 최악의 경우 g=10 → 2^0 + 2^1 + ... + 2^10 ≈ 2^11

### 정사각형 카운팅

**시간복잡도**: O(101 × 101) ≈ **O(10,201)**

### 전체 시간복잡도

**O(8,192 + 20,480 + 10,201) ≈ O(40,000)**

**✅ 결론**: 매우 빠름! 시간 제한(1초) 내에 여유롭게 해결 가능

## 💾 공간복잡도

**O(4 × 11 × 2^10 + 101²) ≈ O(55,000)**

**분석**:
- `dragon[4][11]`: 각 원소는 vector로 최대 2^10 크기
  - 4 × 11 × 1024 ≈ 45,056
- `a[101][101]`: 격자판 배열
  - 101 × 101 = 10,201
- 기타 변수들: O(1)
