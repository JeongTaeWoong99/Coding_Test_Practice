## 🤔 접근법

연속된 부분 수열 중에서 중복 없는 경우의 수를 세는 문제입니다.

처음에는 모든 부분 수열을 직접 생성하고 검사하려 했지만, N이 최대 100,000이므로 O(N²) 이상의 접근은 시간 초과가 발생합니다.

핵심은 **두 포인터(Two Pointers)** 알고리즘을 사용하여 중복 없는 구간을 효율적으로 관리하는 것!

---

## 💡 핵심 아이디어

### 🔑 두 포인터 알고리즘

**문제 조건:**
- 수열에서 연속한 1개 이상의 수를 선택
- 선택한 부분 수열에 같은 수가 여러 번 등장하면 안 됨
- 이러한 조건을 만족하는 경우의 수를 구함

**알고리즘 흐름:**
```
1. sP(시작 포인터)와 eP(끝 포인터) 초기화 (모두 0)
2. eP를 증가시키며 구간을 확장:
   - arr[eP]가 구간에 없으면: visited[arr[eP]] = true, eP++
   - arr[eP]가 이미 구간에 있으면 (중복):
     → ret += (eP - sP)  (sP 시작점의 모든 부분 수열 개수 추가)
     → visited[arr[sP]] = false  (왼쪽 숫자 제거)
     → sP++  (왼쪽 포인터 이동)
3. while 종료 후, 남은 구간 [sP, eP)의 모든 부분 수열 개수 추가
   → ret += k * (k + 1) / 2  (k = eP - sP)
```

**시간 복잡도**: O(N)
- sP와 eP는 각각 최대 N번 이동
- 각 원소를 최대 2번 방문 (eP로 추가, sP로 제거)

**공간 복잡도**: O(M)
- M = 수열에 나타나는 최대 숫자 (100,000)
- visited 배열: O(100,001)

## 🔑 주요 구현 포인트

### 2️⃣ ret += (eP - sP) 의미

**핵심 질문**: "왜 ret++ 한 번씩 더하지 않고 (eP - sP)를 한 번에 더하나?"

**답변**:

중복이 없을 때는 ret를 더하지 않고, **중복 발견 시점**에만 더합니다!

※ sP 기준으로 몇개의 구간이 나오는지만 저장하면 되기 때문이다.

**예시: [1, 2, 3, 1, 2]**

```
Step 1: eP=0, [1]          → 중복 없음, eP++ (ret 안 더함)
Step 2: eP=1, [1,2]        → 중복 없음, eP++ (ret 안 더함)
Step 3: eP=2, [1,2,3]      → 중복 없음, eP++ (ret 안 더함)
Step 4: eP=3, [1,2,3,1]    → 중복 발견!

        ret += (eP - sP) = (3 - 0) = 3

        의미: sP=0 시작점의 부분 수열 3개
        - [1]       (0~1)
        - [1,2]     (0~2)
        - [1,2,3]   (0~3)

        그 후: sP=1, 구간 = [2,3,1]

Step 5: eP=3, [2,3,1]      → 중복 없음, eP++
Step 6: eP=4, [2,3,1,2]    → 중복 발견!

        ret += (4 - 1) = 3 → ret = 6

        의미: sP=1 시작점의 부분 수열 3개
        - [2]       (1~2)
        - [2,3]     (1~3)
        - [2,3,1]   (1~4)
```

**✅ 핵심**:
- 중복 없을 때: eP만 확장 (ret 안 더함)
- 중복 발견 시: 지금까지 만든 구간의 모든 부분 수열 개수를 한 번에 추가
- 여러 번의 중복 발견 → 여러 번 더하기 → 누적

### 3️⃣ 마지막 공식: k × (k + 1) / 2

**상황**: while 문 종료 후
- eP = N (배열 끝까지 도달)
- sP부터 끝까지 모두 **중복 없는 구간**
- 이 구간의 **모든 부분 수열**을 세어야 함!

**공식 의미**: 길이 k인 연속 구간의 모든 부분 수열 개수

```
길이 1: k개
길이 2: k-1개
길이 3: k-2개
...
길이 k: 1개

총합 = 1 + 2 + 3 + ... + k = k(k+1)/2  (등차수열 합)
```

**예시: [3, 1, 2] (k = 3)**

```
길이 1: [3], [1], [2]                 → 3개
길이 2: [3,1], [1,2]                  → 2개
길이 3: [3,1,2]                       → 1개

총합 = 3 + 2 + 1 = 6
공식 = 3 × 4 / 2 = 6  ✅ 일치!
```

**✅ 핵심**:
- while 문은 **중복 발견 시점**에만 ret 갱신
- 마지막까지 중복 없으면 ret에 아무것도 안 더해짐
- **그래서 마지막에 남은 구간을 한 번에 계산!**

### 4️⃣ 등차수열 합 공식 유도

**가우스 방법**:

```
S = 1 + 2 + 3 + ... + (k-1) + k
S = k + (k-1) + (k-2) + ... + 2 + 1  (역순)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2S = (k+1) + (k+1) + (k+1) + ... + (k+1)
2S = k × (k+1)
S = k × (k+1) / 2
```

**코드 구현**:
```cpp
long long k = eP - sP;
ret += k * (k + 1) / 2;
```

## 📊 예시 실행 흐름

**입력 1**:
```
5
1 2 3 4 5
```

**실행 과정**:
```
초기: sP=0, eP=0, ret=0

while 동작:
- eP=0: [1] → 중복 없음, eP=1
- eP=1: [1,2] → 중복 없음, eP=2
- eP=2: [1,2,3] → 중복 없음, eP=3
- eP=3: [1,2,3,4] → 중복 없음, eP=4
- eP=4: [1,2,3,4,5] → 중복 없음, eP=5
- eP=5: while 종료 (eP >= N)

while 종료 시:
- sP=0, eP=5, ret=0 (중복이 한 번도 없었음)

마지막 계산:
k = 5 - 0 = 5
ret += 5 × 6 / 2 = 15

출력: 15
```

**의미**:
- 길이 1: [1], [2], [3], [4], [5] → 5개
- 길이 2: [1,2], [2,3], [3,4], [4,5] → 4개
- 길이 3: [1,2,3], [2,3,4], [3,4,5] → 3개
- 길이 4: [1,2,3,4], [2,3,4,5] → 2개
- 길이 5: [1,2,3,4,5] → 1개
- **총 15개** ✅

## 🚨 주의사항

1. **visited 배열 크기**: 수열 값의 범위(1~100,000)만큼 할당
2. **ret는 long long**: 경우의 수가 매우 커질 수 있음
   - 예: N=100,000 → 최대 100,000 × 100,001 / 2 ≈ 5×10⁹
3. **구간 표기**: [sP, eP) (sP 포함, eP 불포함)
4. **중복 발견 시점**: else 블록에서만 ret 갱신
5. **마지막 계산 필수**: while 종료 후 남은 구간 처리

---

## ⏱️ 시간복잡도

**O(N)**
- sP: 최대 N번 이동
- eP: 최대 N번 이동
- 각 원소를 최대 2번 방문 (추가 1번, 제거 1번)
- N ≤ 100,000 → 충분히 빠름

---

## 💾 공간복잡도

**O(M)**
- M = 수열 값의 최대 범위 (100,000)
- `arr[100001]`: O(N)
- `visited[100001]`: O(M)
- 전체: O(N + M) ≈ O(100,000)
