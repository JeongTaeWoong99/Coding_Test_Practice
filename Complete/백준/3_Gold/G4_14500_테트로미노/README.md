## 🔗 문제 링크

[백준 14500번 - 테트로미노](https://www.acmicpc.net/problem/14500)

**난이도**: Gold 4

---

## 🤔 접근법

N×M 격자에 테트로미노(4칸 폴리오미노) 하나를 놓아 칸에 적힌 수의 합을 최대화하는 문제.

처음에는 5가지 모양 × 회전/반전을 모두 하드코딩하려 했지만, 총 19가지 방향을 일일이 작성하기가 번거롭다.

핵심은 **테트로미노 중 T자를 제외한 모든 모양은 "4칸 연결 경로(path)"** 로 표현된다는 점!

- **DFS 깊이 4**: 시작점에서 인접 칸을 방문하며 4칸 경로를 탐색 → I, O, S, Z, L, J 커버
- **T자 별도 처리**: T자는 분기 구조라 경로로 표현 불가 → 중심 칸 기준 이웃 상위 3개 선택

---

## 💡 정답 풀이 방법

**알고리즘**: DFS + 브루트포스

**핵심 아이디어**:
```
1. 모든 칸 (i, j)를 시작점으로 DFS 깊이 4 탐색
   → T자 제외 모든 테트로미노(18가지 방향) 자동 커버
2. 모든 칸 (i, j)를 T자 중심으로 체크
   → 유효한 이웃을 내림차순 정렬 후 상위 3개 선택 (4가지 방향 커버)
3. 둘 중 최댓값 출력
```

**왜 DFS가 T자를 커버 못 하는가?**
```
T자 형태:
.X.
XXX

중심(X)에서 좌/우/하로 3방향 분기 → 단순 경로(path)가 아닌 트리 구조
DFS는 한 방향으로 뻗어가다 백트래킹하므로, 중심으로 되돌아와 두 방향 뻗기 불가
```

**시간 복잡도**: O(N × M × 3^4)
- 각 칸에서 DFS: 최대 3방향으로 4칸 탐색
- N, M ≤ 500 → 500 × 500 × 81 ≈ 20,250,000 연산

**공간 복잡도**: O(N × M)
- board 배열: O(N × M)
- visited 배열: O(N × M)
- 재귀 스택: O(4)

## 🔑 핵심 포인트

### 1️⃣ DFS로 T자 외 모든 테트로미노 커버

```cpp
void DFS(int x, int y, int depth, int sum)
{
    if (depth == 4)
    {
        maxSum = max(maxSum, sum);
        return;
    }

    for (int d = 0; d < 4; ++d)
    {
        int nx = x + dx[d];
        int ny = y + dy[d];

        if (nx >= 0 && nx < N && ny >= 0 && ny < M && !visited[nx][ny])
        {
            visited[nx][ny] = true;
            DFS(nx, ny, depth + 1, sum + board[nx][ny]);
            visited[nx][ny] = false;  // 백트래킹
        }
    }
}
```

**✅ 핵심**: `visited` 배열 + 백트래킹으로 4칸 단순 경로를 모두 탐색
- I자: 한 방향으로 3칸 직진
- O자: 직각으로 꺾어서 2×2 정사각형 경로
- S/Z자: 지그재그 경로
- L/J자: 직진 후 꺾기

### 2️⃣ T자 별도 처리 — 이웃 상위 3개 선택

```cpp
void CheckT(int x, int y)
{
    vector<int> neighborVals;

    for (int d = 0; d < 4; ++d)
    {
        int nx = x + dx[d];
        int ny = y + dy[d];

        if (nx >= 0 && nx < N && ny >= 0 && ny < M)
        {
            neighborVals.push_back(board[nx][ny]);
        }
    }

    if ((int)neighborVals.size() < 3) { return; }

    sort(neighborVals.rbegin(), neighborVals.rend());
    int tSum = board[x][y] + neighborVals[0] + neighborVals[1] + neighborVals[2];

    maxSum = max(maxSum, tSum);
}
```

**✅ 핵심**: T자 4가지 방향을 "중심 + 이웃 3개 선택"으로 통합 처리
- 이웃이 4개면: 가장 작은 이웃 1개를 제외 (내림차순 정렬 후 top 3)
- 이웃이 3개면: 모두 선택 (경계 칸의 T자)
- 최댓값을 원하므로 상위 3개 선택이 최적

### 3️⃣ 19가지 방향 커버 확인

| 도형 | 방향 수 | 처리 방식 |
|------|--------|---------|
| I자 | 2 | DFS |
| O자 | 1 | DFS |
| S자 | 2 | DFS |
| Z자 | 2 | DFS |
| L자 | 4 | DFS |
| J자 | 4 | DFS |
| T자 | 4 | CheckT |
| **합계** | **19** | |

## 📊 예시 실행 흐름

**예제 3 (체스판 패턴)**:
```
1 2 1 2 1 2 1 2 1 2
2 1 2 1 2 1 2 1 2 1
1 2 1 2 1 2 1 2 1 2
2 1 2 1 2 1 2 1 2 1
```

- DFS 경로: 1,2 교대 → 최대 합 = 6
- CheckT at (1,1)=1 중심: 이웃 (0,1)=2, (2,1)=2, (1,0)=2, (1,2)=2
  → 상위 3개 합 = 6, tSum = 1+6 = **7** ✅
