## 🤔 접근법

1 → N 경로에서 두 정점 v1, v2를 반드시 경유해야 한다.

처음에는 1에서 다익스트라를 한 번 실행한 뒤 dist[v1] + dist[v2]를 더하면 되는 것 아닌가 생각했지만, **v1 → v2 사이의 구간 거리**는 1 출발 다익스트라로는 구할 수 없다.

핵심은 **경유 순서가 두 가지**라는 것:
- 경우 1 : `1 → v1 → v2 → N`
- 경우 2 : `1 → v2 → v1 → N`

각 구간의 최단 거리를 얻으려면 **1, v1, v2에서 각각 다익스트라**를 실행해야 한다.

---

## 💡 정답 풀이 방법

**알고리즘**: 다익스트라 (Dijkstra) × 3회

**핵심 아이디어**:
```
1. distFrom1  = Dijkstra(1)   → 1에서 모든 정점까지 최단 거리
2. distFromV1 = Dijkstra(v1)  → v1에서 모든 정점까지 최단 거리
3. distFromV2 = Dijkstra(v2)  → v2에서 모든 정점까지 최단 거리

경우 1 : distFrom1[v1] + distFromV1[v2] + distFromV2[N]
경우 2 : distFrom1[v2] + distFromV2[v1] + distFromV1[N]
정답   : min(경우1, 경우2)
```

**시간 복잡도**: O(3 × (V + E) log V)
- 다익스트라를 3번 실행, 각 O((V + E) log V)
- V ≤ 800, E ≤ 200,000

**공간 복잡도**: O(V + E)
- 인접 리스트, 거리 배열

## 🔑 핵심 포인트

### 1️⃣ 왜 다익스트라를 3번 실행해야 하는가?

```
[잘못된 생각]
distFrom1[v1] + distFrom1[v2] + ...
→ v1과 v2 사이의 구간은 distFrom1만으로 알 수 없다!

[올바른 생각]
v1에서 v2까지의 거리 → distFromV1[v2]  (v1 출발 다익스트라 필요)
v2에서 N까지의 거리  → distFromV2[N]   (v2 출발 다익스트라 필요)
```

### 2️⃣ 무방향 그래프이므로 경유 순서가 반대인 경우도 고려

```cpp
ll path1 = (ll)distFrom1[v1] + distFromV1[v2] + distFromV2[n]; // 1→v1→v2→N
ll path2 = (ll)distFrom1[v2] + distFromV2[v1] + distFromV1[n]; // 1→v2→v1→N
ll ans   = min(path1, path2);
```

### 3️⃣ long long 캐스팅 필요

INF(1e9)를 세 개 합산하면 int 범위(약 2.1×10⁹) 초과  
→ 첫 항에 `(ll)` 캐스팅으로 이후 연산을 long long으로 진행

### 4️⃣ -1 출력 조건

경로가 존재하지 않으면 합산 결과가 INF 이상  
→ `ans >= INF`이면 -1 출력

## 📊 예제 실행 흐름 (N=4, E=6, v1=2, v2=3)

```
간선 : 1-2(3), 2-3(3), 3-4(1), 1-3(5), 2-4(5), 1-4(4)

[distFrom1]  1→: [-, 0, 3, 5, 4]
[distFromV1] 2→: [-, 3, 0, 3, 4]
[distFromV2] 3→: [-, 5, 3, 0, 1]

경우 1 (1→2→3→4): distFrom1[2] + distFromV1[3] + distFromV2[4] = 3 + 3 + 1 = 7
경우 2 (1→3→2→4): distFrom1[3] + distFromV2[2] + distFromV1[4] = 5 + 3 + 4 = 12

정답: min(7, 12) = 7
```

**O((V + E) log V)** × 3

- V ≤ 800, E ≤ 200,000
- 다익스트라 3회 실행
