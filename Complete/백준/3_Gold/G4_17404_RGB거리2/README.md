**📅 작성일**: 2026-03-25

## 🔗 문제 링크

[백준 17404번 - RGB거리 2](https://www.acmicpc.net/problem/17404)

**난이도**: Gold 4

---

## 🤔 접근법

N개의 집을 R/G/B로 칠하는데, 인접한 집은 서로 다른 색이어야 하는 기본 조건에 더해, **1번 집과 N번 집도 서로 다른 색**이어야 한다.

이 추가 조건 때문에 단순 선형 DP로는 해결이 불가능하다.

원형 배열 DP의 고전적인 해법은 **1번 집의 색을 고정**하고 나머지를 DP로 처리하는 것!

**RGB거리 1(1149)과의 차이**:

| 구분 | RGB거리 (1149) | RGB거리 2 (17404) |
|------|---------------|------------------|
| 조건 | 인접한 집만 다른 색 | 인접 + **1번 ↔ N번도 다른 색** |
| 구조 | 선형 (열린 체인) | 원형 (닫힌 체인) |
| 풀이 | DP 1회 | 1번 색 고정 후 DP 3회 |

---

## 💡 정답 풀이 방법

**알고리즘**: 동적 계획법 (DP) - 바텀업 (Bottom-up)

**핵심 아이디어**:
```
1. dp[i][c] = i번 집을 c색(0:R, 1:G, 2:B)으로 칠할 때의 최솟값

2. 1번 집의 색을 R / G / B 로 고정하여 DP를 총 3번 수행

3. 각 수행마다:
   - 1번 집 초기화 : 고정된 색만 실제 비용, 나머지는 INF
   - 2~N번 집 : 이전 집과 다른 색 중 최솟값으로 전이
   - N번 집에서 : 1번 집과 다른 색인 경우만 ans 후보

4. 3번 수행 중 최솟값이 정답
```

**시간 복잡도**: O(3 × N × 9) = O(N)
- N = 집의 개수 (최대 1,000)
- 1번 색 고정 3가지 × N개 집 × prev 3가지

**공간 복잡도**: O(N)
- dp 배열: O(N × 3)

---

## 🔑 핵심 포인트

### 1️⃣ 왜 1번 집의 색을 고정해야 하는가?

원형 조건에서 N번 집은 **N-1번과 1번 모두와 달라야** 한다.

그런데 DP는 앞→뒤 방향으로 진행되므로, 아직 결정되지 않은 1번 색을 마지막에 체크할 수 없다.

해법: **1번 집 색을 미리 고정** → N번 집에 도달했을 때 1번 색과 같은 경우만 제외하면 원형 조건 자동 충족!

```
first = R 고정 : 1(R) → 2 → 3 → ... → N(G or B)
first = G 고정 : 1(G) → 2 → 3 → ... → N(R or B)
first = B 고정 : 1(B) → 2 → 3 → ... → N(R or G)
```

### 2️⃣ 예제 1번 상세 실행 흐름

**입력**:
```
3
26 40 83   ← 1번 집 (R=26, G=40, B=83)
49 60 57   ← 2번 집 (R=49, G=60, B=57)
13 89 99   ← 3번 집 (R=13, G=89, B=99)
```

---

**🔸 first=0 (1번 집 = R, 26원으로 고정)**

**dp[0] 초기화** (1번 집):
```
dp[0][R] = 26    ← 고정된 색
dp[0][G] = INF   ← 사용 불가
dp[0][B] = INF   ← 사용 불가
```

**dp[1] 전이** (2번 집):
```
dp[1][R] = min(dp[0][G], dp[0][B]) + 49 = min(INF, INF) + 49 = INF
dp[1][G] = min(dp[0][R], dp[0][B]) + 60 = min( 26, INF) + 60 = 86
dp[1][B] = min(dp[0][R], dp[0][G]) + 57 = min( 26, INF) + 57 = 83
```

**dp[2] 전이** (3번 집):
```
dp[2][R] = min(dp[1][G], dp[1][B]) + 13 = min(86, 83) + 13 = 96
dp[2][G] = min(dp[1][R], dp[1][B]) + 89 = min(INF, 83) + 89 = 172
dp[2][B] = min(dp[1][R], dp[1][G]) + 99 = min(INF, 86) + 99 = 185
```

**N번 집 조건** (last != first=R):
```
last=G : 172 ✅
last=B : 185 ✅
→ 이 경우 최솟값 = 172
```

---

**🔸 first=1 (1번 집 = G, 40원으로 고정)**

**dp[0] 초기화** (1번 집):
```
dp[0][R] = INF
dp[0][G] = 40    ← 고정된 색
dp[0][B] = INF
```

**dp[1] 전이** (2번 집):
```
dp[1][R] = min(dp[0][G], dp[0][B]) + 49 = min(40, INF) + 49 = 89
dp[1][G] = min(dp[0][R], dp[0][B]) + 60 = min(INF, INF) + 60 = INF
dp[1][B] = min(dp[0][R], dp[0][G]) + 57 = min(INF,  40) + 57 = 97
```

**dp[2] 전이** (3번 집):
```
dp[2][R] = min(dp[1][G], dp[1][B]) + 13 = min(INF, 97) + 13 = 110   ⭐
dp[2][G] = min(dp[1][R], dp[1][B]) + 89 = min( 89, 97) + 89 = 178
dp[2][B] = min(dp[1][R], dp[1][G]) + 99 = min( 89, INF) + 99 = 188
```

**N번 집 조건** (last != first=G):
```
last=R : 110 ✅   ← 최솟값!
last=B : 188 ✅
→ 이 경우 최솟값 = 110
```

**✅ 최적 경로**: 1번(G=40) → 2번(B=57) → 3번(R=13) = **110**

---

**🔸 first=2 (1번 집 = B, 83원으로 고정)**

**dp[0] 초기화** (1번 집):
```
dp[0][R] = INF
dp[0][G] = INF
dp[0][B] = 83    ← 고정된 색
```

**dp[1] 전이** (2번 집):
```
dp[1][R] = min(dp[0][G], dp[0][B]) + 49 = min(INF, 83) + 49 = 132
dp[1][G] = min(dp[0][R], dp[0][B]) + 60 = min(INF, 83) + 60 = 143
dp[1][B] = min(dp[0][R], dp[0][G]) + 57 = min(INF, INF) + 57 = INF
```

**dp[2] 전이** (3번 집):
```
dp[2][R] = min(dp[1][G], dp[1][B]) + 13 = min(143, INF) + 13 = 156
dp[2][G] = min(dp[1][R], dp[1][B]) + 89 = min(132, INF) + 89 = 221
dp[2][B] = min(dp[1][R], dp[1][G]) + 99 = min(132, 143) + 99 = 231
```

**N번 집 조건** (last != first=B):
```
last=R : 156 ✅
last=G : 221 ✅
→ 이 경우 최솟값 = 156
```

---

**📊 최종 결과**

```
first=R 최솟값 : 172
first=G 최솟값 : 110   ← 전체 최솟값
first=B 최솟값 : 156

ans = min(172, 110, 156) = 110
```

**출력**: `110` ✅

**최적 경로**: 1번집=초록(40) → 2번집=파랑(57) → 3번집=빨강(13) = **110**

---

### 3️⃣ INF 초기화의 역할

```cpp
const int INF = 1e9;
```

1번 집에서 고정되지 않은 색을 INF로 초기화하면,
이후 DP 전이에서 해당 색으로 시작하는 경로는 자동으로 INF + 비용 = INF 유지.

따라서 **고정된 색으로만 시작하는 경로**만 유효한 값을 갖게 된다.

## ⏱️ 시간복잡도

**O(N)**
- 1번 집 색 고정 3가지 × N개 집 × prev 색 3가지 = O(9N) = O(N)
- N ≤ 1,000 → 최대 9,000번 연산 (매우 빠름)

---

## 💾 공간복잡도

**O(N)**
- `cost[1001][3]`: 비용 배열
- `dp[1001][3]`: DP 배열
- 3번의 DP 수행을 같은 배열에 덮어쓰기

---

## 🚨 주의사항

1. **INF 값 설정**: 비용 최대 1,000 × 집 최대 1,000 = 1,000,000이므로 `1e9`로 충분
2. **N번 집 조건**: `last != first`인 경우만 ans 갱신 (원형 조건)
3. **DP 초기화**: 매 `first` 반복마다 dp[0]을 새로 초기화해야 함
4. **INF + 비용 오버플로우**: `int INF = 1e9` 사용 시 `INF + 1000 < INT_MAX`이므로 오버플로우 없음

---

## 🎯 핵심 요약

1. **원형 조건** = 1번 색 고정 후 3회 DP
2. **고정되지 않은 색** = INF로 초기화하여 경로 차단
3. **N번 집에서** = first와 다른 색만 ans 후보
4. **3회 수행 최솟값** = 정답
