## 🔗 문제 링크

[백준 19942번 - 다이어트](https://www.acmicpc.net/problem/19942)

**난이도**: Gold 4

---

## 🤔 접근법

N개의 식재료 중에서 몇 개를 선택해서 최소 영양성분 조건을 만족하면서 비용이 최소가 되는 조합을 찾는 문제이다.

범위가 작아서 (3 ≤ N ≤ 15) 브루트포스로 해결 가능하다.

핵심은 **모든 조합을 생성하여 조건을 만족하는 최소 비용을 찾는 것**!

같은 비용이면 **사전순으로 가장 빠른 조합을 선택**해야 한다.

---

## 💡 정답 풀이 방법

**알고리즘**: 브루트포스(완전탐색) + 조합

**핵심 아이디어**:
```
1. 1개부터 N개까지 모든 선택 개수에 대해 조합 생성
2. next_permutation을 활용한 0/1 마스크 방식으로 조합 구현
3. 각 조합마다 영양성분 합계 계산
4. 조건 만족 시:
   - 비용이 더 적으면 갱신
   - 비용이 같으면 사전순으로 더 빠른 것 선택
5. 최소 비용과 해당 식재료 번호 출력
```

**시간 복잡도**: O(2^N × N)
- 모든 조합: 최대 2^15 = 32,768가지(2^5 X 2^5 X 2^5 = 32,768)
  - N이 3면, 1 2 3 12 13 123 => 6가지가 나옴. 즉, 2^N - 1
  - N이 2면, 1 2 12 _______-=> 3가지가 나옴. 즉, 2^N - 1
- 각 조합마다 N개 원소 순회: O(N)
- 전체: 약 500,000번 연산 (충분히 빠름)

**공간 복잡도**: O(N)
- 식재료 정보 배열: O(N)
- combi 벡터: O(N)
- selected 벡터: O(N)

## 🔑 핵심 포인트

### 1️⃣ next_permutation을 활용한 조합 생성

```cpp
for(int cnt = 1; cnt <= N; cnt++)  // 1개, 2개, ..., N개 선택
{
    vector<int> combi(N, 1);        // 모두 1로 초기화 (미선택)
    fill_n(combi.begin(), cnt, 0);  // 앞 cnt개만 0으로 (선택)

    do
    {
        // combi[i] == 0인 위치가 선택된 식재료
        for(int i = 0; i < N; i++)
        {
            if(combi[i] == 0)  // 선택됨
            {
                // 영양분 및 비용 누적
            }
        }
    } while(next_permutation(combi.begin(), combi.end()));
}
```

**✅ 핵심**:
- `{0, 0, 0, 1, 1}` 형식의 0/1 마스크 사용
- 0의 개수 = 선택할 개수
- next_permutation이 모든 조합을 중복 없이 생성

**💡 원리**:
- {0,0,0,1,1}의 순열 = 5개 중 3개를 선택하는 조합
- 같은 값끼리는 순서가 구분되지 않으므로 중복 없음
- 생성 개수: 5!/(3!×2!) = C(5,3) = 10가지

### 2️⃣ 사전순 비교

```cpp
else if(sumC == minCost && selected < answer)
{
    answer = selected;
}
```

**✅ 핵심**: vector의 `<` 연산자는 자동으로 사전순 비교
- 앞에서부터 순서대로 원소를 비교
- 첫 번째로 다른 값이 나오면 그 값으로 판단
- 예: {2, 3, 4} < {2, 4, 6} (인덱스 1에서 3 < 4)

### 3️⃣ 1-based 인덱스 변환

```cpp
selected.push_back(i + 1);  // 1-based 인덱스
```

**✅ 핵심**: 문제에서 식재료 번호는 1부터 시작
- 배열은 0-based이므로 출력 시 +1 필요

### 4️⃣ 조건 없을 때 처리

```cpp
if(minCost == INT_MAX)
{
    cout << -1 << "\n";  // 조건을 만족하는 조합이 없음
}
```

**✅ 핵심**: 최소 비용이 갱신되지 않았으면 -1 출력

## 📊 예시 실행 흐름

**입력**:
```
6
100 70 90 10
30 55 10 8 100
60 10 10 2 70
10 80 50 0 50
40 30 30 8 60
60 10 70 2 120
20 70 50 4 4
```

**조합 탐색 과정**:
```
1개 선택: {1}, {2}, ..., {6}
  → 조건 미만족

2개 선택: {1,2}, {1,3}, ..., {5,6}
  → 일부 조건 만족, 최소 비용 갱신

3개 선택: {1,2,3}, {1,2,4}, ...
  → {2,4,6} 선택 시:
     단백질: 60+40+20 = 120 ✅
     지방: 10+30+70 = 110 ✅
     탄수화물: 10+30+50 = 90 ✅
     비타민: 2+8+4 = 14 ✅
     비용: 70+60+4 = 134
  → 최소 비용 갱신!

...계속 탐색...
```

**출력**:
```
134
2 4 6
```

## 🚨 주의사항

1. **조합의 모든 경우 확인**: 1개부터 N개까지 모든 선택 개수 시도 필요
2. **사전순 비교**: vector의 `<` 연산자가 자동으로 처리
3. **1-based 인덱스**: 출력 시 +1 필요
4. **조건 없을 때 처리**: minCost가 INT_MAX이면 -1 출력
5. **비용 같을 때**: 사전순으로 더 앞선 것 선택 (`<` 연산자 활용)
