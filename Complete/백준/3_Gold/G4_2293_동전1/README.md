## 🔗 문제 링크

[백준 2293번 - 동전 1](https://www.acmicpc.net/problem/2293)

**난이도**: Gold 4

---

## 🤔 접근법

n가지 종류의 동전을 사용하여 k원을 만드는 경우의 수를 구하는 문제이다.

각 동전은 무한히 사용할 수 있으며, **순서가 다른 조합은 같은 경우**로 취급한다.

예를 들어, `1+2`와 `2+1`은 같은 경우이다.

핵심은 **동적 계획법(DP)을 사용하여 각 금액을 만드는 경우의 수를 저장**하는 것!

이 문제는 **Bottom-up(반복문 + 메모이제이션)** 방식으로 풀 수 있다.

---

## 💡 정답 풀이 방법

**알고리즘**: 동적 계획법 (DP) - 바텀업 (Bottom-up)

**핵심 아이디어**:
```
1. dp[i] = i원을 만드는 경우의 수

2. 초기화:
   - dp[0] = 1 (0원을 만드는 경우의 수는 1개: 아무 동전도 사용하지 않음)
   - 나머지는 모두 0

3. 동전 입력받으면서 DP 갱신:
   - 각 동전 coin에 대해
   - coin원부터 k원까지 순회하며
   - dp[j] += dp[j - coin]  (누적!)

4. 결과:
   - dp[k] 출력 (k원을 만드는 경우의 수)
```

**시간 복잡도**: O(n × k)
- n = 동전 종류 개수 (최대 100)
- k = 목표 금액 (최대 10,000)
- 각 동전마다 k번 순회
- 전체: 100 × 10,000 = 1,000,000 (약 100만 번 연산)

**공간 복잡도**: O(k)
- dp 배열: O(k) = 10,001

## 🔑 핵심 포인트

### 1️⃣ DP 배열 갱신 과정 (예시 1: 동전 [1, 2], k = 4)

**초기화**:
```
dp[0] = 1 (0원을 만드는 경우: 아무것도 안 씀)
dp[1] ~ dp[4] = 0

즉: dp = [1, 0, 0, 0, 0]
```

---

**🔸 동전 1 입력 (coin = 1)**

```
j = 1:
  dp[1] += dp[1 - 1]
       = dp[1] + dp[0]
       = 0 + 1
  → dp[1] = 1  (경우: {1})

j = 2:
  dp[2] += dp[2 - 1]
       = dp[2] + dp[1]
       = 0 + 1
  → dp[2] = 1  (경우: {1, 1})

j = 3:
  dp[3] += dp[3 - 1]
       = dp[3] + dp[2]
       = 0 + 1
  → dp[3] = 1  (경우: {1, 1, 1})

j = 4:
  dp[4] += dp[4 - 1]
       = dp[4] + dp[3]
       = 0 + 1
  → dp[4] = 1  (경우: {1, 1, 1, 1})
```

**동전 1 처리 후 dp 배열**:
```
dp = [1, 1, 1, 1, 1]
인덱스: 0  1  2  3  4
```

**🔹 의미**:
- dp[1] = 1: 1원을 만드는 경우 → {1}
- dp[2] = 1: 2원을 만드는 경우 → {1+1}
- dp[3] = 1: 3원을 만드는 경우 → {1+1+1}
- dp[4] = 1: 4원을 만드는 경우 → {1+1+1+1}

---

**🔸 동전 2 입력 (coin = 2)**

```
j = 2:
  dp[2] += dp[2 - 2]
       = dp[2] + dp[0]
       = 1 + 1
  → dp[2] = 2  (경우: {1+1}, {2})

j = 3:
  dp[3] += dp[3 - 2]
       = dp[3] + dp[1]
       = 1 + 1
  → dp[3] = 2  (경우: {1+1+1}, {1+2})

j = 4:
  dp[4] += dp[4 - 2]
       = dp[4] + dp[2]
       = 1 + 2
  → dp[4] = 3  (경우: {1+1+1+1}, {1+1+2}, {2+2})
```

**동전 2 처리 후 dp 배열 (최종)**:
```
dp = [1, 1, 2, 2, 3]
인덱스: 0  1  2  3  4
```

**🔹 의미**:
- dp[2] = 2: 2원을 만드는 경우 → {1+1}, {2}
- dp[3] = 2: 3원을 만드는 경우 → {1+1+1}, {1+2}
- dp[4] = 3: 4원을 만드는 경우 → {1+1+1+1}, {1+1+2}, {2+2}

---

**📊 최종 결과**

**출력**: `3`

**4원을 만드는 방법**:
1. 1원 4개: {1, 1, 1, 1}
2. 1원 2개 + 2원 1개: {1, 1, 2}
3. 2원 2개: {2, 2}

**총 경우의 수**: 3개 ✅

**✅ 핵심**:
- 동전을 하나씩 입력받으며 DP 배열 갱신
- `dp[j] += dp[j - coin]` (누적!)
- 동전 순서대로 처리하므로 **중복 조합 자동 제거**

### 3️⃣ 왜 동전 순서대로 처리해야 하는가?

**중요한 이유**: 동전 순서대로 처리하면 **중복 조합이 자동으로 제거**됨!

**잘못된 방법** (금액 순서대로 처리):
```cpp
for(int j = 1; j <= k; j++)  // 금액 먼저
{
    for(int i = 0; i < n; i++)  // 동전 나중
    {
        if(j >= coin[i])
            dp[j] += dp[j - coin[i]];
    }
}
```
→ 이렇게 하면 {1, 2}와 {2, 1}을 **다른 경우로 카운트**함!

**올바른 방법** (동전 순서대로 처리):
```cpp
for(int i = 0; i < n; i++)  // 동전 먼저
{
    for(int j = coin; j <= k; j++)  // 금액 나중
    {
        dp[j] += dp[j - coin];
    }
}
```
→ 동전 1로 갱신 → 동전 2로 갱신 → 동전 5로 갱신
→ **순서가 정해져 있으므로 중복 제거됨!**

**✅ 핵심**:
- 동전을 **외부 루프**에 두면 조합 (Combination)
- 금액을 **외부 루프**에 두면 순열 (Permutation)
- 이 문제는 조합을 구하므로 동전을 외부 루프에!

### 4️⃣ coin원부터 시작하는 이유

```cpp
for (int j = coin; j <= k; j++)
```

**왜 0부터가 아니라 coin부터?**
```
coin = 5일 때:

j = 0: dp[0] += dp[-5] ❌ 음수 인덱스 (불가능)
j = 1: dp[1] += dp[-4] ❌ 음수 인덱스 (불가능)
j = 2: dp[2] += dp[-3] ❌ 음수 인덱스 (불가능)
j = 3: dp[3] += dp[-2] ❌ 음수 인덱스 (불가능)
j = 4: dp[4] += dp[-1] ❌ 음수 인덱스 (불가능)
j = 5: dp[5] += dp[0]  ✅ 가능 (dp[0] = 1)
```

**✅ 핵심**:
- coin원 미만은 해당 동전으로 만들 수 없음
- `dp[j - coin]`이 유효하려면 `j >= coin`이어야 함
- 불필요한 연산 방지

---

### 5️⃣ k보다 큰 동전 필터링

```cpp
if(coin > k) continue;
```

**최적화 포인트**:
- k = 10인데 coin = 100이면 사용 불가능
- 불필요한 반복문 실행 방지
- 문제 조건: 동전 가치는 최대 100,000, k는 최대 10,000

## ⏱️ 시간복잡도

**O(n × k)**
- n = 동전 종류 개수 (최대 100)
- k = 목표 금액 (최대 10,000)
- 각 동전마다 k번 순회
- 전체: 100 × 10,000 = 1,000,000 (약 100만 번 연산)
- 매우 빠른 알고리즘

---

## 💾 공간복잡도

**O(k)**
- `dp[10001]`: 각 금액별 경우의 수 저장
- 동전 저장 불필요 (입력받으면서 바로 DP 갱신)
- 추가 공간 복잡도 없음

---

## 🚨 주의사항

1. **dp[0] = 1**: 0원을 만드는 경우의 수는 1개 (아무 동전도 사용 안 함)
2. **동전 순서 처리**: 동전을 외부 루프에 두어 중복 조합 제거
3. **누적 연산**: `dp[j] += dp[j - coin]` (최솟값 비교가 아님!)
4. **배열 크기**: k 최대 10,000이므로 10,001 이상 확보
5. **음수 인덱스 방지**: j는 coin부터 시작
6. **k보다 큰 동전 무시**: 불필요한 연산 제거
7. **입출력 최적화**: `ios_base::sync_with_stdio(false);cin.tie(0);cout.tie(0);` 필수

## 💡 동전 1 vs 동전 2 비교

| 항목 | 동전 1 (2293) | 동전 2 (2294) |
|-----|--------------|--------------|
| **목표** | 경우의 수 구하기 | 최소 동전 개수 구하기 |
| **DP 초기화** | dp[0] = 1 | dp[0] = 0, 나머지 INF |
| **DP 갱신** | dp[j] += dp[j - coin] | dp[j] = min(dp[j], dp[j - coin] + 1) |
| **연산** | 누적 (더하기) | 최솟값 비교 |
| **불가능한 경우** | 0 출력 | -1 출력 |
| **난이도** | Gold 4 | Gold 5 |

**✅ 핵심 차이**:
- **동전 1**: 경우의 수를 **누적**
- **동전 2**: 최솟값을 **비교**

## 🎯 핵심 요약

1. **DP 정의**: `dp[i]` = i원을 만드는 경우의 수
2. **초기화**: `dp[0] = 1` (0원 = 아무것도 안 씀)
3. **점화식**: `dp[j] += dp[j - coin]` (누적!)
4. **루프 순서**: 동전 먼저 → 금액 나중 (중복 제거)
5. **시작 위치**: `j = coin` (음수 인덱스 방지)
6. **최적화**: k보다 큰 동전 무시, 입출력 최적화
