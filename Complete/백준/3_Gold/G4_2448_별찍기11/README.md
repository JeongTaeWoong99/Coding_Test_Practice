## 🖥️ 시각화

> 프랙탈 삼각형이 N=3 → 6 → 12 → 24 로 재귀 분할되며 그려지는 과정을 시각화

---

## 🤔 접근법

N=24 예제 출력을 보고 프랙탈 구조 파악.

- N=3 (기저): 3행짜리 삼각형 하나
- N=6: N=3 삼각형 3개 조합 (상단 중앙 1개 + 하단 좌우 2개)
- N=24: 재귀적으로 반씩 나눠 동일한 구조 반복

패턴을 보자마자 **분할 정복 + 재귀**로 접근.

`Draw(row, col, size)` 함수로 (row, col)을 좌상단으로 하는 size 크기 삼각형을 그리고,
기저 조건(size==3)에서 직접 그리드에 별을 채우는 방식으로 설계.

---

## 💡 정답 풀이 방법

**알고리즘**: 분할 정복 (Divide and Conquer) + 재귀

**핵심 아이디어**:
```
1. 2D char 배열 grid[N][2N-1]을 공백으로 초기화
2. Draw(row, col, size) 재귀 함수:
   - 기저: size==3 → 8개 별 직접 배치
   - 분할: half = size / 2
     - Draw(row,        col + half, half)  ← 상단 삼각형 (중앙)
     - Draw(row + half, col,        half)  ← 하단 좌측
     - Draw(row + half, col + size, half)  ← 하단 우측
3. grid 행별 출력
```

**하단 우측 시작 위치가 col + size인 이유**:
```
전체 너비 = 2*size - 1
하단 좌측: col ~ col+(size-1)  (너비 size, 정확히는 2*half-1)
공백 없음 (삼각형끼리 딱 붙음)
하단 우측: col + size ~ col + 2*size - 2
  → 시작 col = col + size  ✓
```

## 🔑 핵심 포인트

### 1️⃣ 기저 조건 (size == 3)

```
  *          grid[row  ][col+2]      = '*'
 * *         grid[row+1][col+1]      = grid[row+1][col+3] = '*'
*****        grid[row+2][col..col+4] = '*' (5개)
```

8개 별 좌표를 하드코딩으로 직접 배치.

### 2️⃣ 재귀 분해 구조

```
Draw(0, 0, 24)
├── Draw(0,  12, 12)   ← 상단 중앙
│   ├── Draw(0,  18, 6)
│   │   ├── Draw(0,  21, 3) ★기저
│   │   ├── Draw(3,  18, 3) ★기저
│   │   └── Draw(3,  24, 3) ★기저
│   ├── Draw(6,  12, 6)
│   └── Draw(6,  18, 6)   ← (col+size=12+12=24... 아니라 col+size=18+6=24)
├── Draw(12,  0, 12)   ← 하단 좌측
└── Draw(12, 24, 12)   ← 하단 우측 (col+size = 0+24 = 24)
```

### 3️⃣ 그리드 크기

| 변수 | 값 |
|------|-----|
| N 최대 | 3 × 2¹⁰ = 3072 |
| 행 수 | 3072 |
| 열 수 (너비) | 2×3072 - 1 = 6143 |
| grid 배열 | `char grid[3073][6144]` |

## 📊 재귀 동작 분석 (N=24)

```
깊이 0: 1개 호출  (size=24)
깊이 1: 3개 호출  (size=12)
깊이 2: 9개 호출  (size=6)
깊이 3: 27개 호출 (size=3, 기저) → 각 8개 별 = 총 216개 별

총 재귀 호출 수: 1 + 3 + 9 + 27 = 40
```

---

## ⏱️ 시간복잡도

**O(N²)**

- 기저 호출 수: (N/3)² = (N²/9)개 (정확히는 3^k개)
- 각 기저에서 상수 8개 연산
- 전체: O(3^k) = O((N/3)²) = O(N²)

N=3072일 때: 약 1,048,576 번 연산 → 시간 내 충분

---

## 💾 공간복잡도

**O(N²)**

- `grid[3073][6144]` = 약 18MB (256MB 제한 내)
- 재귀 스택 깊이: log₂(N/3) = k ≤ 10 → O(log N)
