## 🤔 접근법

LCS(Longest Common Subsequence, 최장 공통 부분 수열) 문제.

두 문자열이 주어졌을 때, 두 문자열 모두의 부분 수열이 되는 수열 중 **가장 긴 것의 길이**를 구한다.

부분 수열은 연속일 필요가 없고 **순서만 유지**하면 된다는 점이 핵심.

---

## 💡 핵심 아이디어

### 🔑 DP 정의 + 점화식

**알고리즘**: 2차원 DP (Bottom-Up)

**dp 정의**:
```
dp[i][j] = s1의 앞 i글자와 s2의 앞 j글자의 LCS 길이
```

**점화식**:
```
s1[i] == s2[j]  →  dp[i][j] = dp[i-1][j-1] + 1   (대각선 + 1)
s1[i] != s2[j]  →  dp[i][j] = max(dp[i-1][j], dp[i][j-1])   (위/왼쪽 max)
```

**시간 복잡도**: O(N × M)
- N, M : 두 문자열의 길이

**공간 복잡도**: O(N × M)
- dp 배열 : dp[1001][1001]

---

## 🔑 주요 구현 포인트

### 1️⃣ 왜 같으면 대각선 + 1인가?

```
s1[i] == s2[j] → 이 글자를 LCS에 추가할 수 있음

이 글자를 추가하기 직전 상태
= s1의 앞 i-1글자 vs s2의 앞 j-1글자
= dp[i-1][j-1]  ← 바로 대각선(↖) 값

dp[i][j] = dp[i-1][j-1] + 1
```

**✅ 핵심**: 대각선 = "이 두 글자를 제외했을 때의 LCS"

### 2️⃣ 왜 다르면 위/왼쪽 max인가?

```
s1[i] != s2[j] → 둘 중 하나를 포기해야 함

선택지 1: s1[i]를 포기 → dp[i-1][j]  ← 위(↑) 값
선택지 2: s2[j]를 포기 → dp[i][j-1]  ← 왼쪽(←) 값

dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

**✅ 핵심**: 위/왼쪽 중 더 긴 LCS를 만드는 쪽 선택

### 3️⃣ 1-indexed 사용 이유

```cpp
// dp[0][j] = 0 
// dp[i][0] = 0 
→ 자동 초기화 (전역 배열)

// 경계 조건 없이 점화식을 바로 적용 가능
for (int i = 1; i <= len1; ++i)
    for (int j = 1; j <= len2; ++j)
        // s1[i-1], s2[j-1] 로 실제 문자 접근
```

### 4️⃣ 예제 확인 (ACAYKP / CAPCAK)

```
      ""  C  A  P  C  A  K
  ""   0  0  0  0  0  0  0
   A   0  0  1  1  1  1  1
   C   0  1  1  1  2  2  2
   A   0  1  2  2  2  3  3
   Y   0  1  2  2  2  3  3
   K   0  1  2  2  2  3 [4]  ← K==K, 대각선(3)+1 = 4
   P   0  1  2  3  3  3  4

LCS = "ACAK" (길이 4)
```

## 🔬 심층 분석 — 점화식이 성립하는 이유

> 점화식을 외우는 것을 넘어, **왜 이렇게 해도 되는가**를 이해하기 위한 분석

### 📑 목차
1. `dp[i][j]`의 의미 다시 잡기
2. 같을 때 — 왜 대각선 + 1인가
3. 다를 때 — 왜 위/왼쪽 max인가
4. 두 경우 한눈에 비교

---

### 1. `dp[i][j]`의 의미 다시 잡기

```
dp[i][j] = "s1의 앞 i글자" 와 "s2의 앞 j글자" 를 비교했을 때 LCS 길이
```

실제 예제로 확인 (s1 = "ACAYKP", s2 = "CAPCAK"):

```
dp[2][4] = LCS("AC",   "CAPC")  = 2  → "AC"
dp[3][5] = LCS("ACA",  "CAPCA") = 3  → "ACA"
dp[4][3] = LCS("ACAY", "CAP")   = 2  → "CA"
```

> **각 칸은 "두 부분 문자열을 비교한 결과"를 저장한다.**
> i, j가 커질수록 더 긴 문자열을 비교하는 것.

---

### 2. 같을 때 — 왜 대각선 + 1인가

**실제 셀: i=3 (s1[3]='A'), j=5 (s2[5]='A')**

```
       ""  C  A  P  C  A  K
  ""    0  0  0  0  0  0  0
   A    0  0  1  1  1  1  1
   C    0  1  1  1 [2] 2  2   ← dp[2][4] = 2  (대각선)
   A    0  1  2  2  2 [3] 3   ← dp[3][5] = ?  (지금 이 칸)
   Y    0  1  2  2  2  3  3
   K    0  1  2  2  2  3  4
   P    0  1  2  3  3  3  4
```

**생각의 흐름:**

```
s1[3] = 'A' == s2[5] = 'A'  → 같다! 이 'A'를 LCS 끝에 쓰기로 결정.

이 'A' 앞에 뭔가 더 있다면,
그것은 반드시:
  - s1 에서 이 A(3번째) 이전 글자들  →  s1의 앞 2글자 "AC"
  - s2 에서 이 A(5번째) 이전 글자들  →  s2의 앞 4글자 "CAPC"
로 구성된 LCS여야 한다.

→ 그게 바로 dp[2][4] = 2  (↖ 대각선 값)
→ 거기에 방금 맞춘 'A' 추가

dp[3][5] = dp[2][4] + 1 = 2 + 1 = 3  →  LCS = "ACA"
```

**핵심 정리:**

```
dp[i-1][j-1]  =  "s1에서 이 글자 제외" + "s2에서 이 글자 제외" 의 LCS
              =  이 두 글자를 쓰기 직전 상태

"이 글자를 LCS 끝에 쓴다"
→ 그 전 상태는 반드시 두 글자 모두 제외한 범위
→ 그게 대각선(↖) 위치
```

> **✅ 대각선 = "지금 일치한 두 글자를 제외했을 때의 최선" + 1**

---

### 3. 다를 때 — 왜 위/왼쪽 max인가

**실제 셀: i=4 (s1[4]='Y'), j=3 (s2[3]='P')**

```
       ""  C  A  P  C  A  K
  ""    0  0  0  0  0  0  0
   A    0  0  1  1  1  1  1
   C    0  1  1  1  2  2  2
   A    0  1  2 [2] 2  3  3   ← dp[3][3] = 2  (위 칸)
   Y    0  1 [2] ?  2  3  3   ← dp[4][2] = 2  (왼쪽 칸) / [?] = dp[4][3]
   K    0  1  2  2  2  3  4
   P    0  1  2  3  3  3  4
```

**생각의 흐름:**

```
s1[4] = 'Y' != s2[3] = 'P'  → 다르다! 이 두 글자를 동시에 LCS에 쓸 수 없다.

Y와 P 중 적어도 하나는 지금 이 LCS에 기여하지 않는다.

선택지 1: Y를 이 비교 범위에서 제외한다면?
  →  s1의 앞 3글자("ACA")  vs  s2의 앞 3글자("CAP")
  →  dp[3][3] = 2   →  LCS = "CA"

선택지 2: P를 이 비교 범위에서 제외한다면?
  →  s1의 앞 4글자("ACAY")  vs  s2의 앞 2글자("CA")
  →  dp[4][2] = 2   →  LCS = "CA"

둘 다 2이므로 → dp[4][3] = max(2, 2) = 2
```

**"제외"의 진짜 의미:**

```
위 칸    dp[i-1][j]  →  s1 범위를 i-1로 줄임  (Y를 비교 대상에서 뺌)
왼쪽 칸  dp[i][j-1]  →  s2 범위를 j-1로 줄임  (P를 비교 대상에서 뺌)
```

**왜 이 두 선택지만 보면 충분한가:**

```
s1[i] != s2[j] 일 때, LCS에서 가능한 모든 상황:

  1. s1[i] 가 LCS에 포함 안 됨  →  dp[i-1][j]  로 커버됨
  2. s2[j] 가 LCS에 포함 안 됨  →  dp[i][j-1]  로 커버됨
  3. 둘 다 LCS에 포함 안 됨     →  dp[i-1][j-1] (항상 위 두 값 이하)

→ max(위, 왼쪽) 만 보면 모든 경우를 커버할 수 있다
```

> **✅ 위/왼쪽 = "한쪽 글자를 범위에서 빼고 계산한 최선", 그 중 더 큰 쪽 선택**

---

### 4. 두 경우 한눈에 비교

```
┌──────────────────────────────────────────────────────────────┐
│  MATCH (같을 때)                                             │
│                                                              │
│  "이 글자를 LCS 끝에 쓴다"                                    │
│  → 쓰기 직전 상태 = 두 글자 모두 제외 = 대각선 dp[i-1][j-1]  │
│  → dp[i][j] = dp[i-1][j-1] + 1                              │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│  NO MATCH (다를 때)                                          │
│                                                              │
│  "이 두 글자는 LCS에 함께 들어갈 수 없다"                      │
│  → s1[i] 범위 제외 = 위↑   dp[i-1][j]                       │
│  → s2[j] 범위 제외 = 왼쪽← dp[i][j-1]                       │
│  → dp[i][j] = max(위, 왼쪽)                                  │
└──────────────────────────────────────────────────────────────┘
```
