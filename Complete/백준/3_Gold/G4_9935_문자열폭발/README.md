## 🔗 문제 링크

[백준 9935번 - 문자열 폭발](https://www.acmicpc.net/problem/9935)

**난이도**: Gold 4

---

## 🤔 접근법

폭발 문자열이 있으면 제거하고, 남은 문자열을 이어붙이는 과정을 반복하는 문제.


핵심은 **문자열을 스택처럼 사용**하여 한 글자씩 추가하면서 **마지막 부분이 폭발 문자열과 일치하면 즉시 제거**하는 것!

---

## 💡 정답 풀이 방법

**알고리즘**: 스택 + 문자열

**핵심 아이디어**:

```
1. 결과 문자열(ret)을 스택처럼 사용
2. 입력 문자열을 한 글자씩 순회하면서:
   - 문자를 ret에 추가
   - ret의 마지막 부분이 폭발 문자열과 일치하면 제거
3. 모든 입력을 처리한 후:
   - ret이 비어있으면 "FRULA" 출력
   - 그렇지 않으면 ret 출력
```

**시간복잡도**: O(N × M)
- N: 입력 문자열 길이
- M: 폭발 문자열 길이
- 각 문자마다 substr로 M만큼 비교: O(N × M)

**공간복잡도**: O(N)
- ret 문자열의 최대 크기: N

---

## 🔑 핵심 포인트

### 1️⃣ 문자열을 스택처럼 사용

```cpp
string ret;  // 스택 역할

for(char a : S)
{
    ret += a;  // push

    // 폭발 문자열 확인 후 제거
    if(ret.size() >= T.size() && ret.substr(ret.size() - T.size(), T.size()) == T)
    {
        ret.erase(ret.end() - T.size(), ret.end());  // pop
    }
}
```

**핵심**:
- `ret += a`: 문자를 끝에 추가 (스택의 push)
- `ret.erase()`: 마지막 부분 제거 (스택의 pop)
- 매번 마지막 부분만 확인하므로 효율적

---

### 2️⃣ substr로 마지막 부분 확인

```cpp
ret.substr(ret.size() - T.size(), T.size()) == T
```

**설명**:
- `ret.size() - T.size()`: 마지막 M개 문자의 시작 위치
- `T.size()`: 폭발 문자열 길이만큼
- 마지막 M개 문자가 폭발 문자열과 일치하는지 확인

**예시**: ret = "mirkovC4", T = "C4"
- `ret.substr(6, 2)` = "C4"
- "C4" == "C4" → true → 제거!

---

### 3️⃣ erase로 마지막 부분 제거

```cpp
ret.erase(ret.end() - T.size(), ret.end());
```

**설명**:
- `ret.end() - T.size()`: 마지막 M개 문자의 시작 반복자
- `ret.end()`: 끝 반복자
- 범위 `[시작, 끝)`의 문자들을 제거

**예시**: ret = "mirkovC4", T.size() = 2
- `ret.erase(ret.end() - 2, ret.end())`
- "C4" 제거 → "mirkov"

---

### 4️⃣ 크기 체크 필수

```cpp
if(ret.size() >= T.size() && ...)
```

**왜 필요한가?**
- `substr(ret.size() - T.size(), ...)`에서:
  - ret.size() < T.size()이면 음수 인덱스 발생 (오버플로우)
  - 범위를 벗어난 접근으로 런타임 에러 발생
- 반드시 크기를 먼저 확인해야 함!

## 💡 연쇄 폭발의 비밀

**왜 이 알고리즘이 연쇄 폭발을 처리하는가?**

예제 2의 10~11단계를 자세히 보면:
```
ret = "112ab"
폭발 문자열 "12ab" 확인:
  - ret.substr(1, 4) = "12ab" (인덱스 1부터 4개)
  - "12ab" == "12ab" → true ✅
  - ret.erase(ret.end() - 4, ret.end())
  - ret = "1"
```

**핵심**:
- 폭발 후 남은 문자열 "1"에 다음 문자들이 추가되면서
- 새로운 폭발 문자열이 완성될 수 있음
- **매번 문자를 추가할 때마다 폭발 문자열을 확인**하므로
- 연쇄 폭발이 자동으로 처리됨!

## 🚨 주의사항

1. **크기 체크 필수**: `ret.size() >= T.size()` 확인 후 substr 사용
2. **범위 오버플로우 방지**: 음수 인덱스나 범위 초과 방지
3. **빈 문자열 처리**: ret이 비어있으면 "FRULA" 출력
4. **입출력 최적화**: 문자열 길이가 최대 1,000,000이므로 `ios_base::sync_with_stdio(false)` 필수

## ⏱️ 시간복잡도

**O(N × M)**

**분석**:
- 입력 문자열 순회: O(N)
- 각 문자마다 substr로 비교: O(M)
- **총합**: O(N × M)

**제한 조건**:
- N ≤ 1,000,000 (입력 문자열 길이)
- M ≤ 36 (폭발 문자열 길이)
- 최악의 경우: 1,000,000 × 36 = 36,000,000 (충분히 빠름)

---

## 💾 공간복잡도

**O(N)**

**분석**:
- `S` 문자열: O(N)
- `T` 문자열: O(M)
- `ret` 문자열: O(N) (최악의 경우 전체 저장)
- **총합**: O(N)
