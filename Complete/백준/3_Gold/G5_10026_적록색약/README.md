## 🔗 문제 링크

https://www.acmicpc.net/problem/10026 (백준 10026번: 적록색약)

**난이도**: Gold 5

---

## 🤔 접근법

N×N 그리드에서 R, G, B로 색칠된 **구역의 수**를 두 가지 관점으로 구해야 한다.

- **일반인** : R, G, B를 모두 다른 색으로 구분 → BFS로 연결 구역 수 탐색
- **색약인** : R과 G를 같은 색으로 인식 → G를 R로 치환한 후 동일 BFS 적용

핵심은 색약 케이스를 **별도 조건 없이** 구현하는 것!

G → R 전처리만 하면 **동일한 BFS 함수를 재사용**할 수 있다.

---

## 💡 핵심 아이디어

### 🔑 전처리 + BFS 2회

**알고리즘**: BFS (연결 구역 탐색) + 전처리 (G→R 치환)

**핵심 아이디어**:
```
1. 입력을 받아 N×N 배열에 저장
2. 일반인 BFS : visited 초기화 후 BFS → 구역 수 저장
3. 전처리 : 배열의 모든 'G'를 'R'로 치환
4. 색약인 BFS : visited 초기화 후 동일 BFS → 구역 수 저장
5. 두 결과 출력
```

**시간 복잡도**: O(N²)
- BFS 2회 수행 : O(N²) × 2
- G→R 전처리 : O(N²)
- 전체 : O(N²) (N ≤ 100)

**공간 복잡도**: O(N²)
- arr[104][104] : O(N²)
- visited[104][104] : O(N²)

## 🔑 주요 구현 포인트

### 1️⃣ BFS 함수 분리

```cpp
int BFS()
{
    int areaCnt = 0;
    queue<pair<int,int>> bfsQ;

    for (int i = 0; i < n; ++i)
    {
        for (int j = 0; j < n; ++j)
        {
            if (!visited[i][j])
            {
                areaCnt++;  // 새 구역 시작

                // BFS 탐색...
            }
        }
    }
    return areaCnt;
}
```

**✅ 핵심**:
- BFS를 함수로 분리하여 일반인/색약인 **동일 코드 재사용**
- 새 BFS 시작 시에만 `areaCnt++` (탐색 중에는 카운트 X)

### 2️⃣ G→R 전처리 (색약 핵심)

```cpp
// 색약 전처리 : G → R 치환
for (int i = 0; i < n; ++i)
{
    for (int j = 0; j < n; ++j)
    {
        if (arr[i][j] == 'G')
        {
            arr[i][j] = 'R';
        }
    }
}
```

**✅ 핵심**:
- BFS 내부 조건을 건드리지 않고 **입력 데이터만 변환**
- G를 R로 치환하면 색약인은 R과 G를 구분할 수 없는 상태가 됨
- `arr[new] != arr[cur]` 조건 **그대로** 사용 가능

### 3️⃣ visited 초기화

```cpp
// 일반인
memset(visited, 0, sizeof(visited));
int normal = BFS();

// 색약인 (전처리 후)
memset(visited, 0, sizeof(visited));
int colorblind = BFS();
```

**✅ 핵심**:
- BFS 재사용 전 반드시 `memset`으로 visited 초기화
- 전역 배열이므로 첫 번째 BFS 결과가 남아있음

## ⏱️ 시간복잡도

**O(N²)**
- BFS 탐색 2회 : O(N²) × 2
- G→R 전처리 : O(N²)
- N ≤ 100이므로 최악 : 100 × 100 × 3 = 30,000 (충분히 빠름)

---

## 💾 공간복잡도

**O(N²)**
- `arr[104][104]` : N×N 그리드 저장
- `visited[104][104]` : 방문 체크 배열
- BFS 큐 : 최대 N×N 크기
- 재귀 없으므로 스택 오버플로우 없음

---

## 🚨 주의사항

1. **BFS 내부에서 areaCnt 증가 금지** : 새 시작점에서만 카운트해야 함
2. **bfsQ.pop() 누락 주의** : `front()`로 꺼낸 후 반드시 `pop()` 필요
3. **visited 초기화** : BFS 재사용 전 반드시 memset으로 초기화
4. **전처리 후 원복 불필요** : 일반인 BFS 먼저 수행 후 전처리하면 됨
