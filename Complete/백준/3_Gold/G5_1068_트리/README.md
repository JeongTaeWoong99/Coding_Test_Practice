## 🔗 문제 링크

[백준 1068번 - 트리](https://www.acmicpc.net/problem/1068)

**난이도**: Gold 5

---

## 🤔 접근법

트리에서 특정 노드를 삭제하면 그 노드와 모든 자손 노드가 함께 제거된다.

삭제 후 남은 트리에서 리프 노드(자식이 0개인 노드)의 개수를 구해야 한다.

핵심은 **삭제할 노드와 그 서브트리를 제외하고 DFS로 탐색**하면서 리프 노드를 카운트하는 것!

---

## 💡 정답 풀이 방법

**알고리즘**: DFS(깊이 우선 탐색) + 트리 순회

**핵심 아이디어**:
```
1. 입력으로 각 노드의 부모 정보를 받아 트리 구조 생성
   - 부모 → 자식 방향 인접리스트로 저장
   - 부모가 -1인 노드가 루트
2. 루트부터 DFS 탐색 시작
   - 삭제할 노드를 만나면 continue로 건너뛰기 (서브트리 제외)
   - 살아있는 자식의 개수 카운트
3. 자식이 0개이면 리프 노드이므로 1 반환
4. 자식이 있으면 자식들의 리프 개수 합을 반환
5. 예외 처리: 루트 노드를 삭제하면 전체 트리가 사라지므로 0 출력
```

**시간 복잡도**: O(N)
- N = 노드 개수 (최대 50)
- DFS로 각 노드를 한 번씩만 방문

**공간 복잡도**: O(N)
- adj 배열: O(N)
- DFS 재귀 스택: O(N) (최악의 경우 트리 높이가 N)

---

## 🔑 핵심 포인트

### 1️⃣ 부모 → 자식 방향 인접리스트

```cpp
vector<int> adj[54];  // adj[i] = 노드 i의 자식 노드들

for(int i = 0; i < n; i++)
{
    cin >> temp;  // i번 노드의 부모 번호

    if(temp == -1) root = i;               // 루트 노드 저장
    else           adj[temp].push_back(i); // 부모의 자식 목록에 추가
}
```

**✅ 핵심**:
- 입력은 "각 노드의 부모" 정보이지만, 저장은 "부모 → 자식" 방향으로
- 이렇게 하면 DFS 탐색 시 자식들을 바로 접근 가능
- 루트부터 아래로 탐색하는 것이 자연스러움

### 2️⃣ 삭제 노드 처리

```cpp
int DFS(int here)
{
    int ret   = 0;  // 리프 노드 개수
    int child = 0;  // 살아있는 자식 개수

    for(int there : adj[here])
    {
        if(there == removeN) continue;  // 삭제 노드와 서브트리 제외

        ret += DFS(there);
        child++;
    }

    if(child == 0) return 1;  // 리프 노드
    return ret;               // 자식들의 리프 개수 합
}
```

**✅ 핵심**:
- `if(there == removeN) continue;`로 삭제 노드를 만나면 건너뛰기
- 삭제 노드의 서브트리 전체가 자동으로 제외됨
- `child` 변수로 살아있는 자식만 카운트
- 살아있는 자식이 0개면 리프 노드

### 3️⃣ 루트 삭제 예외 처리

```cpp
if(removeN == root)
{
    cout << 0 << "\n";
    return 0;
}
```

**✅ 핵심**:
- 루트를 삭제하면 트리 전체가 사라짐
- 이 경우 리프 노드가 0개이므로 바로 0 출력 후 종료
- 이 처리가 없으면 DFS에서 잘못된 카운트가 발생할 수 있음

### 4️⃣ vector 배열 vs vector<vector>

```cpp
vector<int> adj[54];  // ✅ 배열 형태의 벡터 (권장!)
// vs
vector<vector<int>> adj;  // ❌ 2차원 벡터 (크기 초기화 필요)
```

**✅ 장점**:
- `vector<int> adj[54]`는 별도 초기화 없이 바로 사용 가능
- `adj[0]`, `adj[1]`, ..., `adj[53]` 모두 빈 벡터로 자동 생성됨
- 코딩테스트에서 더 간편하고 안전함

## 📊 예시 실행 흐름

**입력 1**:
```
5
-1 0 0 1 1
2
```

**트리 구조**:
```
       0 (root)
      / \
     1   2 (삭제)
        / \
       3   4
```

**삭제 후**:
```
       0 (root)
      /
     1 (리프)
```

**실행 과정**:
```
1. DFS(0) 시작
2. 자식: 1, 2
   - DFS(1) 호출 → 자식 없음 → 리프 1개 반환
   - 2는 removeN이므로 continue
3. child = 1 (자식 있음)
4. ret = 1 (1번 노드만 리프)
5. 출력: 1
```

**입력 2**:
```
5
-1 0 0 1 1
1
```

**삭제 후**:
```
       0 (root, 리프)
```

**출력**: `1`

**입력 3**:
```
5
-1 0 0 1 1
0
```

**삭제 후**: (트리 전체 사라짐)

**출력**: `0`

- 매우 빠른 알고리즘

## 💾 공간복잡도

**O(N)**
- `adj[54]`: 인접리스트 배열 (각 노드의 자식 저장)
- DFS 재귀 스택: 최악의 경우 트리 높이 N (일직선 트리)

## 🚨 주의사항

1. **루트 삭제 예외 처리 필수**: 루트를 삭제하면 트리 전체가 사라지므로 0 출력
2. **인접리스트 방향**: 입력은 "자식 → 부모"이지만 저장은 "부모 → 자식" 방향
3. **리프 판단 조건**: 살아있는 자식이 0개일 때만 리프 노드
4. **삭제 노드 처리**: continue로 건너뛰면 서브트리 전체가 자동으로 제외됨
