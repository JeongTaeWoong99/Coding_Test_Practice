## 🔗 문제 링크

[백준 1074번 - Z](https://www.acmicpc.net/problem/1074)

**난이도**: Gold 5

---

## 🤔 접근법

2^N × 2^N 크기의 2차원 배열을 Z모양으로 탐색할 때, (r, c) 위치가 몇 번째로 방문되는지 구하는 문제.

직관적으로 생각하면 **Z순서대로 한 칸씩 방문하면서 카운트**하면 되지만, N이 최대 15이므로 시간 초과가 발생한다.

**핵심은 분할 정복(Divide and Conquer)**으로 (r, c)가 포함되지 않은 사분면은 통째로 건너뛰는 것!

---

## 🚨 실패한 풀이 (Answer(실패).cpp.txt)

**알고리즘** : 분할 정복 + 완전 탐색

**접근**: Z순서대로 **진짜 한 칸씩 방문**하면서 `cnt++` 누적, (r, c)에 도달하면 출력

```cpp
// 크기가 1 = 실제 칸 하나에 도착
if (curSize == 1)
{
    if (curY == r && curX == c) // (r, c) 도착!
    {
        cout << cnt;
        found = true;
        return;
    }

    cnt++; // 아니면 다음 칸으로
    return;
}

// Z순서대로 4개 사분면 전부 방문
int half = curSize / 2;
div(half, curY       , curX       ); // 1. 왼쪽 위칸
div(half, curY       , curX + half); // 2. 오른쪽 위칸
div(half, curY + half, curX       ); // 3. 왼쪽 아래칸
div(half, curY + half, curX + half); // 4. 오른쪽 아래칸
```

**❌ 실패 이유**: 시간 초과
- 시간복잡도: **O(4^N)** = O(2^N × 2^N)
- N=15일 때: 2^15 × 2^15 = 32,768 × 32,768 = **약 10억 칸** 방문
- 0.5초 제한에 절대 통과 불가

## 💡 정답 풀이 (Answer(정답_최적화).cpp.txt)

**알고리즘** : 분할 정복 (Divide and Conquer) + 건너뛰기 최적화

**핵심 아이디어**:
```
1. 현재 영역에 (r, c)가 포함되는지 확인
2. 포함되면 → 4개 영역으로 분할하여 재귀
3. 포함되지 않으면 → 해당 영역의 크기(curSize²)만큼 cnt에 누적 (건너뛰기!)
4. 크기가 1이 되어 좌표가 일치하면 → cnt 출력 (답)
```

## 🔑 핵심 포인트

### 1️⃣ 두 풀이의 차이

| | 실패 (완전 탐색) | 정답 (건너뛰기 최적화) |
|---|---|---|
| **(r,c) 없는 사분면** | 끝까지 재귀 진입, 한 칸씩 `cnt++` | `cnt += curSize²`로 **한 번에** 건너뜀 |
| **매 단계 재귀 호출** | 4개 전부 | (r,c) 포함된 사분면만 재귀, 나머지 3개는 O(1) |
| **시간복잡도** | O(4^N) ≈ **10억** (N=15) | O(4N) ≈ **60** (N=15) |
| **결과** | ⚠️ 시간 초과 | ✅ 통과 |

**💡 핵심 발상의 전환**:

실패 코드는 사진처럼 0, 1, 2, 3... 순서대로 **진짜** 방문한다.
```
 0→ 1   4→ 5
   /      /
 2→ 3   6→ 7      ← 모든 칸을 하나씩 방문
   /      /
 8→ 9  12→13
   /      /
10→11  14→15
```

정답 코드는 (r,c)가 없는 영역은 **방문하지 않고 칸 수만 더한다**.
```
예: (r,c) = (3,1)

┌────────┬────────┐
│ 건너뜀 │ 건너뜀 │
│cnt += 4│cnt += 4│  ← 2×2 = 4씩 한번에 더함
├────────┼────────┤
│ 재귀!  │        │
│ 여기만 │ (도달  │
│ 파고듦 │  안함) │
└────────┴────────┘
```

### 2️⃣ 범위 체크 분리

```cpp
bool inY = (r >= curY) && (r < curY + curSize); // r이 현재 Y범위 안에 있는지
bool inX = (c >= curX) && (c < curX + curSize); // c가 현재 X범위 안에 있는지

if (inY && inX)
```

**✅ 핵심**: 한 줄에 몰아쓰면 헷갈리므로 Y범위/X범위를 각각 bool로 분리
- `inY` : r이 [curY, curY + curSize) 범위 안에 있는지
- `inX` : c가 [curX, curX + curSize) 범위 안에 있는지
- 둘 다 참이면 (r, c)가 현재 사분면 안에 있음

### 3️⃣ 4개 영역 분할 순서 (Z자 순서)

```cpp
int half = curSize / 2;
div(half, curY       , curX       ); // 1. 왼쪽 위칸
div(half, curY       , curX + half); // 2. 오른쪽 위칸
div(half, curY + half, curX       ); // 3. 왼쪽 아래칸
div(half, curY + half, curX + half); // 4. 오른쪽 아래칸
```

**✅ 핵심**: Z자 순서대로 왼위 → 오위 → 왼아 → 오아
- 각 영역의 크기는 현재의 절반 (curSize / 2)
- 시작 좌표(curY, curX)에 curSize / 2를 더해서 각 사분면 위치 지정

### 4️⃣ cnt 누적 원리 (건너뛰기)

```cpp
// (r, c)가 현재 사분면 안에 없으면
cnt += curSize * curSize;
```

**✅ 핵심**: **이 사분면에 (r, c)가 없다** = 이 영역은 (r, c)보다 먼저 방문됨
- 해당 영역의 총 칸 수(curSize²)를 한 번에 더함
- 재귀 진입 없이 O(1)로 건너뜀 → **시간 초과 방지의 핵심!**

## 📊 예제 실행 흐름

### 🎯 예제 1: `N=2, r=3, c=1` → 정답: **11**

4×4 배열의 Z순서 방문:
```
 0  1 |  4  5
 2  3 |  6  7
------+------
 8  9 | 12 13
10 11 | 14 15
```

```
div(4, 0, 0) → (3,1)이 범위 안 → 4등분
│
├─ div(2, 0, 0) → 왼쪽 위: (3,1) 범위 밖!
│                  → cnt += 2×2 = 4           ← cnt = 4
│
├─ div(2, 0, 2) → 오른쪽 위: (3,1) 범위 밖!
│                  → cnt += 2×2 = 4           ← cnt = 8
│
├─ div(2, 2, 0) → 왼쪽 아래: (3,1) 범위 안! → 4등분
│   │
│   ├─ div(1, 2, 0) → (3,1) ≠ (2,0) 범위 밖 → cnt += 1  ← cnt = 9
│   ├─ div(1, 2, 1) → (3,1) ≠ (2,1) 범위 밖 → cnt += 1  ← cnt = 10
│   ├─ div(1, 3, 0) → (3,1) ≠ (3,0) 범위 밖 → cnt += 1  ← cnt = 11
│   └─ div(1, 3, 1) → curY==r && curX==c 🎯 → cout << 11 ✅
│
└─ (이미 출력됨, 도달하지 않음)
```

### 🎯 예제 2: `N=3, r=7, c=7` → 정답: **63**

8×8 배열에서 (7,7)은 **맨 마지막 칸** (오른쪽 아래 끝).

```
div(8, 0, 0) → (7,7) 범위 안 → 4등분
│
├─ div(4, 0, 0) → 왼쪽 위: (7,7) 범위 밖!
│                  → cnt += 4×4 = 16          ← cnt = 16
│
├─ div(4, 0, 4) → 오른쪽 위: (7,7) 범위 밖!
│                  → cnt += 4×4 = 16          ← cnt = 32
│
├─ div(4, 4, 0) → 왼쪽 아래: (7,7) 범위 밖!
│                  → cnt += 4×4 = 16          ← cnt = 48
│
└─ div(4, 4, 4) → 오른쪽 아래: (7,7) 범위 안! → 4등분
    │
    ├─ div(2, 4, 4) → (7,7) 범위 밖 → cnt += 4  ← cnt = 52
    ├─ div(2, 4, 6) → (7,7) 범위 밖 → cnt += 4  ← cnt = 56
    ├─ div(2, 6, 4) → (7,7) 범위 밖 → cnt += 4  ← cnt = 60
    └─ div(2, 6, 6) → (7,7) 범위 안! → 4등분
        │
        ├─ div(1, 6, 6) → (7,7) ≠ (6,6) → cnt += 1  ← cnt = 61
        ├─ div(1, 6, 7) → (7,7) ≠ (6,7) → cnt += 1  ← cnt = 62
        ├─ div(1, 7, 6) → (7,7) ≠ (7,6) → cnt += 1  ← cnt = 63
        └─ div(1, 7, 7) → curY==r && curX==c 🎯 → cout << 63 ✅
```

**✅ 핵심 원리**:
- `cnt`는 **(r, c)보다 먼저 방문하는 칸의 총 개수**를 누적
- (r, c)가 없는 사분면은 `curSize²`로 한 번에 건너뜀
- (r, c)가 있는 사분면만 재귀로 파고들어감
- 좌표가 일치하면 그때의 `cnt`가 곧 **방문 순서**

## ⏱️ 시간복잡도

| | 실패 코드 | 정답 코드 |
|---|---|---|
| **시간복잡도** | O(4^N) | O(4N) = **O(N)** |
| **N=15 연산 수** | ~1,073,741,824 (약 10억) | ~60 |
| **0.5초 제한** | ❌ 시간 초과 | ✅ 여유 |

**정답 코드 분석**:
- 매 재귀 단계에서 4개 사분면 중 **1개만** 재귀 진입 (나머지 3개는 O(1)로 건너뜀)
- 재귀 깊이: N단계 (크기가 2^N → 2^(N-1) → ... → 1)
- 각 단계에서 O(1) 작업
- 전체: O(4N) = **O(N)**
