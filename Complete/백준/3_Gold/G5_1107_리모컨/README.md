## 🔗 문제 링크

[백준 1107번 - 리모컨](https://www.acmicpc.net/problem/1107)

**난이도**: Gold 5

---

## 🤔 접근법

현재 채널 100에서 목표 채널 N으로 이동할 때, 고장난 버튼이 있는 리모컨으로 최소 버튼 입력 횟수를 구하는 문제이다.

두 가지 선택지 중 최솟값을 고르면 된다.

1. **+/- 만 사용**: 현재 채널 100에서 +/-로만 이동 → `abs(N - 100)`
2. **숫자 입력 후 +/- 사용**: 고장나지 않은 숫자로만 구성된 임의 채널 ch를 직접 입력 후 +/-로 이동 → `digits(ch) + abs(N - ch)`

핵심은 **채널 0 ~ 1,000,000을 완전탐색**하며, 입력 가능한 채널마다 후보값을 계산해 최솟값을 갱신하는 것!

---

## 💡 정답 풀이 방법

**알고리즘**: 브루트포스 (완전탐색)

**핵심 아이디어**:
```
1. 경우 1 초기값: ans = abs(N - 100)  (현재 100번에서 +/-만 누르는 경우)
2. ch를 0 ~ 1,000,000 완전탐색:
   - CanType(ch): ch의 각 자리가 모두 고장나지 않은 버튼이면 true
   - 조건 만족 시: ans = min(ans, digits(ch) + abs(N - ch))
3. 최솟값 출력
```

**CanType 함수**:
```cpp
// ch를 문자열로 변환 후, 각 자리가 broken[] 여부 확인
bool CanType(int ch)
{
    string s = to_string(ch);
    for (char c : s)
    {
        if (broken[c - '0'])
            return false;
    }
    return true;
}
```

## 🔑 핵심 포인트

### 1️⃣ 두 선택지 비교

| 선택지 | 방법 | 버튼 수 |
|--------|------|---------|
| 경우 1 | +/-만 사용 | `abs(N - 100)` |
| 경우 2 | 채널 ch 직접 입력 후 +/- | `digits(ch) + abs(N - ch)` |

→ 두 경우 모두 고려해야 정답

### 2️⃣ 현재 채널(100)이 이미 목표일 수 있음

```
입력: N=100, 고장 버튼: {0, 1, 5}
경우 1: abs(100 - 100) = 0  ← 이미 도착!
경우 2: 어떤 ch를 눌러도 1 이상
정답: 0
```

→ 경우 1의 초기값이 자동으로 이 케이스를 처리

### 3️⃣ 탐색 범위 1,000,000

- N 최대값이 500,000이므로 탐색 범위를 1,000,000으로 넉넉하게 설정
- N보다 훨씬 큰 채널을 입력해도: `digits + abs(ch - N)` 계산으로 최솟값 비교에서 자연스럽게 탈락

### 4️⃣ 모든 버튼이 고장난 경우

- CanType이 true인 ch가 하나도 없음
- 경우 1(abs(N - 100))만 남아 자동으로 정답

---

## ⏱️ 시간복잡도

**O(1,000,000 × D)**
- 탐색 채널 수: 1,000,000
- CanType 내 자릿수 순회: D ≤ 7 (최대 7자리)
- 전체: 약 7,000,000 연산 (충분히 통과)

---

## 💾 공간복잡도

**O(1)**
- `broken[10]`: 고장 버튼 플래그 (상수 크기)
- 추가 배열 없음
