## 🔗 문제 링크

[백준 1344번 - 축구](https://www.acmicpc.net/problem/1344)

**난이도**: Gold 5

---

## 🤔 접근법

90분 축구 경기를 5분 단위 18개 구간으로 나누고, 각 구간에서 A팀과 B팀이 각각 최대 1골을 넣을 수 있다.

경기 종료 후 **적어도 한 팀이 소수 골**을 넣을 확률을 구하는 문제이다.

핵심은 **여사건** + **독립 사건의 DP**로 접근하는 것!

- 두 팀은 **독립적**으로 득점 → 각 팀의 골 분포를 따로 DP로 계산
- "적어도 한 팀이 소수" = **1 - "두 팀 모두 소수 아님"** (여사건)
- 각 팀의 득점 분포는 **이항 분포**와 동일 (DP로 구현)

---

## 💡 정답 풀이 방법

**알고리즘**: 동적 계획법 (DP) + 확률론 + 여사건

**핵심 아이디어**:
```
1. 상태 정의: dp[i][j] = i번째 구간까지, 해당 팀이 j골 넣을 확률

2. 상태 전이 (각 구간마다):
   - 득점: dp[i+1][j+1] += dp[i][j] * p      (확률 p로 골 성공)
   - 미득점: dp[i+1][j] += dp[i][j] * (1-p)   (확률 1-p로 골 실패)

3. 기저 사례: dp[0][0] = 1.0 (시작 전, 0골일 확률 = 1)

4. 최종 계산:
   - A팀과 B팀 각각 독립적으로 DP 수행
   - P(두 팀 모두 소수 아님) = P(A 비소수) × P(B 비소수)
   - 답 = 1 - P(두 팀 모두 소수 아님)
```

**시간 복잡도**: O(N²) (N = 18, 구간 수)
- 18개 구간 × 최대 18골 = 324번 전이 (매우 빠름)

**공간 복잡도**: O(N²)
- dpA[19][19] + dpB[19][19] = 722개 double

## 🔑 핵심 포인트

### 1️⃣ 여사건 활용 (가장 중요!)

**직접 계산의 어려움:**
```
"적어도 한 팀이 소수"를 직접 구하려면?
→ A만 소수, B만 소수, 둘 다 소수 ... 복잡!

여사건 활용:
P(적어도 한 팀 소수) = 1 - P(두 팀 모두 비소수)
```

**코드:**
```cpp
// 여사건 : "적어도 한 팀이 소수" = 1 - "두 팀 모두 소수 아님"
double notPrimeA = 0.0;
double notPrimeB = 0.0;

for(int j = 0; j <= 18; j++)
{
    if(!isPrime(j))
    {
        notPrimeA += dpA[18][j];
        notPrimeB += dpB[18][j];
    }
}

cout << 1.0 - notPrimeA * notPrimeB;
```

**✅ 핵심**:
- 두 팀은 **독립 사건** → 곱으로 계산 가능
- P(A 비소수 AND B 비소수) = P(A 비소수) × P(B 비소수)
- 여사건으로 한 줄에 정답 계산!

### 2️⃣ DP 전이 (이항 분포)

```cpp
for(int i = 0; i < 18; i++)
{
    for(int j = 0; j <= i; j++)
    {
        dpA[i + 1][j + 1] += dpA[i][j] * pA;        // 득점
        dpA[i + 1][j]     += dpA[i][j] * (1 - pA);  // 미득점
    }
}
```

**DP 전이 다이어그램:**
```
구간 i에서 j골인 상태 dp[i][j]
  ├─ 득점 (확률 p)   → dp[i+1][j+1] += dp[i][j] × p
  └─ 미득점 (확률 1-p) → dp[i+1][j]   += dp[i][j] × (1-p)
```

**✅ 핵심**:
- 각 구간에서 **득점/미득점** 두 가지 경우만 존재
- 각 구간에서 최대 1골 → j는 i를 초과할 수 없음 (j ≤ i)
- 결과적으로 **이항 분포 C(18, j) × p^j × (1-p)^(18-j)** 와 동일

### 3️⃣ 소수 판별

```cpp
bool isPrime(int num)
{
    if(num < 2) return false;

    for(int i = 2; i * i <= num; i++)
    {
        if(num % i == 0) return false;
    }
    return true;
}
```

**0~18 범위의 소수:**
```
소수:    2, 3, 5, 7, 11, 13, 17  (7개)
비소수:  0, 1, 4, 6, 8, 9, 10, 12, 14, 15, 16, 18  (12개)
```

**✅ 핵심**:
- 최대 골 수가 18이므로 18 이하의 소수만 확인
- 0과 1은 소수가 아님에 주의!

### 4️⃣ 두 팀의 독립성

**왜 각 팀을 따로 계산할 수 있는가?**
```
문제 조건: "각 간격에서 A팀이 득점할 확률과 B팀이 득점할 확률이 주어진다"

→ A팀의 득점과 B팀의 득점은 서로 영향을 주지 않음
→ 독립 사건!
→ P(A=j AND B=k) = P(A=j) × P(B=k)
```

**✅ 핵심**:
- 독립이 아니면 3차원 DP (dp[구간][A골][B골])가 필요
- 독립이므로 2차원 DP를 2번 돌리면 됨 → 훨씬 간결!

## 📊 예제 실행 흐름 (예제 1: pA=50%, pB=50%)

### 📋 입력
```
50
50
```

### 🔄 DP 계산 과정

**A팀 (p=0.5) — 처음 3구간만 표시:**

| 구간(i) | 0골 | 1골 | 2골 | 3골 |
|---------|-----|-----|-----|-----|
| 0 | 1.000 | - | - | - |
| 1 | 0.500 | 0.500 | - | - |
| 2 | 0.250 | 0.500 | 0.250 | - |
| 3 | 0.125 | 0.375 | 0.375 | 0.125 |

**18구간 후 최종 분포 (주요 값):**
```
dp[18][0] = C(18,0) × 0.5^18 ≈ 0.0000038   (비소수)
dp[18][2] = C(18,2) × 0.5^18 ≈ 0.000584     (소수)
dp[18][9] = C(18,9) × 0.5^18 ≈ 0.1855       (비소수, 최대값)
```

### 🎯 결과 계산

```
P(A 비소수) = dpA[18][0] + dpA[18][1] + dpA[18][4] + dpA[18][6] + ...
            ≈ 0.6881

P(B 비소수) = 같은 값 (같은 확률이므로)
            ≈ 0.6881

P(둘 다 비소수) = 0.6881 × 0.6881 ≈ 0.4734

답 = 1 - 0.4734 ≈ 0.5266
```

**출력**: `0.5265618908306351` ✅

## 📊 예제 2 분석 (pA=100%, pB=100%)

```
두 팀 모두 매 구간 100% 득점
→ A팀 = 18골, B팀 = 18골
→ 18은 소수가 아님 (18 = 2 × 9)
→ 두 팀 모두 비소수
→ P(적어도 한 팀 소수) = 0.0
```

**O(N²)** (N = 18)

**분석**:
- 외부 루프: 18번 (구간 수)
- 내부 루프: 최대 18번 (골 수)
- 총 연산: 18 × 18 = 324번 (× 2팀 = 648번)
- 소수 판별: O(√18 × 18) ≈ O(1)
- 전체: **거의 즉시 실행**

## 🚨 주의사항

1. **여사건 활용 필수**: 직접 계산하면 포함-배제 원리 필요 → 복잡
2. **독립 사건**: 두 팀의 득점이 독립이므로 확률의 곱 가능
3. **소수 범위**: 0~18 사이의 소수는 {2, 3, 5, 7, 11, 13, 17}
4. **0과 1은 비소수**: 0골, 1골은 소수가 아님!
5. **부동소수점 정밀도**: double로 충분 (10^-6 오차 허용)
6. **퍼센트 변환**: 입력이 퍼센트이므로 100.0으로 나누기 필수
7. **출력 형식**: `fixed << setprecision(16)`으로 충분한 소수점 출력 (스페셜 저지)
