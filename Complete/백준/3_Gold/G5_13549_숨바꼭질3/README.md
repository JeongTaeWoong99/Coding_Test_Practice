## 🤔 접근법

수빈이가 위치 N에서 동생 위치 K까지 도달하는 최소 시간을 구하는 문제이다.

- 걷기 (X-1, X+1) : **1초** 소요
- 순간이동 (2*X) : **0초** 소요

간선의 가중치가 0 또는 1 두 가지이므로 **0-1 BFS** 를 사용한다.

---

## 💡 정답 풀이 방법

**알고리즘**: 0-1 BFS (Deque 활용)

**핵심 아이디어**:
```
1. dist 배열을 전부 INT_MAX로 초기화, 시작 위치만 0
2. 덱에 시작 위치 push
3. 덱에서 꺼낼 때:
   - 순간이동 (비용 0) → 덱 앞에 push_front
   - 걷기 (비용 1)     → 덱 뒤에 push_back
4. 갱신될 때만 (dist[cur] < dist[next]) 덱에 삽입
5. dist[k] 출력
```

**시간 복잡도**: O(N)
- 각 위치를 최대 한 번씩 처리
- N = 100,000

**공간 복잡도**: O(N)
- dist 배열: O(N)

## 🔑 핵심 포인트

### 1️⃣ 0-1 BFS란?

일반 BFS는 모든 간선 가중치가 동일할 때 최단 경로를 보장한다.
간선 가중치가 0과 1 두 종류일 때는 **덱(Deque)** 을 사용하면 된다.

```
가중치 0 → push_front (앞에 넣어서 먼저 처리)
가중치 1 → push_back  (뒤에 넣어서 나중에 처리)
```

덱의 앞에서 꺼낼 때 항상 현재까지 최소 비용 노드가 나오므로 최단 경로 보장!

---

### 2️⃣ 갱신 조건

```cpp
if (dist[cur] < dist[next])
{
    dist[next] = dist[cur]; // 순간이동 (비용 0)
    bfsQ.push_front(next);
}

if (dist[cur] + 1 < dist[next])
{
    dist[next] = dist[cur] + 1; // 걷기 (비용 1)
    bfsQ.push_back(next);
}
```

**✅ 핵심**:
- 더 짧은 경로가 발견됐을 때만 갱신 + 덱에 추가
- 갱신 없으면 불필요한 삽입 방지

---

## 📊 예제 실행 흐름 (5 → 17)

```
힌트 경로: 5 → 10 → 9 → 18 → 17

5  (순간이동, 0초) → 10
10 (걷기 -1, 1초) → 9
9  (순간이동, 0초) → 18
18 (걷기 -1, 2초) → 17

정답: 2초
```

## ⏱️ 시간복잡도

**O(N)** — N = 100,000

- 각 위치는 최대 한 번만 갱신되어 덱에 삽입
- 전체 처리 횟수 = 위치 수 = O(N)
