## 🔗 문제 링크  

[백준 15662번 - 톱니바퀴 (2)](https://www.acmicpc.net/problem/15662)

**난이도**: Gold 5

---

## 🤔 접근법

T개의 톱니바퀴(각 8개 톱니)가 일렬로 배치되어 있고, K번 회전 명령을 수행한다.

톱니바퀴를 회전시킬 때, 인접한 톱니바퀴와 맞닿은 극이 다르면 반대 방향으로 연쇄 회전한다.

핵심은 **회전 전 상태를 기준으로 전파 범위를 미리 결정**한 후 **한 번에 모든 톱니바퀴를 회전**시키는 것!

---

## 💡 정답 풀이 방법

**알고리즘**: 시뮬레이션

**핵심 아이디어**:
```
1. 각 회전 명령마다:
   - rotateDir 배열로 각 톱니바퀴의 회전 방향 결정
   - 회전 전 원본 상태에서 왼쪽/오른쪽으로 전파 체크
   - 모든 톱니바퀴를 동시에 회전 (순차 실행이지만 원본 기준으로 이미 결정됨)
2. 왼쪽 전파:
   - 현재 톱니의 6번 칼날과 왼쪽 톱니의 2번 칼날 비교
   - 극이 다르면 반대 방향으로 회전 설정
   - 극이 같으면 전파 중단
3. 오른쪽 전파:
   - 현재 톱니의 2번 칼날과 오른쪽 톱니의 6번 칼날 비교
   - 극이 다르면 반대 방향으로 회전 설정
   - 극이 같으면 전파 중단
4. 회전 실행:
   - rotateDir 배열에 따라 각 톱니바퀴 회전
   - 시계 방향: 마지막 원소를 맨 앞으로
   - 반시계 방향: 첫 번째 원소를 맨 뒤로
5. 모든 회전 완료 후 12시 방향이 S극(1)인 톱니바퀴 개수 출력
```

**시간 복잡도**: O(K × T × 8)
- K = 회전 횟수 (최대 1,000)
- T = 톱니바퀴 개수 (최대 1,000)
- 각 회전마다 전파 체크: O(T)
- 회전 실행: O(T × 8)
- 전체: 약 8,000,000 연산 (충분히 통과)

**공간 복잡도**: O(T)
- brade 배열: O(T × 8)
- rotateDir 배열: O(T)

## 🔑 핵심 포인트

### 1️⃣ 동시 회전 구현

**핵심: 회전 전 상태를 기준으로 전파 범위 결정**

```cpp
// 1. 회전할 톱니 목록 작성
int rotateDir[1004] = {0};
rotateDir[number] = direction;

// 2. 왼쪽으로 전파 체크 (원본 brade로 직접 확인)
for (int i = number; i > 1; i--)
{
    if (brade[i][6] != brade[i - 1][2])  // 극이 다르면
        rotateDir[i - 1] = -rotateDir[i];
    else
        break;  // 극이 같으면 전파 중단
}

// 3. 오른쪽으로 전파 체크
for (int i = number; i < t; i++)
{
    if (brade[i][2] != brade[i + 1][6])  // 극이 다르면
        rotateDir[i + 1] = -rotateDir[i];
    else
        break;
}

// 4. 한 번에 모든 톱니 회전
for (int i = 1; i <= t; i++)
{
    if (rotateDir[i] == 1)      // 시계 방향
        RotateClockwise(i);
    else if (rotateDir[i] == -1) // 반시계 방향
        RotateCounterClockwise(i);
}
```

**✅ 핵심**:
- 전파 체크 단계에서는 brade 원본을 변경하지 않음
- rotateDir 배열에 모든 회전 방향을 먼저 결정
- 이후 한 번에 모든 톱니바퀴를 회전시킴
- 이 방식으로 "동시 회전" 개념을 정확히 구현

### 2️⃣ 회전 구현 (직접 구현)

**시계 방향 회전**:
```cpp
char tempChar = brade[i][7];  // 마지막 원소 저장
for (int j = 7; j > 0; j--)
{
    brade[i][j] = brade[i][j - 1];  // 한 칸씩 뒤로
}
brade[i][0] = tempChar;  // 마지막 원소를 맨 앞으로
```

**반시계 방향 회전**:
```cpp
char tempChar = brade[i][0];  // 첫 번째 원소 저장
for (int j = 0; j < 7; j++)
{
    brade[i][j] = brade[i][j + 1];  // 한 칸씩 앞으로
}
brade[i][7] = tempChar;  // 첫 번째 원소를 맨 뒤로
```

**✅ 핵심**:
- STL rotate 대신 직접 구현
- 명확하고 디버깅이 쉬움
- 임시 변수 하나만 사용 (메모리 효율적)

### 3️⃣ 맞닿은 톱니 인덱스

```
톱니바퀴 구조 (12시부터 시계방향):
     [0]
 [7]     [1]
[6]       [2]
 [5]     [3]
     [4]

맞닿은 부분:
- 왼쪽 톱니와 맞닿음: [6]
- 오른쪽 톱니와 맞닿음: [2]
```

**✅ 핵심**:
- 현재 톱니의 [6]번과 왼쪽 톱니의 [2]번 비교
- 현재 톱니의 [2]번과 오른쪽 톱니의 [6]번 비교
- N극: '0', S극: '1'

### 4️⃣ 1-based 인덱스 사용

```cpp
char brade[1004][8];  // brade[1]부터 사용

// 입력
for (int i = 1; i <= t; i++)
{
    cin >> bradeState;
    for (int j = 0; j < 8; j++)
        brade[i][j] = bradeState[j];
}

// 회전 명령
cin >> number >> direction;  // number는 1-based
Vang(number, direction);

// 결과 출력
for (int i = 1; i <= t; i++)
{
    if (brade[i][0] == '1')
        ret++;
}
```

**✅ 핵심**:
- 문제에서 톱니바퀴 번호가 1부터 시작
- 배열도 1-based로 사용하면 변환 불필요
- 코드가 더 직관적이고 실수 방지
