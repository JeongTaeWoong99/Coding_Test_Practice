## 🔗 문제 링크

[백준 16928번 - 뱀과 사다리 게임](https://www.acmicpc.net/problem/16928)

**난이도**: Gold 5

---

## 🤔 접근법

처음에는 **그리디**로 접근했다.

매 주사위마다 1~6 중 이동 후 위치가 가장 큰 주사위 값을 선택하는 방식.
뱀은 항상 뒤로 가므로 `bestPos` 갱신 조건에서 걸러진다고 생각했고,
사다리만 `movLadder` map에 저장하는 구조로 설계했다.

하지만 이 접근법은 **반례가 존재한다.**

그리디는 "현재 이동 후 가장 높은 위치"만 보기 때문에,
이후 경로에 뱀이 있어서 더 많은 굴림이 필요한 상황을 전혀 고려하지 못한다.

---

## ❌ 왜 그리디가 틀렸는가

**그리디의 전제**: 매 순간 최선의 선택 = 전체 최선

**이 문제에서 전제가 깨지는 이유:**

```
예시 상황:
현재 위치 A에서 dice=6 → B 이동 (가장 큰 위치)
현재 위치 A에서 dice=3 → C 이동 (더 낮은 위치)

그리디: B를 선택

그런데 B 이후 경로에 뱀이 연달아 있어서
  B → (뱀) → D → (뱀) → E → ... → 100  (5번 더 필요)
C 이후 경로는 사다리가 있어서
  C → (사다리) → F → 100  (2번 더 필요)

→ 그리디는 B를 선택했지만, 실제 최솟값은 C 경로
```

즉, **이후 경로 전체를 보지 않으면** 최솟값을 보장할 수 없다.

---

## 💡 정답 풀이 방법

**알고리즘**: BFS (너비 우선 탐색)

**핵심 아이디어**:
```
1~100번 칸을 그래프의 노드로 보고
주사위 1회 굴림을 가중치 1의 엣지로 본다.

BFS는 레벨(굴림 횟수) 순서로 탐색하므로
100번 칸에 처음 도달하는 순간이 반드시 최솟값이다.
```

**시간 복잡도**: O(100 × 6) = O(600) ≈ O(1)
- 각 칸(100개)을 최대 1번씩 방문
- 각 칸에서 주사위 6가지 탐색

**공간 복잡도**: O(100)
- dist 배열: 크기 101

## 🔑 핵심 포인트

### 1️⃣ 사다리/뱀을 하나의 map으로 통합

```cpp
map<int, int> mov; // from -> to (사다리는 to > from, 뱀은 to < from)
```

- 사다리와 뱀을 구분할 필요 없이 `mov[from] = to`로 통합
- BFS에서 이동 후 `mov.count(next)`로 한 번에 처리

### 2️⃣ BFS에서 방문 체크가 핵심

```cpp
if (dist[next] != -1) continue; // 이미 방문한 칸 스킵
```

- BFS는 레벨 순서로 탐색하므로 **처음 도달했을 때가 최단 거리**
- 이미 기록된 칸은 다시 기록할 필요 없음

### 3️⃣ 사다리/뱀 이동은 굴림 횟수에 포함되지 않음

```cpp
// 사다리/뱀 이동 반영 후 같은 dist 값으로 큐에 추가
if (mov.count(next)) next = mov[next];
dist[next] = dist[cur] + 1; // 주사위 굴림 1회만 카운트
```

- 사다리/뱀을 탄다고 굴림 횟수가 증가하지 않음
- 이동 목적지를 반영한 후 `+1`로 저장

## 📊 예시 실행 흐름

**예제 1** (3 7, 사다리: 12→98 등):

```
dist[1] = 0, bfsQ: [1]

dice=5 → 6번 → dist[6] = 1, bfsQ: [..., 6]
dice=6 → 12번 → (사다리) → 98번 → dist[98] = 1
dice=2 from 98 → 100번 → dist[100] = 2?

실제로는:
굴림 1: 1에서 6 (dist[6]=1)
굴림 2: 6에서 12→98 (dist[98]=2)
굴림 3: 98에서 100 (dist[100]=3)

출력: 3
```

## ⏱️ 시간복잡도

**O(100 × 6)**
- 보드 크기 고정 (1~100)
- 각 칸에서 주사위 6가지 탐색
- 사실상 상수 시간

## 💾 공간복잡도

**O(100)**
- `dist[101]`: 각 칸까지의 최소 굴림 횟수
- `map<int,int> mov`: 최대 30개 (N+M ≤ 30)
- BFS 큐: 최대 100개

---

## 🚨 주의사항

1. **사다리/뱀 이동은 굴림 횟수 불포함**: 이동 목적지만 바꾸고 `+1`은 주사위에만
2. **방문 체크 필수**: 같은 칸에 여러 경로로 도달 가능하므로 `dist != -1`로 스킵
3. **100 초과 이동 불가**: `next > 100`이면 해당 주사위 값 스킵
