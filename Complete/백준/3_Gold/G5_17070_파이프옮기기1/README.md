## 🔗 문제 링크

[백준 17070번 - 파이프 옮기기 1](https://www.acmicpc.net/problem/17070)

**난이도**: Gold 5

## 🤔 접근법

(DP로 짜기는 했는데, 자료구조를 잘못 짬... 다시 해보자...)

N×N 크기의 격자판에서 파이프를 (1, 1)-(1, 2) 위치에서 (N, N)까지 이동시키는 방법의 수를 구하는 문제.

파이프는 가로(→), 대각선(↘), 세로(↓) 3가지 방향으로 놓일 수 있으며, 각 방향에 따라 이동 가능한 방향이 제한됨.

핵심은 **DP 바텀업(Bottom-up) 방식**으로 작은 위치에서 큰 위치로 가능한 경우의 수를 누적시키는 것!

---

## 💡 정답 풀이 방법

**알고리즘** : 동적 계획법 (DP) - 바텀업 방식

**핵심 아이디어**:
```
1. dp[y][x][d] = (y, x)에 파이프 끝이 d 방향으로 도달하는 경우의 수
   - d = 0: 가로 (→)
   - d = 1: 대각선 (↘)
   - d = 2: 세로 (↓)

2. 초기값: dp[1][2][0] = 1 (파이프가 (1,1)-(1,2)에 가로로 놓임)

3. 상태 전이:
   - 가로(0) → 가로(0), 대각선(1)
   - 대각선(1) → 가로(0), 대각선(1), 세로(2)
   - 세로(2) → 세로(2), 대각선(1)

4. (1, 1)부터 (n, n)까지 모든 위치를 순회하며 DP 값 갱신

5. 최종 답: dp[n][n][0] + dp[n][n][1] + dp[n][n][2]
```

**시간 복잡도** : O(N²)
- 이중 for문으로 모든 위치 탐색: O(N²)
- 각 위치에서 7개 if문 확인: O(1)
- 전체: O(N²)

**공간 복잡도** : O(N²)
- dp[24][24][3] 배열: O(N² × 3)
- a[24][24] 배열: O(N²)

## 🔑 핵심 포인트

### 1️⃣ 바텀업 DP의 특징

**⚠️ 중요: 이 문제는 재귀가 없는 순수 바텀업 방식!**

```cpp
// ❌ 재귀 함수가 아님! 단순 검증 함수!
bool canPlace(int y, int x, int d)
{
    // 파이프를 놓을 수 있는지만 확인
    if(d == 0 || d == 2)
    {
        if(a[y][x] == 0) return true;
    }
    // ...
    return false;
}

// ✅ 바텀업: 반복문으로 작은 문제 → 큰 문제 순차 계산
for(int i = 1; i <= n; i++)
{
    for(int j = 1; j <= n; j++)
    {
        // dp[i][j]의 값을 dp[i+1][j], dp[i][j+1]로 전파
        if(canPlace(...)) dp[...][...][...] += dp[i][j][...];
    }
}
```

**✅ 핵심**:
- **재귀 없음** : for문으로 모든 상태 순차 계산
- **작은 → 큰** : (1,1) → (n,n) 순서로 진행
- **모든 경우 탐색** : 7개 if문으로 모든 전이 확인
- **조건부 전파** : dp[i][j][d] > 0일 때만 의미있는 값 전파

### 2️⃣ DP 상태 전이 규칙

**파이프 방향별 이동 가능한 방향:**

| 현재 방향 | 이동 가능 방향 | 코드                                                                                                     |
|----------|--------------|--------------------------------------------------------------------------------------------------------|
| 가로 (→) | 가로, 대각선 | `dp[i ][j+1][0] += dp[i][j][0]`<br>`dp[i+1][j+1][1] += dp[i][j][0]`                                    |
| 대각선 (↘) | 가로, 대각선, 세로 | `dp[i ][j+1][0] += dp[i][j][1]`<br>`dp[i+1][j+1][1] += dp[i][j][1]`<br>`dp[i+1][j][2 ] += dp[i][j][1]` |
| 세로 (↓) | 세로, 대각선 | `dp[i+1][j ][2] += dp[i][j][2]`<br>`dp[i+1][j+1][1] += dp[i][j][2]`                                    |

### 3️⃣ 파이프 배치 가능 조건

```cpp
bool canPlace(int y, int x, int d)
{
    if(d == 0 || d == 2)
    {
        // 가로 또는 세로: 해당 칸만 비어있으면 됨
        if(a[y][x] == 0) return true;
    }
    else if(d == 1)
    {
        // 대각선: 해당 칸, 위쪽, 왼쪽 모두 비어있어야 함
        if(a[y][x] == 0 && a[y-1][x] == 0 && a[y][x-1] == 0)
            return true;
    }
    return false;
}
```

**✅ 핵심**:
- 가로/세로: 목표 칸 1개만 확인
- 대각선: 목표 칸 + 인접 2칸 (총 3칸) 확인

### 4️⃣ 모든 if문 확인의 의미

**🤔 왜 7개 if문을 모두 확인하는가?**

```cpp
for(int i = 1; i <= n; i++)
{
    for(int j = 1; j <= n; j++)
    {
        // ✅ 이 7개 if문은 항상 모두 실행됨!
        if(canPlace(...)) dp[...] += dp[i][j][0]; // IF 1
        if(canPlace(...)) dp[...] += dp[i][j][0]; // IF 2
        if(canPlace(...)) dp[...] += dp[i][j][1]; // IF 3
        if(canPlace(...)) dp[...] += dp[i][j][1]; // IF 4
        if(canPlace(...)) dp[...] += dp[i][j][1]; // IF 5
        if(canPlace(...)) dp[...] += dp[i][j][2]; // IF 6
        if(canPlace(...)) dp[...] += dp[i][j][2]; // IF 7
    }
}
```

**✅ 핵심**:
- 7개 if문은 **모두 실행**됨
- 단, `dp[i][j][d] = 0`이면 `+= 0`이므로 **효과 없음**
- `dp[i][j][d] > 0`일 때만 실제로 값이 전파됨

## 🚨 주의사항

1. **재귀 없음**: 이 문제는 순수 바텀업 방식 (재귀 + 메모이제이션 아님)
2. **모든 if문 확인**: 7개 if문은 항상 모두 확인되지만, dp 값이 0이면 효과 없음
3. **대각선 조건**: 대각선은 3칸 모두 비어있어야 함
4. **1-indexed**: 격자판이 1부터 시작 (0이 아님)
5. **초기값**: dp[1][2][0] = 1로 시작 (파이프가 (1,1)-(1,2)에 가로로 놓임)
6. **경계 체크**: i+1, j+1이 n을 넘으면 자동으로 canPlace에서 false 반환 (배열 범위 밖)
