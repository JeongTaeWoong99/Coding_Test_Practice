## 🤔 접근법

N줄에 숫자가 세 개씩 적혀 있고, 첫 줄에서 마지막 줄까지 내려가면서 얻을 수 있는 **최대 점수와 최소 점수**를 구하는 문제이다.

이동 규칙은 바로 아래 또는 바로 아래와 인접한 열로만 이동 가능하다.

**핵심 제약**: 메모리 제한 **4MB** → N×3 전체 DP 테이블 저장 불가!

따라서 **슬라이딩 윈도우(Rolling Array)** 기법으로, 이전 행만 유지하면서 max DP와 min DP를 동시에 처리하는 것이 최적 풀이이다.

---

## 💡 정답 풀이 방법

**알고리즘**: 다이나믹 프로그래밍 + 슬라이딩 윈도우

**핵심 아이디어**:
```
1. 첫 줄의 값으로 maxDP[3], minDP[3] 초기화
2. 2번째 줄부터 이전 행 기준으로 전이:
   - col 0 : 이전 행의 col 0, col 1 중 max/min
   - col 1 : 이전 행의 col 0, col 1, col 2 중 max/min
   - col 2 : 이전 행의 col 1, col 2 중 max/min
3. 현재 행 계산 후 DP 배열 덮어쓰기 (Rolling Array)
4. 마지막 행의 maxDP 최대값, minDP 최소값 출력
```

**시간 복잡도**: O(N)
- N개 행을 한 번씩 순회 (각 행에서 상수 연산)

**공간 복잡도**: O(1)
- 크기 3짜리 배열만 사용 (행 전체 저장 불필요)

---

## 🔑 핵심 포인트

### 1️⃣ 메모리 제한 4MB → 슬라이딩 윈도우 필수

```
N×3 전체 저장 시: 100,000 × 3 × 4byte × 2(max+min) = 2.4MB
+ 입력 배열까지 합산 시 초과 위험

슬라이딩 윈도우: 크기 3짜리 배열만 유지 → 메모리 O(1)
```

### 2️⃣ 전이 규칙 (열별 접근 가능 범위)

```
이전 행:  [0]   [1]   [2]
          ↓↘   ↙↓↘   ↙↓
현재 행:  [0]   [1]   [2]

col 0 ← 이전 col 0, col 1
col 1 ← 이전 col 0, col 1, col 2
col 2 ← 이전 col 1, col 2
```

### 3️⃣ max/min DP 동시 처리

```cpp
// col 0
newMax[0] = a[0] + max(maxDP[0], maxDP[1]);
newMin[0] = a[0] + min(minDP[0], minDP[1]);

// col 1
newMax[1] = a[1] + max({ maxDP[0], maxDP[1], maxDP[2] });
newMin[1] = a[1] + min({ minDP[0], minDP[1], minDP[2] });

// col 2
newMax[2] = a[2] + max(maxDP[1], maxDP[2]);
newMin[2] = a[2] + min(minDP[1], minDP[2]);
```

**✅ 핵심**: max DP와 min DP를 한 번의 순회에서 동시 처리하므로 O(N)으로 해결

### 4️⃣ newMax/newMin 임시 배열 사용

```cpp
int newMax[3], newMin[3];
// ... 계산 후
for (int j = 0; j < 3; ++j)
{
    maxDP[j] = newMax[j];
    minDP[j] = newMin[j];
}
```

**✅ 핵심**: 임시 배열을 쓰지 않고 maxDP를 직접 갱신하면, col 1 계산 시 이미 갱신된 col 0 값이 사용되어 오답 발생

## 📊 예제 검증

**입력**: N=3, `1 2 3 / 4 5 6 / 4 9 0`

| 행 | maxDP | minDP |
|----|-------|-------|
| 초기 | [1, 2, 3] | [1, 2, 3] |
| i=1 | [6, 8, 9] | [5, 6, 8] |
| i=2 | [12, 18, 9] | [9, 14, 6] |

→ max(12, 18, 9) = **18**, min(9, 14, 6) = **6** ✅

## ⏱️ 시간복잡도

**O(N)**
- N개 행을 한 번씩 순회
- 각 행에서 상수 개의 연산 (3개 열)

---

## 💾 공간복잡도

**O(1)**
- `maxDP[3]`, `minDP[3]`: 크기 3짜리 배열 (슬라이딩 윈도우)
- 전체 N×3 테이블 불필요
- 4MB 메모리 제한에서도 여유롭게 통과
