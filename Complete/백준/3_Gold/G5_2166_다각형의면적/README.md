## 🤔 접근법

N개의 꼭짓점 좌표가 주어진 다각형의 넓이를 구하는 문제이다.

**볼록/오목 다각형 모두 적용 가능한 신발끈 공식(Shoelace Formula)**을 사용한다.

핵심은 **꼭짓점을 순서대로 순회하며 외적(Cross Product)을 누적**하고, 그 절댓값의 절반이 넓이라는 것!

---

## 💡 정답 풀이 방법

**알고리즘**: 신발끈 공식 (Shoelace Formula / 가우스 면적 공식)

**핵심 아이디어**:
```
1. 꼭짓점을 순서대로 (x₀,y₀), (x₁,y₁), ..., (xₙ₋₁,yₙ₋₁) 저장
2. 인접한 두 꼭짓점의 외적을 모두 합산:
   cross = Σ (xᵢ × y_{i+1} - x_{i+1} × yᵢ)  (i = 0 ~ n-1, 인덱스 mod n)
3. 넓이 = |cross| / 2.0
4. 소수점 첫째 자리까지 출력 (fixed + setprecision(1))
```

**시간 복잡도**: O(N)
- N = 꼭짓점 수 (최대 10,000)
- 한 번의 순회로 처리

**공간 복잡도**: O(N)
- x, y 배열: O(N)

## 🔑 핵심 포인트

### 1️⃣ 오버플로우 방지 — long long 필수

```cpp
typedef long long ll;

ll x[10001]; // x 좌표를 ll로 선언
ll y[10001]; // y 좌표를 ll로 선언
```

**✅ 핵심**:
- 좌표 최대 100,000 → 곱 최대 10^10 (int 범위 초과)
- N개 합산 시 최대 10^14 → `long long` 필수
- x, y 배열 자체를 `ll`로 선언하면 곱셈 시 자동으로 `ll` 연산

---

### 2️⃣ 마지막 꼭짓점 처리 — mod N 순환

```cpp
for (int i = 0; i < n; ++i)
{
    int next = (i + 1) % n; // 마지막 꼭짓점은 0번으로 순환
    cross += x[i] * y[next] - x[next] * y[i];
}
```

**✅ 핵심**:
- 마지막 꼭짓점 (i = n-1) 의 next는 0번 (시작점으로 닫힘)
- `% n` 으로 인덱스 순환 처리

---

### 3️⃣ 출력 — fixed + setprecision(1)

```cpp
double area = abs(cross) / 2.0;
cout << fixed << setprecision(1) << area << "\n";
```

**✅ 핵심**:
- `abs(cross)` 로 부호 제거 (시계/반시계 방향 무관)
- `fixed << setprecision(1)` 로 소수점 첫째 자리까지 자동 반올림 출력

## 📊 예제 실행 흐름

**입력**:
```
4
0 0
0 10
10 10
10 0
```

**신발끈 공식 계산**:
```
i=0: (0,0) → (0,10):  x[0]*y[1] - x[1]*y[0] =   0*10 -  0* 0 =    0
i=1: (0,10) → (10,10): x[1]*y[2] - x[2]*y[1] =   0*10 - 10*10 = -100
i=2: (10,10) → (10,0): x[2]*y[3] - x[3]*y[2] = 10* 0 - 10*10 = -100
i=3: (10,0) → (0,0):   x[3]*y[0] - x[0]*y[3] = 10* 0 -  0* 0 =    0

cross = 0 + (-100) + (-100) + 0 = -200
넓이  = |-200| / 2.0 = 100.0
```

**출력**: `100.0`
