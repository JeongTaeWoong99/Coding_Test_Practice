## 🤔 접근법

강토는 N개의 기타 강의를 M개의 블루레이에 녹화하려고 한다.

블루레이는 **모두 같은 크기**이어야 하고, **강의의 순서는 바뀌면 안 된다**.

따라서 **이분 탐색(매개 변수 탐색)**을 사용하여 **가능한 블루레이의 최소 크기**를 찾으면 된다.

핵심은 **블루레이 크기를 이분 탐색하면서, 해당 크기로 M개 이하의 블루레이에 나눌 수 있는지 확인**하는 것!

---

## 💡 핵심 아이디어

### 🔑 이분 탐색 (Parametric Search)

**문제 조건:**
- N개의 강의를 M개의 블루레이에 녹화
- 블루레이는 모두 같은 크기
- 강의의 순서는 바뀌면 안 됨
- 가능한 블루레이의 크기 중 최소값 구하기

**알고리즘 흐름:**
```
1. 이분 탐색 범위 설정:
   - left (최소값): 가장 긴 강의의 길이 (이보다 작으면 해당 강의를 담을 수 없음)
   - right (최대값): 모든 강의 길이의 합 (하나의 블루레이에 모두 담는 경우)

2. 이분 탐색으로 블루레이 크기 탐색:
   - mid = (left + right) / 2
   - Check(mid): mid 크기로 M개 이하의 블루레이에 나눌 수 있는지 확인

3. Check 함수:
   - 현재 블루레이에 강의를 순서대로 담기
   - 담을 수 없으면 새 블루레이 사용
   - 최종적으로 M개 이하로 나눌 수 있는지 반환

4. 이분 탐색 조건:
   - Check(mid)가 true → 더 작은 크기 시도 (right = mid - 1)
   - Check(mid)가 false → 크기 증가 (left = mid + 1)
```

**시간 복잡도**: O(N × log(합))
- 이분 탐색: O(log(합))
  - 합 = 모든 강의 길이의 합 (최대 1,000,000,000)
  - log(1,000,000,000) ≈ 30
- Check 함수: O(N) (최대 100,000)
- 전체: O(N × log(합)) = 100,000 × 30 = 3,000,000 (충분히 통과)

**공간 복잡도**: O(N)
- arr 배열: O(N)

## 🔑 주요 구현 포인트

### 1️⃣ 이분 탐색 범위 설정

```cpp
int left  = 0;  // 최소값: 가장 긴 강의
int right = 0;  // 최대값: 모든 강의 합

for(int i = 0; i < n; i++)
{
    cin >> arr[i];
    left  = max(left, arr[i]);  // 가장 긴 강의가 최소 크기
    right += arr[i];             // 모든 강의 합이 최대 크기
}
```

**✅ 핵심**:
- **left**: 가장 긴 강의가 최소 크기
  - 이유: 블루레이 크기가 가장 긴 강의보다 작으면 해당 강의를 담을 수 없음
- **right**: 모든 강의의 합이 최대 크기
  - 이유: 하나의 블루레이에 모든 강의를 담는 경우

---

### 2️⃣ Check 함수로 가능 여부 판단

```cpp
bool Check(int mid)
{
    int cnt = 1;   // 현재 사용한 블루레이 개수
    int sum = 0;   // 현재 블루레이에 담긴 강의 길이 합

    for(int i = 0; i < n; i++)
    {
        // 현재 강의를 담을 수 없으면 새 블루레이 사용
        if(sum + arr[i] > mid)
        {
            cnt++;
            sum = arr[i];  // 새 블루레이에 현재 강의 담기
        }
        else
        {
            sum += arr[i]; // 현재 블루레이에 추가
        }
    }

    return cnt <= m;  // m개 이하로 나눌 수 있으면 true
}
```

**✅ 핵심**:
- **cnt**: 사용한 블루레이 개수 (1부터 시작)
- **sum**: 현재 블루레이에 담긴 강의 길이 합
- **조건**: `sum + arr[i] > mid`
  - 현재 강의를 담을 수 없으면 새 블루레이 사용
  - cnt 증가 후 새 블루레이에 현재 강의 담기
- **반환**: `cnt <= m`
  - m개 이하로 나눌 수 있으면 true

---

### 3️⃣ 이분 탐색으로 최소 크기 찾기

```cpp
int result = right;

while(left <= right)
{
    int mid = (left + right) / 2;

    // mid 크기로 m개 이하 블루레이에 나눌 수 있는지 확인
    if(Check(mid))
    {
        result = mid;      // 가능하면 결과 저장
        right  = mid - 1;  // 더 작은 크기 시도
    }
    else
    {
        left = mid + 1;    // 불가능하면 크기 증가
    }
}
```

**✅ 핵심**:
- **Check(mid) == true**: mid 크기로 M개 이하 블루레이에 나눌 수 있음
  - result에 mid 저장 (더 작은 크기가 있을 수 있으므로)
  - right = mid - 1 (더 작은 크기 시도)
- **Check(mid) == false**: mid 크기로 M개 이하 블루레이에 나눌 수 없음
  - left = mid + 1 (크기 증가 필요)

## 📊 예제 실행 흐름

**입력**:
```
9 3
1 2 3 4 5 6 7 8 9
```

**실행 과정**:
```
1. 범위 설정:
   - left = 9 (가장 긴 강의)
   - right = 45 (모든 강의 합: 1+2+...+9)

2. 이분 탐색:

   ① mid = (9 + 45) / 2 = 27
      Check(27) = true (cnt = 2 ≤ 3)
      → 1~9 (합 45) 하나의 블루레이로 가능하지만, 27로 나누면:
        블루레이1: 1+2+3+4+5+6+7 = 28 (X) → 1+2+3+4+5+6 = 21 (O)
        블루레이2: 7+8+9 = 24 (O)
        → cnt = 2 ≤ 3 (가능)
      → result = 27, right = 26

   ② mid = (9 + 26) / 2 = 17
      Check(17) = true (cnt = 3 ≤ 3)
      → 블루레이1: 1+2+3+4+5 = 15 (O)
        블루레이2: 6+7 = 13 (O)
        블루레이3: 8+9 = 17 (O)
        → cnt = 3 ≤ 3 (가능)
      → result = 17, right = 16

   ③ mid = (9 + 16) / 2 = 12
      Check(12) = false (cnt = 4 > 3)
      → 블루레이1: 1+2+3+4 = 10 (O)
        블루레이2: 5+6 = 11 (O)
        블루레이3: 7 (O)
        블루레이4: 8 (O)
        블루레이5: 9 (O)
        → cnt = 5 > 3 (불가능)
      → left = 13

   ④ mid = (13 + 16) / 2 = 14
      Check(14) = false (cnt = 4 > 3)
      → left = 15

   ⑤ mid = (15 + 16) / 2 = 15
      Check(15) = false (cnt = 4 > 3)
      → left = 16

   ⑥ mid = (16 + 16) / 2 = 16
      Check(16) = false (cnt = 4 > 3)
      → left = 17

   ⑦ left > right 종료
```

**출력**: `17`

## ⏱️ 시간복잡도

**O(N × log(합))**
- N = 강의의 수 (최대 100,000)
- 합 = 모든 강의 길이의 합 (최대 1,000,000,000)
- 이분 탐색: O(log(1,000,000,000)) ≈ O(30)
- Check 함수: O(N)
- 전체: O(100,000 × 30) = O(3,000,000) (충분히 통과)
