## 🔗 문제 링크

[백준 2565번 - 전깃줄](https://www.acmicpc.net/problem/2565)

**난이도**: Gold 5

---

## 🤔 접근법

(코드는 간단하지만, 그걸 응용해서 떠올리는게 쉽지가 않다...)

두 전봇대 A와 B 사이에 전깃줄이 연결되어 있을 때, 전깃줄이 서로 교차하지 않도록 최소 개수의 전깃줄을 제거해야 한다.

핵심은 **A를 기준으로 정렬한 후, B에서 LIS(최장 증가 부분 수열)를 구하는 것**!

전깃줄이 교차하지 않으려면 A가 증가할 때 B도 증가해야 하므로, B의 LIS 길이가 교차 없이 남길 수 있는 최대 전깃줄 개수가 된다.

---

## 💡 정답 풀이 방법

**알고리즘**: LIS (최장 증가 부분 수열) + 이분 탐색

**핵심 아이디어**:
```
1. A와 B의 연결 위치를 pair로 저장
2. A를 기준으로 오름차순 정렬
   - 이제 A는 증가 순서가 보장됨
3. B에서 LIS를 구함 (이분 탐색 활용)
   - lower_bound로 삽입 위치 찾기
   - 마지막 위치면 LIS 확장
   - 기존 위치면 더 작은 값으로 교체 (미래에 더 긴 LIS 가능)
4. 전체 전깃줄 개수 - LIS 길이 = 제거할 최소 전깃줄 개수
```

**시간 복잡도**: O(n log n)
- 정렬: O(n log n)
- LIS 구하기: O(n log n) (이분 탐색 사용)

**공간 복잡도**: O(n)
- lis 배열: O(n)
- vector v: O(n)

---

## 🔑 핵심 포인트

### 1️⃣ 전깃줄 교차 → LIS 문제로 변환

**전깃줄이 교차하지 않는 조건:**
```
A를 오름차순으로 정렬했을 때,
연결된 B도 오름차순이어야 함!
```

**예시:**
```
입력:
A: 1  3  2  4  6  10  9  7
B: 8  9  2  1  4  10  7  6

정렬 후 (A 기준):
A: 1  2  3  4  6   7   9  10
B: 8  2  9  1  4   6   7  10
   ✗  ✓  ✗  ✗  ✓   ✓   ✓   ✓

B의 LIS: [2, 4, 6, 7, 10]
LIS 길이: 5
제거할 개수: 8 - 5 = 3
```

**✅ 핵심**:
- A 정렬 → A는 증가 보장
- B의 LIS → 교차 없이 남길 수 있는 최대 개수
- n - LIS → 제거해야 할 최소 개수

### 2️⃣ 이분 탐색을 활용한 LIS (O(n log n))

**일반 DP 방식**: O(n²) → 시간 초과 가능

**이분 탐색 방식**: O(n log n) → 효율적! ✅

```cpp
for(int i = 0; i < v.size(); i++)
{
    // lower_bound: v[i].second 이상인 첫 번째 위치
    int pos = lower_bound(lis, lis + len, v[i].second) - lis;

    // 마지막 위치면 LIS 확장
    if(lis[pos] == 0) len++;

    // 삽입/갱신
    lis[pos] = v[i].second;
}
```

**✅ 핵심**:
- `lower_bound`: v[i].second가 들어갈 위치 찾기 (O(log n))
- `pos == len`: 마지막 위치 → 새로운 값 추가 → LIS 확장
- `pos < len`: 기존 위치 → 더 작은 값으로 교체 → 미래에 더 긴 LIS 가능

### 3️⃣ lower_bound 동작 원리

```cpp
// B: [8, 2, 9, 1, 4, 6, 7, 10]
// lis 배열 변화 과정:

i=0, B=8:
  pos = 0 (첫 위치)
  lis[0] = 8  → [8, 0, 0, ...]
  len = 1

i=1, B=2:
  pos = 0 (2는 8보다 작으므로 0번 위치)
  lis[0] = 2  → [2, 0, 0, ...]  ← 더 작은 값으로 교체!
  len = 1

i=2, B=9:
  pos = 1 (9는 2보다 크므로 1번 위치)
  lis[1] = 9  → [2, 9, 0, ...]
  len = 2

i=3, B=1:
  pos = 0 (1은 2보다 작으므로 0번 위치)
  lis[0] = 1  → [1, 9, 0, ...]  ← 더 작은 값으로 교체!
  len = 2

i=4, B=4:
  pos = 1 (4는 1보다 크고 9보다 작으므로 1번 위치)
  lis[1] = 4  → [1, 4, 0, ...]  ← 9를 4로 교체!
  len = 2

i=5, B=6:
  pos = 2 (6은 4보다 크므로 2번 위치)
  lis[2] = 6  → [1, 4, 6, 0, ...]
  len = 3

i=6, B=7:
  pos = 3 (7은 6보다 크므로 3번 위치)
  lis[3] = 7  → [1, 4, 6, 7, 0, ...]
  len = 4

i=7, B=10:
  pos = 4 (10은 7보다 크므로 4번 위치)
  lis[4] = 10 → [1, 4, 6, 7, 10, ...]
  len = 5

최종 LIS 길이: 5
제거할 전깃줄: 8 - 5 = 3
```

**✅ 핵심**:
- ☆ 더 작은 값으로 교체하면 미래에 더 긴 LIS를 만들 가능성이 높아짐
- `lis` 배열은 실제 LIS가 아니라 "길이별 최소값"을 저장
- 최종적으로 `len`이 LIS의 길이

### 4️⃣ pair의 자동 정렬

```cpp
vector<pair<int, int>> v;
v.emplace_back(a, b);

sort(v.begin(), v.end());  // first 기준 오름차순 자동 정렬
```

**✅ 핵심**:
- `pair`는 `first` 기준으로 자동 정렬
- `first`가 같으면 `second` 기준으로 정렬
- 별도의 비교 함수 불필요

## 📊 예제 실행 흐름

**입력**:
```
8
1 8
3 9
2 2
4 1
6 4
10 10
9 7
7 6
```

**정렬 후 (A 기준)**:
```
A: 1  2  3  4  6   7   9  10
B: 8  2  9  1  4   6   7  10
```

**B의 LIS 구하기**:
```
B: [8, 2, 9, 1, 4, 6, 7, 10]

LIS 과정:
8 → [8]
2 → [2]           (8을 2로 교체)
9 → [2, 9]
1 → [1, 9]        (2를 1로 교체)
4 → [1, 4]        (9를 4로 교체)
6 → [1, 4, 6]
7 → [1, 4, 6, 7]
10 → [1, 4, 6, 7, 10]

LIS 길이: 5
```

**결과**:
```
전체 전깃줄: 8개
남길 수 있는 최대: 5개
제거해야 할 개수: 8 - 5 = 3개
```

**출력**: `3`

## 🚨 주의사항

1. **A 정렬 필수**: A를 정렬해야 B의 LIS가 의미를 가짐
2. **lower_bound 이해**: 삽입 위치를 찾는 것이 핵심
3. **교체 전략**: 더 작은 값으로 교체하면 미래에 더 긴 LIS 가능
4. **lis[pos] == 0 체크**: 마지막 위치인지 확인하여 len 증가 여부 결정
5. **pair 자동 정렬**: first 기준으로 자동 정렬되므로 별도 함수 불필요
