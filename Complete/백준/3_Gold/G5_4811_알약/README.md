## 🔗 문제 링크

[백준 4811번 - 알약](https://www.acmicpc.net/problem/4811)

**난이도**: Gold 5

---

## 🤔 접근법

※ 재귀 트리 진행 다이어그램

※ 실제로는 DP를 통해, 중복되는 부분 재귀가 방지됨.(메모이제이션)

70세 박종수 할아버지는 매일 약 반 알을 먹는다. N개의 약이 담긴 병에서 매일 약을 꺼내는데:
- 전체 약(W)을 꺼내면 : 반을 먹고 나머지 반은 병에 다시 넣음
- 반 조각(H)을 꺼내면 : 그대로 먹음

2N일 동안 가능한 서로 다른 문자열(W와 H의 조합)의 개수를 구하는 문제이다.

핵심은 **DP 재귀 + 메모이제이션**으로 중복 계산을 방지하면서 모든 경우의 수를 구하는 것!

---

## 💡 정답 풀이 방법

**알고리즘**: 동적 계획법 (DP) - 탑다운(Top-down) 재귀 + 메모이제이션

**핵심 아이디어**:
```
1. 상태 정의: dp[w][h] = 전체 약 w개, 반조각 h개 남았을 때 가능한 문자열 개수

2. 기저 사례: w == 0 && h == 0
   → 모든 약을 다 먹음 (유효한 문자열 1개 완성)
   → return 1

3. 상태 전이:
   - W 선택 (전체 약 꺼내기): dp[w][h] += dp[w-1][h+1]
     → 전체 약 1개 감소, 반조각 1개 증가
   - H 선택 (반조각 꺼내기): dp[w][h] += dp[w][h-1]
     → 반조각 1개 감소

4. 메모이제이션: 이미 계산된 dp[w][h]는 재사용

5. 시작: dp[n][0] (전체 약 n개, 반조각 0개)
```

**시간 복잡도**: O(N²)

※ 온전한 알약 W 갯수 만큼, 반쪽 H 갯수가 나오기 때문에, 결국 N x N !!!
- 가능한 상태: (w, h) 쌍의 개수 → 최대 31 × 31 = 961개
- 각 상태는 한 번만 계산 (메모이제이션)
- 전체: O(N²)

**공간 복잡도**: O(N²)
- dp[31][31] 배열: O(N²)
- 재귀 스택: 최대 O(N) (깊이가 w+h ≤ 2N)

## 🔑 핵심 포인트

### 1️⃣ DP 상태 정의

**dp[w][h]의 의미:**
```
w: 남은 전체 약 개수
h: 남은 반조각 개수
dp[w][h]: 이 상태에서 가능한 문자열의 개수
```

**예시 (N=2):**
```
초기 상태: dp[2][0] (전체 약 2개, 반조각 0개)

경우 1: W 선택
  → dp[1][1] (전체 1개, 반조각 1개)
    → W 선택: dp[0][2] (전체 0개, 반조각 2개)
      → H 선택: dp[0][1] → H 선택: dp[0][0] = 1  (WWHH)
    → H 선택: dp[1][0] (전체 1개, 반조각 0개)
      → W 선택: dp[0][1] → H 선택: dp[0][0] = 1  (WHWH)

답: 2가지 (WWHH, WHWH)
```

**✅ 핵심**:
- W 선택: 전체 약 감소, 반조각 증가 (w-1, h+1)
- H 선택: 반조각만 감소 (w, h-1)
- 모든 경우를 재귀로 탐색하되, 메모이제이션으로 중복 방지

### 2️⃣ 메모이제이션 패턴

```cpp
ll Go(int w, int h)
{
    // 기저 사례
    if(w == 0 && h == 0)
        return 1;

    // 메모이제이션: 이미 계산된 값 재사용
    ll &ret = dp[w][h];
    if(ret) return ret;  // 0이 아니면 이미 계산됨

    // 상태 전이: 두 경우의 수를 더함
    if(w > 0) ret += Go(w - 1, h + 1);  // W 선택
    if(h > 0) ret += Go(w    , h - 1);  // H 선택

    return ret;
}
```

**✅ 핵심**:
- `ll &ret = dp[w][h]`: 레퍼런스로 직접 접근
- `if(ret)`: 0이 아니면 이미 계산된 값 (재사용)
- `ret +=`: 두 가지 선택의 경우의 수를 누적

### 3️⃣ long long 사용 이유

**문제:**
```
N=30일 때 답: 3,814,986,502,092,304

int 최대값: 2,147,483,647 (약 21억)

3,814,986,502,092,304 > 2,147,483,647
→ int 범위 초과!
```

**해결:**
```cpp
typedef long long ll;
ll dp[31][31];
```

**✅ 핵심**:
- N이 커질수록 경우의 수가 **기하급수적으로 증가**
- N=20일 때 이미 65억으로 int 범위 초과
- **N=30일 때, 3,814,986,502,092,304** → long long 필수!

### 4️⃣ DP 배열 초기화 불필요 (최적화)

```cpp
while(true)
{
    cin >> n;
    if(n == 0) break;

    // DP 배열 초기화 안 함! (이전 계산 재사용)
    cout << Go(n, 0) << "\n";
}
```

**왜 초기화하지 않아도 되나?**
```
예시:
테스트 1: n=6
  → dp[6][0], dp[5][1], ... 계산
테스트 2: n=1
  → dp[1][0] 계산 (이미 테스트 1에서 계산됨!)
  → 바로 재사용 가능
테스트 3: n=4
  → dp[4][0], dp[3][1], ... (일부는 재사용)
```

**✅ 핵심**:
- 작은 N의 결과는 큰 N을 계산할 때 이미 포함됨
- **전역 dp 배열을 계속 재사용** → 중복 계산 대폭 감소
- 이 최적화로 1000개 테스트 케이스도 빠르게 처리 가능!

### 5️⃣ 재귀 종료 조건

```cpp
if(w == 0 && h == 0)
    return 1;
```

**의미:**
- 전체 약도 없고 반조각도 없음
- 모든 약을 다 먹음 = 유효한 문자열 1개 완성
- 이 경로가 1가지 경우의 수에 해당

**잘못된 종료 조건:**
```cpp
❌ if(w == 0 || h == 0) return 1;
   → w만 0이고 h가 남아있으면? 계속 먹어야 함!

✅ if(w == 0 && h == 0) return 1;
   → 둘 다 0일 때만 완성
```

## 📊 예제 실행 흐름 (N=2)

### 📋 입력
```
2
```

### 🔄 재귀 호출 트리

```
Go(2, 0)
├─ W 선택 → Go(1, 1)
│  ├─ W 선택 → Go(0, 2)
│  │  └─ H 선택 → Go(0, 1)
│  │     └─ H 선택 → Go(0, 0) = 1  ✅ [WWHH]
│  └─ H 선택 → Go(1, 0)
│     └─ W 선택 → Go(0, 1)
│        └─ H 선택 → Go(0, 0) = 1  ✅ [WHWH]
└─ H 선택 → Go(2, -1) ❌ (불가능, h > 0 조건 위배)

답: 2
```

**✅ 핵심**:
- W를 먼저 선택해야 H가 생김
- H 선택은 w > 0일 때만 가능 (조건으로 자동 방지)
- 모든 유효한 경로의 수 = 2가지

## ⏱️ 시간복잡도

**O(N²)**
- 가능한 상태 개수: (w, h) 쌍 → 최대 31 × 31 = 961개
- 각 상태는 메모이제이션으로 **한 번만 계산**
- 각 상태에서 연산: O(1) (두 번의 재귀 호출만)
- N ≤ 30이므로 매우 빠름 (약 1,000번 미만 연산)
- 테스트 케이스 1,000개도 충분히 처리 가능

---

## 💾 공간복잡도

**O(N²)**
- `dp[31][31]`: DP 배열 → O(N²)
- 재귀 스택: 최대 깊이 w+h ≤ 2N → O(N)
- 전체: O(N²)

---

## 🚨 주의사항

1. **long long 필수**: N=20부터 int 범위 초과 (N=30은 약 3.8×10^15)
2. **메모이제이션 필수**: 없으면 중복 계산으로 시간 초과
3. **초기화 불필요**: 전역 dp 배열을 계속 재사용하여 최적화
4. **기저 사례**: w == 0 && h == 0일 때만 1 반환 (둘 다 0이어야 완성)
5. **상태 전이**: W 선택 시 (w-1, h+1), H 선택 시 (w, h-1)
6. **다중 테스트 케이스**: 0이 입력될 때까지 반복 (while문 사용)
