## 🤔 접근법

7569번과 동일한 **멀티 소스 BFS** 방식으로 풀었다.

3D → 2D로 단순화 : 층(H) 차원을 제거하고 **4방향** 탐색으로 변경했다.

---

## 🔄 7569번과의 차이점

| 항목 | 7576 (2D) | 7569 (3D) |
|------|-----------|-----------|
| 탐색 방향 | 4방향 (상하좌우) | 6방향 (상하좌우 + 위아래 층) |
| 방향 배열 | `dY[4]`, `dX[4]` | `dH[6]`, `dY[6]`, `dX[6]` |
| 배열 크기 | `arr[1001][1001]` | `arr[104][104][104]` |
| 큐 타입 | `pair<int,int>` | `tuple<int,int,int>` |
| 입력 변수 | `m, n` | `x, y, h` |
| 입력 루프 | 2중 for | 3중 for |
| 시간복잡도 | O(N × M) | O(N × M × H) |

---

## 🔑 핵심 구현

### 4방향 배열

```cpp
const int dY[4] = {-1,  1,  0,  0};
const int dX[4] = { 0,  0, -1,  1};
```

### 멀티 소스 BFS + visited 1-based

```cpp
queue<pair<int, int>> bfsQ;
// 초기 익은 토마토 모두 큐 삽입
if (arr[i][j] == 1) { visited[i][j] = 1; bfsQ.emplace(i, j); }

// BFS 확산
visited[ni][nj] = visited[ci][cj] + 1;

// 최종 출력 (visited 1-based이므로 -1)
cout << ans - 1 << "\n";
```

## ⏱️ 시간복잡도

**O(N × M)**
- 각 칸을 최대 1번씩만 방문 (BFS)
- N, M ≤ 1,000 → 최대 1,000,000번 연산

## 💾 공간복잡도

**O(N × M)**
- `arr[1001][1001]`: 토마토 배열
- `visited[1001][1001]`: 방문 체크 + 경과 일수
