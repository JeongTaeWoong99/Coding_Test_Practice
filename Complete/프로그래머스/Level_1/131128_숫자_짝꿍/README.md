## 🤔 접근법

두 문자열에서 **공통으로 등장하는 숫자**들만 모아 가장 큰 수를 만드는 문제다.

각 숫자(0~9)가 X, Y에 몇 개씩 들어있는지 카운트한 뒤, 숫자별로 `min(X개수, Y개수)`만큼만 짝꿍으로 사용할 수 있다. 가장 큰 수를 만들려면 **큰 자릿수(9)를 앞에, 작은 자릿수(0)를 뒤에** 배치해야 하므로 9부터 0까지 내림차순으로 채워 나간다.

마지막에 두 가지 예외만 처리하면 된다.

- 공통 숫자가 하나도 없으면 → `"-1"`
- 공통 숫자가 0뿐이면 (예 : `"00"`) → `"0"`

---

## 💡 정답 풀이 방법

**알고리즘**: 카운팅(개수 세기) + 그리디

```
1. cntX[10], cntY[10]을 0으로 초기화
2. X, Y를 순회하며 각 숫자 등장 횟수 카운트
3. d = 9 ~ 0 (내림차순):
   - pairCnt = min(cntX[d], cntY[d])
   - answer += 문자 d를 pairCnt개 이어 붙이기
4. answer가 비었으면 -> "-1"
5. answer 맨 앞이 '0'이면 (전부 0) -> "0"
6. 그 외 -> answer 반환
```

```cpp
for (int d = 9; d >= 0; d--)
{
    int pairCnt = min(cntX[d], cntY[d]); // 짝꿍으로 쓸 수 있는 개수 (적은 쪽 사용)

    answer += string(pairCnt, char('0' + d));
}
```

## 🔑 핵심 개념

### 1️⃣ min(개수)로 짝꿍 가능 개수 구하기

같은 숫자를 짝지으려면 양쪽에 모두 있어야 하므로, 사용 가능한 개수는 **둘 중 적은 쪽**으로 결정된다.

```cpp
int pairCnt = min(cntX[d], cntY[d]);
```

예) X에 `0`이 2개, Y에 `0`이 3개면 → 짝꿍으로 쓸 수 있는 `0`은 2개.

### 2️⃣ 9부터 채우면 자동으로 가장 큰 수

자릿수가 같을 때 큰 숫자가 앞에 올수록 수가 커진다. 9 → 0 순서로 이어 붙이면 별도 정렬 없이 가장 큰 수가 완성된다.

| 보유 짝꿍 | 만들어지는 수 |
|----------|--------------|
| 1×1개, 0×1개 | `"10"` |
| 0×2개 | `"00"` → `"0"` 보정 |

### 3️⃣ 0만 남는 경우 처리 — 맨 앞 문자 검사

9부터 내림차순으로 붙였으므로, 결과의 **맨 앞 문자가 `'0'`이라면 9~1이 전혀 없고 0만 모였다**는 뜻이다. 이때는 `"00..."` 대신 `"0"`을 반환한다.

```cpp
if (answer[0] == '0') // 9~1이 하나도 없음 = 0뿐
{
    return "0";
}
```

> ⚠️ `stoi`/`stoll`로 변환해 0을 떼는 방식은 자릿수가 길어지면 오버플로우가 발생하므로, **문자열 상태로 처리**하는 것이 안전하다.

## ⏱️ 시간복잡도

**O(N + M)** — N, M은 각각 X, Y의 길이. 두 문자열을 한 번씩 카운트하고 숫자 10개를 순회할 뿐이다.
