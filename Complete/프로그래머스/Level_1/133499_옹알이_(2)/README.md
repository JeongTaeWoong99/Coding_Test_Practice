## 🤔 접근법

발음 가능한 4개 단어(`"aya"`, `"ye"`, `"woo"`, `"ma"`)만으로 각 단어를 빈틈없이 분해할 수 있는지 검사하는 문자열 파싱 문제.

**(2)의 핵심 조건**: 같은 발음을 **연속해서 두 번** 할 수 없다. 따라서 직전에 사용한 발음(`prev`)을 기억해두고, 같은 발음이 바로 이어지면 매칭을 금지한다.

4개 발음은 서로 **접두사 관계가 없어** 한 위치에서 매칭되는 발음이 최대 1개뿐이므로, 앞에서부터 그리디하게 매칭해도 정답이 보장된다.

---

## 💡 정답 풀이 방법

**알고리즘**: 문자열 그리디 파싱

```
1. 각 단어를 앞에서부터 검사 (idx = 0, prev = "")
2. 현재 위치에서 4개 발음 중 하나와 일치하는지 시도
   a. 직전 발음(prev)과 같은 발음은 건너뜀 (연속 금지)
   b. 일치하면 idx를 발음 길이만큼 전진, prev 갱신
3. 어떤 발음과도 매칭 안 되면 발음 불가 → false
4. 끝까지 빈틈없이 매칭되면 발음 가능 → answer++
```

## 🔑 핵심 개념

### 1️⃣ 직전 발음 추적으로 연속 금지 처리

```cpp
for (string& s : sounds)
{
    if (s == prev) // 직전과 같은 발음은 연속 금지
    {
        continue;
    }

    if (word.compare(idx, s.size(), s) == 0)
    {
        idx += (int)s.size();
        prev    = s;
        matched = true;

        break;
    }
}
```

`prev`만 비교하면 되므로 별도의 복잡한 상태 관리가 필요 없다.

### 2️⃣ 그리디 매칭이 안전한 이유

`"aya"`, `"ye"`, `"woo"`, `"ma"` 는 서로 접두사가 겹치지 않는다. 즉 한 위치에서 동시에 두 발음에 매칭될 수 없으므로, 가장 먼저 찾은 발음을 바로 채택해도 백트래킹이 필요 없다.

### 3️⃣ `string::compare`로 부분 일치 검사

```cpp
word.compare(idx, s.size(), s) == 0
```

`idx` 위치부터 `s.size()` 길이만큼 잘라 `s`와 비교 → 일치 시 0 반환. `substr` 생성 없이 비교 가능해 간결하다.

## ⏱️ 시간복잡도

**O(N × L)**
- N: 단어 개수
- L: 단어 하나의 길이 (각 위치에서 발음 4개를 상수 번 비교)
