## 🤔 접근법

재료가 아래에서부터 순서대로 쌓일 때, **빵-야채-고기-빵(`1-2-3-1`)** 이 연속으로 4개 쌓이면 햄버거 1개가 완성되어 빠져나간다. 빠져나간 자리는 메워지므로, 그 위·아래 재료가 새로 맞붙어 또 다른 햄버거가 완성될 수도 있다.

```
[2, 1, 1, 2, 3, 1, 2, 3, 1]
        └ 1,2,3,1 ┘ 완성! → 제거하면 남은 [2,1]과 뒤쪽이 붙어
[2, 1,            2, 3, 1]
    └  1,2,3,1  ┘ 또 완성!  → 총 2개
```

이렇게 "맨 위 일부를 보고 조건이 맞으면 빼낸다"는 동작은 **스택**으로 정확히 표현된다. 재료를 하나씩 쌓고, 쌓을 때마다 스택 맨 위 4개가 `1-2-3-1`인지 검사해 맞으면 4개를 제거하고 카운트한다.

> **⚠️ 흔한 오답**: `count`를 1→2→3→4로 순차 증가시키며 세는 방식은 제거 후 재료가 다시 맞붙는 경우를 놓친다. 위 예제에서 정답은 2지만 이 방식은 1을 반환한다. 반드시 스택으로 풀어야 한다.

## 💡 풀이 방법 — 스택

**알고리즘**: 스택

`stk` 벡터에 재료를 쌓고, 맨 위 4개가 `1-2-3-1`이면 `resize`로 4개를 잘라낸다.

```
1. 재료 cur를 stk에 push
2. totalSize = stk 크기
3. totalSize >= 4 이고 stk 맨 위 4개가 1-2-3-1이면
   - stk를 totalSize-4 크기로 줄이기 (위에서부터 4개 제거)
   - answer++
```

```cpp
stk.emplace_back(cur);

int totalSize = stk.size();

if (totalSize >= 4 && stk[totalSize - 4] == 1 && stk[totalSize - 3] == 2 && stk[totalSize - 2] == 3 && stk[totalSize - 1] == 1)
{
    stk.resize(totalSize - 4); // 위에서부터 4개를 잘라내 햄버거 재료 제거

    answer++;
}
```

## 🖥️ `resize`로 스택 위에서부터 4개 제거 — 시각화

스택의 맨 위 4개가 `1-2-3-1`로 완성되면, 그 4개를 빼내야 한다. 원칙대로라면 `pop_back()`을 **4번** 호출해야 하지만, 그러면 코드가 길어진다. 대신 `resize(totalSize - 4)` **한 줄**로 끝의 4칸을 한 번에 잘라낸다.

벡터의 **끝(뒤쪽)이 곧 스택의 맨 위**이므로, `resize`로 뒤에서 4개를 줄이면 결과적으로 **스택 위에서부터 4개가 사라진다.**

```
stk = [2, 1, 1, 2, 3, 1]   (totalSize = 6, 맨 위 4개가 1-2-3-1 → 완성!)

  index :  0   1   2   3   4   5
         ┌───┬───┬───┬───┬───┬───┐
   재료  │ 2 │ 1 │ 1 │ 2 │ 3 │ 1 │   ← 위(뒤)
         └───┴───┴───┴───┴───┴───┘
          남길 것  └─ 맨 위 4개 ─┘
          (앞 2개)   1   2   3   1
                       ✂️ resize(6 - 4)

                    │
                    ▼  뒤에서 4칸을 한 번에 잘라냄

  index :  0   1
         ┌───┬───┐
   재료  │ 2 │ 1 │   ← 남은 2개 (totalSize = 2)
         └───┴───┘
```

| 방식 | 코드 | 호출 횟수 |
|------|------|----------|
| 원칙적 pop | `stk.pop_back();` ×4 | 4줄 |
| resize 한 줄 | `stk.resize(totalSize - 4);` | 1줄 ✅ |

> **📝 핵심**: `resize`로 줄어드는 쪽은 항상 **벡터의 뒤쪽 = 스택의 맨 위**다. 그래서 `pop_back` 4번과 결과가 완전히 같으면서도 코드는 한 줄로 끝난다.

## 🔑 핵심 개념

### 1️⃣ 맨 위 4개만 검사 — 스택의 부분 패턴 매칭

햄버거 완성 조건은 항상 **스택 맨 위 연속 4개**로만 결정된다. 따라서 매번 전체를 훑지 않고 `totalSize-4 ~ totalSize-1` 네 칸만 확인하면 된다.

```cpp
stk[totalSize - 4] == 1 && stk[totalSize - 3] == 2 && stk[totalSize - 2] == 3 && stk[totalSize - 1] == 1
```

### 2️⃣ 제거 후 재결합 — 스택이어야 하는 이유

`1-2-3-1`을 빼내면 그 아래 재료와 위 재료가 새로 인접한다. 스택은 pop 즉시 새 맨 위가 드러나므로, 다음 push에서 곧바로 재결합된 패턴을 검사할 수 있다. 단순 카운트 방식이 틀리는 핵심 지점이 바로 이 "재결합"이다.

## ⏱️ 시간복잡도

**O(N)** — N은 `ingredient`의 길이.

각 재료는 정확히 한 번 push되고, 햄버거로 완성될 때 한 번 제거된다 → 총 연산은 N에 비례한다.
