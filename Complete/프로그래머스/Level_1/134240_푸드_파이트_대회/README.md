## 🤔 접근법

두 선수가 양쪽 끝에서 같은 종류·같은 양의 음식을 같은 순서로 먹어 들어와 가운데서 물을 함께 먹는 대회이므로, 결과 문자열은 **가운데 물(`food[0]`)을 기준으로 좌우 대칭(팰린드롬)** 구조여야 한다.

각 음식은 양쪽에 절반(`food[i] / 2`)씩만 공평하게 나눠줄 수 있다(홀수 개라면 1개는 버려짐). 

따라서 1번 음식부터 순서대로 `food[i] / 2`개씩 이어 붙여 왼쪽 절반을 만들고, 가운데에 물을 채운 뒤, 왼쪽 절반을 그대로 뒤집어 오른쪽에 붙이면 정답이 완성된다.

---

## 💡 정답 풀이 방법

**알고리즘**: 구현 (대칭 문자열 생성)

```
1. left = "" 로 시작
2. i = 1 ~ food.size()-1 순회하며 left += string(food[i] / 2, '0' + i)
3. mid = string(food[0], '0')   (가운데 물)
4. right = left를 reverse()로 뒤집은 문자열
5. left + mid + right 반환
```

## 🔑 핵심 개념

### 1️⃣ string(count, char) 생성자 — 문자 반복으로 문자열 생성

`std::string`에는 **같은 문자를 N번 반복한 문자열**을 한 번에 만들어주는 생성자가 있다. 반복문 없이 "문자 하나를 N개 채워 넣기"를 한 줄로 처리할 수 있어 매우 자주 쓰이는 패턴이다.

```cpp
string(size_t count, char ch);   // ch를 count번 반복한 문자열 생성
```

| 표현 | 결과 |
|------|------|
| `string(3, 'a')` | `"aaa"` |
| `string(food[i] / 2, '0' + i)` | 문자 `'0' + i` 를 `food[i] / 2`번 반복 |
| `string(food[0], '0')` | 문자 `'0'` 를 `food[0]`번 반복 |

```cpp
left += string(food[i] / 2, '0' + i); // i번 음식을 (개수/2)개만큼 이어 붙이기
string mid = string(food[0], '0');    // 물을 food[0]개만큼 채우기
```

### 2️⃣ '0' + i — 문자에 정수를 더해 숫자 문자 만들기

`'0'`은 아스키 코드로 48이며, 여기에 정수 `i`를 더하면 숫자 `i`에 해당하는 **문자**가 된다.

- `i = 1` → `'0' + 1` → `'1'`
- `i = 2` → `'0' + 2` → `'2'`
- `i = 3` → `'0' + 3` → `'3'`

즉 `'0' + i`는 "정수 i를 그 숫자를 나타내는 문자로 변환"하는 관용적인 문자 연산 표현이다.

### 3️⃣ 대칭 구조 — 절반만 만들고 뒤집어서 재사용

전체 문자열이 가운데(물)를 기준으로 좌우 대칭이므로, 오른쪽 절반을 따로 계산할 필요 없이 왼쪽 절반을 복사해 `reverse()`로 뒤집기만 하면 된다.

```cpp
string right = left;                       // 왼쪽 절반 복사
reverse(right.begin(), right.end());       // 뒤집어서 대칭 완성
```

## ⏱️ 시간복잡도

**O(N)** — N은 결과 문자열의 길이(food 원소 합 수준). 각 음식을 정해진 개수만큼 한 번씩만 이어 붙이고, 뒤집기 또한 문자열 길이에 비례한다.
