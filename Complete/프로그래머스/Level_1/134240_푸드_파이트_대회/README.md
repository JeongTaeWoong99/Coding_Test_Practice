## 🤔 접근법

두 선수가 양쪽 끝에서 같은 종류·같은 양의 음식을 같은 순서로 먹어 들어와 가운데서 물을 함께 먹는 대회이므로, 결과 문자열은 **가운데 물(`food[0]`)을 기준으로 좌우 대칭(팰린드롬)** 구조여야 한다.

각 음식은 양쪽에 절반(`food[i] / 2`)씩만 공평하게 나눠줄 수 있다(홀수 개라면 1개는 버려짐). 

따라서 1번 음식부터 순서대로 `food[i] / 2`개씩 이어 붙여 왼쪽 절반을 만들고, 가운데에 물을 채운 뒤, 왼쪽 절반을 그대로 뒤집어 오른쪽에 붙이면 정답이 완성된다.

---

## 💡 풀이 방법 1 — string(count, char) 생성자 활용

**알고리즘**: 구현 (대칭 문자열 생성)

```
1. left = "" 로 시작
2. i = 1 ~ food.size()-1 순회하며 left += string(food[i] / 2, '0' + i)
3. mid = "0"   (food[0]은 항상 1이므로 고정값)
4. right = left를 reverse()로 뒤집은 문자열
5. left + mid + right 반환
```

```cpp
for (int i = 1; i < (int)food.size(); i++)
{
    left += string(food[i] / 2, '0' + i); // i번 음식을 (개수/2)개만큼 한 번에 이어 붙이기
}
```

## 💡 풀이 방법 2 — 2중 for문

`string(count, char)` 생성자 없이, 같은 동작을 반복문으로 직접 풀어 쓴 버전. 바깥쪽 루프로 음식 종류를, 안쪽 루프로 절반 개수만큼 한 글자씩 채운다.

```
1. left = "" 로 시작
2. i = 1 ~ food.size()-1 순회
   - foodChar = '0' + i
   - j = 0 ~ food[i]/2-1 만큼 left += foodChar (한 글자씩)
3. mid = "0"   (food[0]은 항상 1이므로 고정값)
4. right = left를 reverse()로 뒤집은 문자열
5. left + mid + right 반환
```

```cpp
for (int i = 1; i < (int)food.size(); i++)
{
    char foodChar = '0' + i;

    for (int j = 0; j < food[i] / 2; j++)
    {
        left += foodChar; // 한 글자씩 채우기 = string(count, char)를 직접 풀어 쓴 것
    }
}
```

## 🔑 핵심 개념

### 1️⃣ string(count, char) 생성자 — 문자 반복으로 문자열 생성

`std::string`에는 **같은 문자를 N번 반복한 문자열**을 한 번에 만들어주는 생성자가 있다. 반복문 없이 "문자 하나를 N개 채워 넣기"를 한 줄로 처리할 수 있어 매우 자주 쓰이는 패턴이다.

```cpp
string(size_t count, char ch);   // ch를 count번 반복한 문자열 생성
```

| 표현 | 결과 |
|------|------|
| `string(3, 'a')` | `"aaa"` |
| `string(food[i] / 2, '0' + i)` | 문자 `'0' + i` 를 `food[i] / 2`번 반복 |

풀이 방법 2의 안쪽 `for`문(`for (int j = 0; j < food[i] / 2; j++) left += foodChar;`)이 바로 이 생성자가 내부적으로 하는 일을 그대로 풀어 쓴 것이다.

### 2️⃣ '0' + i — 문자에 정수를 더해 숫자 문자 만들기

`'0'`은 아스키 코드로 48이며, 여기에 정수 `i`를 더하면 숫자 `i`에 해당하는 **문자**가 된다.

- `i = 1` → `'0' + 1` → `'1'`
- `i = 2` → `'0' + 2` → `'2'`
- `i = 3` → `'0' + 3` → `'3'`

즉 `'0' + i`는 "정수 i를 그 숫자를 나타내는 문자로 변환"하는 관용적인 문자 연산 표현이다.

### 3️⃣ food[0]은 항상 1 — 제한사항을 읽고 식을 단순화하기

제한사항에 **"`food[0]`은 수웅이가 준비한 물의 양이며, 항상 1입니다"** 라고 명시되어 있다. 즉 `food[0]`은 사실상 상수 1이므로, `string(food[0], '0')`이나 `food[0]`번 반복하는 루프 대신 다음과 같이 바로 적어도 결과가 완전히 같다.

```cpp
string mid = "0"; // food[0]은 항상 1 → 매번 "0" 한 글자
```

`food[0]`을 그대로 사용하면 "왜 0이 들어가는지"를 코드가 더 잘 설명해주지만, 제한사항에 고정값으로 박혀있는 만큼 `"0"`으로 단순화하는 쪽이 더 간결하다.

### 4️⃣ 대칭 구조 — 절반만 만들고 뒤집어서 재사용

전체 문자열이 가운데(물)를 기준으로 좌우 대칭이므로, 오른쪽 절반을 따로 계산할 필요 없이 왼쪽 절반을 복사해 `reverse()`로 뒤집기만 하면 된다.

```cpp
string right = left;                       // 왼쪽 절반 복사
reverse(right.begin(), right.end());       // 뒤집어서 대칭 완성
```

## ⏱️ 시간복잡도

**O(N)** — N은 결과 문자열의 길이(food 원소 합 수준). 두 풀이 모두 각 음식을 정해진 개수만큼 한 번씩만 채우고, 뒤집기 또한 문자열 길이에 비례한다. (`string(count, char)` 생성자나 2중 `for`문이나 내부적으로 문자를 채우는 횟수는 동일하다.)
