## 🤔 접근법

매일 한 명의 점수를 받아 명예의 전당(상위 k개)을 유지하며, 그 날의 명예의 전당 최솟값(k번째 최고 점수)을 기록하는 문제.

**핵심**: min-heap을 크기 k로 유지하면, `top()`이 항상 "상위 k개 중 최솟값" = "k번째 최고 점수"가 된다.

---

## 💡 정답 풀이 방법

**알고리즘**: Min-Heap (우선순위 큐)

```
1. 점수를 min-heap에 push
2. heap 크기가 k 초과 시 → pop() (최솟값 제거 → 상위 k개 유지)
3. top() = 상위 k개 중 최솟값 = k번째 최고 점수 → answer에 추가
```

---

## 🔑 핵심 개념

### 1️⃣ Min-Heap으로 Top-K 유지

min-heap을 k개로 유지하면, 상위 k개에 들지 못하는 값(최솟값보다 작은 값)은 즉시 제거된다.

```
k=3, score=[10, 100, 20, 150, 1, 60]

Day1: push(10)   → heap:{10}          top()=10
Day2: push(100)  → heap:{10,100}      top()=10
Day3: push(20)   → heap:{10,20,100}   top()=10  (size==k, pop 없음)
Day4: push(150)  → size=4>3, pop(10) → heap:{20,100,150}  top()=20
Day5: push(1)    → size=4>3, pop(1)  → heap:{20,100,150}  top()=20  (1이 너무 작아 바로 제거)
Day6: push(60)   → size=4>3, pop(20) → heap:{60,100,150}  top()=60
```

### 2️⃣ top()은 항상 최솟값

min-heap에서 `top()`은 루트 = 최솟값. `pop()`도 최솟값을 제거한다.

- `size < k` 구간: 전체 원소의 최솟값 = 명예의 전당 하한선 ✅
- `size == k` 구간: 상위 k개의 최솟값 = k번째 최고 점수 ✅

→ 두 케이스 모두 분기 없이 `top()`으로 해결.

---

## ⏱️ 시간복잡도

**O(n log k)**
- n: score 길이 (최대 1,000)
- push/pop: O(log k) (heap 크기 k 유지)
