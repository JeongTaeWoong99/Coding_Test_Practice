## 🤔 접근법

문자열을 순회하며 각 문자의 **마지막 등장 위치**를 추적하면, 현재 위치와의 차이가 곧 가장 가까운 같은 글자까지의 거리가 된다.

알파벳은 26개로 고정이므로 `int a[26]` 배열에 각 문자의 직전 위치를 기록하고, `-1`이면 처음 등장, 그 외엔 `i - a[c]`를 push한 뒤 위치를 갱신한다.

---

## 💡 정답 풀이 방법

**알고리즘**: 배열(해시) + 구현

```
1. a[26]을 -1로 초기화
2. s[i] 순회:
   a. a[s[i]-'a'] == -1 → 처음 등장 → answer에 -1 push
   b. 그 외 → answer에 (i - a[s[i]-'a']) push
   c. a[s[i]-'a'] = i (위치 갱신)
3. answer 반환
```

---

## 🔑 핵심 개념

### 1️⃣ 알파벳 배열로 직전 위치 추적

```cpp
int a[26];
fill_n(a, 26, -1);

// 처음 나온 경우
if (a[s[i] - 'a'] == -1)
    answer.push_back(-1);
// 이후 등장
else
    answer.push_back(i - a[s[i] - 'a']);

a[s[i] - 'a'] = i;
```

map 없이 크기 26 배열만으로 O(1) 조회·갱신 가능.

---

## ⏱️ 시간복잡도

**O(n)** — n: 문자열 길이
