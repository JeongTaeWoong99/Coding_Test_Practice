## 🤔 접근법

t에서 p 길이만큼의 부분 문자열을 슬라이딩하며 p 이하인 경우를 카운트하는 구현 문제.

처음에는 `stoi()`로 숫자 변환 후 비교를 시도했으나, p의 길이가 최대 18자리이므로 `int` 범위를 초과해 오버플로우가 발생한다.  
두 문자열이 **같은 자릿수**이므로 숫자 변환 없이 문자열 직접 비교로 해결할 수 있다.

---

## 💡 정답 풀이 방법

**알고리즘**: 슬라이딩 윈도우 + 문자열 비교

```
1. 슬라이딩 윈도우로 t에서 p 길이만큼의 부분 문자열을 추출
2. 부분 문자열 <= p 이면 answer++
3. answer 반환
```

## 🔑 핵심 개념

### 1️⃣ stoi() 대신 문자열 직접 비교

**잘못된 코드 (오버플로우 발생)**

```cpp
int checkNum = stoi(p);
int a = stoi(t.substr(i, pLength));
if (a <= checkNum)  // p가 10자리 초과 시 int 오버플로우
```

`stoi()`는 `int`를 반환하므로 최대 약 21억(10자리)까지만 처리 가능.  
p의 길이는 최대 **18자리**이므로 범위 초과 → 오버플로우.

**올바른 코드 (문자열 비교)**

```cpp
if (t.substr(i, pLength) <= p)
```

두 문자열의 **자릿수가 동일**하면 사전순(lexicographic) 비교 = 숫자 크기 비교가 성립한다.  
같은 자릿수에서는 자리값이 높은 앞자리부터 비교하므로 수치 비교와 완전히 동일하게 동작한다.

## ⚠️ 주의 사항

| 비교 방식 | 처리 가능 자릿수 | 문제 |
|-----------|-----------------|------|
| `stoi()` | ~10자리 (int 최대) | 18자리 입력 시 오버플로우 |
| `stoll()` | ~19자리 (long long 최대) | 경계값에서 여전히 위험 |
| **문자열 비교** | **제한 없음** | **없음 (권장)** |

---

## ⏱️ 시간복잡도

**O(|t| × |p|)** — `substr()` 생성이 O(|p|)이고 `|t| - |p|`번 반복
