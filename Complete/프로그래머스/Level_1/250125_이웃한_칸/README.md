---

## 🤔 접근법

n×n 보드에서 특정 칸 `(r, c)`의 색과 **상하좌우 4방향 이웃 칸**의 색이 같은 칸의 수를 세는 배열 탐색 문제.

**핵심**:
- 4방향 델타 배열(`dr`, `dc`)을 이용해 이웃 좌표를 구하고
- 범위를 벗어나는 칸은 건너뛴 뒤 색이 같으면 카운트 증가

---

## 💡 정답 풀이 방법

**알고리즘**: 구현 / 배열 탐색

```
1. color = board[r][c] 저장
2. 4방향(상하좌우) 순회:
   a. nr = r + dr[i], nc = c + dc[i]
   b. 범위 밖이면 skip
   c. board[nr][nc] == color이면 answer++
3. answer 반환
```

---

## 🔑 핵심 개념

### 1️⃣ 4방향 델타 배열

```cpp
int dr[] = {-1, 1, 0, 0};
int dc[] = {0, 0, -1, 1};
```

상(-1,0) / 하(+1,0) / 좌(0,-1) / 우(0,+1) 순서로 정의.

### 2️⃣ 경계 검사

```cpp
if (nr < 0 || nr >= n || nc < 0 || nc >= n) continue;
```

보드가 n×n이므로 행과 열 모두 `[0, n)` 범위를 벗어나면 skip.

---

## ⏱️ 시간복잡도

**O(1)** — 항상 4방향만 확인하므로 보드 크기에 무관
