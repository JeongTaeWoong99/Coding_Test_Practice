## 🤔 접근법

n×n 정사각형 돗자리를 공원(`park`)에 놓을 수 있는지 확인하여, 가능한 가장 큰 돗자리 크기를 반환하는 문제.

**핵심**: `park[i][j] == "-1"` 인 영역만 사용 가능. `mats`를 내림차순 정렬하면 조건을 만족하는 첫 번째 값이 곧 정답이므로 즉시 리턴 가능.

---

## 💡 풀이 방법 1 — 브루트포스

**알고리즘**: 완전 탐색

```
1. mats 내림차순 정렬 (큰 것부터 확인)
2. 각 mat 크기 n에 대해 park의 모든 (r, c)를 시작점으로 확인
3. n×n 범위 전체가 "-1" 이면 즉시 n 리턴
4. 모두 불가능하면 -1 리턴
```

---

## 💡 풀이 방법 2 — 최대 정사각형 DP

**알고리즘**: 2D DP (최대 정사각형)

```
1. dp[i][j]: (i, j)를 우하단으로 하는 최대 빈 정사각형 크기 계산
   - park[i][j] != "-1" → dp[i][j] = 0 (skip)
   - 첫 행/열 → dp[i][j] = 1
   - 그 외 → min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
2. park 전체 순회 → maxSide 계산
3. mats 내림차순 정렬 후, n ≤ maxSide인 첫 번째 값 리턴
```

---

## 🔑 핵심 개념

### 1️⃣ 내림차순 정렬로 즉시 리턴

큰 mat부터 확인하므로, 조건을 만족하는 첫 번째 값이 곧 정답.

```cpp
sort(mats.rbegin(), mats.rend());
for (int curNum : mats)
    if (curNum <= maxSide) return curNum;
```

### 2️⃣ 최대 정사각형 DP 점화식

```
dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
```

세 방향의 최소값 + 1 → (i, j)를 우하단으로 하는 최대 정사각형 크기.

```
예시 (모두 "-1"인 3×3):

dp:  1  1  1
     1  2  2
     1  2  3   ← dp[2][2] = min(2, 2, 2) + 1 = 3
```

## ⏱️ 시간복잡도

| 방법 | 시간복잡도 |
|------|-----------|
| 브루트포스 | O(\|mats\| × rows × cols × n²) |
| 최대 정사각형 DP | O(rows × cols + \|mats\| log \|mats\|) |
