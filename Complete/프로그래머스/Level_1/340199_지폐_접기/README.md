## 🤔 접근법

지폐(bill)를 지갑(wallet)에 넣을 수 있을 때까지 반으로 접는 최소 횟수를 구하는 문제.

**핵심**: 지폐는 회전 가능(가로/세로 교체)하므로 두 방향 중 하나라도 들어가면 OK. 매번 긴 변을 반으로 접는 그리디 전략이 최소 횟수를 보장한다.

---

## 💡 정답 풀이 방법

**알고리즘**: 그리디 시뮬레이션

```
1. 지폐가 지갑에 들어가는지 확인 (회전 고려, 두 방향 OR 조건)
2. 안 들어가면 긴 변을 /2로 접기
3. 들어갈 때까지 반복, 횟수 카운트
```

---

## 🔑 핵심 개념

### 1️⃣ 회전을 고려한 fit 조건

가로/세로를 바꾼 두 방향 중 하나라도 들어가면 성공으로 판정.

```cpp
if ((bill[0] <= wallet[0] && bill[1] <= wallet[1]) ||
    (bill[0] <= wallet[1] && bill[1] <= wallet[0]))
```

### 2️⃣ 긴 변 우선 접기 (그리디)

짧은 변을 먼저 접으면 손해이므로, 항상 긴 변을 절반으로 줄인다.

```cpp
if (bill[0] >= bill[1])
{
    bill[0] /= 2;
}
else
{
    bill[1] /= 2;
}
```

---

## ⏱️ 시간복잡도

**O(log(max(bill)))** — 긴 변이 절반씩 줄어들며 지갑 크기 이하가 될 때까지 반복
