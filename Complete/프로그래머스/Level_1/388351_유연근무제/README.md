## 🤔 접근법

7일간의 출근 기록에서 **토/일을 제외한 모든 평일**에 `출근 희망 시각 + 10분` 이내로 출근한 직원 수를 세는 문제.

**핵심**: 시간이 HHMM 정수로 주어지므로 분 단위로 변환해야 `+10분` 계산이 정확하다.  
→ `950 + 10 = 960`이 아니라 `9:50 → 590분 + 10 = 600분 → 10:00`이 되어야 함.

---

## 💡 정답 풀이 방법

**알고리즘**: 브루트포스 시뮬레이션

```
1. 각 직원마다:
   a. limitTime = ToMinutes(schedules[i]) + 10  (분 단위 마감 시각)
   b. 7일 순회하며 요일 계산 → 토(6)/일(7)이면 스킵
   c. 평일에 ToMinutes(timelogs[i][j]) > limitTime 이면 탈락
   d. 모든 평일 통과 시 answer++
```

## 🔑 핵심 개념

### 1️⃣ HHMM → 분 단위 변환

```cpp
int ToMinutes(int hhmm)
{
    return (hhmm / 100) * 60 + (hhmm % 100);
}
```

`hhmm / 100`으로 시(hour) 추출, `hhmm % 100`으로 분(minute) 추출.

```
ToMinutes(950)  = 9*60 + 50 = 590
ToMinutes(1013) = 10*60 + 13 = 613
```

### 2️⃣ 요일 계산 공식

```cpp
int dayOfWeek = (startday - 1 + j) % 7 + 1;   // 1=월 ~ 7=일
```

`startday`가 1-indexed이므로 -1로 0-indexed 변환 후 mod 7, 다시 +1 복원.

```
startday=5(금), j=0 → (4+0)%7+1 = 5  (금)
startday=5(금), j=1 → (4+1)%7+1 = 6  (토) → 스킵
startday=5(금), j=2 → (4+2)%7+1 = 7  (일) → 스킵
startday=5(금), j=3 → (4+3)%7+1 = 1  (월)
```

## 📊 테스트케이스 추적

### 👔 케이스 2 — `startday=1(월)`, `schedules=[730, 855, 700, 720]` → 2

**평일 인덱스**: j=0(월), j=1(화), j=2(수), j=3(목), j=4(금)

```
직원0 (730 → limitTime=460분=7:40):
  j=0: 710 → 430분 ≤ 460 ✅ | j=1: 700 → 420분 ≤ 460 ✅
  j=2: 650 → 410분 ≤ 460 ✅ | j=3: 735 → 455분 ≤ 460 ✅
  j=4: 700 → 420분 ≤ 460 ✅  → 정상 출근 ✅

직원1 (855 → limitTime=545분=9:05):
  j=0: 908 → 548분 > 545 ❌  → 탈락

직원2 (700 → limitTime=430분=7:10):
  j=0: 705 → 425분 ≤ 430 ✅ | j=4: 710 → 430분 ≤ 430 ✅ (경계!)
  모두 통과  → 정상 출근 ✅

직원3 (720 → limitTime=450분=7:30):
  j=1: 731 → 451분 > 450 ❌  → 탈락

→ answer = 2 ✅
```
