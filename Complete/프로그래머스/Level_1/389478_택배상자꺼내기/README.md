## 🤔 접근법

n개의 박스가 너비 w인 창고에 **뱀 패턴(짝수 행 L→R, 홀수 행 R→L)**으로 쌓여 있을 때,  
num번 박스를 꺼내기 위해 치워야 하는 박스 총 수(num 자신 포함)를 구하는 문제.

**핵심**: num의 행·열 위치를 수학 공식으로 직접 계산한 뒤, 같은 열의 위쪽 박스를 순서대로 세면 된다.  
→ 2D 배열을 실제로 채울 필요 없이 O(1) 공간으로 해결 가능.

---

## 💡 정답 풀이 방법

**알고리즘**: 수학 공식 (배열 없이 직접 계산)

```
1. num의 행(row)       = (num - 1) / w
2. num의 행 내 위치    = (num - 1) % w       ← posInRow, 항상 왼쪽부터 0-indexed
3. num의 실제 열(col)  → 짝수 행: posInRow 그대로
                          홀수 행: w - 1 - posInRow  (좌우 반전)
4. 전체 행 수          = (n + w - 1) / w      ← ⌈n/w⌉ 올림 나눗셈
5. row+1 ~ totalRows-1 행의 col 위치 박스 번호 계산 → n 이하이면 카운트
```

---

## 🔑 핵심 개념

### 1️⃣ posInRow vs col 구분

`posInRow = (num-1) % w` 는 **"이 행의 시작부터 몇 번째?"** 를 0-indexed로 나타낸다.  
그러나 홀수 행은 **오른쪽에서부터** 채워지므로, posInRow=0 이면 실제 열은 맨 오른쪽(col=w-1).  
→ 홀수 행에서는 `col = w - 1 - posInRow` 로 좌우 반전이 필요하다.

```
예시 (w=4):
            col:  0    1    2    3
 row 1 (R→L): [8]  [7]  [6]  [5]
 posInRow:     3    2    1    0    ← (num-1)%w

 box5: posInRow = (5-1)%4 = 0 → col = 4-1-0 = 3  ✅ (맨 오른쪽)
 box6: posInRow = (6-1)%4 = 1 → col = 4-1-1 = 2  ✅
 box8: posInRow = (8-1)%4 = 3 → col = 4-1-3 = 0  ✅ (맨 왼쪽)
```

### 2️⃣ 특정 행·열의 박스 번호 계산

```
r번째 행의 col 위치에 있는 박스 번호:
 짝수 행(L→R): r*w + col + 1    ← 행 시작(r*w+1)에서 col칸 오른쪽
 홀수 행(R→L): r*w + (w - col)  ← col=0이 끝(r*w+w), col=w-1이 시작(r*w+1)
```

### 3️⃣ 올림 나눗셈으로 전체 행 수

```
totalRows = (n + w - 1) / w   ← ⌈n/w⌉, 정수 나눗셈으로 구현
예: n=11, w=4 → (11+3)/4 = 14/4 = 3 행
```

## 📊 테스트케이스 추적

### 📦 케이스 1 — `n=12, w=4, num=3` → 3

**그리드:**
```
           col:  0    1    2    3
row 2 (L→R): [ 9] [10] [11] [12]
row 1 (R→L): [ 8] [ 7] [ 6] [ 5]
row 0 (L→R): [ 1] [ 2] [*3] [ 4]   ← num=3
```

**단계별 계산:**
```
row       = (3-1) / 4 = 0
posInRow  = (3-1) % 4 = 2
col       = posInRow  = 2    (짝수 행이므로 그대로)
totalRows = (12+3) / 4 = 3

row 1 (홀수): boxNum = 1*4 + (4-2) = 6   ≤ 12 ✅ → answer = 2
row 2 (짝수): boxNum = 2*4 + 2 + 1 = 11  ≤ 12 ✅ → answer = 3
```

**결과**: num=3(자신) + box6 + box11 = **3**

---

### 📦 케이스 2 — `n=11, w=4, num=9` → 1

**그리드:**
```
           col:  0    1    2    3
row 2 (L→R): [*9] [10] [11] [ _]   ← num=9, col 3은 n=11 초과라 없음
row 1 (R→L): [ 8] [ 7] [ 6] [ 5]
row 0 (L→R): [ 1] [ 2] [ 3] [ 4]
```

**단계별 계산:**
```
row       = (9-1) / 4 = 2
posInRow  = (9-1) % 4 = 0
col       = posInRow  = 0    (짝수 행이므로 그대로)
totalRows = (11+3) / 4 = 3   → row 2가 마지막 행

위쪽 행 없음 → answer = 1
```

**결과**: num=9 자신만 = **1**
