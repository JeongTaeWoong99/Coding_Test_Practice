## 🤔 접근법

여러 장의 명함을 모두 담을 수 있는 **가장 작은 지갑(직사각형)의 넓이**를 구하는 문제.
핵심은 각 명함을 **회전시켜 눕힐 수 있다**는 점이다.

명함마다 `[가로, 세로]`가 주어지지만 회전이 가능하므로, **긴 변과 짧은 변**으로 구분할 수 있다.
모든 명함의 **긴 변은 한쪽 축(A)으로, 짧은 변은 다른 쪽 축(B)으로** 방향을 통일해 몰아넣는다.

이렇게 정렬하면 지갑의 두 변은 각각
- 한 변 = 모든 명함의 **긴 변 중 최댓값**
- 다른 변 = 모든 명함의 **짧은 변 중 최댓값**

으로 정해지고, 이 둘을 곱한 값이 곧 최소 지갑 넓이가 된다.

---

## 💡 정답 풀이 방법

**알고리즘**: 완전 탐색 (한 번 순회하며 두 축의 최댓값 갱신)

```
1. maxA = 0 (긴 변들의 최댓값), maxB = 0 (짧은 변들의 최댓값)
2. 각 명함 card에 대해:
   a. longSide  = max(card[0], card[1])  (긴 변)
   b. shortSide = min(card[0], card[1])  (짧은 변)
   c. maxA = max(maxA, longSide)
   d. maxB = max(maxB, shortSide)
3. maxA * maxB 반환
```

```cpp
for (auto& card : sizes)
{
    int longSide  = max(card[0], card[1]);
    int shortSide = min(card[0], card[1]);

    maxA = max(maxA, longSide);
    maxB = max(maxB, shortSide);
}

return maxA * maxB;
```

## 🔑 핵심 개념

### 1️⃣ 회전 = 긴 변/짧은 변으로 통일

명함을 돌릴 수 있으므로 `[가로, 세로]`의 순서는 의미가 없다.
`max`로 긴 변을, `min`으로 짧은 변을 뽑아 **모든 명함의 방향을 같게 맞추는 것**이 이 문제의 전부다.
방향을 통일해야 두 축의 최댓값이 각각 최소가 된다.

### 2️⃣ 왜 각 축의 최댓값을 곱하면 최소인가

지갑은 가장 큰 명함까지 담아야 하므로, 각 축의 길이는 그 축에 놓인 변들의 **최댓값 이상**이어야 한다.
긴 변끼리·짧은 변끼리 같은 축에 모으면 두 축의 최댓값이 각각 최소화된다.

만약 어떤 명함만 회전을 안 해서 긴 변이 B축으로 넘어가면, B축 최댓값만 더 커져 넓이가 손해다.
따라서 방향을 통일한 `maxA * maxB`가 항상 최소 넓이다.

### 3️⃣ 정렬 없이 O(n) 순회로 충분

별도의 정렬이나 배열 저장 없이, 명함을 한 번 훑으며 `maxA`, `maxB`만 갱신하면 된다.
각 명함은 독립적으로 두 축의 최댓값에만 기여하기 때문이다.

## ⏱️ 시간복잡도

**O(n)**
- n: 명함 개수 (sizes 길이)
- 명함을 한 번씩만 순회하며 두 축의 최댓값을 갱신
