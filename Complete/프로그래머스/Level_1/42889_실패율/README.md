## 🤔 접근법

각 스테이지의 **실패율**을 구해 내림차순으로 정렬하는 구현 문제.

> **실패율** = (스테이지에 도달했으나 아직 클리어하지 못한 인원) / (스테이지에 도달한 인원)

`stages[i]`는 각 사용자가 **현재 멈춰있는 스테이지 번호**(1 ~ N+1, N+1은 전부 클리어)를 뜻한다.
스테이지 `i`에 **도달한 인원**은 곧 `i` 이상에 멈춰있는 모든 인원과 같다.

전체 인원에서 스테이지를 하나씩 지날 때마다 그 스테이지에 멈춘 인원을 빼 나가면,
**도달 인원을 누적으로 O(N)에 구할 수 있다** (매번 뒤쪽을 다시 세는 이중 반복 불필요).

**주의 규칙**:
- 실패율이 같으면 **스테이지 번호가 작은 순**으로 정렬
- 도달한 인원이 0명인 스테이지의 실패율은 **0**으로 처리

---

## 💡 정답 풀이 방법

**알고리즘**: 누적 카운팅 + 정렬

```
1. stop[i] = 스테이지 i에 멈춰있는 인원 집계
2. total = 전체 인원 (스테이지 1에 도달한 인원)
3. 스테이지 1 ~ N 순회:
   a. rate = (total > 0) ? stop[i] / total : 0
   b. {rate, i} 저장
   c. total -= stop[i]   // 다음 스테이지 도달 인원으로 갱신
4. 실패율 내림차순(같으면 번호 오름차순) 정렬 후 번호만 반환
```

## 🔑 핵심 개념

### 1️⃣ 도달 인원 = 뒤에서부터 누적

스테이지 `i`에 도달한 인원은 `i` 이상에 멈춰있는 모든 인원이다.
전체 인원에서 스테이지를 지날 때마다 그 자리에서 멈춘 인원을 빼면, 별도의 이중 반복 없이 도달 인원이 갱신된다.

```cpp
int total = stages.size(); // 스테이지 1 도달 인원 = 전체

for (int i = 1; i <= N; i++)
{
    double rate = (total > 0) ? (double)stop[i] / total : 0.0;
    rates.emplace_back(rate, i);

    total -= stop[i]; // 다음 스테이지 도달 인원
}
```

### 2️⃣ 도달 인원 0 → 실패율 0

도달한 사람이 없으면 분모가 0이 되어 나눗셈이 불가능하다.
이 경우 문제 정의대로 실패율을 `0`으로 둔다. (`total > 0` 분기로 처리)

### 3️⃣ pair 정렬로 두 기준 동시 처리

`{실패율, 스테이지 번호}` pair를 정렬하되, 실패율은 **내림차순**, 같으면 번호는 **오름차순**이 되도록 비교 함수를 직접 정의한다.

```cpp
bool Compare(const pdi& a, const pdi& b)
{
    if (a.first != b.first)
    {
        return a.first > b.first; // 실패율 높은 순
    }

    return a.second < b.second;   // 번호 작은 순
}
```

## ⏱️ 시간복잡도

**O(N log N)**
- N: 스테이지 개수
- 실패율 계산은 O(N), 정렬에 O(N log N)
