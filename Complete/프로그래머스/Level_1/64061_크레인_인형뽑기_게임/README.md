## 🤔 접근법

`N x N` 격자에 인형이 쌓여 있고, 크레인이 특정 **열(column)** 의 **맨 위 인형**을 하나 집어 바구니에 넣는다.
바구니에 **같은 인형이 연속으로 두 개** 쌓이면 두 개가 함께 터져 사라진다.
`moves` 를 모두 수행했을 때 **터져서 사라진 인형의 총 개수**를 구하는 문제.

```
board (0 = 빈 칸)          moves = [1, 5, 3, 5, 1, 2, 1, 4]
  0 0 0 0 0
  0 0 1 0 3      1번 열의 맨 위 = 4
  0 2 5 0 1      5번 열의 맨 위 = 3
  4 2 4 4 2      3번 열의 맨 위 = 1
  3 5 1 3 1
```

여기서 두 가지 동작이 모두 **"맨 위에서 꺼내고, 맨 위에 넣는다"** 이다.

- **격자의 각 열** → 위에서부터 뽑아 간다 → **스택**
- **바구니** → 맨 위와 비교하고, 같으면 맨 위를 뺀다 → **스택**

즉 `board` 를 2차원 배열 그대로 두고 매번 위에서부터 훑을 필요 없이, **열마다 스택 하나씩** 만들어두면
크레인 동작이 `pop_back()` 한 번으로 끝난다.

## 💡 정답 풀이 방법

**알고리즘**: 스택 (열 스택 + 바구니 스택)

```
1. 열마다 스택을 만든다
   - 각 열을 아래 행(i = n-1)부터 위로 올라가며 0이 아닌 값만 push
   - → back() 이 그 열의 "맨 위 인형"이 된다
2. moves 를 순서대로 처리
   a. col = move - 1  (moves 는 1번 열부터 시작)
   b. 그 열이 비어 있으면 스킵
   c. doll = columns[col].back() 뽑고 pop_back()
   d. 바구니가 비어있지 않고 basket.back() == doll 이면
      - basket.pop_back()  → 두 개가 함께 터짐
      - answer += 2
   e. 아니면 basket 에 push
3. answer 반환
```

## 🖥️ 열을 스택으로 만드는 방향 — 시각화

이 문제에서 **가장 실수하기 쉬운 지점**은 열 스택을 **어느 방향으로 쌓느냐**다.
크레인은 항상 **위쪽 인형부터** 집어가는데, `vector` 의 `back()` 은 **마지막에 넣은 것**을 돌려준다.
따라서 **아래 행부터 넣어야** `back()` 이 "맨 위 인형"이 된다.

```
3번 열 (board[i][2]) 을 스택으로 만들기

  board 의 3번 열        i = n-1 부터 위로 올라가며 push
  ┌─────┐
  │  0  │ i=0  (0 → 건너뜀)              columns[2]
  │  1  │ i=1  ─────── 마지막에 push ──▶ ┌───┐ ← back() = 1  (맨 위 인형) ✅
  │  5  │ i=2  ───────────────────────▶ │ 1 │
  │  4  │ i=3  ───────────────────────▶ │ 5 │
  │  1  │ i=4  ─── 가장 먼저 push ────▶ │ 4 │
  └─────┘                                │ 1 │ ← 맨 아래
                                         └───┘
```

| 쌓는 방향 | `back()` 이 가리키는 것 | 결과 |
|-----------|------------------------|------|
| 위(i=0) → 아래(i=n-1) | 격자의 **맨 아래** 인형 | ❌ 크레인이 바닥부터 집는 꼴 |
| 아래(i=n-1) → 위(i=0) | 격자의 **맨 위** 인형 | ✅ 정답 |

> **📝 핵심**: `vector` 를 스택으로 쓸 때 `back()` = 스택의 **맨 위**. 격자의 위쪽이 스택의 위쪽이 되도록 **아래에서부터** 채운다.

## 🔑 핵심 개념

### 1️⃣ 왜 스택 두 개인가

| 대상 | 동작 | 자료구조 |
|------|------|---------|
| 격자의 각 열 | 맨 위에서 뽑기 | `columns[j]` 스택 N개 |
| 바구니 | 맨 위와 비교 / 맨 위 빼기 | `basket` 스택 1개 |

두 동작 모두 **맨 위(LIFO)** 만 건드리므로 스택이 정확히 들어맞는다.
`board` 를 그대로 두고 매 `move` 마다 위에서부터 0이 아닌 칸을 찾아 내려가도 풀리지만, 그 경우 매번 열을 훑어야 한다.

### 2️⃣ 정답은 "터진 인형 수" — 1이 아니라 2를 더한다

터질 때 사라지는 인형은 **바구니에 있던 것 + 방금 넣은 것, 총 두 개**다.
`answer++` 로 세면 정답의 절반이 나오므로 `answer += 2` 가 맞다.

```cpp
if (!basket.empty() && basket.back() == doll)
{
    basket.pop_back();

    answer += 2; // 방금 뽑은 인형 + 바구니 맨 위 인형, 둘 다 사라짐
}
```

### 3️⃣ 빈 열 처리

`moves` 에 이미 다 비워진 열이 다시 나올 수 있다. 이때 `back()` 을 호출하면 정의되지 않은 동작이므로
**반드시 `empty()` 로 먼저 확인**하고 넘어가야 한다.

```cpp
if (columns[col].empty()) // 뽑을 인형이 없는 열은 스킵
{
    continue;
}
```

### 4️⃣ `moves` 는 1번 열부터

`moves` 의 값은 **1 ~ N** 범위의 열 번호다. 배열 인덱스로 쓰려면 `move - 1` 로 변환해야 한다.

## ⏱️ 시간복잡도

**O(N² + M)** — N은 격자 한 변의 길이, M은 `moves` 의 길이.

- 열 스택 만들기 : 격자 전체를 한 번 훑으므로 `O(N²)`
- 크레인 처리 : 각 `move` 마다 `pop_back` / `push` 상수 시간 → `O(M)`

제한이 `N ≤ 30`, `M ≤ 1,000` 이므로 여유롭게 통과한다.
