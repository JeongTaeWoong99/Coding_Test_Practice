## 🤔 접근법

전화 키패드를 두 엄지손가락으로 누를 때, **각 번호를 어느 손으로 눌렀는지**를 순서대로 반환하는 시뮬레이션 문제.

```
1 2 3
4 5 6
7 8 9
* 0 #
```

**핵심 규칙**:
- `1, 4, 7` (왼쪽 열) → **무조건 왼손**
- `3, 6, 9` (오른쪽 열) → **무조건 오른손**
- `2, 5, 8, 0` (가운데 열) → **현재 위치에서 더 가까운 손**, 거리가 같으면 **주로 쓰는 손**
- 왼손 시작 위치는 `*`, 오른손 시작 위치는 `#`

특별한 알고리즘은 필요 없다. **손의 현재 위치 두 개**만 들고 있으면서,
번호를 하나씩 처리하며 사용한 손의 위치를 갱신해주면 끝난다.

관건은 **키패드를 좌표로 바꾸는 것**과 **거리 계산 방식**이다.

---

## 💡 정답 풀이 방법

**알고리즘**: 시뮬레이션 + 좌표 매핑 테이블 (맨해튼 거리)

```
1. 번호 0~9 의 {행, 열} 좌표를 미리 배열로 만들어 둔다
2. 왼손 = (3, 0) [*], 오른손 = (3, 2) [#] 로 초기화
3. numbers 를 순회하며:
   a. keyPos[num] 으로 누를 번호의 좌표를 꺼낸다
   b. 1/4/7 이면 'L', 3/6/9 면 'R'
   c. 그 외(2/5/8/0)는 두 손의 맨해튼 거리를 비교
      - 더 가까운 손 선택, 같으면 hand 값에 따라 선택
   d. 선택한 손의 위치를 누른 번호의 좌표로 갱신
   e. answer 에 'L' / 'R' 추가
4. answer 반환
```

## 🔑 핵심 개념

### 1️⃣ 숫자 → 좌표는 매핑 테이블로

`(num - 1) / 3`, `(num - 1) % 3` 같은 공식으로도 구할 수 있지만,
**`0` 하나가 그 규칙에서 벗어나기 때문에** 결국 예외 분기가 붙는다.

번호는 0~9로 **딱 10개뿐**이므로, 아예 좌표를 미리 적어두고 꺼내 쓰는 편이 단순하고 실수도 없다.

```cpp
// 키패드 번호별 {행, 열} 좌표 — 공식으로 계산하지 않고 미리 표로 만들어 둠
pair<int, int> keyPos[10] =
{
    { 3, 1 }, // 0
    { 0, 0 }, // 1
    { 0, 1 }, // 2
    { 0, 2 }, // 3
    { 1, 0 }, // 4
    { 1, 1 }, // 5
    { 1, 2 }, // 6
    { 2, 0 }, // 7
    { 2, 1 }, // 8
    { 2, 2 }  // 9
};
```

사용할 땐 인덱싱 한 번이면 끝난다.

```cpp
pair<int, int> target = keyPos[num];
```

| 구분 | 공식 계산 | 매핑 테이블 |
|------|----------|-----------|
| 0 처리 | `if (num == 0)` 예외 분기 필요 | 표의 0번 칸에 그냥 적어둠 |
| 가독성 | 공식이 맞는지 머리로 검산해야 함 | 키패드 모양이 코드에 그대로 보임 |
| 확장성 | 배치가 바뀌면 공식을 다시 세워야 함 | 값만 고치면 됨 |

> 💡 값의 개수가 적고 고정되어 있으면, **계산보다 표가 낫다.**

### 2️⃣ 거리는 맨해튼 거리

키패드는 **상하좌우로만** 이동하므로 대각선 이동이 없다. 따라서 두 좌표의 거리는 행 차이 + 열 차이.

```cpp
int GetDist(pair<int, int> a, pair<int, int> b)
{
    return abs(a.first - b.first) + abs(a.second - b.second);
}
```

> ⚠️ 유클리드 거리(`sqrt`)를 쓰면 대각선을 허용하는 셈이라 **틀린 답**이 나온다.
> 예를 들어 `*`(3,0) → `2`(0,1) 은 실제로 4번 움직여야 하지만, 유클리드로는 약 3.16이다.

### 3️⃣ 손 위치는 "누른 번호"로만 갱신

`1, 4, 7` 처럼 강제로 정해진 번호를 눌렀을 때도 **그 손의 위치는 반드시 갱신**해야 한다.
왼쪽 열을 누른 뒤 왼손이 그 자리에 남아 있어야, 다음 가운데 열 번호의 거리 비교가 맞아떨어진다.

```cpp
if (useHand == 'L')
{
    leftPos = target;
}
else
{
    rightPos = target;
}
```

### 4️⃣ 거리가 같을 때의 tie-break

문제에서 "**두 엄지손가락의 거리가 같다면 오른손잡이는 오른손, 왼손잡이는 왼손**" 이라고 명시한다.
`hand` 문자열을 그대로 비교하면 된다.

```cpp
useHand = (hand == "left") ? 'L' : 'R';
```

## 📊 테스트 케이스

| numbers | hand | 출력 | 포인트 |
|---------|------|------|--------|
| `[1,3,4,5,8,2,1,4,5,9,5]` | `right` | `LRLLLRLLRRL` | 거리 동점 시 오른손 |
| `[7,0,8,2,8,3,1,5,7,6,2]` | `left`  | `LRLLRRLLLRR` | 거리 동점 시 왼손 |
| `[1,2,3,4,5,6,7,8,9,0]`   | `right` | `LLRLLRLLRL`  | 0의 좌표 확인 |

## ⏱️ 시간복잡도

**O(N)** — N: numbers 크기 (최대 1,000)

번호 하나당 좌표 조회와 거리 계산이 모두 상수 시간이므로 선형.
