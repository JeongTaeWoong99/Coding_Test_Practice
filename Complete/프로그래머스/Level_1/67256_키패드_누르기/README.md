## 🤔 접근법

전화 키패드를 두 엄지손가락으로 누를 때, **각 번호를 어느 손으로 눌렀는지**를 순서대로 반환하는 시뮬레이션 문제.

```
1 2 3
4 5 6
7 8 9
* 0 #
```

**핵심 규칙**:
- `1, 4, 7` (왼쪽 열) → **무조건 왼손**
- `3, 6, 9` (오른쪽 열) → **무조건 오른손**
- `2, 5, 8, 0` (가운데 열) → **현재 위치에서 더 가까운 손**, 거리가 같으면 **주로 쓰는 손**
- 왼손 시작 위치는 `*`, 오른손 시작 위치는 `#`

특별한 알고리즘은 필요 없다. **손의 현재 위치 두 개**만 들고 있으면서,
번호를 하나씩 처리하며 사용한 손의 위치를 갱신해주면 끝난다.

관건은 **키패드를 좌표로 바꾸는 것**과 **거리 계산 방식**이다.

---

## 💡 정답 풀이 방법

**알고리즘**: 시뮬레이션 + 좌표 변환 (맨해튼 거리)

```
1. 왼손 = (3, 0) [*], 오른손 = (3, 2) [#] 로 초기화
2. numbers 를 순회하며:
   a. 누를 번호의 좌표를 구한다
   b. 1/4/7 이면 'L', 3/6/9 면 'R'
   c. 그 외(2/5/8/0)는 두 손의 맨해튼 거리를 비교
      - 더 가까운 손 선택, 같으면 hand 값에 따라 선택
   d. 선택한 손의 위치를 누른 번호의 좌표로 갱신
   e. answer 에 'L' / 'R' 추가
3. answer 반환
```

## 🔑 핵심 개념

### 1️⃣ 숫자 → 좌표 변환 공식

`1 ~ 9` 는 3열짜리 격자에 순서대로 배치되어 있으므로, **1을 빼서 0부터 시작하게 만든 뒤** 몫과 나머지로 행/열을 구한다.

```cpp
pii GetPos(int num)
{
    if (num == 0)
    {
        return { 3, 1 }; // 0만 예외 — * 0 # 줄의 가운데
    }

    return { (num - 1) / 3, (num - 1) % 3 };
}
```

| 번호 | `(num-1)/3` (행) | `(num-1)%3` (열) |
|------|------------------|------------------|
| 1    | 0                | 0                |
| 5    | 1                | 1                |
| 9    | 2                | 2                |
| 0    | 3 (예외 처리)     | 1 (예외 처리)     |

> 💡 `0` 은 숫자 순서상 9 다음이 아니라 **맨 아랫줄 가운데**에 있으므로 공식에 들어맞지 않는다. 유일한 예외.

### 2️⃣ 거리는 맨해튼 거리

키패드는 **상하좌우로만** 이동하므로 대각선 이동이 없다. 따라서 두 좌표의 거리는 행 차이 + 열 차이.

```cpp
int GetDist(pii a, pii b)
{
    return abs(a.first - b.first) + abs(a.second - b.second);
}
```

> ⚠️ 유클리드 거리(`sqrt`)를 쓰면 대각선을 허용하는 셈이라 **틀린 답**이 나온다.
> 예를 들어 `*`(3,0) → `2`(0,1) 은 실제로 4번 움직여야 하지만, 유클리드로는 약 3.16이다.

### 3️⃣ 손 위치는 "누른 번호"로만 갱신

`1, 4, 7` 처럼 강제로 정해진 번호를 눌렀을 때도 **그 손의 위치는 반드시 갱신**해야 한다.
왼쪽 열을 누른 뒤 왼손이 그 자리에 남아 있어야, 다음 가운데 열 번호의 거리 비교가 맞아떨어진다.

```cpp
if (useHand == 'L')
{
    leftPos = target;
}
else
{
    rightPos = target;
}
```

### 4️⃣ 거리가 같을 때의 tie-break

문제에서 "**두 엄지손가락의 거리가 같다면 오른손잡이는 오른손, 왼손잡이는 왼손**" 이라고 명시한다.
`hand` 문자열을 그대로 비교하면 된다.

```cpp
useHand = (hand == "left") ? 'L' : 'R';
```

## 📊 테스트 케이스

| numbers | hand | 출력 | 포인트 |
|---------|------|------|--------|
| `[1,3,4,5,8,2,1,4,5,9,5]` | `right` | `LRLLLRLLRRL` | 거리 동점 시 오른손 |
| `[7,0,8,2,8,3,1,5,7,6,2]` | `left`  | `LRLLRRLLLRR` | 거리 동점 시 왼손 |
| `[1,2,3,4,5,6,7,8,9,0]`   | `right` | `LLRLLRLLRL`  | 0의 좌표 예외 처리 확인 |

## ⏱️ 시간복잡도

**O(N)** — N: numbers 크기 (최대 1,000)

번호 하나당 좌표 변환과 거리 계산이 모두 상수 시간이므로 선형.
