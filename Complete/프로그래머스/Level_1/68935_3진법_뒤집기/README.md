## 🤔 접근법

자연수 `n`을 3진법으로 바꾸고, 그 자릿수를 **앞뒤로 뒤집은 뒤** 다시 10진수로 변환하는 문제.

```
45 → 3진법 1200 → 뒤집기 0021 → 10진수 7
```

떠올릴 수 있는 방법은 두 가지다.

- **방식 1** : 3진법 자릿수를 문자열/배열에 모아 뒤집고, 다시 10진수로 계산 (문제 설명 그대로 구현)
- **방식 2** : 나머지를 꺼내는 순서 자체가 이미 "뒤집힌 순서"라는 점을 이용해, **한 번의 while문으로 바로 계산**

`n % 3`으로 꺼내지는 값은 3진수의 **가장 낮은 자리부터**다. 그런데 뒤집은 수에서는 그 값이 **가장 높은 자리**에 온다.
따라서 꺼낼 때마다 기존 결과에 3을 곱해 자리를 한 칸 올리고 새 값을 붙이면, 뒤집기 과정 없이 결과가 완성된다.

---

## 💡 정답 풀이 방법

**알고리즘**: 진법 변환 (호너의 방법으로 뒤집기 동시 처리)

```
1. answer = 0
2. n이 0이 될 때까지 반복
   2-1. answer = answer * 3 + (n % 3)   ← 기존 결과를 한 자리 올리고 새 자릿수 붙이기
   2-2. n /= 3
3. answer 반환
```

```cpp
int answer = 0;

while (n > 0)
{
    answer = answer * 3 + (n % 3);
    n /= 3;
}

return answer;
```

## 🔑 핵심 개념

### 1️⃣ 나머지를 꺼내는 순서 = 이미 뒤집힌 순서

3진법 변환은 낮은 자리부터 나오는데, 뒤집은 수는 그 낮은 자리가 맨 앞으로 간다.
즉 **꺼낸 순서대로 앞에서부터 쌓으면** 그게 곧 뒤집은 결과다.

```
n = 45
45 % 3 = 0 → answer = 0        (3진수 1200의 1의 자리)
15 % 3 = 0 → answer = 0
 5 % 3 = 2 → answer = 2
 1 % 3 = 1 → answer = 2*3+1 = 7
```

### 2️⃣ `answer * 3 + 자릿수` (호너의 방법)

10진수를 만들 때 `answer`에 3을 곱하는 것은 **기존 자릿수를 전부 한 칸 위로 밀어올리는** 동작이다.
그 빈 1의 자리에 새로 꺼낸 값을 넣으면 배열이나 문자열 없이 변환이 끝난다.

### 3️⃣ 앞자리 0은 자동으로 사라진다

`1200`을 뒤집으면 `0021`이 되지만, 10진수로 계산하면 앞의 0은 값에 영향을 주지 않아
별도의 예외 처리 없이 자연스럽게 `7`이 된다.

## ⚖️ 두 방식 비교

| 구분 | 방식 1 (문자열 뒤집기) | 방식 2 (while 한 번) |
|------|--------------------|-------------------|
| 추가 메모리 | 자릿수 저장용 문자열/배열 필요 | 없음 |
| 코드 길이 | 변환 → reverse → 재계산 (3단계) | while 한 줄 |
| 장점 | 문제 설명 그대로라 이해가 쉬움 | 짧고 실수 여지가 적음 |
| 단점 | 문자 ↔ 숫자 변환 실수 가능 | 왜 뒤집히는지 한 번은 이해해야 함 |

`n`이 최대 100,000,000이라 3진법 자릿수가 20자리 정도밖에 안 되므로 두 방식 모두 성능 차이는 없다.
다만 방식 2가 훨씬 짧아 실전에서 유리하다.

## ⏱️ 시간복잡도

**O(log₃ n)** — n을 3으로 나누는 횟수만큼 반복 (최대 20회 수준)
