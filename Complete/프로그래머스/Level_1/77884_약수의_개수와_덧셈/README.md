## 🤔 접근법

`left ~ right` 구간의 각 정수에 대해 **약수의 개수가 짝수면 더하고, 홀수면 빼서** 최종 합을 구하는 문제.

각 수마다 약수의 개수만 알면 되므로, 두 가지 방식으로 접근할 수 있다.

- **방식 1** : 1부터 그 수까지 나눠보며 약수 개수를 직접 센다.
- **방식 2** : 약수 개수가 홀수인 수는 **완전제곱수뿐**이라는 성질을 이용해 `sqrt`로 바로 판별한다.

---

## 💡 정답 풀이 방법

**알고리즘**: 약수 개수 판별 (직접 카운트 / 완전제곱수 판별)

```
1. left ~ right 구간을 순회
2. 각 수 curN의 약수 개수가 짝수인지 홀수인지 판별
3. 짝수 → answer += curN,  홀수 → answer -= curN
4. answer 반환
```

---

## 🔑 핵심 개념

### 1️⃣ 약수 개수가 홀수인 수 = 완전제곱수

약수는 보통 `d`와 `curN / d`가 **쌍으로** 존재하므로 개수가 짝수다.
하지만 완전제곱수(예: 16 = 4×4)는 `4`처럼 자기 자신과 짝을 이루는 약수가 있어
그 하나만 짝 없이 남아 **개수가 홀수**가 된다.

```
6  → 1,2,3,6        (4개, 짝수) → 더하기
16 → 1,2,4,8,16     (5개, 홀수) → 빼기   ← 4가 짝 없이 남음
```

### 2️⃣ 방식 1 — 약수 개수 직접 카운트

```cpp
int curCnt = 0;

for (int checkN = 1; checkN <= curN; ++checkN)
{
    if (curN % checkN == 0)
    {
        ++curCnt;
    }
}

if (curCnt % 2 == 0) answer += curN;
else                 answer -= curN;
```

수 하나마다 1 ~ curN까지 모두 나눠보므로 이해하기 쉽고 직관적이다.

### 3️⃣ 방식 2 — sqrt로 완전제곱수 판별

```cpp
int rootN = (int)sqrt((double)curN); // 제곱근의 정수부

if (rootN * rootN == curN) answer -= curN; // 완전제곱수 → 홀수 → 빼기
else                       answer += curN; // 그 외      → 짝수 → 더하기
```

약수를 세지 않고, **제곱근을 정수로 만든 뒤 다시 제곱해 원래 수와 같은지**만 확인한다.
같으면 완전제곱수(약수 개수 홀수)이므로 뺀다.

> ⚠️ 부동소수 오차 주의 — `sqrt` 결과를 정수로 내림한 뒤 `rootN * rootN == curN`으로 재검증해야 안전하다.

## ⚖️ 두 방식 비교

| 구분 | 방식 1 (직접 카운트) | 방식 2 (sqrt 판별) |
|------|------------------|-----------------|
| 시간복잡도 | O(N·M) | O(N) |
| N | 구간 길이 (right - left + 1) | 구간 길이 |
| M | 각 수의 크기 (약수 탐색 비용) | — |
| 장점 | 직관적, 성질을 몰라도 풀림 | 훨씬 빠름, 코드 간결 |
| 단점 | 수가 커지면 느려짐 | 완전제곱수 성질 + 부동소수 오차 주의 필요 |

**이 문제에서는 방식 1로도 충분하다.**
제약이 `1 ≤ left ≤ right ≤ 1,000`으로 매우 작아, 최악의 경우에도 대략
`1000 × 1000 = 10^6` 번의 연산이면 끝난다. 시간 제한 안에 넉넉히 들어오므로
굳이 sqrt 최적화를 하지 않아도 되고, 오히려 방식 1이 성질을 몰라도 바로 떠올릴 수 있어
실전에서 더 안전한 선택이다. 방식 2는 구간이 훨씬 커질 때 의미가 있다.

---

## ⏱️ 시간복잡도

- **방식 1**: O(N·M) — N: 구간 길이, M: 각 수의 크기 (여기선 최대 10^6 수준)
- **방식 2**: O(N) — 각 수를 sqrt 한 번으로 판별
