## 🤔 접근법

0부터 9까지의 숫자 중 `numbers`에 담기지 않은 숫자들의 합을 구하는 문제.

0~9까지의 전체 합은 항상 **45**로 고정이다.
따라서 `numbers`에 들어있는(있는) 숫자들을 45에서 빼주면, 남는 값이 곧 **없는 숫자들의 합**이 된다.

굳이 어떤 숫자가 빠졌는지 일일이 찾을 필요 없이, 전체 합에서 존재하는 값만 제거하면 된다.

---

## 💡 정답 풀이 방법

**알고리즘**: 수학 (전체 합 - 존재하는 값)

```
1. answer = 45 (0~9의 합)
2. numbers 순회하며 각 원소를 answer에서 뺀다
3. answer 반환 → 없는 숫자들의 합
```

```cpp
int answer = 45;
for (int n : numbers)
    answer -= n;
return answer;
```

---

## 🔑 핵심 개념

### 1️⃣ 0~9의 합은 45로 고정

없는 숫자를 직접 찾지 않고, **전체 합에서 있는 값을 빼는** 여집합 관점으로 접근하면 로직이 단순해진다.

### 2️⃣ 별도 자료구조 불필요

방문 체크용 배열이나 집합 없이 단순 누적 뺄셈만으로 해결된다.

## ⏱️ 시간복잡도

**O(n)** — n: numbers 크기 (최대 9개)
