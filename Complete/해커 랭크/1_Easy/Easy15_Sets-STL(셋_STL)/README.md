## 🤔 접근법

Q개의 쿼리를 처리하는 문제. 각 쿼리는 타입 1(삽입), 2(삭제), 3(조회) 중 하나이며, set의 기본 연산을 그대로 활용해 해결한다.

`set::insert`, `set::erase`, `set::find` 세 함수만으로 직접 구현 가능하며, `erase`는 존재하지 않는 원소에 대해 아무것도 하지 않으므로 별도 예외 처리가 불필요하다.

---

## 💡 정답 풀이 방법

**알고리즘** : STL `set` 기본 연산 활용

**핵심 아이디어**:
```
1. 쿼리 타입 1 → s.insert(x)
2. 쿼리 타입 2 → s.erase(x) (없으면 자동 무시)
3. 쿼리 타입 3 → s.find(x) != s.end() 이면 "Yes", 아니면 "No"
```

---

## 🔑 핵심 포인트

### 1️⃣ set::find로 원소 존재 여부 확인

```cpp
if (s.find(x) != s.end())
{
    cout << "Yes\n";
}
else
{
    cout << "No\n";
}
```

**✅ 핵심**: `find`가 `s.end()`를 반환하면 원소가 없음을 의미한다.
- `find(x) != s.end()` → 존재 → `"Yes"`
- `find(x) == s.end()` → 부재 → `"No"`

### 2️⃣ set::erase의 안전한 삭제

```cpp
s.erase(x); // 없으면 아무것도 안 함
```

**✅ 핵심**: `erase(값)`은 원소가 없으면 아무 동작도 하지 않으므로, 별도의 존재 여부 확인 없이 바로 호출해도 안전하다.

### 3️⃣ set의 특성

```
- 중복 원소 자동 제거
- 삽입 시 자동 오름차순 정렬
- insert / erase / find 모두 O(log N)
```

---

## ⏱️ 시간복잡도

**O(Q log N)**

**상세 분석**:
```
1. 쿼리 Q번 × 각 연산(insert/erase/find) → O(log N)
총합: O(Q log N)
```

**시간 제한 체크**:
- Q ≤ 10^5 기준 → 최악 약 10^5 × 17 ≈ 1.7 × 10^6 연산 → 여유롭게 통과 ✅

---

## 💾 공간복잡도

**O(N)**

**분석**:
- `s` : 삽입된 원소 수 N개 → O(N)
- `q` : O(1) (전역 변수)
- 총 공간: O(N)
