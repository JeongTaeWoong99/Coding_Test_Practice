## 🤔 접근법

T개의 테스트 케이스마다 실수 A, B, C를 각각 다른 형식으로 3줄 출력하는 문제.

- A : 소수점 버리고(truncate) 16진수로 출력 (`0x` prefix, 소문자)
- B : 소수 2자리 + 부호(`+/-`) + 전체 15자 너비 + 빈 자리는 `_` 패딩 (우측 정렬)
- C : 과학적 표기법, 소수 9자리, 대문자 E

`<iomanip>` 출력 조작자를 조합하는 것이 핵심이며, **조작자는 한 번 설정하면 이후 출력에도 계속 유지**되므로 각 출력마다 필요한 조작자를 명시적으로 재설정해야 한다.

---

## 💡 정답 풀이 방법

**알고리즘** : `<iomanip>` 출력 조작자 조합

**핵심 아이디어**:
```
1. A : hex + showbase + nouppercase + (long long) 캐스팅
2. B : dec 복원 + setw(15) + setfill('_') + showpos + fixed + setprecision(2)
3. C : noshowpos + uppercase + scientific + setprecision(9)
```

---

## 🔑 핵심 포인트

### 1️⃣ A 출력 — 16진수 조작자

| 조작자 | 역할 | 없으면? |
|--------|------|---------|
| `hex` | 출력 진법을 16진수로 변경 | `100` 그대로 출력 |
| `showbase` | `0x` prefix 자동 추가 | `64` (prefix 없음) |
| `nouppercase` | 소문자 유지 (0x, a~f) | `0X64` 대문자로 출력 |
| `(long long)` | double → 정수 캐스팅 | `hex`는 정수형에만 동작하므로 필수 |

```cpp
cout << hex << showbase << nouppercase << (long long)A << "\n";
// 100.345 → (long long)100 → 0x64
```

### 2️⃣ B 출력 — 너비/패딩/부호 조작자

| 조작자 | 역할 | 없으면? |
|--------|------|---------|
| `dec` | 16진수 → 10진수로 **복원** | B, C도 16진수로 출력됨 |
| `setw(15)` | 다음 출력의 최소 너비를 15로 지정 | 패딩 없이 그냥 출력 |
| `setfill('_')` | 빈 자리를 `_`로 채움 | 빈 자리가 공백으로 채워짐 |
| `showpos` | 양수에 `+`, 음수에 `-` 부호 추가 | `2006.01` (부호 없음) |
| `fixed` | 소수점 고정 표기 | 과학적 표기법으로 나올 수 있음 |
| `setprecision(2)` | 소수점 이하 2자리 고정 | 유효숫자 2자리로 변함 |

```cpp
// 2006.008 → "+2006.01" (8자) → "_______+2006.01" (15자)
cout << dec << setw(15) << setfill('_') << showpos << fixed << setprecision(2) << B << "\n";
```

### 3️⃣ C 출력 — 과학적 표기법 조작자

| 조작자 | 역할 | 없으면? |
|--------|------|---------|
| `noshowpos` | `+` 부호 **제거** | `+2.331...E+03` 출력 |
| `uppercase` | `E`, `0X` 등을 대문자로 출력 | `2.331415927e+03` 소문자 |
| `scientific` | 과학적 표기법 적용 | `2331.415927000` 출력 |
| `setprecision(9)` | 소수점 이하 9자리 고정 | B에서 설정한 2자리가 유지됨 |

```cpp
// 2331.41592653498 → 2.331415927E+03
cout << noshowpos << uppercase << scientific << setprecision(9) << C << "\n";
```

### 4️⃣ 조작자 유지 주의사항

```
⚠️ 조작자는 한 번 설정하면 이후 출력에도 계속 유지됨!

A에서 hex 켬     → B에서 반드시 dec 로 복원
B에서 showpos 켬 → C에서 반드시 noshowpos 로 해제

예외 : setw(N) 만 유일하게 딱 한 번 적용 후 자동 초기화됨
```

```

```
