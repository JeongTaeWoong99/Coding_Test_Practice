## 📖 개요

알고리즘 문제(백준/해커 랭크/프로그래머스 등등)를 C++로 해결하고 정리하는 개인 학습 저장소입니다.

최적화 및 학습 내용 정리에는 Claude Code를 활용하고 있습니다.

클로드 사용 규칙은 [CLAUDE.MD](./CLAUDE.md) 파일을 참고.

## 📚 학습 방법

```
1️⃣ 알고리즘 문제 풀기 선행
    ↓
2️⃣ 정답 코드와 내 코드 비교 및 최적화
    ↓
3️⃣ 코드 분석
    ↓
4️⃣ Complete 폴더에 정리
    ├── Answer.cpp.txt (최종 코드)
    └── README.md (풀이 및 학습 내용)
```

## 📂 프로젝트 구조

Complete 폴더는 문제 풀이를 완료하고 학습 내용을 정리한 폴더입니다.

```
Complete/
│
├── 📂 백준
│   ├── 📂 1_Bronze
│   ├── 📂 2_Silver
│   ├── 📂 3_Gold
│   └── 📂 4_Platinum
└── 📂 해커 랭크
    ├── 📂 1_Easy
    ├── 📂 2_Medium
    └── 📂 3_Hard
```
