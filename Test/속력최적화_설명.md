## 📊 질문 1: 왜 모듈러 연산을 해야 시간초과가 안 나는가?

### ⏱️ 시간 초과가 발생하는 이유

**문제 조건:**
- 격자판 크기: R, C ≤ 100
- 상어 속력: s ≤ 1000
- 상어 수: M ≤ R×C (최대 10,000마리)

**시뮬레이션 과정:**
```cpp
// 모듈러 연산 없이 그냥 이동하면?
while (true)
{
    ny = y + s * dy[d];
    nx = x + s * dx[d];

    if (범위 내) break;

    // 경계 도달 → 방향 반전 → 다시 이동
    // 이 과정을 속력이 0이 될 때까지 반복!
}
```

**최악의 경우 계산:**
- R = 4, 상어 속력 s = 1000
- 경계를 넘을 때마다 while 루프 1회 반복
- 한 칸씩 이동하면서 방향을 바꾸면 → **1000번 반복!**
- 상어 10,000마리 × 1000번 × C번 시뮬레이션 = **매우 느림**

## 🔄 왕복 주기를 이용한 최적화

### 핵심 아이디어: 상어는 왕복 운동을 한다!

**예시 1: R=4 (행이 4개), 상하 이동 상어**

```
격자판 (y좌표):
┌─────┐
│  0  │ ← 위쪽 경계
├─────┤
│  1  │
├─────┤
│  2  │
├─────┤
│  3  │ ← 아래쪽 경계
└─────┘
```

**상어가 y=0에서 아래로 이동 시작:**

| 속력 | 위치 | 방향 | 설명 |
|-----|------|------|------|
| 0 | y=0 | 하 | 시작 |
| 1 | y=1 | 하 | |
| 2 | y=2 | 하 | |
| 3 | y=3 | 하 | 아래 경계 도달 |
| 4 | y=2 | 상 | 방향 반전! |
| 5 | y=1 | 상 | |
| 6 | y=0 | 상 | 위쪽 경계 도달 |
| 7 | y=1 | 하 | 방향 반전! **→ 속력 1과 같은 상태!** |
| 8 | y=2 | 하 | 속력 2와 같음 |

**🎯 핵심 발견:**
- 한 왕복 = 2 × (R - 1) = 2 × 3 = 6칸
- 속력 6 이동 = 원래 위치 + 원래 방향
- 속력 7 = 속력 1과 동일한 결과
- 속력 1000 = 속력 (1000 % 6) = 속력 4와 동일!

<br>

### 수학적 증명

**왕복 주기:**
```
상하 이동: 한 왕복 = 2 × (R - 1) 칸
좌우 이동: 한 왕복 = 2 × (C - 1) 칸
```

**이유:**
- 0 → (R-1) → 0 까지 이동하면 2×(R-1) 칸
- 이 주기마다 같은 위치, 같은 방향으로 돌아옴

**코드로 표현:**
```cpp
// 속력 1000을 왕복 주기로 나눈 나머지만 계산하면 됨
if(a[i].dir <= 1)  // 상하 이동
    a[i].speed %= (2 * (R - 1));
else              // 좌우 이동
    a[i].speed %= (2 * (C - 1));
```

## 📈 성능 비교

### ❌ 최적화 전

```cpp
// 속력 = 1000, R = 4
int s = 1000;
int count = 0;

while (true)
{
    count++;  // while 반복 횟수
    ny = y + s * dy[d];

    if (범위 내) break;

    // 경계 처리...
    d ^= 1;
}
// count ≈ 166회 반복! (1000 / 6)
```

### ✅ 최적화 후

```cpp
// 속력을 왕복 주기로 나눈 나머지로 변경
int s = 1000 % (2 * (4 - 1));  // s = 1000 % 6 = 4

while (true)
{
    count++;
    ny = y + s * dy[d];

    if (범위 내) break;

    // 경계 처리...
    d ^= 1;
}
// count ≈ 1~2회 반복!
```

**시간 복잡도 비교:**
- 최적화 전: O(M × C × s) = O(10,000 × 100 × 1000) = **10억 연산** → 시간 초과!
- 최적화 후: O(M × C × (R+C)) = O(10,000 × 100 × 200) = **2억 연산** → 통과!

## 💡 직관적 이해

**비유:**
원형 트랙을 달리는 선수를 생각해보세요.

- 트랙 한 바퀴 = 400m
- 선수가 10,000m를 달린다면?
- 실제로 어디에 있을까?
  - 10,000 ÷ 400 = 25바퀴 → 출발점으로 돌아옴
  - 10,000 % 400 = 0 → 출발 위치

**상어도 마찬가지:**
- 격자판에서 왕복 운동
- 1000칸 이동 = (1000 / 6)바퀴 왕복 + 4칸 추가 이동
- 왕복은 무시하고 4칸만 계산하면 됨!

## 🎯 정리

| 항목 | 내용 |
|-----|------|
| **문제점** | 속력이 크면 while 루프 너무 많이 반복 |
| **핵심** | 왕복 주기마다 원래 위치로 돌아옴 |
| **해결책** | 속력을 왕복 주기로 나눈 나머지만 계산 |
| **효과** | while 루프 최대 R+C번만 반복 (매우 적음!) |
| **결과** | 시간 초과 방지 ✅ |

**핵심 코드:**
```cpp
// 이 한 줄로 시간 복잡도가 O(s)에서 O(R) 또는 O(C)로 감소!
if(a[i].dir <= 1) a[i].speed %= (2 * (R - 1));
else              a[i].speed %= (2 * (C - 1));
```
